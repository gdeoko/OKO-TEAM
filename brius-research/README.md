# Brius Research — 2026-07-29

Собрано для Даниэля по запросу «пройди по всем чатам ХЛБ через мой аккаунт ktodaniel + собери всё про Артёма Бриуса».

## Файлы
- `BRIUS_KB.md` — итоговая база знаний (13 разделов + приложения).
- `chats/*.json` — сырые JSON выгрузки 22 каналов/чатов папки «🍞 ХЛБ 🍞» и «briusMENTOR» с описанием, закрепом и последними 200–300 сообщениями. Взято через живую Telegram-сессию acc1 (=@ktodaniel, user_id 1966985736) на OKO VPS без нарушения работы основного userbot.
- `chats_txt/*.txt` — читабельные срезы по каналам (только текстовые посты, 30–60 последних).
- `mht_sites/*.txt` — распакованный текст 5 приложенных .mht лендингов Бриуса.

## Как собрано
- Kurigram in-memory client с session_string, экспортированной из read-only копии `acc1.session` (не мешая живому userbot).
- Диалог-фильтр `messages.GetDialogFilters` → находим папку id=3 (🍞 ХЛБ 🍞) и id=7 (briusMENTOR).
- Перебор pinned + include peers → `get_chat` + `get_chat_history(limit=200..300)`.
- Всё сохранено в `/tmp/brius_kb/` на VPS, скачано в scratchpad кусками, положено в репо.
- Инет-ресёрч через WebFetch/WebSearch: vc.ru, 78.ru, kompromat1, m24, 5-tv, News92, proverj, teletype, 100biografiy, biogr.net, hypestar, affcatalog, youtube, tiktok.
