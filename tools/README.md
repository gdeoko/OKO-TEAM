# Мосты в инфраструктуру OKO

Из облачной сессии Claude нет прямого SSH: наружу ходит только HTTPS через
прокси, а сайты в зоне .рф вообще недоступны. Поэтому всё делается через
HTTP-мост на хосте `104.171.132.45` — там же живёт Chrome с сессиями.

| Скрипт | Что делает |
|---|---|
| `tools/pexec.sh <файл.sh>` | выполнить bash **на хосте моста** (там Chrome, playwright, доступ в рунет) |
| `tools/rx.sh <файл.sh>` | выполнить bash **на проде сайта** `музыкальный-мир.рф` (через мост по SSH) |
| `tools/pget.sh <удалённый> <локальный>` | забрать файл с моста кусками (скриншот, PDF, дамп) |

Ключи (`OKO_POSTER_URL`, `OKO_POSTER_TOKEN` и остальные) приезжают
SessionStart-хуком из `secrets.env.b64`, руками ничего подставлять не нужно.

Мост режет stdout примерно на 120 000 байт и убивает команду через 300 секунд —
длинные выгрузки забирать через `pget.sh`, а не печатать в вывод.

Живой браузер с уже выполненным входом в Яндекс 360:
`bash tools/pexec.sh <(echo '/opt/oko-poster/yandex.sh "https://admin.yandex.ru/"')`
Скриншот страницы остаётся в `/opt/oko-poster/browser/ya.jpg`.
