# Rocket — r6: материалы, совместимость графики и орбита VPN

Статус: кандидат подготовлен; публикация фиксируется после серверной проверки.

## Исправления

- Переходник VPN теперь реализует `RC_REAL.upgradeTree`. В собранной проверочной кабине 47 мешей, остававшихся на Phong из-за отсутствующего метода, используют Standard. Общие материалы переиспользуются; старые освобождаются один раз. Стекло сохраняет прозрачность, карты рельефа сохраняются, светящиеся Basic-экраны не меняются.
- WebGL 2 больше не считается достаточным условием для рендера в RGBA16F. VPN и CDN проверяют расширение цветового буфера. При его отсутствии эффекты используют UnsignedByte, а генерация PMREM не запускается. Это исправляет неподдерживаемые графические операции; HDR-режим поддерживающих устройств сохранён.
- Панель обоих сайтов принимает `RC_REAL.env` только как Texture. В CDN это также имя функции создания окружения; функция больше не назначается материалу вместо текстуры.
- За окном VPN вместо нарисованного диска с условными материками находится сфера с существующей географической текстурой 2048×1024, освещением сцены и тонкой атмосферой. Фоновая плоскость покрывает вид из рубки. Текстура уже используется лунной сценой, новых внешних источников данных нет.
- Дальний космос исключён из выборки поверхностей для сборки кабины частицами. Ранее большая фоновая плоскость также попадала в эту выборку.

## Проверки

45 проверок JavaScript и геометрии проходят. Добавлены сценарии сохранения общих материалов, стекла и рельефа; выбора типа буфера на WebGL 1/2 с расширением и без; исключения дальней сцены из сборки.

`review/native-scene.cjs` запускает настоящий Three r160, модули кабины и финала в Node с `gl@8.1.6` и `@napi-rs/canvas@0.1.80`. Это нативный WebGL 1 рендер, не браузер. Снимки ниже не содержат HTML-вопросов, кнопок, полного мира и браузерного управления прокруткой. Камера взята из конечной дистанции модуля; промежуточный кадр использует ту же точку наблюдения.

| Проверка | Файл | Результат |
|---|---|---|
| Финал 1280×800 | `review/native-frames/r6/finale-1280x800-1.png` | Непустой кадр, ошибки GL отсутствуют |
| Финал 390×844 | `review/native-frames/r6/finale-390x844-1.png` | Непустой кадр, ошибки GL отсутствуют |
| Финал с эффектами VPN | `review/native-frames/r6-post/finale-1280x800-1.png` | Реальные проходы постобработки, UnsignedByte, ошибки GL отсутствуют |
| Сборка с эффектами, доля 0.35 | `review/native-frames/r6-post/finale-1280x800-0.35.png` | 22 000 частиц, ошибки GL отсутствуют |

В JSON сохранены версия Three, камера, число цветов, материалы, команды рисования и диагностические ошибки. Число команд не является измерением FPS. В контрольном рендере r5 (`review/native-frames/r5/`) зафиксированы неподдерживаемые операции PMREM. Первые пустые кадры были ошибкой адаптера VM: нативный модуль не принимал индексные typed array из другого контекста. Они исправлены в проверочном стенде и не записаны как дефект сайта.

Для воспроизведения в Linux с доступным X display и установленными указанными зависимостями:

```sh
ROCKET_GL_DEBUG=1 ROCKET_POST=1 xvfb-run -a node review/native-scene.cjs rocketvpn /tmp/rocket-frames 1280 800 1
```

## Доступ и границы приёмки

Служебный GPU был доступен, но автоматическая проверка отклонила передачу закрытого репозитория и новых правок на внешний GPU-сервер из-за неподтверждённого получателя исходников. Эти операции не выполнялись. На GPU проверялись только публичные файлы действующего VPN. Исправленная версия отрендерена локально, без отправки новых исходников на этот GPU.

Текущий браузер по-прежнему отключает WebGL. Поэтому **полная браузерная приёмка 3D, HDR/WebGL 2, непрерывного движения камеры, игрового полёта и FPS на физических устройствах не завершена**. Нативный рендер сокращает непроверенную область до конкретных пунктов, но не закрывает их. Сходство с Igloo 1:1, фотореализм и универсальная работа без лагов не подтверждены. Рендер 8K не выполнялся.

API, рабочие заявки и разделы админки этим выпуском не меняются. Их предыдущие проверки описаны в RELEASE_R5.md и RELEASE.md. Успешные проверки логики не заменяют визуальную приёмку игры.
