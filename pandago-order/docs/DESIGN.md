# PandaGo Cargo — DESIGN.md (design system, читается агентом перед версткой)

Премиум лид-ген лендинг: техника из Китая под ключ. Кинематографичный
scroll-video, интерактивный 3D, живые WebGL-фоны. Уровень Awwwards.

## Brand core
- Palette (тёплых НЕТ):
  - navy   `#0A1E42`  фон/база
  - abyss  `#050E1F`  глубокий фон секций
  - electric`#1A6BE0` основной акцент, CTA
  - cyan   `#3B9EFF`  вторичный акцент, свечения, линии
  - cyanSoft`#9FD0FF` подписи, hairlines
  - porcelain`#F5F8FC` основной текст
  - ink    `#7C93B4`  вторичный текст
  - line   `rgba(120,160,220,.16)` границы
  - Зелёный только внутри логотипа. Никакого лайма/оранжевого/золота.
- Fonts: Unbounded 700/800 (заголовки, бренд), Golos Text 400/500/600/700
  (текст), JetBrains Mono (тех-подписи, координаты, чипы).
- Тон: премиум, инженерный, спокойная уверенность. «Вы». Без эмодзи.
  Без длинных/средних тире. Без «не X, а Y». Только SVG-иконки.

## Layout
- Контейнер max 1200px, паддинг clamp(18px,4vw,40px). 100svh секции.
- Типографика через clamp(). Тач-цели 44px+. 0 горизонтального overflow.
- Ритм: крупные воздушные секции, hairline-разделители, номера секций моно.
- Сетка карточек: auto-fit minmax(260px,1fr), gap 18-24px.

## Signature (фирменная фишка)
Сквозной «маршрут-хребет»: тонкая cyan-линия-трек с движущейся точкой-искрой,
идёт через весь сайт справа, синхронна скроллу (Гуанчжоу → Монголия → Москва).
Плюс единый кинокадр-полёт в hero (scroll-scrub видео) и живой 3D-квадрик,
который въезжает и реагирует на курсор/тап.

## Компоненты
- Кнопки: primary = electric заливка, порцелан текст, радиус 100px, hover
  lift+brightness. glass = rgba(255,255,255,.05)+blur+border. Магнитный hover.
- Чипы/бейджи: моно 10-11px, uppercase, letter-spacing .16em, cyanSoft,
  border line, полупрозрачная подложка + blur.
- Карточки: фон rgba(8,20,42,.55), border line, радиус 18-20px, hover =
  подъём + cyan-glow border + лёгкий tilt. Внутри — иконка SVG, заголовок
  Unbounded, факт моно.
- Оверлеи текста на видео/3D: тёмный радиальный+линейный градиент под текстом.
- Загрузка: cyan-кольцо-спиннер на navy.

## Motion
- Reveal по скроллу: opacity+translateY(16px), stagger 60ms, ease out.
- Hero-видео: pinned, scroll двигает currentTime (scrub .5).
- 3D: авто-вращение в покое + драг + hover-glow + горячие точки.
- React Bits WebGL-фон в отдельных секциях (тёмный, движется в покое).
- prefers-reduced-motion → отключить scrub/пульсы/курсор, дать постеры.

## Структура (воронка)
1. Hero: кинокадр-полёт + оффер + CTA (рассчитать / Telegram).
2. Как это работает: 4 шага маршрута (завод → граница → таможня → двери).
3. Интерактив 3D: квадрик, крутите, горячие точки, характеристики.
4. Каталог/категории: квадро / мото / гидро, топ-позиции с ценами из catalog.
5. Калькулятор стоимости под ключ.
6. Сравнение с дилером (экономия, DEALER_MARKUP 1.6).
7. Гарантии/почему мы: сроки 30 дней, таможня внутри, 2400+ поставок.
8. Кейсы/отзывы.
9. Заявка (форма newLead) + Telegram.
10. Футер: реквизиты, кредиты 3D/ассетов.
