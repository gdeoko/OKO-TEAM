## Цвета
- Логотип-акцент (лайм): `#9AFF00` · фон бренда: `#080a06`
- Чернила печати: синий `#1e3a8a` (по умолчанию), фиолетово-синий `#2b4fd8`, чёрный `#111111`, лайм `#9AFF00`
- Чернила подписи: navy `#1e2a8a`; для тёмного фона — `signature-white.png`

## Печать — как выбрать
- **seal-*.svg (чистая)** — для экрана, приложения, сертификатов, где нужна идеально ровная печать.
- **seal-*-stamp.png (оттиск)** — для «живых» документов: лёгкая резиновая фактура, неравномерность
  чернил, микро-пропуски, прозрачность ~90 %. Остаётся ровной и читаемой.
- Для юр-документов РФ — `blue` или `violet`. Для брендовых материалов — `lime`. Ч/б печать — `black`.

## Подпись + печать в документе
1. Подпись (`signature.png` или `-black` на светлом фоне) кладётся над строкой подписанта.
2. Печать (`seal-blue-1024-stamp.png`) — рядом/поверх, слегка перекрывая подпись, как в реальных документах.
3. Для приложения используйте `app/assets/brand/seal.svg` и `signature.png`
   (или base64 `seal.b64` / `signature.b64` для инлайна).

## Правила
- Логотип не перекрашивать вне набора цветов и не искажать пропорции.
- Печать/подпись — юридически значимые реквизиты; хранить и применять аккуратно.
