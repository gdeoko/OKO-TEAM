# МЕТАНОЙА — логотип (бренд-паспорт)

Знак: μ (мю) + золотые крылья. Метафора — свет/маяк, ангел-хранитель, начало.
Мастер: `metanoia-logo-master-transparent.png` (прозрачный, из оригинала 2160²).

## Цвета бренда
- Navy (тёмно-синий): `#1A3A52`  · тёмный фон/буква
- Gold (золото):       `#D4A574`  · акцент/крылья/CTA
- Cream (кремовый):    `#FAF8F5`  · текст на тёмном
- Terracotta:          `#C97064`  · доп. акцент
- Blue:                `#7AAED4`  · доп. акцент

## Структура
- `png/` — прозрачные PNG: 32,64,128,256,512,1024,2048
- `on-black/` — на navy-фоне (png+jpg): 256,512,1024
- `on-white/` — на белом (png+jpg): 256,512,1024
- `mono/` — одноцветный силуэт: white / navy / gold / black (256,512,1024)
- `jpg/` — быстрые jpg на белом/navy 1024
- `vector/metanoia-logo.svg` — SVG (встроен растр 2048, 1:1, масштабируется)
- `icon/` — 32..512 + `favicon.ico`
- `metanoia-logo-b64.txt` — data-URI для `<img src=...>`

## Правила
Ставить ТОЛЬКО прозрачный PNG (без фонового квадрата). Пропорции не искажать,
цвета не менять. На тёмном — оригинал/cream/gold; на светлом — оригинал/navy.
