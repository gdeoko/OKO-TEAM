# ЗоОпт — оклейка витрины павильона №69-70

Генератор 16 печатных PDF-плёнок для единого брендированного оформления витрины
зоомагазина ЗоОпт в стиле логотипа (чёрный + лайм-зелёный + жёлтая «луна», айвори фон).

Заменяет разнобой баннеров (Royal Canin / Monge / Pro Plan / Premier / Sirius) на
целостную минималистичную премиум-систему.

## Что генерируется

16 плёнок (8 верхних + 8 нижних) + `index.pdf` (контактный лист-превью):

| Секция | Верх | Низ |
|--------|------|-----|
| 1 (65 см) | Логотип ЗоОпт + СКЛАД·МАРКЕТ | Часы работы 9:00–18:00 + QR |
| 2 (51 см) | СОБАКАМ (силуэт на луне) | Лапа + иконки (миска/косточка/поводок) |
| 3 (51 см) — **дверь №70** | Номер 70 + ВХОД | zoopt.ru (можно оставить прозрачной) |
| 4 (65 см) | КОШКАМ | Клубок/когтеточка + «300+ товаров» |
| 5 (65 см) — **дверь №69** | Номер 69 + ВХОД | Логотип + zoopt.ru |
| 6 (51 см) | ГРЫЗУНАМ И ПТИЦАМ | Колесо/жёрдочка/кормушка |
| 7 (51 см) | АКВАРИУМИСТИКА | Волны + пузыри |
| 8 (65 см) | ОПТ для магазинов и ветклиник | QR прайса + телефон |

## Запуск

```bash
pip install -r requirements.txt
python3 src/generate_all.py
```

Результат — в `output/`. Имена: `vitrina_XX_[top|bottom]_[ШхВ].pdf` (размеры — обрезной формат в см).

## Технические параметры печати (реализовано)

- **Цвет:** все векторные заливки — **CMYK** (проверено: только оператор `k`, ни одного RGB).
  CMYK-эквиваленты HEX бренда заданы в `src/design_system.py`.
- **Размеры страниц:** обрезной формат + **bleed 5 мм** со всех сторон
  (65×90 → 660×910 мм, 51×117 → 520×1180 мм, 65×110 → 660×1110 мм, 51×57 → 520×580 мм) — совпадает с ТЗ.
- **Метки реза (crop marks):** в зоне вылета на всех четырёх углах обрезного формата.
- **Шрифты:** Unbounded (заголовки) + Onest (подписи), **встроены и в сабсетах** (проверено `pdffonts`);
  кириллица полностью покрыта.
- **Материал (для типографии):** плёнка Oracal 641 / Orajet 3651, матовая антивандальная ламинация,
  печать экосольвент/латекс 4+0, 150 dpi при реальном размере.

## Проверка перед отправкой

```bash
pdfinfo  output/vitrina_01_top_65x90.pdf      # размер страницы в pts (÷72×25.4 = мм)
pdffonts output/vitrina_01_top_65x90.pdf      # все шрифты emb=yes
pdftoppm -r 100 -png output/index.pdf preview # визуальный контроль
```

## Архитектура

- `src/design_system.py` — единая точка правды: CMYK-цвета, шрифты, bleed/crop marks,
  хелперы (фон, зелёные полосы 3 см, листочки, логотип-локап, жёлтый круг, QR, текст с трекингом).
- `src/silhouettes.py` — векторные силуэты животных (собака/кошка/рыбка/попугай/хомяк/черепаха)
  и иконки товаров — плоские чёрные/зелёные формы в стиле лого, без растра.
- `src/layouts.py` — 16 плёнок (по одной функции на плёнку), контент по ТЗ.
- `src/generate_all.py` — оркестратор: проверка ассетов → 16 PDF → `index.pdf` → сводка.
- `assets/` — шрифты (с кириллицей), обработанный логотип и эмблема, исходные фото витрины.

## ⚠️ Что доработать до финальной печати (важно)

1. **Оригинал логотипа в векторе.** Присланный `логотип_ЗоОпт.png` — растр ~660 px (похоже,
   сгенерирован ИИ). Для крупных плёнок (секция 1 верх, секция 5 низ) шрифтовая часть «ЗОО·ОПТ»
   уже пересобрана вектором (чёткая на любом размере), но **эмблема (пёс+кот на луне) — растр**
   и на большом размере будет мягковатой. Идеально — получить у клиента исходник логотипа
   в векторе (AI/EPS/SVG/PDF); тогда эмблема тоже станет идеально резкой. Автотрассировка potrace
   пробовалась — на этом PNG даёт грязный контур из-за сглаженных краёв, поэтому не используется.
2. **Сертифицированный PDF/X-4.** Сейчас это корректный CMYK-PDF с нужной геометрией, вылетами,
   метками реза и встроенными шрифтами. Для формального PDF/X-4 нужен встроенный **OutputIntent
   с ICC-профилем** (ISO Coated v2 / FOGRA39). Большинство типографий делают эту конвертацию на
   препрессе сами; при необходимости добавим OutputIntent в генератор (нужен ICC-файл профиля).
3. **Растровые изображения (логотип/эмблема)** встроены как RGB — RIP типографии конвертирует их
   в CMYK при печати. При желании пред-конвертируем в CMYK на этапе финализации.
4. **Нижние «иконочные» плёнки (2/4/6 низ)** сейчас лаконичные; при согласовании можно усилить
   детализацию иконок.
5. **Двери (секции 3 и 5, низ):** по ТЗ рекомендовано оставить нижние 30–40 см **прозрачными**
   (видно покупателя внутри). Сгенерированы простые айвори-плёнки как альтернатива — решает клиент.
