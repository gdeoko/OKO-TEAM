# Банк звуков сайта

Двадцать шесть записей, сгенерированных в ElevenLabs Sound Effects под
аккаунтом okoteam.top@gmail.com. Каждый файл: моно, 44,1 кГц, mp3 80 кбит,
громкость сведена к одному уровню (loudnorm I=-18, петли I=-19), пики
ограничены с запасом, тишина по краям срезана у разовых эффектов.
Всё вместе весит 684 КБ и не грузится, пока человек не включит звук.

## Как это устроено в коде

`assets/rc-sound.js` держит два слоя. Непрерывный - гул двигателя, поток,
эфир - по-прежнему синтез: он тянется минутами и обязан идти за скоростью
прокрутки. Разовые события берут записи отсюда.

- `snd.эф(имя, доля)` - разовый эффект, отдаёт false, если запись ещё не
  доехала. Все методы событий сперва зовут его, потом синтез.
- `snd.фон(имя, громкость)` - петля, громкость ведётся плавно.
- `snd.дай(имя)` - заказать файл. Ошибка сети помечает имя как несбывшееся,
  и событие до конца сеанса остаётся за синтезом.
- `snd.прогревРубки()` - заказ пачки на входе в полёт.

Ничего не грузится заранее: первый экран не тянет звук, который человек
может и не включить.

## Что где звучит

| файл | момент |
|---|---|
| `click` | нажатие в интерфейсе |
| `hover` | наведение на цель в списке |
| `confirm` | подтверждение действия |
| `deny` | отказ: не хватает заряда, рукав ещё закрыт |
| `panel-in`, `panel-out` | справка, меню целей, досье, панель задания |
| `switch` | клавиши доски АВТО и СКАН |
| `type` | тик счётчика на приборе |
| `ignite` | заход в полёт |
| `engine`, `climb` | петли тяги и набегающего потока (запас к синтезу) |
| `boom` | посадка на опоры |
| `hyper` | пробой в чужой рукав |
| `arrive` | выход на орбиту тела |
| `dock` | шлюз открывается |
| `brake` | полная остановка |
| `radar` | запрос трафика |
| `scan` | включение скана |
| `lock` | курс проложен |
| `alarm` | манёвр обхода, авария на узле, узел потерян |
| `beacon` | запас |
| `node` | узел поднят |
| `amb-cabin` | фон в рубке |
| `amb-space` | фон снаружи |
| `reveal`, `success` | появление карточки, защищённый канал поднят |

## Как сгенерировать заново

Скрипты лежат на VPS в `/opt/oko-poster/rcsnd`: `rcsnd_bank.py` (список и
промпты), `post.sh` (сведение и замеры). Ключ ElevenLabs берётся из
`/opt/oko-poster/cfg/secrets.env` и наружу не уходит; ходить в API нужно
через нидерландский выход `127.0.0.1:10840`, российский адрес там закрыт.
Готовое лежит в `/opt/oko-poster/rcsnd/web`.
