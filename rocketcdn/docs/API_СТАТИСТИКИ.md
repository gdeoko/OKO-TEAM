# API статистики Rocket CDN

Прислал сетевой администратор клиента 14.09.2026 со словами «там много
различных функций». Задачи на встройку он не ставил: прислал как справку.
Записываю сюда, чтобы не осталось только в переписке.

Первоисточник: https://doc.rocketcdn.ru/api_desc/statistics/

## Главное, что надо знать до первого запроса

**Токен в браузер не отдаём.** `CDN-AUTH-TOKEN` это ключ от кабинета
клиента: по нему видно весь его трафик, все хосты и все пути. Любой код,
который выполняется на странице, читается человеком через «просмотр кода»,
и ключ оттуда уедет вместе со страницей. Значит запрос делает сервер, а
страница спрашивает уже свой сервер. У нас это правило общее для всех
проектов: ключи не вписывать в код сайтов и не отдавать в браузер.

**Пять обращений в минуту, больше служба не даёт** (429). Сводку за месяц
считать отдельными запросами по дням нельзя: параметр `granularity` для
того и есть, один запрос вместо тридцати.

**Статистика отстаёт до часа.** Число за последний час будет неполным, и
это не сбой. Нужна свежая полоса прямо сейчас - другой раздел, realtime
(`/app/realtimestat/v1/`).

**`end` не включается в расчёт.** Сутки 20 мая это
`start=2026-05-20T00:00:00`, `end=2026-05-21T00:00:00`. Поставить концом
23:59 значит потерять последнюю минуту суток на каждом запросе.

## Что где лежит

| путь | что отдаёт |
|---|---|
| `/app/statistic/v3/` | суммарно: трафик, подключения, кэш, пиковая полоса |
| `/app/statistic/v3/<группа>` | та же сводка, разложенная по группе |
| `/app/statistic/v3/times[/<группа>]` | то же по времени, шаг задаёт `granularity` |
| `/app/streamstat/v2/` | видеопотоки: просмотры, зрители, пик |
| `/app/realtimestat/v1/accounts/...` | полоса прямо сейчас, без отставания |
| `/app/activesessions/v1/streams` | кто смотрит поток в эту секунду |
| `/app/dns-stat/v1/` | Managed DNS |
| `/app/ioss-statistic/v1/` | оптимизация картинок |
| `/app/logs/v1/accounts/<аккаунт>/exists` и `/get` | сырые логи, gzip-потоком |

Группы у `statistic/v3`: `customs` (метки), `referrers`, `codes`,
`countries`, `regions`, `browsers`, `platforms`, `hosts`, `paths`,
`resources`, `accounts`.

## Поля ответа

    traffic       общий трафик, БАЙТЫ
    hits          количество подключений
    cache_ratio   доля выдачи из кэша, от 0 до 1, без округления
    bandwidth     пиковая скорость, БИТЫ в секунду

Трафик в байтах, полоса в битах. Показывать человеку одну единицу на оба
числа нельзя, разойдётся в восемь раз.

## Грабли формата

**Даты по ISO 8601, секунды ВСЕГДА `00`**: `YYYY-MM-DDThh:mm:00`.

**Плюс в часовом поясе кодируется как `%2B`.** В адресной строке `+` это
пробел, и `+03:00` доедет как ` 03:00`. Правильно `%2B03:00`.

**`granularity` в упрощённом виде**: `P1M`, `P1D`, `PT5M`, `PT1H`. Смесь
вида `P1DT12H` служба не принимает.

**`timezone` идентификатором IANA**: `Europe/Moscow`, не `+03:00`.

**`sort` это знак и поле одной строкой**: `-traffic` по убыванию,
`+traffic` по возрастанию.

**Язык ответа** берётся из `language` в строке запроса, потом из заголовка
`Accept-Language`, иначе английский. У `countries` и `regions` приходят
коды, а рядом `country_name` и `region_name` на выбранном языке.

## Пример

    curl -H "CDN-AUTH-TOKEN: $TOKEN" \
      'https://api.rocketcdn.ru/app/statistic/v3/?start=2026-08-31T11:01:00&end=2026-09-19T10:01:00&account=jetimeje17'

    {"start":"...","end":"...","account":"jetimeje17",
     "hits":2104772,"traffic":40603470765,
     "cache_ratio":0.8231922443391645,"bandwidth":5612541}

## Где это применимо у нас

Сайт `rocketcdn.ru` это витрина: он рассказывает про услугу и принимает
заявки, чужого трафика не показывает. Личный кабинет клиента живёт
отдельно, на `lk.rocketcdn.ru`, и статистика место ему.

Если однажды понадобится показать числа на витрине (живой счётчик отданного
трафика в шапке, карта стран), порядок такой: токен лежит в `config.php`
рядом с остальными ключами, `api.php` отдаёт уже посчитанное своим
`action`, ответ кэшируется на сервере не меньше чем на пять минут. Пять
обращений в минуту это предел на весь ключ, а не на посетителя: сотня
человек на странице выберет его за секунды, и служба закроет доступ всем,
включая кабинет клиента.
