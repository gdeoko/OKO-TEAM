# Анимированные стикеры и эмодзи Rocket CDN · VPN

Два набора для @rocket_cdn_bot: **стикеры** (крупные, в переписку) и
**кастом-эмодзи** (мелкие, в текст и в оформление канала). Оба собраны из
**одних и тех же файлов**, поэтому пары совпадают буквально, а не «похожи»:
Telegram принимает анимированные эмодзи тем же форматом `.tgs` 512×512, что
и стикеры.

33 единицы: бренд и космос, VPN, CDN, реакции для чата.

## Что внутри

| раздел | единицы |
|---|---|
| Бренд и космос | взлёт, знак Rocket, Земля, Юпитер, Марс, Сатурн, Луна, Солнце, комета, космонавт |
| Rocket VPN | щит, замок закрыт, замок открыт, ключ, анонимность, смена страны, туннель, блок снят |
| Rocket CDN | молния, свои ЦОД, спидометр, раздача, облако, стриминг, загрузка, рост, турбо |
| Реакции | готово, не вышло, спасибо, одобряю, внимание, привет |

## Откуда взят бренд

**Логотип не перерисован.** Знак «R» с ракетой берётся из фирменного вектора
проекта (`assets/brand/rocketcdn-logo-vector.svg` и `assets/rocketvpn-logo.svg`)
и переводится в фигуры Lottie один в один — `svg2lottie.py` разбирает пути,
градиенты и трансформации. Надписи «RocketCDN», «RocketVPN» и слоган отрезаны:
в размере строки они превращаются в грязь, а знак узнаётся и там.

Единственный кусок логотипа, залитый картинкой — шлейф за ракетой. Картинок
в `.tgs` нет, поэтому шлейф собран вектором по тем же трём полосам, под тем же
углом и с тем же затуханием (`brand_logo.trail`).

**Планеты в цветах NASA.** Оттенки сняты с текстур, которые лежат на самом
сайте (`assets/space/*.webp`) и крутятся в его полёте. Отсюда ржавый Марс,
песочный Сатурн и полосы Юпитера с красным пятном.

**Зал ЦОД** срисован с фотографий сайта (`assets/gen/dc-moscow`, `dc-almaty`,
`dc-prague`): стойки в перспективе, циановые огни состояния, отражение на полу.

Палитра — из `assets/rc.css`: циан `#42B2DC`/`#0A5897` у CDN, фиолет
`#8A59F6`/`#5B32C9` у VPN.

## Стиль

Подложки нет, стикер прозрачный. Объём держат сами предметы: металл со
светлой полосой вдоль формы, отражённый свет по тёмному краю, блик и мягкая
тень-опора (`parts.sphere`, `parts.metal`, `parts.shadow`, `parts.glow`).
Язык взят у логотипа: у его ракеты корпус блестит, а не залит одним цветом.

Формы держатся крупными нарочно — один и тот же файл работает и стикером во
весь экран, и эмодзи размером со строку.

## Сборка

```bash
cd src
python3 build.py            # собрать все .tgs в ../out
python3 build.py launch     # пересобрать один сюжет
```

Сборка сама проверяет требования Telegram: холст 512×512, 60 кадров в
секунду, не длиннее 3 секунд, вес до 64 КБ, только фигурные слои без масок и
эффектов. Весь пак весит около 43 КБ — предел на один файл 64 КБ.

## Посмотреть глазами

```bash
npm install lottie-web
node tools/preview.mjs out /куда/класть 120
```

Рендерит `.tgs` тем же движком, каким их покажет плеер, и снимает кадр. Нужен,
чтобы смотреть на результат, а не верить, что JSON собрался правильно.

## Заливка

```bash
export ROCKET_BOT_TOKEN=...      # токен @rocket_cdn_bot
export ROCKET_OWNER_ID=...       # user_id владельца набора
python3 tools/upload.py --check  # что уже залито
python3 tools/upload.py          # залить оба набора
```

Telegram придерживает создание наборов и сам называет паузу (обычно пять
минут) — скрипт ждёт ровно столько и пробует снова.

Ссылки после заливки:

- эмодзи: https://t.me/addemoji/rocket_icons_by_rocket_cdn_bot

### Грабли, на которые уже наступили

- **Порядок слоёв.** Lottie рисует первый элемент верхним. Здесь принято
  писать снизу вверх, как ложатся краски, а переворачивает список `_stack`.
  Переворачивается только стопка групп: внутри одной группы порядок «фигура,
  потом заливка» менять нельзя, иначе стиль отвяжется от фигуры.
- **Координаты.** Вся геометрия живёт в координатах холста 512. Если нарисовать
  предмет вокруг нуля, а движение задать слою, предмет уедет в угол: у слоя
  якорь в центре холста.
- **Дуга окружности** задаётся касательными длиной `0.55·r`. Ломаная через три
  точки даёт «ёлочку», а не дугу.
- **Масок в .tgs нет**, обрезать по кругу нечем — всё, что не должно торчать,
  держится внутри кадра геометрией.
- **Шлейф не входит в габарит знака**: `ROCKET_BOX` описывает корпус, поэтому
  ракету со шлейфом надо ставить с запасом, иначе он вылезет за край.
