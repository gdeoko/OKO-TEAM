# Rocket CDN · сайт, админка, бот

Одностраничный сайт сети доставки контента Rocket CDN с панелью управления,
телеграм-ботом и мини-приложением. Клиент: Сетевой Администратор, домен
`rocketcdn.ru`, личный кабинет `lk.rocketcdn.ru`.

Развёртывание описано в [DEPLOY.md](DEPLOY.md).

## Что сделано

**Сайт.** Тёмная и светлая темы с переключателем, русский и английский языки,
живой глобус сети на 218 точек присутствия с дугами трафика и собственными ЦОД,
поиск по городам с фильтром по регионам, семь продуктов, шесть преимуществ,
схема работы сети, сценарии применения, вопросы и ответы, форма заявки и
обратный звонок. Разметка Schema.org, Open Graph, sitemap, манифест.

**Аналитика.** Свой счётчик без внешних сервисов: посещения, уникальные,
клики по «Регистрации», переходы к подключению, глубина прочтения, устройства
и системы, источники переходов, города, которые искали на карте, ошибки
у посетителей. Данные складываются в `data/stats` по дням.

**Админка** (`admin.html`). Вход по паролю. Графики по дням, сравнение с
прошлым периодом, таблица заявок со статусами и выгрузкой в CSV, список узлов
сети, редактор текстов сайта, проверка почты и Телеграма.

**Бот** `@rocket_cdn_bot`. Нижнее меню отдельно для гостей и для администраторов,
уведомления о заявках с кнопками, сводка аналитики по команде, привязка чата и
тем командой `/bindchat`, мини-приложение по кнопке.

**Почта.** Письма уходят через SMTP Gmail в фирменном тёмном шаблоне: одно
владельцу, второе клиенту, если он оставил адрес.

**Фильм по прокрутке.** Страница снята как один фильм: ракета летит через весь
сайт и физически задевает интерфейс - сдувает чипы первого экрана, будит
счётчики, бросает пакеты данных в виджеты, качает карточки ЦОД струёй, роняет
галочки на девять пунктов по световым дорожкам при посадке. Ближе к концу
страницы люк тамбура перекрывает кадр, и мы оказываемся внутри корабля: рубка
пять метров в диаметре, панели по кругу, иллюминаторы с планетой, пульт с
анкетой. Вся геометрия и все текстуры считаются процедурно, ни одной модели и
ни одного килобайта в критическом пути. Режиссёрский сценарий - `docs/SCENARIO.md`.

**Заставки.** Главная встречает разгоном: поток пакетов данных летит на зрителя
с настоящей перспективой, скорость идёт за честным процентом загрузки, на финале
поток схлопывается в капсулу со знаком. Звук синтезируется на месте, без единого
файла, и включается только если человек уже разрешал звук на сайте. Для личного
кабинета собраны три отдельные заставки - `splash-lk.html`, там же кнопка
«скопировать код»: витрина исполняет ровно тот код, который отдаётся
разработчику кабинета.

**Запасной сценарий.** На слабом устройстве, при просьбе меньше движения и если
объёмный слой не поднялся, фильм превращается в раскадровку: восемь запечённых
кадров вместо сцен, все хуки отрабатывают по появлению в кадре, стекло остаётся
запечённым. Весь текст, форма заявки, обе темы и оба языка на месте. Приёмка
простая: выключаем JavaScript целиком, страница читается и форма отправляется.

## Устройство

```
index.html             главная, заставка «Разгон» встроена в шапку документа
app.html               мини-приложение Телеграма
admin.html             панель управления
splash.html            пять ранних эскизов заставок
splash-lk.html         три готовые заставки для личного кабинета, с выдачей кода
api.php                заявки, аналитика, данные для админки
bot.php                телеграм-бот, запускается раз в минуту
cron.php               отчёт в 9:00 и уборка, запускается раз в час
config.php             конфиг и общие функции, секреты в config.local.php (в git нет)
docs/SCENARIO.md       режиссёрский сценарий: карта сцен, порядок работ, бюджет
assets/rc-geo.js       218 узлов, три ЦОД, маска суши
assets/rc-globe.js     глобус на canvas, без внешних библиотек
assets/rc-i18n.js      весь текст сайта, два языка
assets/rc.css          дизайн-система, обе темы, рифма с палитрой кабинета
assets/rc-gl.js        бюджет контекстов WebGL и ленивая загрузка объёмного слоя
assets/rc-rocket.js    ракета: полёт по сплайну, отдаёт своё положение в CSS
assets/rc-interior.js  тамбур и рубка корабля, процедурная геометрия
assets/rc-hooks.js     точки касания ракеты и содержимого
assets/rc-motion.js    режимы прокрутки, простоя и ступенчатой деградации
assets/rc-fallback.js  запасной сценарий и доступность
assets/storyboard/     восемь запечённых кадров для запасного сценария
```

Внешних зависимостей нет: ни библиотек, ни CDN, ни базы данных, ни звуковых
файлов. Шрифт и все ассеты лежат локально, звук синтезируется в браузере.

## Управление из бота

Администраторам доступны кнопки «Состояние» и «Тексты сайта». Состояние - те же
цифры, что во вкладке админки: почта, бот, привязка чата, заявки без ответа,
дни до конца сертификата, свободное место, адрес телеграма. Тексты правятся
прямо в переписке: раздел, строка, новый текст; старое значение всегда
показывается перед заменой, последнюю правку отменяет `/undo`, все изменения
пишутся в `data/admin_log.json`. Отчёт по требованию - `/report`, расписание
в 9:00 это не сдвигает.
