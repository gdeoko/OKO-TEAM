# Rocket CDN · сайт, админка, бот

Одностраничный сайт сети доставки контента Rocket CDN с панелью управления,
телеграм-ботом и мини-приложением. Клиент: Сетевой Администратор, домен
`rocketcdn.ru`, личный кабинет `lk.rocketcdn.ru`.

Развёртывание описано в [DEPLOY.md](DEPLOY.md).

## Что сделано

**Сайт.** Тёмная и светлая темы с переключателем, русский и английский языки,
живой глобус сети на 218 точек присутствия с дугами трафика и собственными ЦОД,
поиск по городам с фильтром по регионам, семь продуктов, шесть преимуществ,
схема работы сети, сценарии применения, вопросы и ответы, форма заявки и
обратный звонок. Разметка Schema.org, Open Graph, sitemap, манифест.

**Аналитика.** Свой счётчик без внешних сервисов: посещения, уникальные,
клики по «Регистрации», переходы к подключению, глубина прочтения, устройства
и системы, источники переходов, города, которые искали на карте, ошибки
у посетителей. Данные складываются в `data/stats` по дням.

**Админка** (`admin.html`). Вход по паролю. Графики по дням, сравнение с
прошлым периодом, таблица заявок со статусами и выгрузкой в CSV, список узлов
сети, редактор текстов сайта, проверка почты и Телеграма.

**Бот** `@rocket_cdn_bot`. Нижнее меню отдельно для гостей и для администраторов,
уведомления о заявках с кнопками, сводка аналитики по команде, привязка чата и
тем командой `/bindchat`, мини-приложение по кнопке.

**Почта.** Письма уходят через SMTP Gmail в фирменном тёмном шаблоне: одно
владельцу, второе клиенту, если он оставил адрес.

## Устройство

```
index.html         главная
app.html           мини-приложение Телеграма
admin.html         панель управления
api.php            заявки, аналитика, данные для админки
bot.php            телеграм-бот, запускается раз в минуту
cron.php           отчёт в 9:00 и уборка, запускается раз в час
config.php         конфиг, секреты в config.local.php (в git не хранится)
assets/rc-geo.js   218 узлов, три ЦОД, маска суши
assets/rc-globe.js глобус на canvas, без внешних библиотек
assets/rc-i18n.js  весь текст сайта, два языка
assets/rc.css      дизайн-система, обе темы
```

Внешних зависимостей нет: ни библиотек, ни CDN, ни базы данных.
Шрифт и все ассеты лежат локально.
