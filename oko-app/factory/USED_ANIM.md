## КАК ДЕЛАТЬ (обязательный порядок на каждый ролик)
1. Прочитать этот файл — увидеть, какие визуальные формы/механики УЖЕ заняты.
2. Придумать под сегменты ролика 8–12 НОВЫХ анимаций (метафора под смысл цифры/факта),
   которых тут ЕЩЁ НЕТ. Пример разных метафор: жидкостный счётчик, разлетающиеся частицы-искры,
   3D-разворот детали, морф-трансформация цифры, тепловая шкала, «осциллограф» звука мотора,
   спидометр с реальной физикой стрелки, карта с анимированным треком частицами, изометрия склада,
   таймлайн-гармошка, «разбор на запчасти» (exploded view), кинетическая типографика по буквам и т.д.
3. НАПИСАТЬ их КОДОМ (HTML/CSS/JS, window.render(t)) специально под ролик — не звать пресеты.
4. Отрендерить (capture.js → qtrle), собрать. Свериться с этим файлом — ноль повторов формы.
5. Дописать сюда: № ролика, список НОВЫХ анимаций (форма+моушен), чтобы дальше их не повторять.

## ЖУРНАЛ НОВЫХ АНИМАЦИЙ (заполнять с #16)

### #16 (batch A) — КВАДРО «сколько стоит владеть» — 6 авторских анимаций С НУЛЯ
Файл-исходник: `pipeline/overlay_16.html` (свой `window.render(t)`, НЕ build_accents.py).
Каждая форма новая по геометрии И моушену, ни одна не из библиотеки:
1. **Кинетическая типографика** — слово «ДОРОГО» въезжает побуквенно (стаггер-дроп + доворот),
   затем амбер-перечёркивание свайпом, буквы гаснут в серый, штампуется «— МИФ» (back-ease).
2. **Жидкостный бак топлива** — SVG-бак с анимированной волновой поверхностью жидкости
   (sin-волна пересчитывается каждый кадр), заливка до ~30%, «30 %/бак · хватает на выходные».
3. **Весы-балансир** — SVG-коромысло на оси, наклон с overshoot-отскоком; чаша ЕВРОПА ×3
   тяжёлая (опускается), КИТАЙ ×1 лёгкая (поднимается), маятниковый sway чаш затухает.
4. **Гармошка-регламент + часы** — 3 карточки (МАСЛО/ФИЛЬТР/ЦЕПЬ) раскрываются по ширине
   (accordion, back-ease, стаггер), в углу круговые часы со стрелкой-разверткой 0→30 мин + сектор.
5. **Блоки затрат под аркой аренды** — низкий стек зелёных блоков «ВЛАДЕНИЕ·ГОД» растёт снизу,
   поверх рисуется большая пунктирная парабола «АРЕНДА·СЕЗОН» с бегущим маркером (dashoffset-draw).
6. **Сборка лого из искр** — 44 частицы (golden-angle) слетаются к центру, вспышка-кольцо на
   схлопывании, из них проявляется лок-ап DIESEL CARGO + вайп-подчёркивание «ПИШИТЕ ГОРОД».
Зоны разнесены (центр / низ-бак / коромысло-центр / лево+угол / лево-стек+арка / центр-лок-ап).
Стилевые пресеты 0–4 НЕ использованы — весь вид нарисован под этот ролик.

### #17 (batch B) — ГИДРО «всё лето на воде» — 6 авторских анимаций С НУЛЯ
Файл: `pipeline/overlay_17.html`. Формы новые, не пересекаются с #16 и библиотекой:
1. **Water-shatter** — «РОСКОШЬ» распадается на капли-брызги (golden-angle разлёт) и собирается «ДОСТУПНО».
2. **Exploded modules** — силуэт делится по вертикали на КОРПУС/МОТОР/ПОМПА с галочками «заводское».
3. **Speed-осциллограф** — волна нарастающей амплитуды = разгон, км/ч на гребне (НЕ спидометр-циферблат).
4. **Radial season fan** — 4 активности (рыбалка/катание/вейк/сплав) веером по дугам из центра «ЛЕТО».
5. **Under-key conveyor** — ящики доставка→таможня→документы едут поездом по ленте в ворота «ГОТОВО».
6. **Splash-crown lockup** — концентрические волны + корона брызг, из них лого DIESEL CARGO.
Акцент-цвет воды AQUA #39C6E6 добавлен к бренд-амберу (только этот ролик). Зоны разнесены.

### #18 (batch A) — КВАДРО «проедет везде» — 6 авторских анимаций С НУЛЯ
Файл: `pipeline/overlay_18.html`. Формы новые, ≠ #16/#17/библиотеки:
1. **Terrain-flip cycle** — карточки ГРЯЗЬ/ПЕСОК/ПОДЪЁМ/КАМНИ по очереди flip-in (rotateY) + штамп «✓ПРОЙДЕНО» + прогресс-точки.
2. **Incline-horizon** — весь горизонт наклоняется (подъём), квадро-маркер карабкается по склону, счётчик градусов.
3. **Padlock-unlock** — 3 узла (блокировки/пониженная/защита) открываются замком (дужка поднимается) + тег «С ЗАВОДА».
4. **Map-pins drop** — 4 сценария (охота/рыбалка/снег/стройка) падают булавками на карту-контур с bounce + рябь + пунктир-трек.
5. **4×4 power-grid** — вид сверху, 4 колеса пульсируют тягой (стрелки), центр «4×4», бар «ТЯГА %».
6. **Dust-trail lockup** — пыльный след прочерчивает экран L→R, за ним проявляется лого DIESEL CARGO.
Акцент tan/пыль #C9A66B (этот ролик). Голос: Qwen3-TTS (HF, Dylan — интерим до выбора Даниэля).

### #19 (batch B) — МОТО «городской» — 6 авторских анимаций С НУЛЯ
Файл: `pipeline/overlay_19.html`. Формы новые, ≠ #16/#17/#18/библиотеки:
1. **Traffic-weave** — авто-блоки стоят, мото змейкой (sine) проезжает между ними со следом-трейлом.
2. **Fuel-drop counter** — дискретные капли падают в бак (мало = экономно), «БАК = НЕДЕЛЯ».
3. **Parking-fit** — рамка парковки (угловые скобки) сжимается вокруг мото, «1 МЕСТО = 3 МОТО».
4. **KM-milestones** — верстовые щиты 10/30/50 тыс.км пролетают в перспективе по дороге с бегущими дэшами.
5. **Model-carousel** — 3 силуэта ГОРОД/СПОРТ/КЛАССИКА свайпаются каруселью + точки-индикаторы.
6. **Headlight-reveal** — луч фары проходит по экрану L→R и открывает лого DIESEL CARGO.
Акцент cyan #4FD1C5 (этот ролик). Голос: Silero eugene (нативный русский).

### #20 (batch A) — МОТО «распаковка» — 6 авторских анимаций С НУЛЯ
Файл: `pipeline/overlay_20.html`. Формы новые, ≠ #16–19/библиотеки:
1. **Box-open** — крышка коробки откидывается (перспектива через cos), внутренний свет, «МОТОЦИКЛ» на бренд-ленте.
2. **Parts-snap assembly** — детали (руль/зеркала/колесо) прищёлкиваются к силуэту с флешем + бар сборки 0→100%.
3. **Contents arc-out** — карточки комплекта (документы/ключи/зарядка/инструмент) вылетают из коробки по дуге.
4. **Leader-line spec tags** — выноски с точками к мотоциклу (ПРОБЕГ 0 / ГАРАНТИЯ / ЗАВОДСКАЯ СМАЗКА), линия растёт к плашке.
5. **Price-tag swap** — ценник «САЛОН» зачёркивается свайпом, ниже падает амбер-ценник «ЗАВОД дешевле».
6. **Ignition lockup** — стрелка тахометра метёт по дуге + вспышка зажигания, из неё проявляется лого DIESEL CARGO.
ГОЛОС: Piper Ruslan + RUAccent (финальный, авто-ударения). Первый ролик на новом голосе.
