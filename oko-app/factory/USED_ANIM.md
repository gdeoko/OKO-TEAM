### #16 (batch A) — КВАДРО «сколько стоит владеть» — 6 авторских анимаций С НУЛЯ
Файл-исходник: `pipeline/overlay_16.html` (свой `window.render(t)`, НЕ build_accents.py).
Каждая форма новая по геометрии И моушену, ни одна не из библиотеки:
1. **Кинетическая типографика** — слово «ДОРОГО» въезжает побуквенно (стаггер-дроп + доворот),
   затем амбер-перечёркивание свайпом, буквы гаснут в серый, штампуется «— МИФ» (back-ease).
2. **Жидкостный бак топлива** — SVG-бак с анимированной волновой поверхностью жидкости
   (sin-волна пересчитывается каждый кадр), заливка до ~30%, «30 %/бак · хватает на выходные».
3. **Весы-балансир** — SVG-коромысло на оси, наклон с overshoot-отскоком; чаша ЕВРОПА ×3
   тяжёлая (опускается), КИТАЙ ×1 лёгкая (поднимается), маятниковый sway чаш затухает.
4. **Гармошка-регламент + часы** — 3 карточки (МАСЛО/ФИЛЬТР/ЦЕПЬ) раскрываются по ширине
   (accordion, back-ease, стаггер), в углу круговые часы со стрелкой-разверткой 0→30 мин + сектор.
5. **Блоки затрат под аркой аренды** — низкий стек зелёных блоков «ВЛАДЕНИЕ·ГОД» растёт снизу,
   поверх рисуется большая пунктирная парабола «АРЕНДА·СЕЗОН» с бегущим маркером (dashoffset-draw).
6. **Сборка лого из искр** — 44 частицы (golden-angle) слетаются к центру, вспышка-кольцо на
   схлопывании, из них проявляется лок-ап DIESEL CARGO + вайп-подчёркивание «ПИШИТЕ ГОРОД».
Зоны разнесены (центр / низ-бак / коромысло-центр / лево+угол / лево-стек+арка / центр-лок-ап).
Стилевые пресеты 0–4 НЕ использованы — весь вид нарисован под этот ролик.

6. **Splash-crown lockup** — концентрические волны + корона брызг, из них лого DIESEL CARGO.
