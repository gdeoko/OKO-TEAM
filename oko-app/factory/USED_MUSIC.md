# РЕЕСТР МУЗЫКИ — на КАЖДЫЙ ролик СВОЙ трек, без повторов (закон Даниэля 22.07)

Правило: музыка НЕ повторяется между роликами. Трек выбирается `pipeline/pick_music.py <bucket> <theme>`
под настроение бакета (viral/useful/sales) из пула `music/`, дедуп по `music/used_music.json`.
Плюс пер-ролик обработка в `audio.py` (сдвиг секции + темп + EQ по MUSIC_SEED) — даже соседние треки звучат иначе.
Каждый ролик пишем сюда: № — файл — бакет — почему подходит теме/сценарию.

## СТАТУС ПУЛА
- Сейчас в `music/` только 1 плейсхолдер `bed01_neutral.mp3` (копия старого общего бэда).
- Нужен НОРМАЛЬНЫЙ пул из 20–30+ разноплановых треков (чистая лицензия для коммерч. TikTok/YouTube/IG).
  Источник — по решению Даниэля (см. вопрос от 22.07): библиотека по подписке (Epidemic/Artlist/Uppbeat),
  либо встроенные библиотеки площадок, либо кураторский CC0-пул, либо треки от Даниэля.
- ДО расширения пула сборка новых роликов музыкой ограничена (audio.py требует MUSIC_TRACK).
