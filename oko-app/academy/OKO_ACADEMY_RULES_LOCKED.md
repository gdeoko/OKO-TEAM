# АКАДЕМИЯ OKO — ЖЁСТКИЕ ПРАВИЛА СБОРКИ (ЗАКОН, читать ПЕРЕД каждым уроком)

Утверждено Даниэлем. Это канон. Отклонение = брак. Читать этот файл перед сборкой ЛЮБОГО урока.

## 0. МАСШТАБ
- 3 направления: **Медийность · Маркетинг · Нейросети**.
- В каждом **5 блоков**, в блоке **~9 уроков** → **136 уроков всего**.
- Сертификат — за пройденное **направление целиком** (не за урок).
- Собрать ПОЛНОСТЬЮ: видео + текст + тесты + игры + задания + сертификаты. Без остановок.

## 1. ВИДЕО-УРОК (главное)
- **Формат кадра — 16:9 (1920×1080). Везде.** Плеер урока горизонтальный.
- **Это ВИДЕО, где каждую секунду ВСЁ движется.** НЕ слайд-шоу, НЕ смена статичных картинок.
  Постоянное движение под темп музыки, речи и озвучки.
- **Чистая моушен-инфографика.** БЕЗ стоков (Pexels/Pixabay) и БЕЗ i2v-видео-генераций.
  Только код-движение: WebGL/three.js, Lottie, GSAP/anime.js, кинетическая типографика,
  Remotion-инфографика, GL-переходы, частицы, 3D-GLB, свечения, морфинг.
- **Обложка** — генерится в Higgsfield (промпт англ., ≥2000 симв., логотип OKO как reference),
  ставится ПЕРВЫМ КАДРОМ (хук в первые 0.5 сек).
- **Караоке-субтитры** (слово подсвечивается в такт речи).
- **Длина 2–10 мин** — по глубине темы.
- Способ производства: код-сцена (HTML+WebGL/GSAP/Lottie) под озвучку → захват в mp4 (Playwright→ffmpeg).
  Итог — mp4-файл. В приложении играется БЕЗ кнопки скачать (nodownload).

## 2. ЗВУК
- **Голос — клон Даниэля (XTTS). НЕ трогать, озвучка норм.**
- **Текст озвучки — через ХУМАНИЗЕР:** живая речь от первого лица, по смыслу,
  БЕЗ нейросетевых оборотов, без канцелярита, с паузами и интонацией. Как говорит живой человек.
- **Музыка — всегда под смысл урока** (Freesound), дакинг под голос.
- **SFX — под анимации** (whoosh на переходы, поп на появления, cha-ching на деньги, импакты).

## 3. ЖЁСТКОЕ ПРАВИЛО АНТИ-ПОВТОРОВ (нулевая терпимость)
Ни разу не повторяется — ни внутри урока, ни между уроками:
**игра, тест, задание, слайд, звук, музыка, фон, визуал, наложение, кадр, инфографика, моушен, палитра, композиция, тип перехода.**
- Всё уникальное на каждый урок — на основе АНАЛИЗА конкретного урока.
- Ведётся глобальный реестр использованного (`academy/registry.json`): перед сборкой урока
  проверяем, что каждый элемент отличается от всех прошлых. Использовал — записал.

## 4. ИГРЫ (интерактив) — библиотека движков, уникально на урок
Не только «пары». Минимум 12–15 разных движков: drag-порядок, заполни пропуск,
свайп-сортировка, таймлайн, горячие точки на картинке, собери воронку, тренажёр-диалог,
викторина на время, мемори, термин-кроссворд, «правда/ложь» на скорость, сопоставление колонок,
собери структуру поста, ранжирование и т.д. На урок — свой, не повторять.

## 5. ТЕСТЫ и ЗАДАНИЯ
- Тест: содержательный, порог зачёта 70%, пересдача. Вопросы разные по форме, без повторов между уроками.
- Задание (практика): реальное, применимое сразу; проверка ИИ-куратором; уникальная механика/формат на урок.

## 6. КОНТЕНТ = РЕАЛЬНАЯ ПОЛЬЗА (актуальность июль 2026)
- Каждый урок собирается С НУЛЯ: сначала глубокий, реально полезный текст-разбор темы
  (интересно, понятно, красиво), потом на его основе — визуал.
- **Ресёрч:** WebSearch по теме — свежие данные, работающие механики, цены/модели ИИ 2026,
  лайфхаки, реальные ссылки/инструкции. + материал **Брилса/ХЛБ** из `academy/source/`
  (медийность, маркетинг). Ничего устаревшего/выдуманного.
- Обучение должно ЗАТЯГИВАТЬ и давать результат даже за 2 урока. Реальные фишки, махинации, польза.
