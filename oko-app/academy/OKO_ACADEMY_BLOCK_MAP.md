Сертификат — только за всё направление. Уроки пропускаемые.

Каждый урок = видео (голос-клон Даниэля) → карусель слайдов → конспект → кнопки-инструменты
(реф) → тест → мини-игра. Формат объекта урока — как в `modules/academy/script.js`.

## ФОРМАТ ОБЪЕКТА УРОКА (строго)
```
{ title, sub:'M:SS · видео (голос Даниэля) + слайды + тест + игра', dur:'M:SS',
  videoUrl?:'https://okoteam.top/media/oko_<dir>_<block>_<n>.mp4',  // опционально, пока в производстве
  c1, c2,                       // две строки крупной обложки-плашки (капс, коротко)
  slides:[ {t, pts:[...4-5 буллета, ключевые слова и ИНСТРУМЕНТЫ в <b>…</b>], svg:'<svg viewBox="0 0 120 70" ...brand line-icon...>'} ...5-8 ],
  quiz:[ {q, o:[4 варианта], a:index} ...5-6 ],
  pairs:[ ['левое','правое'] ...5 ],           // мини-игра на соответствие
  task:{ intro, chips:[...5], ph:'пример…', verdict:'ответ куратора…' } }
```
Правила: без эмодзи; инструменты писать через `<b>ChatGPT</b>` и т.п. (кнопки подтянутся из AC_TOOLS);
SVG — только тонкие линии currentColor, viewBox 120×70; тексты живые, по методологии ХЛБ, без воды.
