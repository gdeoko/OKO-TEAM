# Урок 1 — «Карта нейросетей 2026» (эталон видео-урока Академии OKO)

Полностью анимационный видео-урок 1920×1080, ~4 мин. Собран локально, 0 кредитов.

## Голос: Silero **eugene** (бренд OKO, бесплатно, безлимит) — скилл /oko-voice.
## Рендер: детерминированный покадровый 30fps (без лагов) → см. render_frames.py.

## Пайплайн (воспроизвести)
1. `narration_silero.py` — гуманизированная озвучка edge-tts (Dmitry), ударения+паузы, → `vo/full.mp3` + `timings.json`.
2. `whisper` (small) → `words.json` (тайминги слов).
3. `karaoke.py` — караоке-субтитры ASS: текст сценария 1:1, тайминги из Whisper (difflib-выравнивание).
4. `fetch_audio.py` — музыка + SFX с Freesound (под смысл урока).
5. `scene.html` — 9 сцен, каждая со своей механикой (сетка-фон со свечением, 3D-карточки,
   мозаика, гейдж, осциллограф+эквалайзер, сравнение-бары, формула, аутро). GSAP-таймлайн под тайминги озвучки.
6. `cover.html` — обложка (первый кадр), логотип 1:1 из brand/, сетка+орбита 7 семей.
7. Запись сцены через Playwright (чёрный лидер-маркер для точной синхры) → webm.
8. `assemble.py` — обложка→урок (xfade), озвучка + приглушённая музыка (sidechain) + SFX,
   вшивание караоке, loudnorm. → `oko_lesson1.mp4`.

## Правила (закреплены в CLAUDE.md)
- Всё динамично, ничего статичного; разнообразие приёмов без повторов.
- Логотип только из `oko-app/brand/`. Обложка — первым кадром.
- Промпты генерации — на английском, 2000+ символов, с логотипом-референсом.
