# АКАДЕМИЯ OKO — СПЕЦ СБОРКИ (утверждено Даниэлем 23.07.2026)

Это обязательный ориентир для сборки Академии в приложении. Строить строго по нему.

## Приоритет
СНАЧАЛА приложение на 100% рабочее БЕЗ демо, готовое к запуску. Потом сайт-лендинг.
`okoteam.top/` = приложение.

## 3 направления (не 4)
1. **Медийность** (личный бренд, упаковка, контент, соцсети) — 6 блоков.
2. **Маркетинг** (копирайтинг, хуки, триггеры, стратегия, продвижение, монетизация;
   сюда же вбираем полезное из «Продажи») — 7 блоков.
3. **Нейросети** (практика, деньги, инструменты, вайбкодинг, автоматизация) — 5 блоков, ~27 уроков.

Источник контента: `academy/OKO_ACADEMY_CURRICULUM.md` (Медийность/Маркетинг),
`academy/OKO_ACADEMY_AI_TRACK.md` (Нейросети), `academy/source/` (201 слайд, 101 голосовой).

## Структура
Направление → **несколько блоков** → в блоке **несколько уроков**.
**Сертификат — только после прохождения ВСЕГО направления** (не за урок).
Уроки можно **пропускать** (без жёстких ограничений — вдруг человек уже знает).

## Каждый урок (обязательный состав, именно в этом порядке)
1. **Видео-обучение** — озвучка **голосом Даниэля (клон, XTTS)**, инфографика, моушен,
   караоке-субтитры, всё динамично (стандарт reels-machine). Голос-клон:
   `scratchpad/vclone/OKO_voice_clone/` (reference `daniel_ref_28s.wav` / `_163s.wav`,
   скрипты `oko_voice_pro.py`). НЕ Silero — именно клон Даниэля.
2. **Карусель слайдов** (листаемые слайды из материала — визуальная выжимка).
3. **Текстовое обучение** (конспект, подробно и красиво).
4. **Реальные кнопки-ссылки на приложения** — красивые кнопки, по возможности
   **реферальные** (наша выгода). Инструменты из уроков: ChatGPT, Claude, Gemini,
   Higgsfield, Midjourney, Suno, ElevenLabs, Lovable/Bolt, Cursor, Vercel/Cloudflare,
   n8n/Make/Zapier и т.д.
5. **Тест** (закрепление, порог прохождения, пересдача — уже есть в модуле).
6. **Интерактивные игры** — интересные, полезные, удобные, понятные, закрепляющие материал.
Далее → следующий урок. Прошёл всё направление → сертификат (именной PDF, печать/подпись/лого).

## Голос — НАВСЕГДА для Академии
Все уроки — **клоном голоса Даниэля** (XTTS-v2, локально, безлимит). Образцы в
`OKO_voice_clone/reference/`. Бренд-Silero — только как запасной, если клон недоступен.

## Сертификат
Именной PDF: чёрный+лайм, Bebas Neue+Montserrat, глаз OKO, печать+подпись, уникальный
ID+QR на страницу верификации. Выдаётся ТОЛЬКО по завершении всего направления.
Плюс (для партнёров) официальное приглашение стать партнёром OKO.

## Реф-ссылки (наша выгода)
Все внешние инструменты — через реф-ссылки, где есть партнёрка; иначе обычная кнопка.
Собрать реестр реф-ссылок отдельно и подставлять в кнопки уроков.
