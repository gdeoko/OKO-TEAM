## БЛОК 1. СТАРТ И ПРОМПТИНГ

**Урок 1. Карта нейросетей 2026 — какая модель для чего**
- Текст: ChatGPT-5, Claude, Gemini 3. Картинки: Midjourney V8, Flux 2, Nano Banana Pro, GPT Image 2. Видео: Veo 3.1, Kling 3.0, Runway. Код: Cursor, Claude Code, Lovable. Озвучка: ElevenLabs, edge-tts. Музыка: Suno. Авто: n8n.
- Таблица «задача → модель → цена».

**Урок 2. Промптинг как навык (главный мультипликатор)**
- Формула промпта: Роль + Задача + Контекст + Формат + Примеры + Ограничения.
- Приёмы: «думай пошагово», few-shot (примеры), негативы, итерации.
- Шаблоны промптов под контент/картинки/видео.

**Урок 3. Рабочее место нейродельца**
- Связка ChatGPT + Claude + Gemini (у каждой сильные стороны).
- Агрегаторы (один вход к десяткам моделей): **Higgsfield** (фото/видео/3D), **OpenRouter** (LLM), fal.ai (генерации).
- Расширения, горячие клавиши, хранение промптов.

**Урок 4. ЛАЗЕЙКИ и экономия (топ-урок)**
- **Higgsfield Ultra (~$99/мес) = почти безлимит** множества топ-моделей из одного окна — дешевле, чем платить каждой по отдельности.
- **edge-tts — профессиональная озвучка бесплатно** (мужской/женский рус. голос).
- **n8n self-hosted — автоматизация бесплатно** (только сервер).
- **Kling 3.0 — самое дешёвое видео** (~$0.10/сек, ~$0.84 за 10 сек с звуком).
- Free-планы стопкой, студенческие, реферальные кредиты; VPN для гео-закрытых.
- Осторожно: **Sora закрывают** (веб/апп с 26.04.2026, API с 24.09.2026) — не строить пайплайн на ней.

**Урок 5. Безопасность, этика, авторские**
- Как не спалить «нейронку» (субтитры, живой голос, реальные кадры).
- Дипфейки и лицо: только своё/с согласия; правила площадок.
- Авторские на музыку/картинки; коммерческая лицензия.

## БЛОК 2. КОНТЕНТ НЕЙРОСЕТЯМИ *(главный по деньгам)*

**Урок 1. Тексты, которые продают** — ChatGPT-5 / Claude / Gemini: посты, сценарии Reels, продающие тексты, прогревы. Связка с треком «Маркетинг» (структура поста, хуки).

**Урок 2. Картинки** — когда что:
- **Midjourney V8** ($10/30/60·мес) — арт, эстетика.
- **Flux 2 Pro** (~$0.055/картинка) — фотореализм, открытая.
- **Nano Banana Pro / 2** (~$0.045–0.15) — редактирование, объёмы, текст на картинке.
- **GPT Image 2** — точность промпта и текст.
- **Higgsfield** — всё из одного окна (безлимит на Ultra).

**Урок 3. Аватары и фото с твоим лицом** — **Higgsfield Soul** (обучение цифрового двойника на 5–20 фото), генерация себя в любой сцене. (Ровно то, что мы делали для Даниэля.)

**Урок 4. Видео** — цены за клип и когда что:
- **Veo 3.1** — лучший «всё-в-одном», 4K, родной звук.
- **Kling 3.0** — кинематографично + дёшево (~$0.10/сек), мультишот со звуком.
- **Runway** — под маркетинг: консистентность персонажа, редактор.
- **Higgsfield** — агрегатор всех, дёшево тестировать; Ultra ~$99.

**Урок 5. Озвучка** — **ElevenLabs** (реалистично, ~$5–22/мес), **edge-tts** (бесплатно, рус. голоса), дубляж на языки.

**Урок 6. Музыка** — **Suno** (~$10/мес): треки под ролики, джинглы, фон.

**Урок 7. Автосборка контента** — связка картинка → видео → озвучка → монтаж (караоке-субтитры, инфографика). Это и есть **Контент-завод OKO** — показываем на живом примере.

## БЛОК 3. ВАЙБКОДИНГ *(сайты, приложения, боты — без кода)*

**Урок 1. Что такое вайбкодинг + карта инструментов**
- **Lovable** ($25/мес) — самые красивые аппы «из коробки».
- **Bolt** ($25) — за вечер проверить идею.
- **v0** (free $5 кредитов, $20/мес) — UI от Vercel.
- **Cursor** ($20) — глубокое понимание кода, для сложного.
- **Claude Code** — терминальный агент (то, чем собран сам OKO).
- **Replit** (Core $20 / Pro $95) — облако + деплой.
- Связка-эталон: **Lovable (UI) → Cursor/Claude Code (логика)**.

**Урок 2. Лендинг за вечер** — от идеи до деплоя в Lovable/Bolt, подключение домена.

**Урок 3. Приложение/сервис** — Lovable → Cursor: база данных, вход, оплата.

**Урок 4. Телеграм-бот на ИИ** — без кода, связка с LLM, автоответы.

**Урок 5. Лазейки вайбкодинга** — бесплатные кредиты, шаблоны, бесплатный деплой (Vercel/Cloudflare), как не сжигать токены.

# СИСТЕМА СЛАЙДОВ (как делать — отвечаю на твой вопрос)

Слайды делятся на **2 типа** — так и решаем, что генерить в Hg, а что я строю кодом:

### Тип A — ИНФОГРАФИКА (строю кодом бесплатно, ~70% слайдов)
Таблицы цен, списки, шаги, схемы связок, «до/после», чек-листы. Единый бренд-шаблон
(чёрный + лайм, лого OKO), легко анимируются в видео. **Генерить в Hg не нужно.**

### Тип B — ГЕНЕРАТИВНЫЕ ВИЗУАЛЫ (ты в Higgsfield, ~30%)
Обложки уроков, hero-иллюстрации темы, атмосферные фоны, ИИ-арт-примеры. ~2–3 на урок.
По моим детальным промптам, в стиле бренда.

### Из чего состоит УРОК (шаблон, 8–12 слайдов)
1. **Обложка урока** — тема, номер, лого (тип B или A).
2. **Зачем** — боль/выгода одним экраном (A).
3. **Суть** — 2–4 слайда теории/схем (A).
4. **Инструменты и цены** — таблица (A).
5. **Пошагово/демо** — 2–3 слайда + **кадры реальных действий** (запись экрана) (A + видео).
6. **Лазейка** — секрет/экономия, акцентный слайд (A).
7. **Пример/кейс** — результат (A/B).
8. **Задание (ДЗ)** — карточка (A).
+ **Тест** в конце блока, **экзамен** в конце направления → **сертификат**.

### Итог по объёму (направление Нейросети)
- ~27 уроков × ~10 слайдов = ~270 слайдов.
- Из них тип B (генерить в Hg): ~2–3/урок = **~70 слайдов** → у тебя безлимит, это легко.
- Остальные ~200 — инфографика кодом (бесплатно).
- Видео-уроки — собираю конвейером (озвучка+караоке+инфографика), **0 кредитов**.

**Вывод:** тебе не нужно генерить 1000 слайдов вслепую. Нужно ~70 брендовых визуалов
на направление по моим промптам — остальное строю кодом. Скажу точный список промптов,
когда утвердим программу.
