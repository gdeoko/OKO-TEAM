# КП для Дмитрия — закрытый клуб по видеомонтажу
Живой адрес: https://okoteam.top/kp-dmitry

Адаптация основного КП (oko-app/kp) под оффер Димы Волкова:
Telegram-бот + mini-app клуба по подписке (Lava API, автокик при неоплате),
уроки YouTube+VPS (1080p, 4 урока 4К), домен, сервер.

Тарифы: СТАРТ 50 000₽ (только Telegram) · БИЗНЕС 75 000₽ (+браузер, админка) ·
ПОД КЛЮЧ 100 000₽ (+ИИ-агент 24/7 на Gemini, админка PRO, рассылки, дублирующее меню).
Все сроки — до 10 рабочих дней. Без упоминаний 50/50. Сопровождение 5/7/10 т.₽/мес.
Техрасходы отдельно: домен ~2000₽/год, VPS 2000–5000₽/мес.

- `build.py` — собирает kp_dmitry.html из шаблона основного КП (замены текстов+тарифов)
- `gen_contracts.py` — генерирует 3 договора из эталона (docx, XML-правки):
  цена/состав работ/сроки 10 раб.дней/поэтапная оплата/пункт 2.4 о сопровождении
- Договоры встроены в кнопки «Скачать договор» каждого тарифа
- Ассеты (glb, спрайты, видео) — общие с /kp, скопированы на VPS в kp-dmitry/
