## 1. Кратко

Собран **полный кликабельный прототип OKO** — весь путь пользователя и все разделы
приложения работают как единый продукт: splash → вход → онбординг → мессенджер,
лента, биржа, мини-аппы, партнёрка, профиль, оплата. Общий чат — **уже настоящий**
(Supabase Realtime). Проверено на Android/iPhone/десктоп: 0 ошибок, 0 багов вёрстки.

Дальше — подключение реального бэкенда (после домена и хостинга): Telegram-вход,
платёжки, ИИ-мини-аппы на живых данных, медиа в S3.

## 2. Что уже работает ПО-НАСТОЯЩЕМУ (не мок)

- ✅ **Живые чаты через Supabase Realtime** — все комнаты (общий чат + группы + каналы).
  Сообщения реально доставляются между всеми, кто открыл ссылку. История в базе.
- ✅ **Анонимный вход** (Supabase Auth) — гостевые профили `Гость-XXXX`.
- ✅ **Защита базы (RLS)** — Row Level Security на всех 28 таблицах; писать можно только
  в свой профиль и в предопределённые чаты, чужие таблицы закрыты. Проверено двумя клиентами.
- ✅ **Инфраструктура развёрнута:** Supabase (28 таблиц), S3 (2 бакета, lifecycle 24ч),
  Telegram-бот @okoappbot, Gemini (3 ключа), Claude API — подключены и проверены.
- ✅ **Сервер-каркас** `oko-app/server` (Fastify + Supabase, ключи sb_/JWKS) — готов к наращиванию.

## 5. Что осталось по ТЗ (крупными блоками)

**Бэкенд-интеграция (после домена/хостинга):**
1. **Авторизация** — вход через Telegram (@okoappbot, initData / Login Widget), телефон/e-mail,
   один аккаунт на всех устройствах, привязка реф-кода к партнёру.
2. **Мессенджер live** — медиа через presigned S3 (фото/видео/файлы), запись голосовых и
   кружочков на клиенте + сжатие, реальные статусы доставлено/прочитано/печатает, личные чаты
   между реальными пользователями (сейчас общие комнаты).
3. **Лента live** — посты/комментарии/реакции в БД, медиа в постах.
4. **Оплата** — Lava.top + крипта + рублёвый эквайринг, вебхуки → активация лимитов,
   TG Stars в Mini App, тарифный middleware во всех модулях.
5. **Мини-аппы на живых данных:**
   - Система роста → очередь → Claude API (MASTER-TZ) → HTML-система → S3 → кабинет + превью Даниэлю.
   - Видео-премодератор → Gemini-анализ → «исправить» (ffmpeg) → постинг VK/TG.
   - Партнёрка → реальные клики/регистрации/оплаты/начисления, заявки на выплату.

**Более крупные модули (по плану ТЗ, дни 11–15):**
6. **ИИ-штат** — агент «Поддержка» (RAG по базе знаний, «позвать человека» → @okohelp),
   агент «Ассистент» (командный чат Даниэля, утренний отчёт, команды → n8n).
7. **Контент-завод** (Business/Scale) — n8n-пайплайн: контент-план → сценарии (Claude) →
   Fliki рендер → Whisper субтитры + ffmpeg → постинг по расписанию → метрики.
8. **Звонки** — LiveKit 1-на-1 и групповые, запись в S3.
9. **TG Mini App** — веб-сборка ядра + @telegram-apps/sdk, бот-уведомитель.
10. **Админка** — пользователи, подписки, платежи, начисления/выплаты, фича-флаги, логи агентов, метрики.
11. **Безопасность/лимиты** — rate-limiting на нейро-эндпоинты, шифрование токенов соцсетей,
    роли user/partner/staff/admin, антиспам в чатах.

**Стек-переход:** прототип сейчас — самодостаточный HTML. По ТЗ ядро — React Native + Expo
(iOS/Android/Web из одного кода). Прототип служит эталоном UI/UX для переноса в Expo.

## 6. Критерии готовности к запуску (из ТЗ, раздел 5)

- [ ] Регистрация по реф-ссылке начисляет партнёру
- [ ] Оплата любого тарифа активирует лимиты моментально (в прототипе активация статуса — ✅ мок)
- [ ] Чат: 200 сообщений/сек без деградации (нагрузочный тест)
- [ ] Система по анкете: результат уровня ручных работ (5 реальных анкет)
- [ ] Премодератор: цикл загрузка → анализ → исправление → постинг в VK/TG
- [ ] Агент поддержки не выдумывает (тест на 50 вопросах вне базы)
- [x] Инфраструктура автоудаления временных видео настроена (S3 lifecycle 24ч)
- [ ] Кнопка «позвать человека» доходит до @okohelp
