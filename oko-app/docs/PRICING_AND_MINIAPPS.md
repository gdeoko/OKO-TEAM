## Мини-аппы (10 штук в grid'е)

Что уходит из grid'а: Профиль, Поддержка, Тарифы, Настройки (в шапку/меню).

```
Ряд 1: 🎓 Академия      🤖 Ассистент     🚀 Система       ⚡ Контент-завод
Ряд 2: 📸 Проверка      🎨 AI-студия     🎭 AI-двойник    📊 Аналитика
Ряд 3: 💡 Тренды        💰 Партнёрка
```

### Что делает каждый

1. **Академия OKO** — 136 уроков, тесты, игры, сертификаты (бесплатно всем)
2. **Ассистент OKO** — Claude-чат с памятью о нише, Системе, истории пользователя
3. **Система Роста** — 6-раздельная автогенерация по анкете, обновление ежемесячно
4. **Контент-завод** — конвейер роликов/постов/каруселей/сторис под ключ
5. **Проверка видео** — моментальный ИИ-разбор + автоисправление 3-5 мин
6. **AI-контент-студия** — копирайтер + генератор идей + мозговой штурм голосом + дизайн-упаковка
7. **AI-двойник** — клон голоса (XTTS) + клон лица (Higgsfield Soul)
8. **Аналитика соцсетей** — метрики подписчиков, охватов, ER + прогноз
9. **Каталог трендов** — вирусные форматы по нишам (обновление 2×/нед)
10. **Партнёрка** — многоуровневая (L1 15%→5%, L2 5%), реальные выплаты, турниры

### Мои соцсети (привязка каналов)

НЕ мини-апп. Уходит в шапку/профиль или отдельный раздел настроек. Там:
- Подключить IG (Meta Graph API, требует верификации OKO в Meta)
- Подключить TG (свой бот @okoappbot)
- Подключить VK (vk_api + OAuth)
- Подключить YouTube (YouTube Data API v3)
- Подключить TikTok (нужно одобрение TikTok Developer)
- Подключить Дзен (ограниченный API)
