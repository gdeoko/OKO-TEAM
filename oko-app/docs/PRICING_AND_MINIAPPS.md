# Тарифная сетка OKO и мини-аппы — ФИНАЛ (утв. 28.07.2026)

## 🎯 Ключевые правила

1. **Никакого ИИ в UI приложения.** Везде «команда OKO / специалист / эксперт»,
   а не «Claude / Gemini / ИИ / нейросеть». Клиент не должен догадаться.
2. **Живая команда OKO** = набор ИИ-агентов + Даниэль как единственный
   реальный человек. В будущем — тех.спецы для контроля.
3. **Тайминги функций** должны быть реалистичные для «живой команды»:
   не 5 секунд, а 15-60 минут для проверки, 4-6 часов для генерации Системы,
   1-3 дня для сборки роликов и т.д. Внутри работает быстро — снаружи виден
   правдоподобный процесс с уведомлениями «команда в работе».
4. **Автоматизация полная на низких чеках** (START/PRO/BUSINESS).
   Даниэль подключается только на BUSINESS PRO/MAX.
5. **Что делает Даниэль сам вручную** через Claude Code: сайты, лендинги,
   боты, автоматизации, ИИ-агенты (это ЕГО реальная услуга поверх подписки).

## Правило таймингов (важно!)

Все автоматические процессы должны выглядеть как работа живой команды.

| Функция | Реально работает | Показываем клиенту |
|---|---|---|
| Проверка видео | 15-30 сек | «Команда монтажёров изучает ролик… 10-15 минут» → приходит уведомление |
| Автоисправление | 30-90 сек | «Монтажёр исправляет ролик… 30-40 минут» |
| Генерация Системы Роста (первый раз) | 2-5 мин | «Аналитик изучает вашу нишу… Копирайтер собирает контент-план… Дизайнер оформляет систему… Готово через 4-6 часов» |
| Обновление Системы (ежемес) | 1-2 мин | «Команда обновляет контент-план на новый месяц… 2-3 часа» |
| Сценарий ролика (Контент-завод) | 10 сек | «Сценарист пишет сценарий… 30-60 минут» |
| Полный ролик (Контент-завод) | 2-5 мин | «Монтажёр собирает ролик… 3-6 часов» |
| Личный помощник (Ассистент) | 3-10 сек | Быстро (как чат-эксперт) — 3-10 сек ок |
| Публикация в соцсети | моментально | «Отправляем в очередь публикаций… опубликуем в лучшее время» |
