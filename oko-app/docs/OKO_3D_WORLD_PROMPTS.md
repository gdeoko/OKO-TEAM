# OKO — промпты для 4K-картинок → 3D-мир в MIND

> Метод: asset-first. Сначала генеришь МАСТЕР (Core Eye) — он задаёт стиль. Потом модули в ТОМ ЖЕ стиле.
> Модель: **nano_banana_pro** (4K/текст) или gpt_image_2. Разрешение 2K–4K. **2–4 варианта/ракурса на объект.**
> Для MIND (image→3D): объект изолирован, в кадре целиком, нейтральный near-black фон, ровный свет.
> Каждый объект потом: `upload_reference_image` → `start_model_generation` (multi_image_to_3d при 2–4 ракурсах) → approve → GLB.
