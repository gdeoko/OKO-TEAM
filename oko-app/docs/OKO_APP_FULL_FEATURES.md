> Один взгляд — всё твоё дело. OKO собирает лучшее из **Telegram** (чаты, каналы,
> звонки), **VK** (лента, мини-приложения), **Instagram** (алгоритмы, охваты),
> **Avito** (биржа) и **Zoom** (созвоны) — и добавляет сверху **ИИ-штат** и
> **конвейеры автоматизации**. Не десять вкладок, а один поток.
>
> Бренд: чёрный + лайм #9AFF00, Bebas Neue + Montserrat, кинематографичный
> минимализм уровня Apple/Tesla. Тёмная и светлая темы. Никаких эмодзи в UI —
> только фирменные SVG-иконки. Владелец: OKO TEAM (@ktodaniel).

## 1. МЕССЕНДЖЕР — ядро (уровень Telegram)

Сердце OKO. Реалтайм через Supabase — сообщения долетают мгновенно между всеми.

### 1.1 Типы диалогов
- **Личные чаты** — один на один, сквозная история.
- **Группы** — до 200 000 участников, роли, права.
- **Каналы** — вещание на подписчиков, посты уходят в ленту.
- **Сообщества** — канал + чаты + мини-аппы под одной крышей (гибрид Telegram-канала и VK-группы).

### 1.2 Сообщения — всё, что умеет топовый мессенджер
- **Текст** с форматированием, ссылками, упоминаниями @, хэштегами.
- **Фото / видео / файлы** — через presigned S3 напрямую с устройства (лимит по тарифу: Free 100 МБ, Start/Pro 2 ГБ, Business/Scale — без лимита).
- **Голосовые сообщения** — запись на клиенте, волна-визуализация, сжатие.
- **Видео-кружочки** — как в Telegram, запись с камеры, круглый плеер.
- **Опросы** — варианты, проценты, анонимность.
- **Стикеры** — 12+ фирменных наборов OKO (глаз, лайм-персонаж, реакции).
- **Гео, контакты, «деньги»** (запрос/перевод) — из меню вложений.

### 1.3 Действия над сообщением (контекстное меню)
Долгий тап → 8 быстрых реакций + стикеры, и меню: **Ответить** (с цитатой),
**Копировать**, **Переслать**, **Редактировать**, **Закрепить**, **Выделить**,
**Удалить** (у себя / у всех).

### 1.4 Статусы и присутствие (живой слой)
- **Онлайн / был(а) недавно** — presence в реальном времени.
- **«Печатает…»** — видно, кто набирает.
- **Галочки доставлено / прочитано**.
- **Реакции в реальном времени** — прилетают всем сразу.

### 1.5 Организация
- **Папки чатов**: Все / Личные / Группы / Каналы, свои папки.
- **Бейджи непрочитанного**, закреплённые сверху.
- **Поиск** по чатам, по сообщениям, по людям и каналам.
- **Пустые состояния** — красивые, с приглашением начать.

### 1.6 Управление каналом / сообществом
Статистика (охваты, подписчики, вовлечённость), **продвижение** (тарифы охвата),
кто может писать, админы и права, закреплённые посты, ссылки-приглашения,
**монетизация** (платная подписка на канал — в дорожной карте).

## 3. ЛЕНТА (VK + Instagram: алгоритмы + охваты)

### 3.1 Две вкладки
- **Подписки** — хронологически, всё от тех, на кого подписан.
- **Рекомендации** — ранжирует алгоритм OKO (свежесть + вовлечённость; ML-алгоритмы после накопления данных). Как в Instagram, а не мёртвая лента VK.

### 3.2 Посты
- Текст, фото, видео, **карусели**, ссылки.
- **Лайки, комментарии** (живые, реалтайм), **репост в чат**, **сохранённое**.
- Меню поста: пожаловаться, скрыть, копировать ссылку, статистика.

### 3.3 Продвижение (встроенный доход)
- **Реклама поста** — платно: пост показывается целевой аудитории, метка «Реклама», поднимается в топ рекомендаций (охваты, гео, интересы).
- **Продвижение канала** — тарифы охвата, буст подписчиков.

### 3.4 Сторис
- Кольца сторис сверху ленты, **просмотрщик с прогресс-баром**, ответы, реакции.
- Создание сторис: фото/видео/текст, наложения бренда.

## 6. МИНИ-АППЫ (15+, главный раздел «Сервисы»)

Каждый мини-апп = экран на общем каркасе + мост к API (`window.OKO.call`) +
доступ и лимиты по тарифу. Ниже — **всё**, что запланировано, волнами.

### ВОЛНА 1 — ЗАПУСК (15 июля)

**1. Система роста по анкете** ⭐ флагман · *Pro и выше*
Анкета из **8 секций** (кто ты, ниша, цель, площадки, аудитория, время, формат,
бюджет) → Claude по мастер-промпту (MASTER-TZ) собирает **персональную систему
продвижения** уровня ручной работы → готовая **HTML-система** в фирменном стиле →
в личный кабинет клиента. На выходе — конкретный план на 30 дней: формат контента,
ритм постинга, площадка-ядро, воронка под цель, стратегия под бюджет. Превью
уходит в командный чат Даниэля → [ОК / Правка] → выдача клиенту.

**2. Видео-премодератор** ⭐ вирусный магнит · *Free 1/мес → Business без лимита*
Загрузка ролика (до 10 ГБ) → **Gemini-анализ**: кольцо готовности в %, вероятность
попадания в рекомендации, **сила хука в первые 3 секунды**, удержание, качество
звука и картинки, попадание в тренд, **риски** (авторская музыка, нет субтитров,
нарушение политик), технические параметры. Кнопка **«Исправить одним кликом»** —
перегенерация обложки и субтитров, пересборка ffmpeg. Кнопка **«Опубликовать»** —
постинг во все подключённые сети. Исходники автоудаляются через 24 часа.

**3. Партнёрский кабинет** ⭐ двигатель роста · *Start и выше*
Реф-ссылка (приложение + сайт) + **QR**. Статистика в реальном времени:
клики → регистрации → оплаты → начисления (**15% L1 / 5% L2**, ступень 15%→5%
после 6 месяцев подписки клиента). **Живой график** дохода (7/30/90 дней). История
начислений и выплат, **заявка на выплату** (карта / USDT / Lava), реквизиты.
Материалы для продвижения (креативы, тексты, обучение).

**4. Биржа услуг** — см. §4 (полноценный Avito внутри).

**5. Контент-завод** · *Business / Scale* — см. §8 (конвейер роликов под ключ).

### ВОЛНА 2 — АВГУСТ

**6. Генератор сценариев**
Ниша + формат → Claude выдаёт сценарии Reels/Shorts по структурам залетевших
роликов: хук, тело, оффер, призыв. Варианты хуков A/B.

**7. Генератор каруселей**
Тема → многослайдовая карусель (заголовки, тезисы, дизайн-сетка бренда) готовая
к постингу.

**8. Распаковка личности** (пробник Системы)
Мини-анкета → ИИ вытаскивает сильные стороны, темы, тон-оф-войс, позиционирование.
Бесплатный «вкус» флагманской Системы — заводит в воронку Pro.

### ВОЛНА 3 — ОСЕНЬ

**9. Анализ конкурентов**
Ссылки на конкурентов → разбор контента, форматов, частоты, сильных приёмов →
что забрать себе.

**10. Трендвотчер** (еженедельный, удержание)
Каждую неделю — актуальные тренды, звуки, форматы под твою нишу. Причина заходить
в приложение постоянно = якорь подписки.

**11. Прогрев-конструктор**
Собирает прогрев под запуск/оффер: последовательность сторис/постов, тайминг,
триггеры, призывы.

### ВОЛНА 4 — ДАЛЕЕ

**12. Генератор лид-магнитов**
Гайд/чек-лист/мини-курс из твоей экспертизы → готовый PDF/страница для сбора базы.

**13. Документы** (КП / договор / оферта)
Юнит-конструктор деловых документов под самозанятых/ИП: коммерческое предложение,
договор, оферта, акт — по реквизитам и параметрам сделки.

**14. Юнит-экономика**
Калькулятор экономики продукта/услуги: себестоимость, маржа, точка безубыточности,
сценарии «что если».

**15. Нетворкинг-рулетка**
Случайные полезные знакомства внутри OKO по нишам/целям — комьюнити-механика.

### ПЛЮС (конвейеры/конструкторы)
- **Сайт по клику** (*Business*) — из Системы собирается лендинг по фирменной сетке.
- **Конструктор ботов** — конфиг под готовый движок из анкеты.
- **CRM-лайт** (*Pro*) — простая воронка сделок/лидов внутри приложения.

## 7. ИИ-ШТАТ (агенты)

Агент = роль (системный промпт) + база знаний + инструменты. Оркестрация n8n,
модели Claude/Gemini по задаче.

### На запуск
**1. Поддержка** — 24/7 во всех чатах и личке. Отвечает **только из базы знаний**
(RAG: тарифы, инструкции, FAQ, кейсы). Не знает → честно говорит «уточню у команды»
и **эскалирует человеку** (@okohelp). Кнопка **«позвать человека»** всегда рядом.
Деньги/возвраты/споры — сразу к человеку, сам не решает.

**2. Ассистент** (командный чат Даниэля) — **утренний отчёт** (регистрации, оплаты,
MRR, чистыми, проблемные диалоги), принимает **команды человеческим языком** →
черновик действия → исполнение через n8n.

### Обновление
**3. Продажник-прогрев** — онбординг новых: ниша → кейсы → тариф.
**4. Менеджер клиента** — онбординг платных, напоминания по шагам, удержание.

Железные правила: всегда кнопка «позвать человека»; агент не трогает деньги/возвраты;
первые 2 недели все диалоги читаются, промпты правятся; никакого внешнего спама.

## 8. КОНТЕНТ-ЗАВОД (конвейер под ключ, Business/Scale)

Мини-апп + бэкенд-конвейер, который делает ролики **за клиента**:

`контент-план из Системы → агент-сценарист (Claude, форматы залетевших роликов) →
Fliki (рендер) → Whisper (субтитры с таймкодами) + ffmpeg (прожиг субтитров +
обложка Gemini) → очередь постинга → публикация по расписанию (VK/TG на старте,
далее IG/YT/TT) → агент-аналитик снимает метрики по API → корректирует следующий
контент-план по тому, что принесло просмотры/заявки.`

**Панель клиента**: календарь публикаций, статусы каждого ролика (сценарий →
озвучка → монтаж → субтитры → готово → опубликовано), метрики охватов. Кнопка
подтверждения Даниэля перед выдачей (отключается поклиентно). Себестоимость ролика
$0.5–1.5. Живой монтажёр — только на Scale.

## 10. ПАРТНЁРСКАЯ ПРОГРАММА (двигатель дистрибуции)

- **2 уровня** (юридическая чистота): **15%** с оплат приведённого клиента,
  **5%** с оплат клиентов его партнёров.
- Ступень: 15% первые 6 месяцев подписки клиента, далее 5%.
- Персональная реф-ссылка на приложение и сайт, QR.
- Кабинет в реальном времени: клики, регистрации, оплаты, начисления, выплаты.
- **Скорость и прозрачность выплат = главный фактор роста сети.**
- Партнёрам: бесплатное обучение маркетингу/нейронкам + соавторство со страницами OKO.
- Работают только за %, без фиксов. Цель: 300 активных к сентябрю, 1000 к декабрю.

## 12. СКВОЗНЫЕ СИСТЕМЫ

- **Глобальный поиск** — по чатам, людям, каналам, постам, сервисам.
- **Центр уведомлений** — сообщения, реакции, начисления, системные.
- **Онбординг** — 4 брендовых экрана при первом входе.

- **Тёмная / светлая тема**, mobile-first, safe-area, микроанимации.

## 13. БЕЗОПАСНОСТЬ И ЛИМИТЫ
