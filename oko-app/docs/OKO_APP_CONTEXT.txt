Expo), из которого собираются все витрины.

Запуск 15 июля 2026:

- Telegram Mini App — ФУЛ-ВЕРСИЯ (не лайт). Ограничения платформы:
  пуши шлёт бот-уведомитель; звонки открываются во внешнем браузере

Второй эшелон (август):
- RuStore (бесплатно, модерация пара дней)
- Google Play ($25 разово; новым аккаунтам обязательное закрытое

Все клиенты — «морды» к одному API. Данные только на сервере.
Обновления логики — мгновенно у всех без модерации сторов.

6. ИИ-ШТАТ (АГЕНТЫ)
----------------------------------------------------------------
Агент = роль (системный промпт) + база знаний + инструменты.
Оркестрация: n8n. Модели: Claude / GPT по задаче.
Себестоимость: токены API (~$30-100/мес на агента поддержки
при 1000 пользователей).

Состав на запуск:
  1) ПОДДЕРЖКА — 24/7 во всех чатах и личке, отвечает только из
     базы знаний, не знает -> честно говорит и эскалирует человеку.
  2) АССИСТЕНТ (командный чат Даниэля) — утренние отчёты
     (регистрации, оплаты, проблемные диалоги), принимает команды
     человеческим языком, раздаёт задания другим агентам.
Первое обновление:
  3) ПРОДАЖНИК-ПРОГРЕВ — онбординг новых: ниша -> кейсы -> тариф.
     Деньги/скидки/обещания — только эскалация.
  4) МЕНЕДЖЕР КЛИЕНТА — онбординг платных, напоминания по шагам,
     контроль результатов. Работает на удержание.

Железные правила:
- У клиента всегда есть кнопка «позвать человека».
- Агент не решает вопросы денег, возвратов, обещаний.
- Первые 2 недели все диалоги читаются, промпты правятся.
- Наружный спам (массовые отклики на чужих площадках) — не делаем:
  баны аккаунтов и доменов. Агенты работают внутри продукта.

7. КОНВЕЙЕРЫ АВТОМАТИЗАЦИИ
----------------------------------------------------------------
КОНТЕНТ-ЗАВОД (тарифы Business/Scale):
  контент-план из Системы клиента -> агент-сценарист (Claude,
  форматы залетевших роликов) -> Fliki API (рендер) -> Whisper
  (субтитры с таймкодами) + ffmpeg (прожиг субтитров + обложка из
  Gemini; CapCut не нужен, публичного API у него нет) ->
  автопостинг по расписанию -> агент-аналитик снимает метрики по
  API соцсетей -> корректирует следующий контент-план по роликам,
  которые принесли просмотры/заявки. Ежедневные отчёты клиенту и
  в командный чат.
  Себестоимость ролика: $0.5-1.5 (40-80₽). Подрядчики (200₽/ролик)
  не нужны на массовых тарифах. Живой монтажёр-редактор — только
  Scale (докрутка ключевых роликов).

СБОРКА СИСТЕМ / САЙТОВ / БОТОВ (Pro/Business/Scale):
  анкета -> Claude API (мастер-промпт = MASTER-TZ) -> HTML Система /
  сайт по шаблонной сетке / конфиг бота под готовый движок.
  Кастомные сайты от 100к₽ — руками.

КОНТРОЛЬ КАЧЕСТВА: первые 1-2 месяца между «агент сделал» и «ушло
клиенту» — кнопка подтверждения в командном чате (превью -> ок /
правка). При стабильном качестве — полный автомат поклиентно.

ПОСТИНГ ПО API: Instagram (нужен бизнес-аккаунт + страница FB),
YouTube, TikTok (нужна заявка на одобрение приложения), VK, TG.

8. ИНФРАСТРУКТУРА И ХРАНИЛИЩЕ
----------------------------------------------------------------
- VPS: Timeweb Cloud (старт 1500-3000₽/мес). НЕ webhost1.
- БД + realtime чаты: Supabase (Postgres + Realtime).
- Медиа: объектное хранилище S3 (Timeweb S3 / Selectel / R2).
  Оплата по факту (~1.5-2₽/ГБ/мес). Терабайт заранее НЕ нужен:
  1000 юзеров = 50-200 ГБ в первые месяцы.
- Загрузка файлов: presigned URL — файлы летят с устройства прямо
  в S3, минуя сервер. Крупные файлы — multipart.
- Раздача: CDN поверх S3.
- Лимиты по тарифам: Free до 100 МБ/файл, Start/Pro до 2 ГБ,
  Business/Scale без ограничений.
- Временные файлы (видео на проверку до 10 ГБ): lifecycle policy,
  автоудаление через 24 часа после анализа.
- Звонки: LiveKit SDK (не пишем сами). Поток не хранится; запись
  созвона — фича платных тарифов, пишется в S3 (~0.5-1 ГБ/час).
- Сжатие медиа на лету.
- Свой физический сервер — не раньше 20-30к активных.

9. ЭКОНОМИКА
----------------------------------------------------------------
Целевая чистая маржа: 50%+.
Структура расходов (% от выручки, при $50-100к/мес):
  партнёрка 12-14, платёжки 6-8, нейронки/рендер 8-12,
  инфраструктура 2-3, команда 10-13, налоги (ИП УСН 6%) 6-7,
  реклама 0 (её роль выполняет партнёрка).
  Итого 44-57% -> рычаги удержания маржи:
  1) ступенчатая партнёрка (15% -> 5% после 6 мес),
  2) доп. пакеты сверх лимитов с маржой 60-70%,
  3) годовые тарифы −20% (деньги вперёд, отвал ноль).
Почти все расходы переменные — модель защищена от минуса.

Платежи: Lava.top + крипта + рублёвый эквайринг. Биллинг сторов не
используем (комиссия 15-30% + недоступен в РФ). Юрлицо: ИП РФ ->
ESL Дубай (бюджет $20к) — с прибыли, после выхода на обороты.
