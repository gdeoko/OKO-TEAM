# OKO APP — план на 6 дней до запуска (v0.21 → v1.0), старт 09.07, запуск 15.07

Решение: продукт запуска — веб/PWA на базе `oko-app/prototype/index.html` (живая витрина
по публичной ссылке). Все API-подключения — в конце, разом, перед запуском. Expo-нативка —
после запуска. Работаю автономно, без пауз, деплой после каждого блока.

Эталоны функционала: **Avito** (биржа), **Telegram** (мессенджер, профиль, реакции),
**ВКонтакте** (лента, сообщества) — берём лучшее из каждого в единое приложение с алгоритмами.

- [x] Категории-направления (сетка с иконками)

- [x] Детальная карточка (галерея, описание, продавец, отзывы)
- [x] Личный кабинет продавца (мои объявления, статусы, статистика)

- [x] Избранное (отдельная вкладка)
- [x] Чат с продавцом внутри мессенджера
