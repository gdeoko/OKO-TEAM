# WebGL / премиум-сайты — база приёмов (копим из расшифровок)

> Живая база знаний. Даниэль кидает расшифровки роликов → сюда выжимаются конкретные техники.
> Читать в начале сессий по сайтам. Каждый приём — проверяемый, с параметрами.

---

## №1 — Хром / полированный металл (источник: weblove)
**Задача:** сделать зеркальный хром/сталь.
- НЕ пытаться сделать «светом». Секрет — **envMap** (карта окружения).
- Материал: `MeshStandardMaterial` с **metalness ≈ 1** и **roughness ≈ 0**, затем задать ему **envMap**.
- Поверхность зеркалит окружение → сразу читается как отполированная сталь.
- Практика для нас: envMap можно испечь через `PMREMGenerator.fromScene(...)` или снять `CubeCamera`.
  Это рендерится и в headless (в отличие от `transmission`, который на swiftshader чёрный).

## №2 — «Жидкое» превращение формы (vertex displacement)
**Задача:** чтобы форма «дышала и плавилась», а не стояла на месте.
- **Анимированный vertex displacement**: шумовая функция (noise) сдвигает точки геометрии **каждый кадр**.
- Реализация: в вершинном шейдере смещать `position` вдоль нормали на `noise(pos*scale + uTime)`;
  либо на CPU гонять позиции. Форма постоянно морфится/пульсирует.
- Это ровно то «стекло рассыпается/собирается» с референсов — делается шумом по вершинам.

## №3 — Один акцентный цвет (emissive + монохром) — принцип силы
**Задача:** чтобы акцент был «мощным».
- **Одно ядро** = `emissive` материал с **ОДНИМ hex-цветом**.
- Вся страница работает на **одной цветовой палитре**, всё остальное — **монохром**.
- Именно эта **сдержанность** делает акцент сильным. (Для OKO: лайм #9AFF00 как единственный акцент на near-black.)

---
_Как применять к OKO:_ хром-глаз OKO = приём №1 (metalness1/rough0/envMap); «живой» глаз = приём №2
(vertex displacement); вся палитра — приём №3 (лайм-акцент + монохром-чёрное).
Приёмы №1 и №2 рендерятся в headless → агент может проверять их сам, не вслепую.
