# WebGL / премиум-сайты — база приёмов (копим из расшифровок)

> Живая база знаний. Даниэль кидает расшифровки роликов → сюда выжимаются конкретные техники.
> Читать в начале сессий по сайтам. Каждый приём — проверяемый, с параметрами.

---

## №1 — Хром / полированный металл (источник: weblove)
**Задача:** сделать зеркальный хром/сталь.
- НЕ пытаться сделать «светом». Секрет — **envMap** (карта окружения).
- Материал: `MeshStandardMaterial` с **metalness ≈ 1** и **roughness ≈ 0**, затем задать ему **envMap**.
- Поверхность зеркалит окружение → сразу читается как отполированная сталь.
- Практика для нас: envMap можно испечь через `PMREMGenerator.fromScene(...)` или снять `CubeCamera`.
  Это рендерится и в headless (в отличие от `transmission`, который на swiftshader чёрный).

## №2 — «Жидкое» превращение формы (vertex displacement)
**Задача:** чтобы форма «дышала и плавилась», а не стояла на месте.
- **Анимированный vertex displacement**: шумовая функция (noise) сдвигает точки геометрии **каждый кадр**.
- Реализация: в вершинном шейдере смещать `position` вдоль нормали на `noise(pos*scale + uTime)`;
  либо на CPU гонять позиции. Форма постоянно морфится/пульсирует.
- Это ровно то «стекло рассыпается/собирается» с референсов — делается шумом по вершинам.

## №3 — Один акцентный цвет (emissive + монохром) — принцип силы
**Задача:** чтобы акцент был «мощным».
- **Одно ядро** = `emissive` материал с **ОДНИМ hex-цветом**.
- Вся страница работает на **одной цветовой палитре**, всё остальное — **монохром**.
- Именно эта **сдержанность** делает акцент сильным. (Для OKO: лайм #9AFF00 как единственный акцент на near-black.)

---
_Как применять к OKO:_ хром-глаз OKO = приём №1 (metalness1/rough0/envMap); «живой» глаз = приём №2
(vertex displacement); вся палитра — приём №3 (лайм-акцент + монохром-чёрное).
Приёмы №1 и №2 рендерятся в headless → агент может проверять их сам, не вслепую.

## №4 — Чек-лист «дорогого» сайта ($10k vs $200) — планка качества
8 признаков, отличающих премиум-сайт от шаблона (по чему судить свою работу):
1. **Точка зрения** — уникальность, своя идея; не «ещё один шаблон».
2. **Типографика** — продуманные шрифты, размеры, трекинг, иерархия.
3. **Сдержанная палитра** — мало цветов (см. приём №3: один акцент + монохром).
4. **Иерархия** — ясно, что главное, что второстепенное; взгляд ведётся.
5. **Качественные изображения** — реальные ассеты, не стоковые заглушки (см. asset-first, п.3b стратегии).
6. **Тонкая анимация** — микро-движение, не «дискотека»; появления, параллакс, плавность.
7. **Адаптивность** — идеально на мобиле (Даниэль смотрит с телефона — это критично).
8. **«Невидимые» детали** — скорость, плавность, отсутствие лагов/швов.

## №5 — Процесс сборки (как строить, чтобы вышло дорого)
- **Использовать установленные скиллы:** `frontend-design`, `ui-ux-pro-max` — они задают высокий стандарт
  дизайна и уводят от «заезженных» дефолтов. Применять ПЕРЕД сборкой UI.
- **Точный бриф + референсы-скриншоты** — качество прямо зависит от детальности запроса и приложенных
  примеров стиля. Чем конкретнее — тем ближе к желаемому.
- **Итерации по КОНКРЕТНОМУ фидбеку** — задача → вариант → «вот это не так» → точечная правка
  (см. также asset-first п.3b: не гадать, читать фидбек, чинить конкретное, проверять свой вывод).
- **Медиа — сторонними инструментами**, потом интеграция (у нас: Higgsfield для картинок/видео/3D).
- **Деплой** — у нас Higgsfield website (true-journey-418), не Hostinger/Vercel.

## №6 — 7 уровней сайтов на Claude Code (лестница качества, источник: Jack / Hermes)
Принципы накапливаются — каждый уровень поверх предыдущего:
1. **«Хватай и иди»** — просто «сделай мне сайт» как чат-боту. Качество ~3/100. Классический «AI-сайт».
2. **Скриншоты + ссылки-референсы** — «показывай, не рассказывай». ~10/100, но скачок.
   Ресурсы для мудборда/референсов: **Godly.io, Land-book, Awwwards, Dribbble** (+ Halo Lab и т.п.).
   → берёшь понравившийся экран → скидываешь агенту как референс стиля.
3. **Дизайн-скиллы** — установить и ИСПОЛЬЗОВАТЬ: `frontend-design`, `ui-ux-pro-max` (67 стилей, 106 палитр,
   пары шрифтов), `shadcn`. Скиллы кодифицируют экспертизу дизайна → большой скачок. (У НАС ОНИ ЕСТЬ.)
4. **Медиа, не только текст/графика** — картинки и видео. Дать агенту генератор через **MCP** → он программно
   генерит все ассеты сам. (У НАС = Higgsfield MCP. Это ровно наш уровень 4+.)
   Тех-детали генерации картинок: 2–4 варианта; **2K достаточно** (4K не нужен, 1K мало); аспект под кадр (21:9 для широких hero).
5–7. **Дальше** (в ролике не раскрыто — промо к платному курсу): «серьёзный скачок качества», дизайн-системы,
   память, монетизация. Догоним из следующих расшифровок, если будут.

**Где мы:** у нас уже есть уровень 3 (скиллы) + уровень 4 (Higgsfield MCP для медиа) + метод asset-first (п.3b).
То есть по этой лестнице мы уже высоко — не хватает только собрать реальный OKO по всему стеку.
