# АКАДЕМИЯ OKO — план и видение (обучение × партнёрка)

> Мини-апп «Академия OKO» — обучающий движок, встроенный в приложение и **тесно
> связанный с партнёрской программой**. Партнёр обучается маркетингу, продажам,
> медийности и нейросетям, получает **именные сертификаты** и **официальное
> приглашение стать партнёром OKO**, и только потом идёт зарабатывать. Обученный
> партнёр продаёт больше → сеть растёт → это маховик роста вместо рекламы.
>
> Источник контента: методология Артёма (текст — уже в агенте), 947 фото-слайдов,
> 101 голосовой урок (расшифровка через Gemini), видео-уроки (ждём недостающие
> части архива).

---

## 1. ЗАЧЕМ (бизнес-логика, а не просто «курс»)

Академия работает сразу на 3 цели:
1. **Маховик партнёрки.** Обученный партнёр = продаёт лучше = приводит больше
   клиентов = сеть растёт. Реклама не нужна, её роль выполняет обучение + %.
2. **Продажник самого приложения.** Оффер: «оформи партнёрку → получи обучение +
   сертификат + именное приглашение стать партнёром OKO». Сильный крючок на START.
3. **Монетизация знаний.** Кто не хочет в партнёрку — покупает доступ к курсам по
   тарифам (START/PRO). Отдельный поток ценности внутри подписки.

**Соц-доказательство и виральность:** именной сертификат и официальное приглашение —
это то, что партнёр сам публикует в соцсетях → приводит новых. Обучение продаёт
обучение.

## 2. СТРУКТУРА (один движок — 4 трека)

**Академия OKO** → треки одинаковой структуры (легко масштабировать):

| # | Трек | Источник | Приоритет |
|---|---|---|---|
| 1 | **Маркетинг** | материал Артёма | первый, готов по методологии |
| 2 | **Продажи** | материал Артёма / OKO | первый |
| 3 | **Медийность** | OKO | вторая волна |
| 4 | **Нейросети** | OKO (связка с ИИ-инструментами приложения) | вторая волна |

Каждый трек:
```
Трек → Модули → Уроки (видео / фото-слайды / аудио + конспект) →
       Тест после модуля → Итоговый тест трека → Сертификат (именной PDF) →
       (для партнёров) Официальное приглашение стать партнёром OKO
```

Элементы урока: плеер (видео/аудио), слайды, текстовый конспект (из расшифровки),
чек-лист «что сделать», кнопка «отметить пройденным», **ИИ-наставник** (отвечает по
материалу урока из базы знаний).

---

## 3. ГЕЙМИФИКАЦИЯ И ПРОГРЕСС (чтобы доходили до конца)

- **Прогресс-бар** по треку и по всей Академии (%).
- **Стрик** (дни подряд), напоминания через бота/пуш.
- **Ачивки** (бейджи профиля): «Маркетолог OKO», «Продажник OKO», «Медийщик OKO»,
  «Нейро-мастер OKO», «Выпускник Академии» (все 4 трека).
- **Тесты**: 5–10 вопросов после модуля, порог прохождения (напр. 80%), пересдача.
- **Сертификат** выдаётся только после итогового теста трека — ценность не
  обесценивается.

---

## 4. СЕРТИФИКАТ (официально, красиво, легально)

- **Брендовый PDF**: чёрный + лайм, Bebas Neue + Montserrat, глаз OKO, подпись
  OKO TEAM.
- **Именной**: ФИО партнёра, название трека, дата, **уникальный ID + QR** →
  страница верификации (`oko.../verify/<id>`), чтобы сертификат нельзя было
  подделать и можно было проверить.
- **Формулировка честная**: «Сертификат о прохождении курса» (не гос-диплом,
  аккредитацию не заявляем) — легально и мотивирует.
- **Официальное приглашение партнёру**: отдельный именной документ — «Приглашаем
  <Имя> официально стать партнёром проекта OKO», с реф-статусом и подписью. Это
  соц-доказательство, которое партнёр публикует.

## 5. ДОСТУП И МОНЕТИЗАЦИЯ (как распределить)

| Аудитория | Что открыто | Логика |
|---|---|---|
| **FREE** | 1–2 вводных урока каждого трека + «Распаковка личности» + превью сертификата | крючок на апгрейд |
| **Партнёр** (активация со START) | **ВСЯ Академия бесплатно** + все сертификаты + именное приглашение | «оплата» партнёра = продвижение приложения; $15 — вход в партнёрку, обучение внутри неё |
| **START $15** (не партнёр) | Треки **Маркетинг + Продажи** + сертификаты по ним | «научись продавать» |
| **PRO $49** | + **Медийность + Нейросети** (полная Академия) | для тех, кому нужны знания/ИИ, а не партнёрка |
| **BUSINESS/SCALE** | Всё + приоритетные разборы, живые созвоны (Scale) | премиум-сопровождение |

**Ключевая механика:** партнёрство = самый выгодный вход. Заплатил $15 → получил
всю Академию + право зарабатывать. Кто хочет только знания без партнёрки — берёт по
тарифам (половина на $15, полное на $49). Это ровно идея Даниэля, аккуратно разведённая.

## 6. ИНТЕГРАЦИЯ В ПРИЛОЖЕНИЕ

Академия живёт в **двух точках входа** (один движок):
1. **Раздел «Сервисы»** — плитка «Академия OKO» (мини-апп).
2. **Партнёрский кабинет** — блок «Обучение партнёра»: путь онбординга
   `активировал партнёрку → пройди треки → получи сертификаты + приглашение →
   разблокированы материалы для продвижения и выплаты`.

Подключается к уже готовому:
- **Каркас мини-аппов** (`window.OKO.call`) — Академия = ещё один мини-апп.
- **Тарифный middleware** — гейтинг доступа (FREE/START/PRO + флаг «партнёр»).
- **Модуль партнёрки** — прогресс обучения виден в кабинете, влияет на статус.
- **S3** — видео/аудио/слайды уроков, presigned-раздача.
- **ИИ-штат** — новый агент **«Наставник Академии»** (RAG по расшифровкам уроков).

## 8. ПАЙПЛАЙН КОНТЕНТА (из архива → в курс)

1. **Текст-методология Артёма** → структура треков/модулей (уже в агенте).
2. **101 голосовой урок** → **Gemini-расшифровка** (ключ на VPS через прокси,
   батчем, методично) → конспекты уроков + наполнение `kb_documents`.
3. **947 фото-слайдов** → визуалы уроков (сопоставить со скриптами по порядку).
4. **Видео-уроки** → когда придут недостающие части архива (z05…+ финальный .zip):
   разложить по модулям, залить в S3.
5. **Тесты** → сгенерировать Claude из конспектов (проверка усвоения), вычитать.
6. **Сертификаты** → шаблон PDF (чёрный+лайм) + генератор с именем/QR.
