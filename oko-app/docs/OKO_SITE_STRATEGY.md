## 0. Что за сайт и зачем
Сайт-витрина приложения **OKO**, который:
- живёт во **всех соцсетях** и ведёт **напрямую в приложение**;
- заставляет человека **захотеть себе такое** (эффект «ахуеть, как шикарно», самый необычный сайт);
- сразу даёт **скачать/открыть**: Telegram (primary, OKO — Telegram-first), **Play Market**, **RuStore**, **веб-версия**.

Главный KPI сайта — **переход в приложение**. Всё подчинено этому.

## 2. МЕХАНИКА «ахуеть»-сайта (согласовано с Даниэлем — это ядро)
Гибрид, как на топовых AI-сайтах: **генеративное видео + hover-маска + 3D/GLB + WebGL-приёмы**, собранные в одну картину.

**Поток Hero → сайт:**
1. **Hero-визуал** (фото/рендер, генерит Даниэль) → **оживить** (image-to-video) — как он двигается сам по себе до скролла.
2. **Скролл-скраб**: при прокрутке видео проматывается по скроллу.
3. **Бесшовный переход** к следующему видео (правило: последний кадр = первый кадр следующего) ИЛИ плавный уход в блок с **GLB/3D**.
4. **Hover-маска**: второе видео 1:1 поверх Hero, проявляется под курсором/пальцем через радиальную маску (свечение/другая анимация «под взглядом»).
5. **Per-device**: **16:9 для ПК**, **9:16 для телефона** — чтобы везде было резко на весь экран.

**Честная поправка:** топ-референсы (igloo.inc, oryzo.ai) — студия **Lusion**, ручной WebGL/Blender, месяцы. 1:1 соло не повторить. НО видео-гибрид Даниэля + 3D-акценты + чистая типографика + умный скролл = **реально премиум-класс**. Берём его механику.

## 3. ⭐ 4K БЕЗ ЛАГОВ — техническое решение (ключ ко всему)
**Проблема:** 4K-**видео** на скролле лагает — браузер декодирует 4K-кадр и ищет опорный кадр каждый кадр скролла; телефон задыхается. Это физика декодера. «Просто 4K видео» всегда будет глючить (проверено в этом чате — сырой video-scrub умирал на мобиле).

**Решение (техника Apple, их скролл-сайты так работают):**
Не скрабим видео — **скрабим последовательность кадров на `<canvas>`**:
1. Генеративное видео → **ffmpeg разбирает на 90–150 кадров**.
2. Кадры = **WebP, в разрешении ПОД ЭКРАН** (не буквальные 4K): телефон ~1080–1440px = уже «4K-резко»; ПК ~1600–1920px.
3. Canvas рисует нужный кадр по позиции скролла. **Нет video-декода, нет seek — просто подмена готовой картинки** → масло даже на слабом телефоне.
4. Прогрессивная подгрузка кадров + постер, чтобы не ждать; декод через `createImageBitmap`.
5. Раздаём **9:16 телефону / 16:9 ПК** через `matchMedia`.

**Итог:** настоящее 4K-видео на скролле — всегда риск лагов; но **результат, который выглядит 4K везде и НЕ лагает, — достижим** через canvas-скраб кадрами. Hover-маска — второй лёгкий слой под радиальной маской. 3D/GLB — только для одного фокус-объекта (не весь экран, иначе перф).

## 4. СТРУКТУРА САЙТА (блоки) — предложение
Порядок под конверсию «соцсети → скачать»:

1. **Hero** — «ахуеть»-момент: оживлённый визуал + скролл-скраб + hover-маска + глаз OKO.
   Заголовок + подзаголовок + **кнопки: Открыть в Telegram (primary) · Play Market · RuStore · Веб-версия**.
2. **Манифест (1 строка)** — что такое OKO одним ударом.
3. **Проблема → решение** — «10 вкладок и сервисов vs один OKO» (визуальный контраст).
4. **Модули OKO** — кинематографичные секции (есть 6 готовых диорам):
   Штаб · Контент-завод · Пре-модерация · Маркет · Партнёрка · Приложение.
5. **Как это работает** — 3 шага: открыл в Telegram → подключил → поехал.
6. **Для кого** — блогеры / малый бизнес / команды.
7. **Соцпруф / цифры / отзывы** — когда появятся (пользователи, кейсы).
8. **Финальный CTA** — большие кнопки Telegram / Play Market / RuStore / Веб + **QR-код** для десктопа (сканируй телефоном → приложение).
9. **Футер** — соцсети, контакты, юр. инфо.

## 7. Канал передачи ассетов (обход лимита 30 МБ на загрузку в чат)
1. **Лучший — не грузить вообще:** всё, что Даниэль генерит **в Higgsfield**, лежит у них → агент тянет напрямую через MCP (по генерации/медиа). Просто кинуть ссылку на генерацию.
2. **Универсальный — публичная ссылка:** Яндекс.Диск / Google Drive / **catbox.moe** (до 200МБ) / **litterbox** (до 1ГБ, временно) / WeTransfer (до 2ГБ) → прислать **прямую ссылку** на файл → агент скачивает `curl`. (Проверено — так тянули демки 21st.dev.)
3. **Своё хранилище (если надо):** presigned-ссылка в R2/HF S3 (ключи в secrets: `R2_*`, `HF_S3_*`; R2 может быть закрыт сетевой политикой — проверять).

## 9. Честная калибровка (ЧТОБЫ НЕ ПОВТОРЯТЬ ОШИБКИ)
**Что НЕ работало / отвергнуто:**
- Сырой video-scrub 4K → лаги/смерть на мобиле (решение — п.3, canvas-кадры).
- Абстрактные частицы / шейдерный глаз → «мутно», «не моё».
- Чужие готовые эффекты (curl-lines, 21st-блоки) → «не OKO, не моё» ← **главный вывод: сайт должен быть про OKO (глаз, его диорамы), а не про чужую красоту.**
- Погоня «выглядеть как те сайты» вместо «быть OKO» → тупик.

**Что зашло / верно:**
- Плавность `/flow` (когда оптимизировали под мобилу).
- **Механика Даниэля** (п.2) — правильная и достижимая.
- Реальные ассеты Даниэля (его рендеры/лого) = единственное, что ощущается «моим».

**Принцип для app-чата:** сначала **идентичность OKO** (глаз, его мир, его метафора), потом — эффекты. Не наоборот.

## 10. Грабли среды (техническое)
- WebGPU в headless-Chromium (swiftshader) — device lost, визуально не проверить → QA на реальном устройстве.
- Higgsfield MCP регулярно отваливается/реконнектится — просто ретраить вызов.
- Vite + top-level await → в конфиге `build.target: 'esnext'`.
- Playwright: браузер `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`; из headless внешние URL иногда `ERR_CONNECTION_RESET` (curl через прокси — ок).
- SessionStart-хук грузит `secrets.env` в каждый shell; вручную: `source <(base64 -d secrets.env.b64)`.

## 11. Следующие шаги для app-чата
1. **Финализировать** нейм-строку/таглайн (п.1) и тон.
2. **Собрать Hero-эталон** по механике (п.2) с решением 4K-без-лагов (п.3): оживлённый визуал → canvas-скраб кадрами → hover-маска → версии 16:9/9:16. Обкатать на телефоне Даниэля.
3. **Обкатать канал ассетов** (п.7): Даниэль генерит в Higgsfield → агент тянет оригинал.
4. Зашло — **раскатать на все блоки** (п.4) по той же механике, добить контент.
5. **Подключить ссылки**: Telegram (primary) + Play Market + RuStore + веб-версия + QR для десктопа.
6. Деплой на витрину (п.6), QR/ссылки в соцсети.

**Бюджет:** видео-генерации (Hero + hover + по секциям ×2 формата) = кредиты Higgsfield — планировать заранее. Картинки — Даниэль (безлимит), видео — агент (кредиты, лимит был 500, спрашивать при превышении).
