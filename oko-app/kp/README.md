# КП OKO TEAM — премиальный моушен-сайт коммерческого предложения

Живой адрес: https://okoteam.top/kp/

## Что это
Одностраничный моушен-сайт (КП) с продуктовыми тарифами СТАРТ / БИЗНЕС / ИМПЕРИЯ.
Бренд: чёрный #050505 + лайм #9AFF00, шрифты Unbounded + Onest, без эмодзи.

## Технологии
- Живой Spline WebGL фон (кубы) — самохостинг `spline/` (viewer + scene.splinecode)
- Three.js (importmap, самохостинг `js/vendor/`) — DOM-синхронная WebGL-сцена голограмм
- Lenis + GSAP + ScrollTrigger — плавный скролл, моушен, бесшовный луп
- `holo.js` — единый рендерер голограмм: глаз (GLB `assets/oko-eye.glb`),
  рука/женщина/робот (видео `kp-media/ref|fig/*.mp4` как WebGL-голограммы:
  luma-key шейдер, лайм-свечение «нейронов», сканлайны, физика наклона/скролла).

## Сборка
`python3 build.py` → `kp_v4.html` (подставляет карточки/тарифы/отзывы в `template.html`).
Готовый файл кладётся как `index.html`.

## Деплой (VPS okoteam.top)
Через control-эндпоинт: чанковая base64-загрузка `index.html` + `js/holo.js`
в `/var/www/okoteam/kp/`. Крупные бинарники (glb, spline, vendor, kp-media)
уже лежат на VPS и переносятся только при изменении.

## Проверка
QA-рендер реальным google-chrome (h264) на VPS: десктоп + мобайл, скролл-стопы,
проверка WebGL-контекста, воспроизведения видео-голограмм, отсутствия overflow/ошибок.

## Оптимизация под слабую сеть/телефон (v4.1)
- **Глаз (GLB)**: 5.42 МБ → 658 КБ (×8.2) через gltf-transform: текстуры 1024 WebP,
  меш упрощён до ~19k верт + квантизация (KHR_mesh_quantization — нативно в three,
  без доп. декодера). Вид идентичен. Грузится даже на медленном мобильном интернете,
  поэтому показывается настоящий 3D-глаз, а не плоский fallback-логотип.
- **Фон Spline**: рендерится в пониженном разрешении (68% линейно ≈ 46% пикселей)
  и растягивается CSS-scale до 100% — сцена, физика касания/свечения, движение
  квадратов и кадрирование НЕ меняются, только чуть мягче. Меньше нагрузка GPU = нет лагов.

## Раунд v5 — правки Даниэля (100% шикарно)
- **Глаз**: PNG-заглушка убрана из hero/клона полностью — глаз ТОЛЬКО 3D GLB.
  GLB ужат до 495 КБ (512 WebP + упрощение + квантизация). Прелоадер держится,
  пока глаз не загрузится → плоский PNG не виден никогда.
- **Бесконечный скролл в обе стороны**: bidirectional seamless loop (клон == hero),
  вниз и вверх бесшовно; overscroll-behavior отключён.
- **Рука**: кадры видео robohand привязаны к скроллу (currentTime = прогресс скролла) —
  одновременно выезжает слева и раскрывается из кулака в ладонь. Заголовок
  «ЧТО МЫ ПРЕДЛАГАЕМ» в одну строку поверх. Пустоты между блоками убраны.
- **Женщина**: оригинальный цвет видео, нейроны мозга перекрашиваются в зелёный/белый
  по скроллу; гибрид — стоит: играет, скроллишь: цепляется к пальцу (scrub). Меньше,
  голова не обрезается и не накладывается на карточки. Видео аспект-fit (без искажений).
- **Гарантии**: премиальные 3D банковские карты с видео-фонами (reels), чип+иконка,
  голографический блик, 3D-наклон (pointer/gyro), компактная сетка 3×2 / адаптив.
- **FAQ**: вау-сцена, робот вырезан из белого фона (флуд-матирование) и рендерится
  ПЛОТНЫМ (не прозрачным) сверху, свечение сцены; все вопросы видны, single-open
  аккордеон, ответ раскрывается под вопросом (не на роботе).
- **Робот-ассет**: `kp-media/fig/robot.webp` (67 КБ, alpha-вырезка из assist.mp4).
