# Zedian portfolio — сборка по спеке пользователя

Стек: React 18 + Vite + Tailwind v3 + Framer Motion + lucide-react.
Собрано по детальному брифу Даниэля (тёмная премиум-тема, #0d1116/#00df8f, 3D-стек карточек,
физика перетаскивания ID-бейджа, аккордеон стадий).
Сборка: `npm i && npx vite build` → dist/. Деплой: dist/* → сайт true-journey-418 в app/public/zedian/.
Живёт: /zedian/. Картинки — Unsplash (внешние URL).
