# OKO — логотип (все форматы)

Мастер-знак: глаз OKO (бровь + глаз-полумесяц), лайм #9AFF00 на чёрном #080a06.
НЕ перекрашивать, НЕ искажать пропорции, НЕ обрезать знак.

## Что где
- `oko-logo-master-*.png` — оригиналы 1000×1000 (на прозрачном / на чёрном).
- `png/` — прозрачный PNG, полный, размеры 32–1024 (для UI, наложений).
- `jpg/` — JPG на чёрном и на белом, 256–1024 (соцсети, документы, где не нужен альфа-канал).
- `on-black/` — на чёрном, PNG+JPG (главный бренд-контекст).
- `on-white/` — на белом, PNG+JPG (документы, светлые макеты).
- `icon/` — квадратные иконки 32–512 + `favicon.ico` (аппы, вкладки; поля обрезаны по знаку, сам знак целый).
- `vector/` — `oko-logo.svg` (прозрачный) + `oko-logo-on-black.svg`, `*.pdf` (печать, масштаб без потерь), превью `*-1024.png`.

## Цвета
- Лайм: `#9AFF00`  · Фон: `#080a06` / `#0d0d0d` · Текст: белый.

## Правила
- Тёмный фон — основной. На светлом использовать `on-white`.
- Свободное поле вокруг знака ≥ высоты брови.
- Для вкладок/аппов — `icon/`. Для UI на тёмном — `png/` или `vector/`.
