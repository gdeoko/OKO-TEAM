# ПЛАНКА КАЧЕСТВА OKO (обязательна каждому агенту)
Уровень: «студия из 50 топ-спецов за $1B». Ничего статичного, ноль шаблонности и повторов.

## Визуал
- Бренд: чёрный #0a0a0a + лайм #9AFF00, Bebas Neue (дисплей) + Montserrat (текст). БЕЗ эмодзи — только SVG.
- ОБЕ темы идеальны: тёмная (дефолт) и `:root[data-theme="light"]`. Проверять каждую правку в обеих.
- Всё живое: hover/active, плавные transition (cubic-bezier), micro-анимации появления, лёгкий parallax,
  свечения/glow по бренду, skeleton при загрузке. Ничего «мёртвого» и резкого.
- Иконки: выверенные SVG (stroke 7, round, viewBox 0 0 100 100), никаких кривых/рваных. Единый вес и стиль.
- Кнопки/чипы/карточки: единые радиусы (var(--r-*)), тени, состояния; аккуратные отступы; ничего не наезжает.
- Инфографика кодом (CSS/canvas/SVG): графики, счётчики, прогресс-кольца, бары — анимированные.
- Никаких «непонятных» элементов: если блок есть — понятно зачем, подпись/тултип; лишнее убрать.

## Правила
- Правишь ТОЛЬКО свои файлы (см. задание). base.html — отдельный владелец, остальные его НЕ трогают
  (доработки — chain-патчами функций + CSS из своего модуля, таргетируя существующие id/классы).
- Русский интерфейс, mobile-first, но десктоп не ломать. Safe-area (env(safe-area-inset-*)) учитывать.
- navstack: новые вьюхи — nvPush(label, closeFn). Деньги — walletCharge/walletAdd/okoEarn.
- Персист состояния — localStorage oko-<модуль>. Реалистичные данные, не лорем.
- Проверка: node --check своего script.js + смоук в headless Chromium (playwright, /opt/pw-browsers/,
  390x844 И 1280x800, обе темы) со скриншотами. Финальную сборку build.py делает QA-фаза — тебе build
  только для смоука (гонки допустимы).
