# OKO APP — Мастер-ТЗ финальной боевой версии (заказ Даниэля, 17.07)

Цель: приложение на 100% функциональное, красивое, продающее, без «демо-заглушек»,
адаптированное под web / Android (Play Market, RuStore) / iOS (App Store) / ПК / Telegram mini-app.
Бренд: чёрный #0a0a0a + лайм #9AFF00, Bebas Neue + Montserrat, БЕЗ эмодзи (SVG-иконки),
две темы обязаны выглядеть отлично. Максимальный визуал везде (Higgsfield 3D/видео/картинки,
CSS-инфографика, анимации, красивые фоны). Единый стек навигации «назад» (navstack).

## A. КРИТИЧНЫЕ БАГИ (чинить в первую очередь)
1. Рулетка тёмная в СВЕТЛОЙ теме (казино-стол) — сделать светлый премиум-вариант колеса и стола.
2. Тёмная плашка в светлой теме (баланс-хиро, карточки казино) — покрыть светлую тему.
3. ВНИЗУ всех разделов пустое поле — убрать (высота/паддинги, safe-area, лишний спейсер).
4. Меню сообщения: НЕТ «Закрепить»/«Удалить» видимо — добавить полноценное контекст-меню
   (реакции + Ответить/Копировать/Закрепить/Переслать/Удалить/Редактировать) как в Telegram.
5. Стикеры и эмодзи — вынести ПРЯМО к полю ввода (кнопка-смайл слева у composer, панель
   стикеров/эмодзи выдвигается над клавиатурой), как в Telegram, а не отдельным путём.
6. Голосовые кружочки: иконки и интерфейс некрасивые + функционал слабый — переделать
   (красивая запись, волна, кружок-видео запись/просмотр, скорость, отмена свайпом).
7. Звонки: видео не работает, кнопки/иконки некрасивые — переделать экран звонка
   (аудио+видео, красивые контролы, аватар/фон, таймер, сворачивание).
8. Кривые иконки/кнопки по всему приложению — заменить на выверенные SVG (единый набор).

## G. АРХИТЕКТУРА СБОРКИ (эталон)
- Модульная: `oko-app/app/modules/<name>/{style.css,screen.html,overlay.html,script.js}` →
  `build.py` → единый `prototype/index.html`. Контракт: `app/CONTRACT.md`.
- Правило параллельной работы: base.html правит ОДИН агент; каждый модуль — свой владелец;
  новые фичи — новые модули. Никаких коллизий по файлам.
- Бэкенд: Supabase (нужен SUPABASE_PAT в env — СПРОСИТЬ у Даниэля) — auth + персист с
  fallback на localStorage. Пока ключа нет — работаем на localStorage-слое, но код готов к БД.
