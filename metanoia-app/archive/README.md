# Что здесь лежит

Работа, которую школа приняла раньше, но которая по правкам Екатерины от
19.08.2026 из приложения снята. Файлы не удаляем: они оплачены и могут
понадобиться, если школа передумает. Но из `public_html` они убраны, чтобы
не висеть открытыми страницами на домене школы и не путать родителей.

- `presentation/` — презентации к урокам трёх глав. Пункт «Презентации к
  урокам» Екатерина попросила убрать из профиля целиком; сами страницы
  никуда не вели, но лежали в открытом доступе.
