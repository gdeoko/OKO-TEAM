# Как собрать приложение для Android

Проект это тонкая обёртка: она открывает школу в доверенном окне браузера,
без адресной строки и без кнопок браузера. Всё содержимое живёт на сайте,
поэтому обновление школы не требует новой версии в магазине.

## Что нужно один раз

1. Android Studio (или только командные инструменты Android SDK) и JDK 17.
2. Домен школы с настоящим сертификатом HTTPS.

## Шаг 1. Вписать домен

В трёх местах, все три обязательны:

- `app/build.gradle` → `manifestPlaceholders`: `hostName` и `defaultUrl`;
- `app/src/main/res/values/strings.xml` → адрес в `asset_statements`;
- на сервере школы: `public_html/.well-known/assetlinks.json`.

## Шаг 2. Сделать ключ подписи

```bash
keytool -genkeypair -v -keystore metanoya.keystore -alias metanoya \
  -keyalg RSA -keysize 2048 -validity 10000
```

Ключ и пароль хранить как паспорт: без него нельзя выпустить обновление.
Отпечаток для сервера:

```bash
keytool -list -v -keystore metanoya.keystore -alias metanoya | grep SHA256
```

Строку вида `AB:CD:...` вписать в `assetlinks.json` вместо заглушки и
выложить файл так, чтобы он открывался по адресу
`https://<домен>/.well-known/assetlinks.json`.

Проверить связь: <https://developers.google.com/digital-asset-links/tools/generator>

## Шаг 3. Собрать

```bash
./gradlew bundleRelease   # файл .aab для Play Market
./gradlew assembleRelease # файл .apk для RuStore и для проверки на телефоне
```

Готовое лежит в `app/build/outputs/`.

## Если адресная строка всё-таки видна

Значит `assetlinks.json` не совпал с ключом подписи. Причины по частоте:
файл отдаётся не с того домена, отпечаток от другого ключа (например от
отладочного вместо боевого), файл отдаётся с неверным типом содержимого.
Тип должен быть `application/json`.

## Проще, но с чужими руками

То же самое умеет делать Bubblewrap:

```bash
npx @bubblewrap/cli init --manifest https://<домен>/manifest.json
npx @bubblewrap/cli build
```

Он сам скачает Android SDK, сделает ключ и соберёт оба файла. Наш проект
отличается тем, что в нём уже стоят цвета школы, заставка, права на
микрофон и камеру для голосовых и кружочков в чатах и русское имя.
