# Как собрать приложение для App Store

В папке лежит готовый исходник обёртки: одно окно `WKWebView`, которое
открывает школу. Содержимого внутри нет, поэтому обновление уроков на
сервере видно сразу, без новой версии в магазине.

Нужен компьютер Mac с Xcode 15 или новее. Ни у нас, ни в контейнере его
нет: этот шаг делается на машине Екатерины или на арендованном Mac
(MacinCloud, MacStadium, от 20 $ в месяц).

## Шаг 1. Вписать домен

`Metanoya/Info.plist`, ключ `MTSchoolURL`. Одно место, больше адрес нигде
не повторяется.

## Шаг 2. Получить проект Xcode

```bash
brew install xcodegen
cd store/ios
xcodegen generate      # появится Metanoya.xcodeproj
open Metanoya.xcodeproj
```

Если ставить XcodeGen не хочется: в Xcode «File → New → Project → App»,
имя `Metanoya`, интерфейс Storyboard, язык Swift. Потом удалить созданные
`ViewController.swift`, `AppDelegate.swift`, `SceneDelegate.swift`,
`Main.storyboard` и перетащить в проект нашу папку `Metanoya`. В настройках
цели убрать `UIApplicationSceneManifest` из Info.plist и поставить наш
`Info.plist` как файл целей.

## Шаг 3. Подпись

В Xcode: цель `Metanoya` → Signing & Capabilities → Team, выбрать команду
Apple Developer школы. Идентификатор `ru.metanoya.app` должен быть заведён
в App Store Connect до первой отправки.

## Шаг 4. Собрать и отправить

```
Product → Archive → Distribute App → App Store Connect
```

Дальше в App Store Connect: описание из `../ОПИСАНИЯ-ДЛЯ-МАГАЗИНОВ.md`,
снимки `../screens/ios-*.png`, иконка берётся из проекта.

## Что уже сделано в коде

- микрофон и камера в чатах: разрешение спрашивает система своим окном,
  тексты вопросов на русском лежат в `Info.plist`;
- сертификат и альбом сохраняются: файл ловится делегатом загрузки и
  уходит в обычный лист «Поделиться», откуда его кладут в фотографии;
- ссылки наружу (почта, телефон, Телеграм) открываются системой, школа при
  этом остаётся открытой;
- цвет фона и строки состояния меняется вместе с ночной темой телефона;
- нет связи, потянули вниз, школа перезагрузилась;
- поворот выключен, школа только вертикально, как в макете;
- боковой свайп «назад» отключён: экраны листает само приложение своей
  стрелкой, иначе жест уводил из урока.

## Про правило 4.2 у Apple

Apple не любит приложения, которые просто открывают сайт. В нашу пользу
играют работа без интернета, свои голосовые и кружочки, сохранение
сертификата в фотографии, ночная тема и уведомления. Отказ с первого раза
здесь обычное дело и снимается перепиской с ревьюером: в ответе стоит
показать, что приложение работает в самолётном режиме и что запись голоса
идёт через системный микрофон.

Разумный порядок запуска: сначала Телеграм и RuStore, они дают почти всю
российскую аудиторию, App Store уже после них.
