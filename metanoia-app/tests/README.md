# Проверки приложения

100 сценариев на Playwright. Каждый открывает настоящее
приложение в браузере, делает то же, что сделал бы ребёнок или родитель, и
проверяет результат, а не наличие кнопки. Правило проекта: считается не
«экран открылся», а «дело сделалось» — нажать, перезагрузить, посмотреть,
что осталось.

## Как запустить

```bash
# один раз: поставить Playwright рядом с проверками
cd metanoia-app/tests && npm install

# приложение раздаём обычным сервером из public_html
cd ../public_html && python3 -m http.server 8777 &

cd ../tests
node full.mjs          # одна проверка
bash всё.sh            # все подряд, по строке на проверку
bash сервер.sh         # те, которым нужен настоящий сервер (поднимает сам)
python3 kartinki.py    # картинки уроков: пропуски, повторы, размеры
```

Нужен Playwright и браузер: в наших контейнерах это
`/opt/pw-browsers/chromium`, путь прописан в каждом файле.

Часть проверок работает с настоящим сервером на `127.0.0.1:8099`
(`svoi2`, `svoi3`, `konflikt`, `tyazhelo`, `token`, `parol*`, `synclive`,
`tgfull`). Всё, что им нужно, поднимает `сервер.sh`: заводит чистую базу,
заливает `db/schema.sql`, пишет `config/.env` со свежим ключом подписи,
запускает PHP и делает копию `index.html` под именем `_t.html` с адресом
этого сервера. Ручной рецепт лежит в `../HOSTING-RUNBOOK.md`.

## Что чем проверяется

| Файл | Что доказывает |
|---|---|
| `full` | сквозной проход: главная, урок, задание, питомец, игры, битые файлы |
| `pravki` | все 25 пунктов списка правок Екатерины разом |
| `svoi`, `svyazka`, `semya` | у каждого ребёнка свой прогресс, связка не рушится, семейное остаётся общим |
| `svoi2`, `svoi3` | то же с настоящим сервером и на чистом втором устройстве |
| `glavy`, `plitki`, `imya`, `kolokol`, `istorii` | на экранах ребёнка настоящие цифры и имена, а не макет |
| `lavka` | пожелание из лавки доходит до родителя |
| `cert`, `cert2`, `certdl` | бланк только за сданную проверку, имя своё, скачивается |
| `exam`, `task5`, `zamok` | проверка знаний, пять видов заданий, порядок открытия уроков |
| `chat`, `chat3`, `chatnote`, `podderzhka`, `safety` | переписка, стоп-слова, жалобы, честная оговорка про сервер |
| `voice`, `circle`, `photo`, `audio3`, `verse` | голосовые, кружочки, снимки, озвучка уроков и стиха дня |
| `games`, `games3`, `igry`, `escape`, `nagrada` | все 17 игр открываются и отпускают назад, у каждой своя картинка, окна закрываются |
| `xss`, `xss2` | текст от семьи не выполняется как код |
| `tema`, `tema2`, `tema3`, `narrow`, `uzko`, `dostup` | тёмная тема, узкий экран, подписи для чтения с экрана |
| `offline`, `standalone`, `vitrina` | работа без сети, сборка одним файлом, витрина со своими шрифтами и без запросов наружу |
| `kniga2` | книга школы: у каждой главы своя картинка по ходу рассказа |
| `lang`, `espanol`, `docs`, `versiya`, `gorod` | испанский, документы, версия, город семьи |
| `wipe3`, `predel`, `reg`, `onboard`, `pin`, `kids`, `deti`, `child` | удаление аккаунта, предел детей, вход, код родителя, профили |
| `tgapp`, `tgfull` | мини-приложение Телеграма и вход по подписи |
| `konflikt`, `tyazhelo`, `token`, `synclive` | перенос прогресса: конфликт ревизий, тяжёлая переписка, протухший токен |
| `parol`, `parol2`, `parol3` | регистрация, вход почтой, письмо о новом пароле |
| `pervyden`, `passlesson`, `glavnaya` | первый день семьи целиком, урок открывает следующий, у нового ребёнка нет чужих цифр |
| `wreport`, `slozhnost`, `limit` | родительский отчёт по настоящему, игра правда становится сложнее, лимит игр и код родителя |
| `share`, `oauthbtn`, `ask` | приглашение второму родителю, кнопки входа, помощник на тяжёлых темах |
| `downloads`, `stick`, `broken` | скачивания и звук, действия держатся после перезапуска, мусор в памяти не роняет приложение |
| `audio`, `font`, `fallback` | озвучка урока играет, шрифты свои, у уроков без обложки честная заглушка |
| `udalenie` | удаление аккаунта описано и страницей сайта, и экраном приложения |
| `store-shots` | снимки экранов для магазинов приложений |
| `kartinki.py` | картинки уроков: пропуски, повторы по хешу, размеры |

## Что эти проверки уже поймали

Голосовые, которые не играли; видеокружочки, которые открывались звуковым
плеером; сертификат с чужим именем; отчёт и альбом по выдуманным данным;
код родителя, зашитый как 1234; прогресс, общий на двоих детей; тёмную
тему, где текст красился цветом фона; имя ребёнка, выполнявшее скрипт;
конфликт ревизий, стиравший работу без связи; сертификат, который
сохранялся файлом без имени и расширения. Список подробнее в
`../../МЕТАНОЙА-ПАМЯТЬ.md`.
