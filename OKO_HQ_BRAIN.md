# OKO HQ — Мозг (память компании, спецификация)

Дополнение к `OKO_HQ_SPEC.md`. Центр зала — живой анимационный МОЗГ: хранит и растит ВСЮ память
OKO. От каждого ноутбука к нему тянутся лаймовые нервы-волокна; каждое волокно = категория/файл;
на волокнах узлы = записи; ты и агенты кладут/читают память, всё видно вживую.

## 1. Что такое «мозг» технически
Это **визуализация + хранилище + слой разбора**:
- **Хранилище**: файлы/тексты/данные на VPS (`/opt/oko-agents/docs/`, `data_runtime/`, `brain/`) +
  загруженные тобой файлы. Плоский markdown/файлы (как обсидиан-vault у Knox — «no database»),
  индекс в JSON.
- **Разбор (мост)**: кидаешь файл/видео/голос → мост (Claude Code) структурирует: OCR/whisper/парс
  → раскладывает в нужную категорию → создаёт узлы. Ровно как обучение (текст+101 голосовое) сейчас.
- **Визуал**: Three.js — ядро + волокна + узлы + импульсы (см. §4 спека).

## 3. Узел памяти (модель данных)
```json
{
  "id": "kb_sales_dozhim_01",
  "cat": "sales",                 // категория (см. таблицу)
  "title": "Дожим молчащего клиента",
  "type": "text",                 // text|image|pdf|audio|video|json|link
  "size": 4120,
  "mtime": 1784150000,
  "author": "claude",             // claude | daniel | agent:<id>
  "tags": ["дожим","предоплата","скрипт"],
  "preview": "Мне нужна определённость...",
  "path": "/opt/oko-agents/docs/sales_knowledge_artem.md#dozhim",
  "fiber": 0.42                   // позиция на волокне (для визуала)
}
```

## 4. Визуал мозга (Three.js)
- **Ядро**: пульсирующая структура в центре (нейро-сфера / пучок волокон / раздвижной кристалл),
  медленно вращается и «дышит» (scale-осцилляция), внутри частицы (лайм+бирюза), объёмное свечение.
- **Волокна**: `CatmullRomCurve3`/`QuadraticBezierCurve3` от ноутбука к ядру, `TubeGeometry` +
  emissive-материал по цвету категории. По волокну — бегущие импульсы (спрайты/точки вдоль кривой).
- **Узлы**: `InstancedMesh` glow-сфер на позициях `fiber` вдоль волокна; hover — увеличение+свечение;
  клик — зум камеры + панель.
- **Активность**: агент пишет в память → импульс ноутбук→ядро + вспышка ядра; читает → импульс
  ядро→ноутбук. Загрузка файла → частица от чата к ядру → «врастание» нового узла (scale 0→1).

## 5. Панель памяти (клик по узлу)
Открывается стеклянная панель:
- Превью: текст (моно), картинка, pdf (первая стр.), аудио (волна+плеер), видео (кадр).
- Метаданные: тип, размер, дата, автор, теги, путь.
- Кнопки: **Открыть · Скачать · Редактировать · Заменить · Удалить**.
- «Кто использует»: какие агенты читают этот узел (подсветка их волокон).

## 6. Загрузка в мозг (через чат)
```
Ты кидаешь файл/видео/голос в поле ввода
  → частица летит к ядру (анимация)
  → POST /api/brain (multipart)
  → мост (Claude Code) разбирает:
       pdf/doc/img → OCR (tesseract, локально)
       видео       → кадры + аудио → whisper (локально)
       голос       → whisper (локально)
       текст/ссылка→ парс/фетч
  → структурирует: категория + теги + заголовок + превью
  → создаёт узел(ы) на нужном волокне (анимация врастания)
  → тост «разобрано: N узлов» + запись в ленту
```
ПРАВИЛО (из опыта обучения): тяжёлый разбор — ЛОКАЛЬНО (whisper/tesseract), НЕ через Gemini-ключи
(они общие с живым агентом, 429 уронит продажи).

## 7. API мозга
```
GET    /api/brain                 → [узлы] (+фильтр ?cat= ?tag= ?q=)
GET    /api/brain/:id             → полное содержимое узла
GET    /api/brain/:id/download    → файл
POST   /api/brain                 → загрузка (multipart) → разбор → узлы
PUT    /api/brain/:id             → редактировать/заменить
DELETE /api/brain/:id             → удалить
GET    /api/brain/graph           → структура волокон+узлов для визуала
WS     импульсы/активность (кто читает/пишет)
```

## 8. Поиск и связи
- Строка поиска над мозгом (Ctrl+K) → совпадающие узлы/волокна подсвечиваются, камера ведёт к
  ближайшему.
- Семантические теги связывают узлы между волокнами (тонкие связи-линии при выделении узла).
- «Память клиента»: клик по клиенту-узлу → подсвечивает его диалоги, КП, договор, макеты.

## 9. Рост мозга (геймификация памяти)
Чем больше разобранного материала — тем «богаче» и ярче ядро (больше волокон, плотнее частицы).
Счётчик: узлов в памяти, категорий, «здоровье» базы (насколько актуальна). Это и есть «мозг растёт».
