Пользовательское соглашение
Редакция от 04.08.2026

1. Общие положения

Настоящее пользовательское соглашение регулирует отношения между сервисом Exora (далее — «Сервис») и физическим лицом (далее — «Клиент»), использующим сервис для обмена криптовалют.

Использование Сервиса означает полное и безоговорочное согласие Клиента с условиями Соглашения.

2. Предмет соглашения

Сервис предоставляет Клиенту возможность обмена криптовалюты Tether USD (USDT) на российские рубли (RUB) и обратно через оператора Сервиса.

Работаем в круглосуточном режиме 24/7, без выходных.

3. Порядок оказания услуг

  • Клиент оставляет заявку через бот @exorappbot или мини-приложение
  • Оператор связывается с Клиентом в течение 5–15 минут для подтверждения условий
  • После подтверждения Клиент осуществляет перевод средств/криптовалюты
  • Сервис в течение 10–30 минут производит встречный перевод
  • Обмен считается завершённым после подтверждения обеими сторонами

4. Лимиты и комиссии

  • Минимальная сумма — 300 USDT
  • Максимальная сумма — 100 000 USDT
  • Комиссия Сервиса — 0%, курс включает все накладные расходы
  • Курс фиксируется на момент подтверждения заявки оператором

5. Обязанности Клиента

  • Предоставить корректные реквизиты для перевода
  • При ошибке в реквизитах Сервис не несёт ответственности за утрату средств
  • Подтверждает, что средства получены законным путём
  • Не использовать Сервис для отмывания денежных средств и незаконной деятельности

6. AML-политика

Сервис проводит автоматическую проверку кошельков через открытые источники (TronScan, GoPlus Security, TON Center). Сервис оставляет за собой право отказать в обмене при выявлении высокого риска.

В случае отказа средства возвращаются на исходный кошелёк за вычетом комиссии сети.

7. Ограничение ответственности

Сервис не несёт ответственности за: убытки от предоставления некорректных реквизитов, изменение курса между созданием и подтверждением заявки, задержки в блокчейн-сетях, действия банков и криптобирж.

8. Разрешение споров

Все споры разрешаются в претензионном порядке. Претензия направляется в поддержку. Сервис обязуется рассмотреть в течение 10 рабочих дней.

9. Заключительные положения

Сервис вправе изменять условия. Актуальная редакция — в мини-приложении. Продолжение использования означает согласие с новой редакцией.

Политика конфиденциальности
Редакция от 04.08.2026

1. Общие положения

Настоящая Политика описывает порядок сбора, хранения и обработки персональных данных Клиентов сервиса Exora.

Используя Сервис, Клиент выражает согласие с условиями настоящей Политики.

2. Собираемые данные

  • Telegram ID, username, имя — при взаимодействии с ботом
  • Адреса криптовалютных кошельков
  • Реквизиты для получения RUB (карта, СБП, телефон)
  • История заявок и обменов
  • Технические данные: IP-адрес, тип устройства, время сессий

3. Цели обработки

  • Оказание услуг обмена криптовалюты
  • Связь с Клиентом для подтверждения заявок
  • Соблюдение требований AML/KYC
  • Улучшение работы Сервиса
  • Уведомления о статусе заявок и изменении курса

4. Хранение данных

Данные хранятся на серверах в защищённом виде. Срок хранения — не менее 5 лет с момента последней активности (в соответствии с ФЗ №115-ФЗ).

5. Передача третьим лицам

Сервис не передаёт данные третьим лицам, за исключением:

  • По требованию уполномоченных органов РФ
  • Публичные blockchain-эксплореры для AML (только адрес кошелька)
  • API Telegram, Binance, CoinGecko для базовой работы

6. Права Клиента

  • Запросить удаление своих персональных данных
  • Получить копию собранных о нём данных
  • Отозвать согласие на обработку данных

7. Локальное хранилище

Мини-приложение использует localStorage для хранения истории заявок на устройстве Клиента. Эти данные не передаются на сервер.

8. Изменения Политики

Сервис вправе изменять Политику. Актуальная редакция — в мини-приложении.

9. Контакты

Частые вопросы
Ответы на популярные вопросы
Как это работает
Как создать заявку на обмен?+
Откройте бот @exorappbot, нажмите «💱 Обмен USDT» — откроется мини-приложение. Выберите направление, сеть, укажите сумму, свой адрес и контакт. Нажмите «Создать заявку» — оператор свяжется в течение 5–15 минут.
Сколько занимает обмен?+
Средняя скорость — 10–30 минут с момента подтверждения оператором. Зависит от загруженности блокчейна и наличия оператора онлайн (работаем 24/7).
Какая комиссия?+
Комиссия сервиса — 0%. Курс, который вы видите, уже включает всё. Дополнительно списывается только сетевая комиссия блокчейна (~1–2 USDT для TRC-20).
Сети и валюты
Какие сети USDT поддерживаются?+
TRC-20 (Tron, рекомендуется — минимальная комиссия), ERC-20 (Ethereum), BEP-20 (BSC), TON.
Могу ли я обменять BTC/ETH/TON?+
Основное направление — USDT. Обмен других валют возможен по индивидуальному запросу — свяжитесь с оператором.
Лимиты
Какие лимиты обмена?+
Минимум — 300 USDT. Максимум — 100 000 USDT. Для больших сумм — по индивидуальной договорённости.
Нужна ли верификация?+
При соответствии стандартной AML-проверке — не требуется. Для сумм свыше 50 000 USDT возможен запрос дополнительных данных.
AML-проверка
Что такое AML-проверка?+
Проверка кошелька на связь с санкционными списками, миксерами, украденными средствами. Проводится автоматически через TronScan, GoPlus Security, TON Center для каждой заявки.
Что если кошелёк не прошёл AML?+
Средства возвращаются на исходный кошелёк за вычетом сетевой комиссии. Свяжитесь с поддержкой для уточнения причин — иногда проблема в свежести кошелька (<7 дней).
Безопасность
Как убедиться, что вы не мошенники?+
Работаем через договор. Отзывы: @okoreviews. Кейсы: @okocase. За каждой заявкой — живой оператор.
Что если я ошибся в адресе?+
До подтверждения оператором можно отменить заявку. Если средства уже переведены на неверный адрес — возврат невозможен. Всегда проверяйте адрес и сеть перед переводом.
Уведомления
Как получать уведомления о курсе?+
В боте: /alert 95 — придёт уведомление при достижении курса 95 ₽. Работает в обе стороны.
Как отследить статус заявки?+
В мини-приложении откройте «Заявки» → тапните на заявку. Увидите таймлайн: создана → в работе → оплата → выдача. Push-уведомления приходят в бот при смене статуса.
Поддержка
Как связаться с поддержкой?+
Пишите @dmdiam. Работаем 24/7, время ответа — до 15 минут.
Есть ли API для автоматизации?+
Для корпоративных клиентов — API-доступ с webhook-уведомлениями. Условия обсуждаются индивидуально.
