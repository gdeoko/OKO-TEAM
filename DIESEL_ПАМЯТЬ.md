`tt_bio_zhdu.mjs` заполняет поле, жмёт Save, держит окно открытым и ждёт человека
до трёх часов, после капчи сам повторяет Save до восьми раз и сверяет результат по
ЖИВОЙ странице, а не по нажатой кнопке.

```bash
vexec 'TT_WAIT=180 bash /opt/oko-poster/tt_bio_start.sh'   # поднять окно
vexec 'tail -8 /opt/oko-poster/logs/tt_bio.log'            # что там
vexec 'bash /opt/oko-poster/tt_ubrat.sh'                   # снять окно
```

**Три грабли, каждая стоила прогона:**

1. `закрытьОкошки` из загрузчика роликов жала кнопку `Cancel` В САМОЙ модалке
   правки и закрывала её. После открытия правки эту чистку звать нельзя.
2. Playwright считает поле Bio невидимым (у модалки свой скролл) и валится на
   `waitForSelector`. Работать надо изнутри страницы: `scrollIntoView`, `focus`,
   потом `keyboard.insertText`.
3. Профиль браузера держится замком. Осиротевшее окно валит следующий запуск
   с `Failed to create a ProcessSingleton`. Снимать по PID (`tt_ubrat.sh`), а не
   по образцу: образец в строке команды убивает вызывающий shell.

**Bash не принимает кириллические имена переменных.** `ОБРАЗЕЦ=...` даёт
`command not found`, и скрипт тихо делает не то. Имена латиницей, вывод русский.
