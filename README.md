# DUCK'S GAME SPACE

Cinematic 3D-сайт игрового клуба DUCK'S (Москва). Один непрерывный мир,
камера летит по фильму, частицы перетекают между формами, звук синтезируется
в реальном времени.

## Стек
- Vite + Three.js 0.164.1 + Lenis + GSAP
- Web Audio API (весь звук синтезом, без mp3)
- Чистый JS ES2022, Vanilla CSS

## Запуск
```bash
npm install
npm run dev -- --host
```
Открой `http://localhost:5173` на ПК и адрес сети на телефоне.

## Сборка
```bash
npm run build
```
Результат в `dist/`.

## Что сделано (срез магии — этап 1)
- Hero: заголовок, подзаголовок, описание, кнопки, параллакс по скроллу
- Главный переход: облако из 25 000 частиц собирается из утки (`duck.glb`),
  при скролле камера влетает сквозь облако, частицы перетекают по дугам
  в форму мозга (`brain.glb`) — визуализация слогана «играй мозгами»
- Звук: волшебный пэд C-major-7, колокольчики при касании частиц,
  звук формирования, hover/click отклики, кнопка mute, стартовый оверлей
- Кастомный курсор, прогресс-бар, счётчик секций, секция «О клубе» с тезисами

## Модели
`public/models/` — duck, brain, dart, ball8 (оригиналы ~28 МБ).
Перед продакшеном сжать через `@gltf-transform/cli` (Draco + WebP) до 3-5 МБ.
