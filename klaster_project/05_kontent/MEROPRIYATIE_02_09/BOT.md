# Бот брокер-тура: что переносим из RocketVPN и что меняем

## Что уже готово и проверено

Исходник: `bot.php` проекта RocketVPN, блок функций `contest_*`
(лежит на сервере в `/opt/oko-poster/tmp/rocketcdn-p3-site/bot.php`).

Работающая механика:

| функция | что делает |
|---|---|
| `contest_code($uid)` | персональный код от id через HMAC-SHA256, подделать нельзя |
| `contest_bot_link($code)` | ссылка `t.me/<бот>?start=ref_КОД` |
| `contest_remember_ref` | запоминает, по чьей ссылке человек пришёл, до того как он подтвердит участие |
| `contest_member($uid)` | проверка подписки на канал через `getChatMember` |
| `contest_join` | заводит участника, начисляет балл пригласившему, режет самоприглашение |
| `contest_points` / `contest_ranked` | баллы и рейтинг |
| `contest_top_text` | топ участников с местами |
| `contest_winners_text` | фиксация победителей с ПОВТОРНОЙ проверкой подписки |
| `contest_card` | карточка участника: статус, место, персональная ссылка, кнопки |

Две вещи в этом коде сделаны правильно и их надо сохранить при переносе.
Первая: балл начисляется только после того, как приглашённый и подписался, и
нажал «Участвую» — накрутка ботами не проходит. Вторая: если Telegram API
недоступен или канал задан неверно, победители не фиксируются вовсе, вместо того
чтобы молча принять техническую ошибку за отписку участника.

## Что меняем под брокеров

**1. Условие участия — регистрация, а не подписка.**
Первый шаг: анкета. Подписка на канал остаётся вторым шагом и даёт доступ к
списку свободных блоков, но входным билетом становится регистрация на тур.

**2. Анкета из четырёх вопросов.**
- Имя и агентство.
- Телефон для связи.
- Какой запрос клиента сейчас в работе: метраж, мощность, нагрузка.
- Придёте лично или подключитесь онлайн.

Третий вопрос делает двойную работу: по нему подбирается индивидуальный подарок,
о котором клиент писал в анонсе, и он же превращает каждого зарегистрированного
в тёплый лид для отдела аренды ещё до мероприятия.

**3. Приз за приглашения — не мерч, а приоритет по объекту.**
Брокеру не нужна футболка, ему нужна сделка. Работающий приз: первым получать
список новых свободных блоков до того, как он уйдёт в общий рынок. Клиенту это
ничего не стоит, брокеру стоит дорого. Мерч и подарки остаются приятным
дополнением при регистрации.

**4. Главный приз за сделку живёт отдельно.**
Путешествие за лучшую сделку до 1 октября считает отдел аренды по факту
подписанных договоров. С реферальными баллами не смешивается: одно про явку,
другое про результат. Смешивать нельзя — иначе брокер, приведший двадцать
коллег и не сделавший ни одной сделки, будет считать себя обманутым.

**5. Что бот отдаёт после мероприятия.**
Список свободных блоков на дату, планы корпусов, конструктивный расчёт по
нагрузке, техусловия по мощности. Это превращает разовый бот события в
постоянный инструмент для брокера и оставляет базу живой.

## Аналитика

Бот пишет в тот же JSON, что и RocketVPN: кто пришёл, по чьей ссылке, когда,
сколько привёл. Плюс выгрузка в админ-панель `clusterspace.ru/admin`, где уже
живут заявки с сайта. Отчёт отделу аренды: сколько зарегистрировано, сколько
придёт лично, сколько онлайн, какие запросы клиентов заявлены, топ приглашающих.
