## Отклонено и почему

1. **Штраф 5 000 рублей за просрочку ответа** (вердикт по 07.09 Telegram). Не
   поставлен: это денежное обязательство перед клиентом, его подтверждает
   собственник. Формулировка вынесена в служебное.
2. **Вилка ставки 9 000 - 14 500 рублей за м² в год** (вердикт по 07.09 Telegram).
   Не поставлена: цифра ничем не подтверждена, пункт 3.3 файла
   `НА_ПОДТВЕРЖДЕНИЕ.md` прямо говорит, что рыночного среза нет. Вместо неё в посте
   стоит обещание дать ставку и платёж по строкам в первом ответе.
3. **Переносы единиц на недели 3 и 4** (предлагались для карусели 07.09, Telegram
   09.09, ВК 09.09, Telegram 11.09, Дзен 13.09). Отклонены: число единиц по
   договору в месяце фиксировано, а недели 3 и 4 в этот момент правят другие
   агенты. Каннибализация закрыта переписыванием углов, а не сдвигом дат.
   Результат подтверждается povtory.py: 0 пересечений выше 18 % по всему месяцу.
4. **Добавить вторую единицу в 10.09** (вердикт по историям). Отклонено по той же
   причине: это сверх договорного числа единиц. День усилен внутри существующей
   серии - подсчётом по факту, режимом отгрузки и контактами.
5. **Цифра hh.ru по сроку закрытия вакансии оператора ЧПУ** (вердикт по 07.09
   Дзен). Не поставлена: проверенного среза нет, а подставлять N с датой в
   публикуемый текст нельзя. Заменена на способ, который читатель выполняет сам.
6. **Прямая цитата главного механика и подпись автора в РБК.** Не выдуманы,
   вынесены в служебное как запрос клиенту. Без имени и письменного согласия блок
   не ставим.
7. **Структура вердикта для 13.09 («9 цифр, по которым выбирают цех»).** Заменена
   на денежную по прямому указанию: две статьи Дзена разводятся на «что
   спрашивать» и «что считать деньгами» без общих пунктов. Вариант вердикта
   оставлял бы у обеих статей общий костяк из нагрузки, высоты, лифта, ворот и
   мощности.
