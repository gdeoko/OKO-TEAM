# Проект «Кластер» для Claude Code

Комплексное маркетинговое продвижение бизнес-парка «Кластер» (ООО «Активити») силами OKO TEAM. Договор 005/2026 от 24.06.2026, срок 3 месяца, старт 02.07.2026.

## Как пользоваться этой папкой

Главный файл проекта — `01_context/CONTEXT_KLASTER.txt`. Это единственный источник правды по всему, что связано с проектом: стороны, реквизиты, условия договора, финансы, ТЗ, ЦА, продукт, конкуренты, план, вопросы, история, договорённости, журнал изменений.

Правило: новых контекстных файлов не создавать. Все обновления вносятся в CONTEXT_KLASTER.txt в соответствующие разделы. Старые данные не удаляются, помечаются как «УСТАРЕЛО ДД.ММ.ГГГГ», новая версия рядом. Каждое изменение фиксируется записью в разделе 20 (журнал изменений).
