# Сбор аудитории под брокер-тур

Данные в репозиторий не кладём: это контакты живых людей. Всё лежит на
сервере в `/opt/oko-poster/baza_tur*.csv` и `baza_tur.json`.

## Что чем собирается

| Шаг | Файл | Что даёт |
|-----|------|----------|
| Агентства Москвы и области | `parser_osm3.py` | 470 организаций из открытых карт |
| Агентства по стране | `parser_osm_rf.py` | 2061 организация |
| Почты с их сайтов | `sbor_pocht.py` | обходит контакты и подвалы |
| Каталог Yell | `parser_yell.py` | 796 агентств Москвы: телефоны, Телеграм |
| Профильные чаты | `tg_poisk.py` | 52 группы и канала по недвижимости |
| Люди из чатов | `tg_sbor.py` | авторы сообщений, то есть живые участники |
| Сводка | `svod_vse.py` | единая база и три CSV |

## Итог первого захода

792 организации с почтой · 697 организаций с телефоном ·
2121 человек из чатов, у 1690 есть ник для связи, 848 писали от трёх раз.

## Грабли, которые стоили времени

Overpass закрыт с московского адреса сервера, работает через выход в
Нидерландах (`socks5 127.0.0.1:10840`), и не принимает `--data-urlencode`,
только `--data`. Один большой прямоугольник он тоже не отдаёт, поэтому карта
режется на клетки.

2ГИС и Яндекс.Карты закрыты капчей по адресу браузера, поэтому объём берём
каталогом Yell, а не картами.

Аккаунты acc1 и acc2 постоянно держит служба `oko-agents`, второе
подключение тем же ключом Телеграм отклоняет (`AUTH_KEY_DUPLICATED`).
Для сбора берём acc3 либо останавливаем службу на время работы.

Почты у риелторов в каталогах почти нет: у Yell её показывают 18 карточек из
796. Основной канал связи с этой аудиторией это телефон и Телеграм.
