# Рассылка по брокерам

База контактов в репозиторий не кладётся: это персональные данные 53 человек,
телефоны и почта. Живёт только на сервере, `/var/www/klaster-data/brokers.json`,
права www-data. Источник - файл Александра из чата МЕРОПРИЯТИЯ от 27.08.

Что где:
  · `rassylka_brokery.py` - именные письма, 36 адресов после дедупликации;
    отметка `priglashen_email` не даёт отправить второй раз;
  · `--звонки` собирает список тех, у кого почты нет (15 человек), с готовым
    текстом для мессенджера;
  · отправка идёт через `core.safe_send`, значит чёрный список, антидубль,
    квота и рубильник запуска работают как везде.

Рубильник сейчас открыт для Телеграма и ВК, почта закрыта. Пока Даниэль не
включит канал почты, письма не уйдут, и это правильно: рассылка идёт от имени
клиента, запускаем её по прямому слову.

Связка с ботом живёт в `03_deliverables/bot/bot.php`: телефон из анкеты
находит человека в базе, ставит билет и время. В админке это раздел «Брокеры».
