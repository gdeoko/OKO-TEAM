# Рабочие заметки

Черновики, гипотезы, референсы, любые внутренние материалы, которые не идут клиенту напрямую.

## Что складываем сюда

- Идеи и мозговые штурмы
- Референсы других проектов
- Черновики текстов до финализации
- Тестовые прототипы
- Скриншоты чужих решений для анализа
- Заметки со стратегических созвонов

## Что НЕ храним здесь

- Финальные версии deliverables (они в `03_deliverables/`)
- Оригиналы клиента (они в `04_originals/`)
- Контекст проекта (он в `01_context/CONTEXT_KLASTER.txt`)
