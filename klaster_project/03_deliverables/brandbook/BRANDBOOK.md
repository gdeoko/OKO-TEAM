# Брендбук «Кластер» (v1, 18.07.2026)

Бизнес-парк «Кластер» (ООО «Активити»). Стиль: светлый, чистый, технологичный, промышленная строгость.
Референс визуала: technomoscow.ru. Тон: на «вы», экспертно.

## 1. Логотип

Эмблема: шестерёнка (индустрия, производство) со стилизованной фигурой человека с поднятыми руками
(люди, успех, «пространство успешных компаний»). Воссоздан по реальному логотипу с фасада и лобби парка.

Файлы — папка `logo/`:
- Векторные исходники (SVG): `klaster-logo-horizontal.svg`, `-white.svg`, `-onwhite.svg`,
  `klaster-logo-stacked.svg` (+ tagline), `-white.svg`, `klaster-emblem.svg`, `-white.svg`, `-amber.svg`,
  `klaster-appicon-amber.svg`, `klaster-appicon-dark.svg`.
- `png/` — прозрачный фон, высокое разрешение (1024–1600 px).
- `jpg/` — на белом фоне.
- `pdf/` — векторные, для типографии.
- `favicon/` — favicon.ico (16/32/48), apple-touch-icon (180), icon-192, icon-512.
- `_proof_lockups.png` — обзор всех начертаний.
- `logo_reference/` — фото оригинала (шестерёнка на стене лобби, фасад).

Компоновки:
- Горизонтальная (эмблема + «КЛАСТЕР») — основная, для шапок и документов.
- Вертикальная (эмблема / «КЛАСТЕР» / слоган) — для соцсетей, аватаров, обложек.
- Только эмблема — favicon, иконка приложения, watermark.

Правила использования:
- Охранное поле вокруг логотипа: не менее высоты эмблемы / 2.
- Минимальная ширина горизонтальной версии: 120 px (экран), 24 мм (печать).
- Нельзя: искажать пропорции, менять цвета эмблемы вне палитры, наклонять, добавлять тени/градиенты,
  ставить на пёстрый фон без подложки, менять шрифт вордмарка.
- На тёмном фоне — белая версия. На амбер-подложке — графитовая эмблема.

## 3. Типографика

- Дисплей/заголовки: **Oswald** (условно-узкий индустриальный гротеск, заглавные, вес 500–700).
  Кириллица. Используется в логотипе и заголовках H1–H3.
- Текст/интерфейс: **Manrope** (гуманистический гротеск, 400/500/700). Кириллица. Абзацы, кнопки, подписи.
- Иерархия: H1 44–72px Oswald 700 uppercase, tracking +0.5; H2 28–40 Oswald 600; body 16–18 Manrope 400/500.
- Правила: без длинных тире в клиентских текстах; без эмодзи в интерфейсе (только SVG-иконки);
  числа/единицы — Manrope 700 (для цифр объекта).

## 4. Иконки и графика
- Стиль иконок: линейные, 1.75px, скруглённые концы, монохром (графит или амбер). Без заливок-эмодзи.
- Геометрия бренда: мотив шестерёнки/сот (hexagon), прямые индустриальные линии, чёткая сетка.
- Фото: реальные рендеры и снимки объекта (папка website/assets/img). Приоритет — фасады, интерьеры,
  инфраструктура, производство. Единый тёплый/нейтральный грейдинг.

## 5. Применения
- Сайт (светлая тема + амбер акцент), соцсети (аватар = эмблема на амбер/графит, обложки со слоганом),
  презентации, полиграфия (визитки, стенды, навигация — амбер+графит), email-подписи.
