emblem (без надписи), horizontal (эмблема + надпись сбоку), appicon (иконка).

Правила: не искажать пропорции, не менять цвета вне палитры, не добавлять тени.
На тёмном фоне — светлая/on-dark версия. Минимальная ширина: 24 мм печать / 120 px экран.
