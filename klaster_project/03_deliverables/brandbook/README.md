# Брендбук «Кластер»

## Что делаем

Полный брендбук с нуля (если у клиента нет своего логотипа в векторе).

## Состав

- Логотип: основной, монохром, инверсия, favicon
- Цветовая палитра: основные и дополнительные, коды HEX/RGB/CMYK
- Типографика: заголовки, основной текст, акценты
- Использование логотипа: охранное поле, минимальные размеры, что нельзя
- Иконки и графические элементы
- Примеры применения: сайт, соцсети, презентация, полиграфия

## Стиль

Светлый, чистый, современный. Промышленная строгость + технологичность. Не помпезно, без золотых логотипов, без градиентов девяностых. Референс technomoscow.ru.
