СТРУКТУРА
  01_znak/       — основной знак: монограмма-«А» + вордмарк АКТИВИТИ
  02_emblema/    — только эмблема (монограмма-«А») для иконок и вотермарков
  03_avatar/     — круглый и квадратный аватар на тёмном (соцсети, мессенджеры)
  04_favicon_web/— favicon.ico, apple-touch, web-иконки (192/512)
  05_na_fone/    — знак на белом / тёмном / радиальном фоне (превью применений)
  06_odnocvet/   — одноцветные версии (золото/чёрный/белый) + вектор mono.svg

ФОРМАТЫ в каждом наборе
  .svg  — вектор, бесконечное масштабирование (пиксель-точный, встроенный хайрез)
  .png  — прозрачный фон, мастер + размеры 1600/1024/512/256/128
  .jpg  — на белом и на тёмном фоне
  .pdf  — для типографии (300 dpi)
  06_odnocvet/aktiviti-emblem-mono.svg — истинный контурный вектор (для 1 цвета,
          гравировки, тиснения, вышивки)

ПРАВИЛА
  • Охранное поле вокруг знака — не менее высоты перекладины «А».
  • Не искажать пропорции, не менять цвета, не наклонять, не добавлять тени.
  • На светлом — основной знак; на тёмном — тот же знак (золото читается);
    для одного цвета — набор 06_odnocvet.
  • Аватар — набор 03 (круглый для TG/IG/YT, квадратный где нужен квадрат).
  • Мин. ширина знака с вордмарком: 120 px (экран) / 24 мм (печать).

Знак сгенерирован по оригинальному логотипу парка и доведён до премиум-качества,
затем разложен и собран во все форматы 1:1.
