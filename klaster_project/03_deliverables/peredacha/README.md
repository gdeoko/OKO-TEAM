# Страница передачи проекта «Кластер»

Закрытая паролем страница для заказчика: что сделано, где живёт, какие доступы
переходят, что осталось за заказчиком, и весь архив материалов.

- Публичный адрес: `https://okoteam.top/peredacha/klaster/?k=<пароль>`
- Калитка (проверка пароля): `/var/www/okoteam/peredacha/klaster/index.php` на VPS,
  пароль задан в ней же, страница отдаётся через `readfile`.
- Сама страница лежит ВНЕ корня сайта: `/opt/oko-poster/peredacha/klaster.html`,
  права 644.
- Архив материалов: `/opt/oko-poster/peredacha/arhiv/`, тоже вне корня.
  Обозреватель `arhiv.php`, выдача файлов `fayl.php` — оба проверяют тот же пароль
  и не выпускают за пределы каталога архива.

## Два сборщика

| Файл | Что собирает |
|---|---|
| `peredacha_polnaya.py` | ПОЛНАЯ версия: все доступы, логины, пароли и токены в открытом виде. Значения берёт на сервере из мастер-хранилища `/opt/oko-poster/cfg/OKO_MASTER_VAULT.md` и боевого `api/config.php`. Запускать ТОЛЬКО на сервере. Результат в репозиторий не кладём. |
| `peredacha_build.py` | Чистая версия без единого пароля: сводка проекта и перечень передаваемых доступов. Её результат (`klaster.html`) лежит рядом и безопасен. |

Полная версия сама вырезает нашу внутреннюю кухню: раздел механики генерации,
VNC рабочего стола, прокси и PAC. Клиенту уходят только доступы его проекта.

## Как развернуть

```sh
# чистая версия (локально)
python3 peredacha_build.py && cp klaster.html /opt/oko-poster/peredacha/klaster.html

# полная версия (только на сервере, от root)
php live_cfg.php && python3 peredacha_polnaya.py && rm -f /opt/oko-poster/peredacha/live_cfg.json
curl -s -o /dev/null -w "%{http_code}\n" "https://okoteam.top/peredacha/klaster/?k=<пароль>"
```

## Что лежит в архиве

- `chat/` — 290 вложений рабочего форума, разложенные по веткам (271,9 МБ).
- `chat_zip/` — те же вложения архивами по веткам.
- `pakety/` — готовые пакеты: брендбук, сайт, контент-план, соцсети, Система OKO,
  рабочие заметки, оригиналы заказчика.
- `chat_opis.json` — опись переписки: кто, когда, в какой ветке, с какой подписью.

Выгрузка чата делается скриптом `/tmp/chat_polnyi.py` (сообщения) и
`/tmp/chat_skachat.py` (вложения). ВАЖНО: перед запуском гасим службу агентов
(`{"op":"agents_stop"}` на `$CONTROL_URL/agent`) и поднимаем после
(`agents_start`) — иначе второе подключение к сессии Telegram убивает аккаунт.

## Правила страницы

- Самодостаточная: ни одного внешнего запроса, лого внутри файлом base64.
- Без эмодзи, тёмный верх и фирменный янтарь «Активити», mobile-first.
- `noindex, nofollow` в разметке, в robots.txt путь не светим.
- ПОЛНАЯ версия — самый ценный файл проекта. После приёмки её снимают,
  а все пароли меняют: порядок смены написан на самой странице.
