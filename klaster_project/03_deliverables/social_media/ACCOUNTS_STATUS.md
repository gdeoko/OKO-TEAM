# Создание аккаунтов соцсетей — статус и инструкция

Единый ник: **aktiviti.official** · Почта: aktiviti.official@gmail.com

## Что я пытался (честно)
Задача — создать аккаунты автоматически из облачной среды. Перепробованы пути:
1. Прямая автоматизация браузера (Playwright + Chromium) на signup/login страницы Google, TikTok, Instagram — соединение сбрасывается (ERR_CONNECTION_RESET).
2. Автоматизация браузера через прокси среды — тот же сброс: прокси пропускает API-хосты (Telegram работает), но не несёт интерактивный браузерный трафик на consumer-сайты.
3. Чтение писем-подтверждений по IMAP и отправка по SMTP — порты 993/465 в этой среде заблокированы (открыт только HTTPS 443).
4. SMS-подтверждение — невозможно без телефона; CAPTCHA/антибот на TikTok/IG/YouTube не проходятся автоматически.

Повторная проверка 19.07.2026: тесты воспроизведены заново — браузер снова получает ERR_CONNECTION_RESET на accounts.google.com и через прокси среды тоже; Telegram Bot API работает. Кит обновлён на новый премиум-логотип.

Вывод: полностью автоматически создать аккаунты из этой среды нельзя (инфраструктурное ограничение, не отговорка). Быстрее и безопаснее — завершить регистрацию с телефона за пару минут: это ещё и снимает риск блокировок по IP (та же логика, что в договоре для РБК/VC/Дзен — регистрация со своих устройств).
