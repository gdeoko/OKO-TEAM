# Деплой сайта «Кластер»

## Что это
Классический сайт: статика (HTML/CSS/JS) + PHP-бэкенд формы. Не конструктор.
Работает на любом обычном PHP-хостинге (или VPS с nginx+php-fpm). Домен оплачивает клиент.

## Файлы
- `index.html` — страница.
- `assets/` — css, js, fonts (вшиты base64), img (реальные фото/рендеры), logo, favicon.
- `api/lead.php` — приём заявки: уведомления в Telegram (@aktivitiorderbot, всем 4 руководителям) + письмо + лог в `data/leads.json`.
- `api/config.php` — ключи (в git НЕ коммитится; лежит локально; на сервере создать из `config.sample.php` или задать переменные окружения ACTIVITI_*).
- `.htaccess` — кэш, gzip, защита `data/` и `config.php`.
- `robots.txt`, `sitemap.xml`, `site.webmanifest`.
- `preview-standalone.html` — самодостаточный превью-файл (всё вшито, открывается офлайн, без бэкенда; для показа).

## Шаги деплоя (обычный хостинг)
1. Купить домен, навести на хостинг, включить SSL (Let's Encrypt).
2. Залить содержимое папки `website/` в корень сайта (public_html).
3. Создать `api/config.php` из `api/config.sample.php`, вписать токен бота, chat_id руководителей, Gmail app-password (значения — в secrets.env проекта). Либо задать ENV ACTIVITI_*.
4. Проверить, что PHP имеет `curl` (для SMTP и Telegram). На большинстве хостингов есть.
5. Права: папка `data/` доступна на запись PHP (0755/0775).
6. Обновить в `index.html` реальный домен в canonical/OG и `sitemap.xml` (сейчас плейсхолдер klaster-park.ru).
7. Подключить Яндекс.Метрику/Google Analytics (вставить счётчик перед `</head>`).

## Проверка формы
Отправить тестовую заявку → должны прийти: сообщение в @aktivitiorderbot всем 4 руководителям + письмо на ddouglas@activity.su + запись в `data/leads.json`.
Примечание: из облачной среды разработки почтовые порты закрыты, поэтому SMTP тестируется уже на хостинге. Telegram работает и из среды.

## Быстрый предпросмотр без хостинга
Открыть `preview-standalone.html` в браузере (в т.ч. на телефоне). Форма в превью показывает успех локально (без реальной отправки).
