# Сайт бизнес-парка «Кластер»

## Что делаем

Лендинг под ключ + чат-бот на сайте.

## Стек

Чистый HTML/CSS/JS + PHP + JSON + cron. Не конструктор, не шаблон.

## Обязательные разделы

- Первый экран: оффер, ключевая ценность, CTA
- Блок «О парке»: краткое позиционирование
- Транспортная доступность: карта с метро Каспийская (2028), МЦД Котляково (2029), Царицыно (шаттл), парковка 550 мест
- Технические параметры помещений: потолки 9м, нагрузка 4000 кг/м², мощность 100 кВт, отдельные входы
- Инфраструктура: кафе-столовая, кофейня, «КластерКлаб» (раздевалки, душевые, зоны отдыха)
- Отрасли для арендаторов: микроэлектроника, оптика, ИКТ, энергоэффективные технологии, наноматериалы, медтех
- Каталог свободных помещений (обновляемый)
- Форма заявки
- Анкета арендатора для квалификации лида
- Отличия от конкурентов: статус технопарка, 2 станции метро строятся по периметру, современный ремонт
- Работа с возражениями: далеко от центра, инфраструктура, метро

## Технические требования

- Адаптивная вёрстка, мобильная версия
- PageSpeed 95+
- SSL, аналитика (Яндекс.Метрика/GA)
- SEO с самого старта: мета, Schema.org, ключи под аренду промки в Москве
- Хостинг входит в услугу, домен оплачивает клиент отдельно

## Референс визуала

technomoscow.ru — светлый, чистый

## Чат-бот на сайте

Прогревает клиента, отвечает на частые вопросы (метро, ремонт, погрузка), может отправлять презентацию, планировки, договорные шаблоны.
