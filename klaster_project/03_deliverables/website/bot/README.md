# Бот брокер-тура «Кластер»

`bot.php` — самодостаточный вебхук на PHP, живёт на домене клиента
`https://clusterspace.ru/bot.php` рядом с сайтом. Данные в `data/bot/`, закрыты
nginx-правилом `location ^~ /data/ { deny all }`.

Механика перенята с розыгрыша RocketVPN: персональный HMAC-код, балл только
после завершённой регистрации приглашённого, фиксация победителей с повторной
проверкой подписки, отказ фиксировать рейтинг при недоступном API.

## Развёртывание

1. `bot.php` в корень сайта, `data/bot/config.php` по образцу `config.sample.php`.
2. Токен, секрет и соль в конфиг. Секрет уходит в URL вебхука, соль — в HMAC.
3. Бот должен быть администратором канала `@radialnya` (для проверки подписки).
4. Вебхук: `setWebhook url=https://clusterspace.ru/bot.php?s=<секрет>`.

## Команды

- `/start` — регистрация, выдача билета и ссылки для приглашений
- `/bilet`, `/menu` — открыть билет и меню
- `/stat` — статистика (только админам)
- `/pobediteli` — фиксация победителей по приглашениям (только админам)
