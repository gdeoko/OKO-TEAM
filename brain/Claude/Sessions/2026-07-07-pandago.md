# 2026-07-07 · PandaGo /order/ + сборка oko-magic

## Сделано
- Полный премиум-редизайн pandago-order/: скролл-путешествие (одна Three.js
  сцена на весь сайт, камера по CatmullRom за байком, этапы: подиум, порт,
  тихая зона, горы, башни+ворота), GLSL-аврора c uProgress, игровой HUD
  (этапы, lerp-координаты, звук WebAudio), fx.js (скрэмблинг, курсор,
  магниты, Lenis), чистая адаптивная таблица сравнения вместо шторки.
- Байк: poly.pizza CC-BY (Zsky), перекрашен кодом под бренд, кредит в футере.
- Превью-деплой: forest-beach-360.higgsfield.app (статика в app/public/).
- Self-QA: journey.js в scratchpad (6 точек скролла, 2 вьюпорта, консоль).
  ВАЖНО: scrollTo в тестах только behavior:'instant', иначе рваные кадры.
- Смержена ветка claude/new-branch-setup-mq8llw (oko-magic, brain/, zoopt,
  vendor-библиотеки). oko-web-factory удалён, его арсенал влит в oko-magic
  (секции: бесплатные 3D-источники, референс PandaGo).

## Решения
- Сравнение цен: слайдер-шторка рвала цены на мобилке - заменена таблицей.
- Фикс-канвас на весь сайт + секции-вуали; карточки уплотнены до rgba .78.
- HUD включается после p>0.045, чтобы не дублировать hero.

## Среда (грабли)
- Ключи (HF_TOKEN и др.) в этой сессии НЕ видны: контейнер создан до их
  добавления. Новые сессии получат из Environment variables.
- gradio_client работает и анонимно (Z-Image-Turbo /generate жив).
- Gmail MCP подключился (search_threads, create_draft, labels).

## Незакрытое
- HF-видео-пролёт со scroll-scrub для секции процесса (ждёт команды).
- 3D из фото техники (кредиты Higgsfield), Mixamo-пак (ручное скачивание).

  возвращать из b93868d.
