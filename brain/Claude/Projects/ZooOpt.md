# ЗооОпт · Склад · Маркет

#проект/зооопт #статус/в-работе

Бренд: «ЗооОпт» — ТРИ «о» (Зоо+Опт)! Лого: пёс+кот на жёлтой луне в чёрном круге.
Палитра: айвори #F5F1E8, зелёный #1B8A3A / #0F5C24, жёлтый #FFD500, чёрный #0A0A0A.
Шрифты: Unbounded (заголовки), Onest (текст). Павильон №69-70, тел +7 (977) 99-555-66, zoopt.ru.

## Готово
1. **Печать**: 16 PDF оклейки витрины (CMYK, bleed 5мм, метки реза, шрифты встроены) + index.pdf.
   Код: `zoopt/src/` (design_system, layouts, generate_all, ai_generate). Запуск: `python3 src/generate_all.py`.
   Визуал животных: AI (FLUX-Krea) → вырезка силуэтов → фирменный жёлтый круг. Архив клиенту отправлен (v2, с исправленным «ЗооОпт»).
2. **Сайт «Ночной рейс»**: https://spicy-panther-317.higgsfield.app
   Скролл-путешествие по 3D-миру: 5 глав (пролог/собаки/кошки/малыши/портал ОПТ), станции-луны с силуэтами,
   bloom, HUD+рейл, whoosh-звук, 3D-лиса (крутить, 3 анимации), утка CC0. Код: `zoopt/site/`.
