## МОДЕЛЬ РАБОТЫ ЗАВОДА (слово Даниэля 2026-09-04) — ГЛАВНОЕ
Ежедневно старт в назначенное время (уточняется: 04:00 или 07:00 МСК).
1. Включаю рубильник (`core/launch.py on`).
2. ЧАС 1 — анализ конкурентов по правилам (10 конкурентов от 1М, по 3 ролика = 30,
   разбор ~30 пунктов) + собрать страницу в АДМИН-ПАНЕЛИ клиента (всё отобразить) +
   отправить нужное сообщение в рабочий чат в ОТДЕЛЬНУЮ ВЕТКУ. Всё поэтапно по
   docs/ЗАВОД_ПОЭТАПНО.md и КОНТЕНТ_ЗАВОД.md.
3. ЧАС 2 — собрать ВЕСЬ контент дня: ролики + посты + карусели + статьи + сторис.
4. Контент собираем НА СЛЕДУЮЩИЙ день (не на сегодня) и шлём на УТВЕРЖДЕНИЕ.
5. НЕ публикуем, пока клиент/владелец не подтвердит «хорошо, в публикацию».
6. Двухсторонний мост: рабочий-чат <-> агент на VPS <-> эта Claude-сессия.
   - Клиент подтвердил публикацию -> агент передаёт сюда -> я ставлю публикацию в расписание.
   - Клиент задал вопрос / попросил правку -> приходит сюда -> отрабатываю по правилам.
Вся сборка = 2 часа (1 час анализ + 1 час контент). Всё строго по прочитанным
правилам и приёмке (QA >=85/100, ноль повторов, длинное тире никогда,
озвучка только ElevenLabs, генерация по правилу №1).
