# Проект: Автоматизация контент-завода (reels-machine + автопостинг)

Статус: СТАРТ ПОСЛЕ сайта PandaGo. Клиентское ТЗ зафиксировано 09.07.2026.
Движок роликов — скилл `reels-machine` (готов, бесплатный). Здесь — обвязка автоматизации.

## Требования клиента (дословный смысл)
- 3 ролика/день в TikTok + YouTube + Instagram. За 60 дней — 500 роликов.
- Разнообразие в КАЖДОМ ролике: кадры, стоки, 3D/WebGL, Lottie, инфографика, фигуры.
  Ни один не шаблонный. Постоянны ТОЛЬКО: голос, шрифт, цвета.
- Под каждое приложение — зайти в реальный апп, отснять видео работы; вставлять свои демки.
- Higgsfield НЕ тратить (платно, 2 кр/фото). Обложки — БЕСПЛАТНО, свой красивый текст.
  Обложка = первый кадр (сейчас обложек на роликах нет). Каруселей не надо.
- Публикация по аналитике лучшего времени (пример: 10:00, 15:00, 18:00 — но по данным).
- Ежедневная аналитика на бесплатном хостинге: отдельная ссылка, полные данные с каждой
  соцсети — потрачено, охваты, просмотры, переходы на сайт. Залетевшее — делать чаще
  (темы, время суток, форматы). Держать в памяти, анализировать, авто-публиковать.
- «Платишь везде» — уточнить: органика или платное продвижение (реклама)?
- Качественно, без багов/лагов, автономно 2 месяца.

## Что уже есть (скилл reels-machine)
Сборка ролика 1080×1920 полностью бесплатно и локально: edge-tts (ru Dmitry/Svetlana),
Pexels/Pixabay стоки, Freesound музыка/sfx, 125 gl-переходов, three.js (объект-в-кадре,
турнтейбл, 3D-текст, частицы, туннель, 2.5D-параллакс Depth-Anything, MapLibre карта),
Remotion инфографика, Lottie, rembg-коллаж, караоке-ASS, 3-этапный ffmpeg, реестр
USED_EFFECTS (запрет повторов). Обложку добавить бесплатно: HTML→скриншот.

## Чего НЕ хватает (это и есть автоматизация)
1. Бесплатная генерация обложек (HTML→screenshot, on-brand, идеальный текст) — в скилл.
2. Съёмка реальных апп: web-приложения — Playwright (ок); нативные mobile — сложно
   (эмулятор/присланные клипы). Флаг.
3. Слой публикации в 3 сети — API-постер.
4. Расписание + постинг в оптимальное время.
5. Сбор аналитики с каждой сети (просмотры, охват, клики, расход).
6. Дашборд аналитики на бесплатном хостинге (из Supabase).
7. Цикл оптимизации (винрейт → чаще делать залетевшее).
8. Автономность/оркестрация на 60 дней.
9. Платное продвижение (если да) — ad API + бюджеты, отдельный тяжёлый модуль.

## Рекомендованный стек
- **Оркестратор: n8n** (self-host, бесплатно, cron+HTTP+соцсети) — «один сервис подключить всё».
  Альтернативы: Make.com (проще, платно), Zapier (есть, дорого на объёме).
- **Публикация+аналитика: Ayrshare** (один API → TikTok+YouTube+IG, авторизация+статы).
  Бесплатная альтернатива: Postiz (self-host) или Blotato.
- **БД: Supabase** (есть) — очередь роликов, лог постов, аналитика.
- **Дашборд: статик-сайт на бесплатном хостинге** (Higgsfield/GitHub/Cloudflare Pages) из Supabase.
- **Раннер завода:** нужен постоянный (VPS/облачный runner) — эфемерная сессия Claude не 24/7.
- **Claude как креатив-мозг:** через Routines (cron) — собирает дневную партию/ревьюит
  аналитику/обновляет очередь тем. Детерминированную сборку делают скрипты скилла.

## Честные риски (обязательно проговорить)
- Платформы ограничивают автопостинг: TikTok Content API — нужна аппрув (иначе только
  приватные драфты); Instagram Graph — Business-аккаунт + ревью FB-приложения, лимит
  ~25-50 reels/день; YouTube API — квота (upload ~1600 units, дефолт 10k/день ≈ 6 загрузок,
  можно запросить больше). 9 постов/день реально, но нужна правильная настройка/аппрувы.
- «Без багов, автономно» — реалистично через MVP → стабилизация → масштаб, с burn-in и
  мониторингом. Не «переключатель», а сборка + супервизируемый разгон.
- Нативные mobile-апп записи — хрупко; web-версии + присланные клипы надёжнее.
- Платная реклама — отдельные ad-аккаунты/бюджеты/платёжки по каждой сети, риск слива —
  начинать с органики, платное позже с жёсткими лимитами.
