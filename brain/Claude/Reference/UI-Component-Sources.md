# Источники компонентов и дизайна против «шаблонного» вида (проверено 09.07.2026)

Главный принцип (из ролика, верный): НЕ просить «сделай красиво с нуля».
Давать агенту **визуальный референс + готовые компоненты + DESIGN.md**. Тогда результат
сразу сильнее и не шаблонный. Использовать во ВСЕХ сайтах OKO.

## 1. React Bits — reactbits.dev
- Open-source, **130+ анимированных React-компонентов**: тексты, **фоны (WebGL/шейдеры)**, UI.
- Настройки крутятся в браузере → копируешь код. Лицензия MIT + Commons Clause (коммерция OK).
- GitHub: github.com/DavidHDev/react-bits. Есть даже **MCP-сервер** (135+ компонентов):
  github.com/ceorkm/reactbits-mcp-server.
- **Ключевое для нас:** там десятки готовых ЖИВЫХ фонов (Aurora, Particles, Waves, Silk,
  Threads, Dot Grid, Beams и т.д.) — real-time WebGL, бесплатно, drop-in. Это ровно «живой
  фон, который двигается в покое», без AI-видео и без шаблона.

## 2. UIverse.io
- Крупнейшая open-source библиотека UI, **5800+ элементов** от сообщества.
- Кнопки, карточки, лоадеры, анимации, hover-эффекты. Экспорт: CSS / Tailwind / React / Figma.
- MIT, бесплатно для коммерции. github.com/uiverse-io/galaxy.
- Для нас: полированные микро-компоненты (кнопки, карточки, свечения) — без «дефолтного» вида.

## 3. DESIGN.md — designmd.app / github.com/voltagent/awesome-design-md
- Текстовые файлы дизайн-систем (цвета, шрифты, отступы, правила компонентов в Markdown+YAML),
  которые агент читает ПЕРЕД генерацией UI → единый, консистентный, не-шаблонный результат.
- **461+ готовых DESIGN.md**. Кладёшь в репо → агент делает UI под этот стиль.
- Для нас: написать **PandaGo DESIGN.md** (наш бренд: navy #081833 + cyan/electric, шрифты,
  отступы, компоненты) — держит весь сайт в одном премиум-стиле. То же для ЗооОпт / OKO.

## Как применяем в OKO
1. Живые фоны и эффекты — берём из **React Bits** (WebGL-фоны, тексты, частицы), бесплатно.
2. Микро-UI (кнопки/карточки/лоадеры) — **UIverse**.
3. Единый стиль без шаблона — свой **DESIGN.md** на каждый проект.
4. Плюс наш контент (видео/3D/кадры) поверх — уникальность.
