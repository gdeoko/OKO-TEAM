## Ключевые инструменты (я вызываю через MCP сама)
| Инструмент | Что делает |
|-----------|-----------|
| `generate_image` | картинки (gpt_image_2, nano_banana_2 и др.) |
| `generate_video` | видео (seedance_2_0, kling, gemini_omni; роли start/end image, video ref) |
| `generate_3d` | **фото → GLB 3D-модель** (та самая «пачка корма, что разлетается») |
| `upscale_image/video` | до 2K/4K |
| `remove_background` | вырезка (для параллакс-слоёв) |
| `motion_control` | recast / puppeteer / перенос движения |
| `reframe`, `outpaint` | смена AR / расширение кадра |
| `models_explore` | подбор модели под задачу |
| Supercomputer / Apps | готовые апки: Ad Studio, MotionForge, Cover Studio, Shorts Studio, AI Influencer, Explainer |
