# OKO — Как делать супер-сайты уровня Awwwards (и круче)
### Полное досье: почему «библиотеки не помогают», как это сделано у топов, что нужно и сколько стоит

Собрано по нашему общению (Даниэль × Claude Code, июль 2026). Это рабочий документ —
кладётся в проект/мозг и читается перед любым премиум-сайтом.

---

## 1. ГЛАВНЫЙ ВЫВОД (почему 20 раз получалась фигня)

**Библиотеки и генераторы шаблонов НЕ решают задачу.** Three.js, GSAP, Lottie, Spine, готовые
UI-киты — это инструменты, а не результат. Сам по себе «крутой стек» даёт средний сайт.

Мы 20 раз упирались не в код, а в **КОНТЕНТ и МЕТОД**:
- **Код-механику мы умеем** (скролл-скраб, параллакс, 3D, вырезки — всё проверено, работает).
- **Проваливался контент**: самодельные картинки и стоки не собираются в «единую картину» —
  у них разный свет, стиль, ракурс. Кино не монтируется из чужих кадров.
- **Проваливался метод бесшовности** — не знали правило стыков (см. раздел 4). Без него
  «полёт камеры» рвётся на склейках = «глюкнутое видео».

**Правда про топ-сайты, которую никто не говорит:** «живого 3D с фотореал-животными в браузере»
не существует даже у победителей Awwwards. Всё «кино» — это **заранее отрендеренное AI-видео,
скрабленное скроллом** (техника Apple/Emons). Камера реально движется — скролл лишь двигает время.
Секрет = не интеграция, а **бюджет на качественный видео-контент + правильный метод сборки**.

## 2. РАЗБОР РЕФЕРЕНСОВ (папка `видео_референсы/` + `кадры_разбор/`)

Все «ахуенные сайты из Claude Code» — ОДНА формула: **дорогое AI/рендер-видео + вырезки-параллакс +
крупная типографика + скролл**. Ни в одном нет живого 3D в браузере.

| # | Пример | Как сделано технически |
|---|--------|------------------------|
| 00 | **NomadaToast (бургер)** | 3D-объекты СЛОЯМИ поверх анимированного фона: булка/котлета/сыр — отдельные модели (или PNG-секвенции из 3D). GSAP-таймлайн разлетает по скроллу и сводит в «пачку на столе». Фон — отдельный слой. |
| 01 | **Omni Flash (London-трюки)** | Не сайт, а модель Google Gemini Omni Flash: даёшь СВОЁ видео + текст-промпт → правит сцену (волна из реки, фургон в невесомости, стеклянный мост). «Щёлкнул пальцами». |
| 02 | Интерьер-галерея | Полноэкранный AI-видео-фон интерьера + минимум UI. |
| 03 | Пастель-небо + рыбка | Видео-фон неба + **PNG-вырезки** (колонна, ракушка, рыбка) с параллаксом — «разлетаются» на скролле. |
| 04 | VERTEX3D (здание) | Отрендеренный **облёт здания** = видео-скраб. |
| 05 | Unmatched Trust (волны) | Тёмная типографика + волны. Самое простое — чистый CSS/JS, без видео. |
| 06 | FIND Real Estate | **Видео в маске букв** (CSS clip-path по тексту) + небо-фон. |
| 07 | Катана | Облёт продукта (видео или один GLB на тёмном фоне). |
| 08 | Adidas × Foot Locker | Готовый рекламный 3D-ролик бренда как фон + шоп-UI. |
| 09 | Remotion | «Видео кодом»: React-компоненты рендерятся в MP4. Для промо/титров/инфографики, не для фотореал-фона. |

**Вывод:** 90% эффекта = видео-скраб + вырезки. 3D живой нужен ТОЛЬКО для интерактива
(крутить продукт мышкой, игровое путешествие по сплайну, частицы под курсор).

## 3. ЧТО НУЖНО (стек OKO, проверено боем)

### Бесплатно / уже есть ($0)
- **Claude Code** — сборка кода, вёрстка, логика, self-QA.
- **Скраб-механика** (GSAP + Lenis + видео currentTime), **three.js** (живой 3D-слой), **Rive**, **Remotion**.
- **Pexels/Pixabay API** — настоящие 1440p/4K стоки бесплатно (для черновиков и вставок).
- **HF Spaces** (Z-Image, wan) — бесплатные генерации в лимите квоты.
- **Real-ESRGAN** — апскейл до 4K бесплатно в нашей среде.
- **Скиллы**: `scroll-world` (полёт сквозь мир), `forja-landing` (кино-лендинг + анти-AI-slop критика),
  `reels-machine` (завод роликов), `oko-magic` (регламент), `remotion-video`.

### Платно (топливо для «единой картины»)
- **Higgsfield Ultra ($99/мес, годовая)** — Kling 3.0/Seedance 2.0 (до 4K), Omni Flash (правки-магия),
  фото→3D (GLB), безлимит картинок. MCP = я генерю сама. **Omni Flash = 3 кредита/сек** (8с = 24 кр).
- **Gemini API (за факт, ~$0.80/8с)** — Omni Flash / Veo 3 напрямую, резерв когда кредиты кончились;
  плюс мозги/картинки для функций приложения OKO APP.

### Блокеры к тебе (1 клик каждый)
- Домен `r2.cloudflarestorage.com` в network policy окружения → стриминг видео без «зависаний».
- `GEMINI_API_KEY` + биллинг → в Environment variables окружения.

## 4. КАК СОБИРАТЬ (метод scroll-world — папка `метод/`)

Полный процесс в `метод/scroll-world_SKILL_полный_метод.md`. Ядро:

1. **Интервью**: тема/бизнес, бренд-кит (4-6 hex), арт-дирекшн (единый «style preamble» — залог
   цельности), 5-7 сцен-глав по цепочке ценности.
2. **N сцен-стиллов** — по одной картинке на главу, ВСЕ с одинаковым style preamble (gpt_image_2).
3. **N dive-клипов** — камера влетает в каждую сцену (seedance_2_0 image-to-video, старт = стилл сцены).
4. **N-1 коннекторов** — ⚠️ **ГЛАВНОЕ ПРАВИЛО БЕСШОВНОСТИ:** старт/конец коннектора = РЕАЛЬНЫЕ
   отрендеренные кадры соседних клипов (ffmpeg extract), **НЕ исходные стиллы**. Свежий рендер всегда
   чуть другой → «поп» на стыке. Frame-identical + маленький crossfade (~0.08) = НЕТ склеек.
5. **Энкод для скраба**: `-crf 20 -g 8 -movflags +faststart -an` + лёгкий `unsharp`. Дублировать
   WebM/VP9 (Chromium/headless не всегда декодит H.264).
6. **Движок** `метод/scrub-engine_движок.js` — берётся как есть. Внутри **blob-seek**: грузит клип
   как Blob и скрабит currentTime, поэтому работает на любом хостинге (даже без HTTP Range —
   это лечит «видео зависло на 1 кадре», нашу главную боль).
7. **QA-гейт (не пропускать):** прогон headless, 3 позиции скролла, **хэши кадров ОБЯЗАНЫ отличаться**.
   Одинаковые = скраб мёртв. Console чистый, overflow 0 на 360px, mobile + reduced-motion фолбэк.

**Две архитектуры камеры:**
- **A) Непрерывный форвард-тэйк** (реализм/walkthrough): камера только вперёд, каждый следующий
  клип стартует с реального ПОСЛЕДНЕГО кадра предыдущего, без end-image. Без коннекторов. Дороже
  (строго последовательно), но идеально бесшовно.
- **B) Диорама dive+aerial** (миниатюрный мир god's-eye): влёт + коннектор «взлёт-облёт-снижение».
  Быстрее (параллельно), но разворот камеры на стыке — только для карты-миниатюры.

**Как сделать КРУЧЕ референсов:** поверх видео-скраба добавляем наш слой — three.js частицы/3D-объекты,
GSAP-разлёт элементов (как бургер), Rive-персонажи, kinetic-типографика, звук-дизайн (WebAudio).
У референсов этого слоя обычно НЕТ — это наше преимущество.

## 5. СТОИМОСТЬ И ЗАРАБОТОК

**Себестоимость сайта:** ~600-900 кредитов HG (N картинок + 2N-1 видео) ≈ 1500-3000 ₽.
Ultra 3000-6000 кр = **3-8 сайтов/мес** с запасом.

**Экономия:** короткие 5-6с лупы вместо длинных роликов (×2 дешевле); черновики дешёвой моделью
(wan ~$0.08), чистовая генерация только утверждённых сцен; фикс seed = без пересъёмок; 720p + Real-ESRGAN
до 4K бесплатно; скраб только на hero, остальное — лупы и параллакс-вырезки (бесплатно).

**Заработок (по нашим цифрам):** сайт продаётся 60-70к ₽ (такие стоят 150-200к). Маржа ~95%.
**5 сайтов/мес = 300-350к ₽, 10 = 600-700к ₽.** + контент-завод роликов (reels-machine) на клиентов
= +100-250к ₽/мес на той же подписке. Потенциал производственной мощности **~400к-1М ₽/мес**.

## 6. ПОРЯДОК ЗАПУСКА (когда оплачен Higgsfield)

1. Тест-клип Omni Flash → замер реального расхода кредитов, запись в паспорт.
2. `/scroll-world` на проекте: интервью → сцены → генерация мира (фоном) → коннекторы по правилу
   стыков → энкод → сборка движком → QA хэшами.
3. Слой «круче»: three.js/GSAP-разлёт, Rive, звук.
4. Деплой (Higgsfield websites + githack-зеркала), проверка live curl'ом.
5. Показ + правки (правки в коде мгновенные).

**Итог:** механика собрана и проверена полностью. Не хватало метода бесшовности (теперь есть,
скилл scroll-world) и топлива (кредиты HG). С ними — уровень референсов достижим с первого
правильного прогона, а наш доп-слой делает результат выше их.
