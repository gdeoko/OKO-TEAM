## Среда Claude Code (web)
- Облачный контейнер, репо клонируется свежим. Всё ценное — коммитить и пушить сразу.
- Ветка работы: `claude/new-branch-setup-mq8llw` (зоопт+сайт). OKO-app — `claude/new-session-w2ptqy`.
- Исходящий HTTPS через прокси `$HTTPS_PROXY`. curl работает, node fetch мимо прокси НЕ ходит.
- apt: сначала `apt-get update`, иначе 404 на пакетах. Установлены: ffmpeg, poppler-utils, potrace.

## Playwright / скриншоты / видео
- Python playwright + системный Chromium: `/opt/pw-browsers/chromium-1194/chrome-linux/chrome`.
- Args для WebGL в headless: `--use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader --no-sandbox`.
- Прокси браузеру: `proxy={"server":$HTTPS_PROXY,"bypass":"localhost,127.0.0.1"}` — БЕЗ bypass localhost не откроется.
- Видео: record_video_dir в new_context, скролл РЕАЛЬНЫМИ mouse.wheel (Lenis перехватывает), webm→mp4 через ffmpeg.
