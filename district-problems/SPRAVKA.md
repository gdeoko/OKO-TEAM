# Справка: проблемы жителей по адресам (для карты на anisimov201.ru)

Источник — обход жителей, поселение Сосенское и соседние территории НАО.
**175 заявок, 78 адресов, 32 категории проблем.** ФИО и телефоны из выгрузки
исключены — в карту идут только «проблема + адрес + число заявок».

Дубли убраны: блок по Скандинавскому/Липовому в исходнике был вставлен дважды
(те же люди и телефоны) — считали один раз. Одна заявка может попадать сразу
в несколько категорий (например «крысы и парковки»), поэтому сумма по
категориям больше числа заявок.

## Что бросается в глаза (для повестки)

- **Парковки — проблема №1 с огромным отрывом**: 47 из 175 заявок, четверть всех
  обращений, и почти на каждом адресе. Это тема, которую жители называют первой.
- **Липовый парк, 4к1 — отдельный кейс УК**: ДУ МКД, потопы, плесень, лифты,
  невывоз мусора, не дают сменить УК. Готовый адресный сюжет.
- **Крысы** — системная проблема Липового парка (8, 9, 10, 7, 4к1, 4к3), связана
  с невывозом мусора: два верхних адреса по крысам совпадают с адресами по мусору.
- **Запахи** локализованы жёстко: бульвар Веласкеса (Фуд Сити и промзона) —
  4 адреса подряд, плюс канализация на Фитаревской 15/19.
- **Дубы** — единая тема по всей Коммунарке (9 адресов), звучит как «вырубка
  дубов-аборигенов без ухода за оставшимися насаждениями».
- **Питбайки + ночные гонки** — 18 заявок вместе, вечерний шум по Липовому парку
  и Скандинавскому бульвару.
- **Лифты** — точечно, но остро: Липовый парк 2 (застревают на 2 часа), 4к1, 8к1,
  Фитаревская 17, Лазурная 14.

## Файлы для загрузки

- `problems-map.json` — готовая структура для карты: точка = адрес, внутри список
  проблем с количеством заявок и примерами формулировок. Поле `geocode_query` —
  строка для геокодера Яндекса, координаты подставить при импорте.
- `problems-by-address.csv` — плоская таблица «адрес; зона; проблема; заявок; примеры».
- `problems-by-category.csv` — «проблема; всего заявок; топ-адреса».
- `build.py` — исходник агрегации, туда же дописывать новые обходы.

Разделитель в CSV — точка с запятой, кодировка UTF-8.
