# Проблемы жителей по адресам — данные для карты на anisimov201.ru

Единый источник правды — сырые списки обхода в `inbox/*.txt`.
Всё остальное собирается из них командой `python3 ingest.py`.

| Файл | Что это |
|---|---|
| `inbox/*.txt` | сырьё: списки обхода как их прислали, в любом формате |
| `ingest.py` | парсер и агрегатор: режет по телефонам, **выбрасывает ФИО и телефоны**, нормализует адреса, раскладывает по категориям, снимает дубли |
| `problems-map.json` | точки для карты: адрес, зона, число заявок, проблемы с количеством и примерами |
| `problems-by-address.csv` | плоская таблица «адрес; зона; проблема; заявок; примеры» |
| `problems-by-category.csv` | «проблема; всего заявок; топ-адреса» |
| `render.py` | собирает читаемую справку из `problems-map.json` |
| `Справка_проблемы_по_адресам.html` / `.pdf` | справка для чтения и печати |

## Догрузить новый обход

```
# 1. положить файл с сырым текстом
cp новый_список.txt inbox/07_novyy.txt
# 2. пересобрать данные
python3 ingest.py
# 3. пересобрать справку
python3 render.py
```

`ingest.py` печатает отчёт: сколько записей разобрано, сколько дублей снято,
сколько осталось без адреса или без категории. Нераспознанное помечается
«Не размечено — проверить вручную», а не выбрасывается молча.

## Персональные данные

ФИО и телефоны в выгрузку не попадают. Телефон используется только внутри
парсера — чтобы разрезать текст на заявки и снять повторы. Сырьё в `inbox/`
содержит ПД: это рабочий материал, не публиковать.
