## 12. Проверка серверной части на настоящей базе (05.09.2026)

На машине разработки MariaDB нет по умолчанию, но ставится:
`apt-get update -qq && apt-get install -y -qq mariadb-server`, поднимать так:
`mkdir -p /run/mysqld && mariadbd --user=root --datadir=/var/lib/mysql
--socket=/tmp/mdb/m.sock --bind-address=127.0.0.1`. Пользователь для проверки
