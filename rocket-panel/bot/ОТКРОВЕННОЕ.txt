# ЧТО ПРОИСХОДИТ В КАДРЕ — строки владельца
#
# Одна строка на сценарий:   ключ = текст
#
# Всё остальное бот собирает сам и одинаково для всех сценариев:
# сохранение лица, кожа с порами, анатомия рук, поведение ткани, свет,
# объектив, композиция, цвет, список запретов. Это около трёх тысяч
# знаков, и трогать их не нужно. Здесь пишется только одно: что именно
# происходит в кадре.
#
# ПРАВИЛА, ИХ ТРИ.
#
# 1. ПО-АНГЛИЙСКИ. Модели обучены на английском; русский текст даёт
#    мусор, а не отказ — то есть ошибку видно только на готовой
#    картинке, когда коины уже списаны.
#
# 2. ОПИСЫВАЙТЕ ТО, ЧТО ВИДНО В КАДРЕ. Модель рисует кадр, а не
#    понимает намерения. «She is nervous» не даёт ничего; «her hands are
#    clenched, shoulders raised, jaw tight» даёт.
#
# 3. ОДНА СТРОКА. Перенос строки обрывает запись — длинный текст пишите
#    в одну строку, сколько угодно длинную.
#
# Пустая строка или её отсутствие — не поломка. Сценарий соберётся и
# покажет героиню в заданном плане и свете, просто без явного действия.
# Проверить, где пусто: /scenes в боте (только для админов).
#
# Формат виден на примере — он нарочно не откровенный, чтобы было
# понятно, КАК писать, а не ЧТО:
#
#   un_close = She is laughing with her head tipped back, eyes closed, one hand at her collarbone.
#
# После правки перезапустить бота:  systemctl restart amberry
#
