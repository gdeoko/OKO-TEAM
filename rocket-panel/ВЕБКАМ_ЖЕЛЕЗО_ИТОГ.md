# Железо: итоговый выбор по трём узлам. 20.09.2026

Схема принята владельцем: **три составляющие, три разных провайдера.**

1. Сервер с видеокартой — персонажи, звонки, генерация фото и видео
2. Обычный сервер — сайт, Telegram-бот, переписки, база клиентов
3. Объектное хранилище S3 — мастер-копия героинь, медиа, резервные копии

Требование владельца ко всем трём: **у каждого обязателен REST API**, скорость,
отсутствие прямых запретов по тематике, никаких сюрпризов.

Курс: 1 USD = 92 ₽, 1 EUR = 106,5 ₽.

---

## Узел 1. Видеокарта

**Под все требования сразу (48 ГБ видеопамяти, 128 ГБ ОЗУ, 16 ядер, 1 ТБ диска,
REST API, оплата картой, нет запрета на тематику) не подошёл никто.** У каждого
кандидата своя дыра. Ниже — четыре ближайших.

### packet.ai — самое дешёвое, но требует проверки

- **RTX PRO 6000, 96 ГБ видеопамяти**, 30 ядер, 90 ГБ ОЗУ
- **$0,66/час = $299/мес = 27 500 ₽**
- в правилах про взрослый контент **ни слова**; запрещено
  `illegal, harmful, exploitative, or abusive content`
- оплата через Stripe

Недобор по оперативной памяти: 90 ГБ вместо 128. По нашему расчёту в работе
нужно 29 ГБ — запас четырёхкратный, то есть на задачу это не влияет.

**Красный флаг, который надо проверить до оплаты.** Та же карта у Hyperstack
стоит $1,85 в час, здесь $0,66 — **втрое ниже рынка**. Так бывает, когда карта
делится между клиентами либо когда это перепродавец чужих мощностей. Проверять
живьём: реальная ли это целая карта, какая скорость диска, кто владелец.

### GPU-Mart (DatabaseMart) — идеальное железо, но нет API

- **A6000, 48 ГБ**, 36 ядер, **256 ГБ ОЗУ**, **2 ТБ NVMe**
- **$409/мес = 37 600 ₽**
- совпадает со всеми характеристиками владельца один в один

**Дыра:** REST API управления серверами у них нет. Нашёлся только
OpenAI-совместимый API для языковых моделей — это не то. Управлять машиной
программно не получится.

### Hyperstack — надёжный, дорогой, аккаунт уже заведён

- **A100, 80 ГБ**, 28 ядер, 120 ГБ ОЗУ, 100 ГБ + 750 ГБ временного
- **$0,95/час по резерву = 64 000 ₽/мес** плюс диск
- REST API, Terraform, SDK на Python и Go — всё есть
- про взрослый контент в правилах упоминаний нет
- аккаунт заведён 19.09, почта подтверждена, доступы в хранилище

**Дыра:** наличие карт показывается только после заполнения платёжных данных,
то есть до оплаты подтвердить нельзя. Минимальный срок резерва нигде не указан.

### Beam и Voltage Park — чистые правила, но дорого

**Beam**: A100 80 ГБ за $1,36/час = 91 400 ₽. В договоре §3.2 из сексуальной
тематики запрещён только CSAM. Но эндпоинтов создания и остановки машины в
публичной документации нет, только CLI.

**Voltage Park**: H100 от $1,99/час = 133 600 ₽. В их AUP пятнадцать запретов,
**про взрослый контент ни одного**. API живой, оплата картой прописана в
договоре. Единственный, у кого сошлось всё, кроме цены — состав инстанса они
не публикуют.

### Кто отпал и почему

| | причина |
|---|---|
| **Vultr** | их же API отдаёт `"locations": []` — свободных мощностей нет. Плюс в правилах `obscene` |
| **Cyfuture AI** | дословно: `Under no circumstance is pornography permitted` |
| **Sesterce, Oblivus** | 120 ГБ ОЗУ вместо 128 |
| **Crusoe, Koyeb, Civo** | 8–15 ядер вместо 16 |
| **Novita AI** | 125 ГБ ОЗУ и нет в наличии |
| **Cudo Compute** | публичная аренда закрыта 31.03.2026 |
| **Qubrid AI** | только контракты от года |
| **Clore.ai, Spheron** | маркетплейсы, расчёты криптой |
| **vshosting.eu** | L40S от €751, но API управления не нашли |

## Узел 2. Обычный сервер

### OneProvider, Монреаль — берём

- Xeon E5-2697 v4, **18 ядер / 36 потоков**, **128 ГБ DDR4**, **2 × 2 ТБ NVMe**
- канал 1 Гбит, трафик **безлимитный**
- **$129,99/мес = 11 960 ₽**, установочный платёж **ноль**
- REST API полный: `panel.op-net.com/api` — заказ, переустановка, отмена, счета
- оплата: карты, PayPal, Apple Pay, Google Pay

**Про тематику сказано прямо:**

> We tolerate adult content as long as it remains legal. However, you should be
> aware of your server's location's laws.

> OneProvider requires to be notified may you wish to provide adult content.

Запрещено только `child pornography or obscene speech or material`.

**Условие: тематику надо задекларировать при заказе.** Не сделаем — аккаунт
могут снять без предупреждения. Это тот же механизм, что нас уже подвёл, только
здесь он работает в нашу пользу: сказал заранее — вопросов нет.

### Psychz — единственные, кто говорит «да» прямым текстом

> Yes, we allow porn web hosting at all our data center locations subject to
> certain government policies all users must follow.

> We strictly forbid Child or Animal pornography.

24 ядра, 128 ГБ, **канал 10 Гбит**, безлимит, $122,40/мес. REST API есть, плюс
официальный провайдер для Terraform. **Дыра:** диск NVMe идёт отдельным допом,
цену допа выяснить не удалось — только через запрос в отдел продаж.

### Важная поправка: HOSTKEY отпадает

Весь вечер 19.09 я держала HOSTKEY в списке и говорила, что в их юридических
страницах про контент не сказано ничего. **Это было неполно.** Я читала договор
и правила, но не FAQ — а в FAQ у них прямо написано, что хостинг adult (NSFW)
запрещён. Вычёркиваем.

Так же отпал **netcup**, который был бы самым дешёвым (€71,36 за 16 ядер,
64 ГБ и 2 ТБ NVMe): в их AGB прямой запрет на
`material of a pornographic or commercially erotic character`.

Прочие: **HostSlim** — тематику разрешают, цены хорошие, но REST API нет.
**Advin Servers** — `Pornography websites (unless with prior approval)`, и по
адресу их «API» лежит демонстрационная спецификация Mintlify, а не рабочий
интерфейс. **InterServer, Hivelocity, Hostwinds, Sharktech** — тематику
разрешают, но в нужной цене мало ядер либо цену на нужный конфиг не публикуют.
**Vultr, DigitalOcean, Linode, UpCloud, Civo, Kamatera** — 64 ГБ памяти стоят
$270–600, отсекаются ценой. **Aeza, VDSina** — российские.

## Узел 3. Хранилище S3

### iDrive e2 — берём

- **$6,00 за ТБ в месяц**, 2 ТБ = **$12 = 1 104 ₽**
- растёт само, оплата по факту, минимальный счёт — 1 ТБ
- **минимального срока хранения файла нет** — удаляем когда хотим, без штрафа
- исходящий трафик бесплатный в пределах трёх объёмов хранения, дальше $10/ТБ
- S3-совместимый API

**Правила — самое чистое, что нашлось на рынке.** Из всей сексуальной тематики
в их AUP ровно один пункт:

> Use the Services to store, distribute, or transmit material involving child
> sexual exploitation or abuse.

Слов `obscene`, `adult`, `pornographic`, `indecent` в документе **нет вообще**.

### Backblaze B2 — вторым экземпляром

$6,95 за ТБ, 2 ТБ = 1 279 ₽. Правила такие же чистые: слов про порно, взрослое
и непристойное в договоре нет. Другая компания, другая инфраструктура — то есть
копия переживёт блокировку первого хранилища.

Бонус: трафик в Cloudflare, Fastly и bunny.net у них **бесплатный** — это
готовая раздача через CDN за ноль рублей.

### Кого нельзя

Все четверо были бы дешевле, и все четверо запрещают прямым текстом:

- **Hetzner**, п. 8.2: `pornographic or obscene material`. Проверено отдельно —
  это общие условия компании, на Object Storage и Storage Box тоже
  распространяются.
- **Contabo**: `pornographic or obscene materials`
- **OVH**: `obscene, pornographic`
- **Scaleway**: `Content … that is pornographic is strictly prohibited`

**Wasabi** — отдельно. Их AUP наконец достали через читающий прокси:
`material that is obscene` и `vulgar, obscene`, причём «vulgar» стоит отдельно
от «незаконного», то есть трактовка целиком за ними. Плюс минимальный срок
хранения файла **90 дней** и минимум терабайт в месяц. Не берём.

**DigitalOcean Spaces** — формулировка самая аккуратная из всех
(`Unlawful Pornography` — только детское и без согласия), есть встроенный CDN,
но 2 ТБ стоят 3 768 ₽, втрое дороже iDrive.

## Что проверить до оплаты

1. **packet.ai** — целая ли карта или делится, скорость диска, кто владелец,
   работает ли API. Цена втрое ниже рынка требует объяснения.
2. **OneProvider** — как именно декларировать тематику при заказе.
3. **Psychz** — цена NVMe-допа, вдруг выйдет дешевле OneProvider при канале
   в десять раз шире.
4. **Hyperstack** — минимальный срок резерва.

## Чего не удалось достать

- дословные правила **Vultr** и **UpCloud** — обе страницы закрыты
  Cloudflare 403, в архиве тоже нет;
- состав инстанса у **Voltage Park** и **Beam** по A100;
- цена NVMe-допа у **Psychz**;
- наличие карт у **Hyperstack** без заполнения платёжных данных.
