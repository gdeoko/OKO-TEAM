# AMBERRY — BRAND PACK (логотип)

Бренд бота 18+. Отдельный от OKO намеренно: ни имени OKO, ни лайма
`#9AFF00`, ни ссылок на okoteam.top здесь нет и быть не должно —
репутация основного бренда не зависит от ночного.

Всё построено программно из одного эталона, вектором, без искажений
пропорций.

## Структура

```
logo/
  svg/  amberry-{mark,icon}-{neon,white,black,mono-graphite}.svg
        вектор, прозрачный фон
  png/  amberry-{mark,icon}-{цвет}-{32,48,64,128,256,512,1024,2048}.png
        прозрачные, все размеры
        amberry-{mark,icon}-{on-black,on-white}-{512,1024,2048}.png
        на фоне
  pdf/  amberry-{mark,icon}-{цвет}.pdf, -{on-black,on-white}.pdf
        вектор для печати
  ico/  amberry-icon-{цвет}.ico, favicon.ico
        вкладка браузера, ярлык
```

## Два знака — и это не дублирование

**mark** — ягода и надпись AMBERRY. Основной знак.
**icon** — одна ягода в квадрате, без слова.

Выбор по размеру, а не по вкусу: на 96 px слово ещё читается, на 48 уже
схлопывается в розовую полоску. Мельче 96 px ставится **icon**. Порог
зашит в `brand.mark_or_icon()`, чтобы его не решали на глаз каждый раз.
По той же причине `favicon.ico` собран из иконки, а не из знака.

## Четыре цвета

| | | |
|---|---|---|
| `neon` | `#FF0A8C` + тёмная подложка `#150309` | основной, на любом фоне |
| `white` | `#FFFFFF` | только на тёмном |
| `black` | `#000000` | только на светлом, ч/б печать |
| `mono-graphite` | `#2A2630` | сдержанный, документы и партнёрские материалы |

**Почему у `neon` есть подложка, а у остальных нет.** Промежутки между
костянками в знаке — это просвет, а не линия. У цветного знака под
рисунок положен тёмный силуэт ягоды, поэтому промежутки читаются на
любом фоне. У одноцветных подложки нет специально: одним цветом просвет
можно показать только дыркой. Белый знак кладут на тёмное, чёрный на
светлое — там дырка и работает. Добавишь подложку — получишь тёмное
пятно поперёк белого логотипа.

## Правила

- Знак берётся отсюда и **нигде не рисуется заново**.
- Не перекрашивать вне этих четырёх вариантов и не тянуть по одной оси.
- Свободное поле вокруг знака — не меньше высоты одной костянки.
- Янтарь `#FFB020` — акцент интерфейса (цена, награда, подписка), не
  цвет логотипа. Разольёшь его по макету — неон перестанет читаться
  неоном.
- Фон бренда — чистый чёрный. Серый убивает неон.

## Как пересобрать

```
python build_vector.py   # эталон amberry-71-flat.jpg → mark.svg + icon.svg
python build_pack.py     # svg → png, pdf, ico во всех цветах и размерах
```

Меняется знак — меняется эталон и запускаются оба скрипта. Править
файлы пака руками нельзя: следующая сборка их затрёт.
