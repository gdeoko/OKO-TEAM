# Формат 2 «Снимает лишнее» — движок

Полное описание формата — `../ФОРМАТЫ_РОЛИКОВ.md`. Здесь как им пользоваться.

Три шага, каждый отдельным файлом. Так и отлаживается: упало на третьем —
первые два переделывать не нужно.

    export APIMODELS_KEY=...
    python3 кадр_снятия.py ника 0                     # кадр: одета, под одеждой купальник

    export ROCKET_GPU_URL=... ROCKET_GPU_USER=... ROCKET_GPU_PASS=...
    python3 движение.py вход-ника-бассейн-день.jpg движение.mp4

    python3 сборка_ролика.py ника движение.mp4 снятие-ника.mp4 2.9

Третий аргумент сборки — **момент**: секунда, к которой кадр обязан быть
уже закрыт. Её выбирают глазами по раскадровке движения, а не на угад:

    ffmpeg -i движение.mp4 -vf fps=4 кадр%02d.jpg

Берётся пик подъёма вещи — дальше по промпту бота пошло бы то, чего
показывать нельзя. Без аргумента сборка сама берёт две трети длины.

## Что где живёт

| файл | что делает |
|---|---|
| `кадр_снятия.py` | входной кадр через APIMODELS: бытовая обстановка, под одеждой купальник |
| `движение.py` | ролик снятия НА НАШЕЙ КАРТЕ через панель бота — бесплатно |
| `карточка.py` | прозрачные наложения: кнопки бота и финальная карточка, в том числе покадровая анимация появления |
| `сборка_ролика.py` | муть с разгоном, кнопки, карточка, растяжка хвоста — всё ffmpeg |

`карточка.py` общая с Форматом 1: режим `неон` даёт тёмную подложку, без
него — прозрачность. Держать два описания одного и того же нельзя.

## Грабли, уже пойманные

**Кнопка зациклена бесконечно** (`loop=-1`), и `overlay` без `shortest=1`
тянет ленту до длины бесконечного входа: ролик на семь секунд вышел
тридцатичетырёхсекундным.

**Хвост растягивается, и момент на новой ленте другой.** `растянуть()`
отдаёт и путь, и пересчитанную секунду — брать старую нельзя.

**Адрес панели меняется** при каждом перезапуске туннеля Cloudflare.
Не отвечает — смотреть `/etc/amberry.env` на сервере бота, а не чинить код.

**Карта отдаёт 704x1280 и 16 к/с.** Сборка сама приводит к 1080x1920 и 30.

Рабочие файлы (`*.mp4`, `.работа/`) в git не идут — регенерируются.
