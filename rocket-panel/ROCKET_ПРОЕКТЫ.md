## 2. Личный кабинет хостинга — ждём документацию

Новый проект с созвона 14.09. Кабинет, из которого человек сам заводит сервер,
платит и управляет.

- Вход: номер телефона и код в сообщении (требование закона). Госуслуги как способ
  входа не берём. Плюс свой никнейм и пароль, чтобы не вводить почту каждый раз.
- **База клиентов остаётся у нас.** Поставщику (Билайн) по API уходит номер аккаунта,
  а не почта. Иначе через год база окажется у поставщика и работать с этими людьми он
  сможет без нас. Код подтверждения отправляет наше приложение, не сторонний сервис.
- По API передаются только те, кто начал пользоваться услугой; на регистрации ещё
  ничего не уходит.
- Ориентир интерфейса: Beget (минимализм, меню слева, подменю по клику). Не Timeweb.
  Вектор клиента: всё по одной кнопке, сложное под капот, меньше кликов до действия.
- Биллинг: BILLmanager, клиент покупает и присылает документацию.
- Одобрение оператора на отправку кодов занимает три-четыре дня, ставить в план заранее.
- Срок ориентировочно две-три недели с момента, когда обе документации на руках.

Ждём от клиента: документация API поставщика, доступ и документация BILLmanager.
Дальше созвон по векторам.

## 3. Онлайн игра (механика казино) — в работе

Сборка под ключ: приложение, три сайта под разные гео, бот, двадцать игр, агенты
вместо штата, контент-завод. Сумма около 1 000 000 ₽, при старте от 300 000 ₽ (30 %),
остаток долями по факту, срок около месяца, окупаемость около шести месяцев.

**Доля OKO: 25 % чистой прибыли** — договорённость голосом на созвоне 14.09. Клиент
выступает инвестором (разработка, контент, реклама), OKO собирает под ключ и после
сдачи остаётся совладельцем, продолжая вести и усиливать продукт. Условие просится в
договор до начала сборки.

**Название.** Не «казино», а игра с механикой казино: лицензий нет, модель как у
крупных телеграм-игр. Названия и логотипы приносит OKO вариантами, выбираем вместе.

**Решения с созвона:**

- Механика считается кодом и кронами, не нейросетью: упавший сервис не имеет права
  остановить схему.
- Сбой переводит участок на ручную механику, игрок этого не замечает. Полная остановка
  только при крупном сбое, с честной табличкой о технических работах.
- Пятнадцать-двадцать человек штата закрываются автоматизацией.
- На запуск десять-пятнадцать игр, дальше каждая обнова добавляет новые.
- Сначала тесты форматов, потом веб-версия и три лендинга, затем ещё три под другие гео.
- Гео не только русское: английский язык и Америка с самого начала.
- Магазины приложений — отдельный канал потока.

**Раскачка:** пятьдесят пачек соцсетей, тридцать-пятьдесят аккаунтов по десять роликов
в день. Формат, который сейчас берёт больше всех: нарезка популярного фильма на
сорок-пятьдесят секунд, поверх логотип и адрес площадки, два-три миллиона просмотров
почти на каждом. Контент-завод: пять форматов, от тысячи роликов в месяц, первый месяц
внутри оплаты сборки.

**Решить до старта:** юрисдикция и гео, платёжные провайдеры по каждому гео, первая
пятёрка механик, бюджет закупа рекламы (считается отдельно), название и логотип,
запись доли в договор.

## 4. AI-аватар — созвон

Видеообщение прямо на сайте, как звонок. Пять готовых персонажей на выбор, своего
человек не создаёт. Главное требование к картинке — живой вид, чтобы собеседник
читался человеком. Ответ в реальном времени, любой язык, у каждого персонажа характер.
Цель шире развлечения: приучить людей говорить с ИИ, видя лицо. Продавать клиент
умеет сам.

Технически закрываем кодом Джарвиса плюс аватар, рабочий пример — онлайн-урок с
аватаром куратора. Железо у клиента своё: шесть RTX 6000 и две A100, это снимает
главную статью расходов.

На проект смотрит второй подрядчик (видео-ИИ, платное ТЗ). Наше преимущество на
созвоне — живой рабочий пример и своё железо, а не обещание.

Нужны замеры до любой цены: задержка ответа, стоимость минуты разговора, сколько
разговоров тянет одна карта. Без этих чисел цена будет выдумкой.
