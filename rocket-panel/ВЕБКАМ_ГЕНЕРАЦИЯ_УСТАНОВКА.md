# Генерация 18+ для героинь ROCKET. Установка и проверка

Задача: героиня в переписке присылает своё фото или ролик на 5 секунд.
Персонажи синтетические, совершеннолетние, созданы нами. Чужих фотографий на
вход не подаём — ни одной, никогда.

---

## 1. Ответ на главный вопрос: ограничений нет

Фильтр живёт в облачных сервисах, а не в весах модели. Скачанные веса на своей
карте отказывать не умеют — там нет ни классификатора, ни модерации.

Дословно из карточки Chroma на HuggingFace:

> released in a state as is and has not been aligned with a specific safety filter

То есть модель выпущена без выравнивания под фильтр безопасности.

**Обхода тут нет.** Мы не ломаем чужую защиту и не обманываем сервис: берём
открытые веса под свободной лицензией и запускаем у себя.

## 3. Установка, по шагам

```bash
# окружение
sudo apt update && sudo apt install -y git python3-venv python3-pip ffmpeg
git clone https://github.com/comfyanonymous/ComfyUI && cd ComfyUI
python3 -m venv venv && . venv/bin/activate
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
pip install huggingface_hub

# менеджер нод и поддержка GGUF
git clone https://github.com/ltdrdata/ComfyUI-Manager custom_nodes/ComfyUI-Manager
git clone https://github.com/city96/ComfyUI-GGUF custom_nodes/ComfyUI-GGUF

# картинки: Chroma
hf download lodestones/Chroma1-HD --local-dir models/diffusion_models/chroma
hf download Comfy-Org/flux_text_encoders t5xxl_fp8_e4m3fn.safetensors \
   --local-dir models/text_encoders
hf download Comfy-Org/Lumina_Image_2.0_Repackaged \
   split_files/vae/ae.safetensors --local-dir models/vae

# видео: Wan 2.2 в кванте Q8 (15,4 ГБ — влезает в 24 ГБ)
hf download QuantStack/Wan2.2-I2V-A14B-GGUF --include "*Q8_0*" \
   --local-dir models/diffusion_models/wan22

# запуск
python main.py --listen 0.0.0.0 --port 8188
```

Точные имена файлов у Wan-квантов меняются между ревизиями — смотреть список
в репозитории перед скачиванием, не угадывать.

## 4. Как это работает в переписке. Важное про скорость

Тут есть подвох, который ломает наивную схему.

| что | сколько занимает |
|---|---|
| картинка Chroma | 5–15 секунд |
| ролик 5 секунд, Wan 2.2 + LightX2V | 1–3 минуты |
| ролик 5 секунд, Wan 2.2 без ускорения | 10–40 минут |

**Три минуты ожидания в живой переписке — это провал.** Поэтому схема такая:

1. **Библиотека заранее.** На каждую героиню заранее генерим 150–300 фото и
   30–60 роликов: разные наряды, позы, планы, степень откровенности.
   Отдаётся мгновенно, как будто она достала фото из галереи.
2. **Генерация по запросу — только под конкретную просьбу**, когда участник
   просит что-то своё. Пишем «печатает…» и «делает фото…», отдаём через минуту.
   Задержка становится частью сцены, а не багом.
3. **Приоритет очереди:** живая переписка всегда выше фоновой догенерации
   библиотеки.

Экономика тоже за библиотеку: один ролик генерится один раз, а отдаётся сотням
участников.

## 5. Пять героинь: как держать одно и то же лицо

Это главная техническая задача проекта. Без неё героиня в каждом кадре разная,
и никакой личности не получается.

1. Генерим 20–30 эталонных кадров героини: разные ракурсы, свет, крупность.
2. Отбираем лучшие, чистим, подписываем.
3. Обучаем **LoRA**: 800–1500 шагов, **2–4 часа на карте 24 ГБ**.
   Это «паспорт» героини, дальше все генерации идут с ней.
4. Сверху **PuLID** — добивать схожесть в сложных ракурсах.
5. Готовый кадр → Wan 2.2 I2V. Лицо в ролике сохранится, потому что оно уже
   правильное на входном кадре.

Одна LoRA на героиню, пять LoRA всего. Базовая модель висит в памяти постоянно,
LoRA подгружается за секунды — поэтому переключение между героинями бесплатное.

**Документируем происхождение.** На каждый эталонный кадр сохраняем модель,
сид, промпт, дату. Это доказательство, что героини сгенерированы, а не сняты с
живого человека. Единственная защита при любой проверке — и стоит она ноль.

## 6. План проверки. Что именно тестируем

Порядок жёсткий: сначала дешёвое и быстрое, потом дорогое.

| # | проверка | как понять, что прошло |
|---|---|---|
| 1 | ComfyUI поднялся, Chroma грузится | веб-интерфейс открылся, модель в списке |
| 2 | **Отказов нет** | откровенный запрос отрабатывает и отдаёт картинку, а не пустоту |
| 3 | Качество | лицо, руки, анатомия без грубых артефактов на 1024×1024 |
| 4 | Скорость картинки | замерить секунды на кадр, посчитать поток |
| 5 | LoRA на героиню | обучить на тестовом персонаже, проверить узнаваемость в 10 новых кадрах |
| 6 | Wan 2.2 I2V | оживить свой же кадр, 5 секунд, замерить время |
| 7 | Ускорение LightX2V | то же самое за 4 шага, сравнить время и качество |
| 8 | Поток | две задачи разом: что с памятью, что со скоростью |

Пункты 1–4 закрываются за первый вечер. Пункт 5 — плюс 3–4 часа.
Пункты 6–8 — второй день.

**Стоимость проверки:** на почасовой аренде карты 24 ГБ это примерно
0,4–0,5 € в час, то есть **двое суток тестов ≈ 20–25 €**.

## 7. Что блокирует

Карты нет. Это единственное, что мешает начать.

Вся проверка выше требует одну NVIDIA на 24 ГБ. Сегодня в наличии:

| | видеопамять | цена | где |
|---|---|---|---|
| RTX 4090 | 24 ГБ | €319/мес | HOSTKEY, Исландия |
| RTX 3090 | 24 ГБ | €319/мес | HOSTKEY, Нидерланды |
| A5000 | 24 ГБ | €279/мес | HOSTKEY, Нидерланды |

Все с почасовой оплатой и выдачей от 15 минут.

Отдельно: 24 ГБ хватает и на проверку, и на обучение LoRA, и на видео в кванте
Q8. Для запуска на поток понадобится вторая карта — картинки и видео нельзя
держать на одной, они выбивают друг друга из памяти.
