# Rocket — пакет исправлений после r2

8 сентября 2026. Основа опубликованного сайта: `76f229692dcbdfea73f9d4e4da8d76f4ee42fde5`.

**Пакет опубликован сначала как r3, затем вошёл в итоговый r4. После r4 прошли 19 серверных проверок. Визуальная приёмка 3D с WebGL не завершена. Текущий отчёт: `RELEASE_R4.md`.**

## Изменения этого продолжения

| Продукт | Проблема | Исправление |
|---|---|---|
| VPN | После сбоя вступления обработчики продолжали блокировать колесо, касания и клавиши | Все способы завершения вступления освобождают ввод, включая оба страховочных таймера |
| VPN | Вступление перехватывало ввод в форме | Поля и кнопки сохраняют собственное клавиатурное поведение |
| VPN | Отложенный resize выполнялся после остановки графики | Перед пересчётом повторно проверяется состояние мира |
| VPN | Ошибка выделения ресурсов частиц оставляла изменённые материалы | Частичные ресурсы освобождаются, исходные материалы рубки возвращаются |
| VPN | Пустая выборка частиц оставляла рубку скрытой | Завершение подготовки отделено от наличия поля частиц |
| VPN | Сбой графики при открытой игре оставлял вопросы скрытыми | Игра закрывается, вопросы возвращаются |
| CDN и игра | Минимальная плотность могла превышать бюджет на большом экране; resize не пересчитывал предел | Запуск, адаптация и resize используют общий предел по пикселям и размеру текстуры GPU |
| CDN | Пробел на раскрываемой карточке мог управлять полётом | Клавиши чтения карточки не управляют кораблём |
| Админка | Поздний ответ за прежний период заменял свежую сводку | Устаревшие ответы игнорируются, частичная загрузка не смешивает периоды |
| Админка | Ошибка загрузки сопровождалась сообщением об обновлении | Строка состояния сообщает о неудаче и сохранении прежних данных |
| Админка | Запрос ожидал без предела, неоднозначная запись могла повторяться | Тайм-аут 15 секунд; автоматический повтор только для чтения |
| Админка | Скрытое меню оставалось доступно клавиатуре | inert, удержание Tab, возврат фокуса и корректный переход на desktop |
| Админка | Повреждённый hash попадал в CSS-селектор | Раздел выбирается только из существующих пунктов |
| Игра | Проверка конечной позиции пропускала путь через защитную область планеты | Проверяется весь отрезок движения, остановка у первой границы |
| Игра | Скрытая вкладка могла продолжать обновление мира | Кадр пропускается, время и окно оценки скорости сбрасываются |

Сохраняются предыдущие подготовленные изменения: общий прогресс, финал с настоящей 3D-рубкой и читаемой панелью, раскрываемые вопросы, восстановление качества и обработка тайм-аута формы. Их подробности — в `VPN_AUDIT_2026-09-08.md`.

## Проверки

- 43 проверки JavaScript/геометрии прошли.
- 13 изолированных проверок API, 12 хранилища и 7 доставки прошли. Межпроцессный flock в PHP.wasm пропущен. Внешние уведомления не отправлялись.
- 4 проверки подготовки/отката прошли на временных искусственных каталогах: в том числе возврат обеих ссылок при ошибке HTTP и отказ при изменении исходного файла клиентом.
- Манифест содержит 12 файлов интерфейса с SHA-256 старой и новой версии; локальная сверка прошла.
- В опубликованном VPN повторно обнаружено сочетание `rv-no-webgl` и оставшегося `рв-вступление`. В браузере проверены переключение CDN на седьмую текстовую карточку и наличие административного входа. Это прежний r2, не новая версия.
- Браузер вновь сообщил `GL_RENDERER = Disabled`. Сходство с Igloo, свет, материалы, швы камеры, FPS и длительная работа на физических устройствах остаются непроверенными.

## Публикация r3 и итоговое дополнение r4

`deploy/followup.py` рассчитан на существующий клиентский r2. Он не содержит ключей и не изменяет PHP-код приложения, nginx, интеграции или записи обращений.

Локальная проверка:

```sh
python3 deploy/followup.py verify-source
python3 -m unittest discover -s deploy -p 'test_followup.py'
```

На клиенте через разрешённое подключение, из каталога проверенного исходного пакета:

```sh
sudo python3 deploy/followup.py stage
# Проверить изолированный стенд и новую сцену в браузере.
sudo python3 deploy/followup.py prepare
sudo python3 deploy/followup.py activate
sudo python3 deploy/followup.py health
```

При публикации r3 подготовка сверила исходные файлы r2 и создала `/var/www/rocket-releases/20260908-r3`. Прежние каталоги сохраняются. Активация переключает VPN, затем CDN; PHP-FPM получает мягкую перезагрузку. Проверяются ответы сайтов/API и опубликованные байты. При ошибке возвращаются прежние ссылки. Явный откат: `sudo python3 deploy/followup.py rollback`. Записи обращений при этом не откатываются.

Команды r3 **выполнены**, после переключения прошли 18 проверок. Затем устранён обнаруженный в браузере недочёт прямого запуска игры без WebGL: сообщение на двух языках и возврат на сайт/VPN. Это дополнение опубликовано как r4, после переключения прошли 19 проверок. Текущий `followup.py` берёт базовую и новую версии из манифеста; сейчас это r3 → r4. Манифест r3 сохранён как `deploy/r3-manifest.json`. Старые `activate.py` и `health.py` относятся только к r2.

## Подключение и результат

После отдельного подтверждения пользователя восстановлен доступ к служебному серверу и к клиенту через SSH с sudo. Предыдущие ограничения доступа разрешены; повторных запросов подтверждения при этой публикации не понадобилось. Значения ключей и паролей не выводились и не включались в Git.

Перед работой действующий r2 прошёл 19 проверок; свободно 43 ГБ. Обновления сначала проверены на изолированном стенде. При обеих активациях сохранены прежние каталоги и проверено наличие всех пяти существовавших обращений. Серверная логика и данные не заменялись.

На опубликованном VPN подтверждены восемь раскрываемых ответов, новая метка скрипта и отсутствие оставшейся блокировки вступления при сбое WebGL. CDN и вход админки открываются. На стенде повторно открыты все 17 разделов админки, проверено меню на 320 px, переключение семи карточек и отсутствие горизонтального переполнения проверенных блоков на 320/390/768/1440 px.

Полёт, свет, материалы, швы переходов, FPS и сравнение с Igloo по-прежнему требуют браузера с работающей 3D-графикой. Публикация не является подтверждением этих свойств.
