# КОНТЕНТ-ЗАВОД «Метанойя»

Ветка для производства и постинга контента (Reels/Shorts/TikTok + Telegram/VK)
для продвижения приложения и школы «Метанойя». Эксперт — Екатерина Павленко.

## Что здесь
- **`00-МАСТЕР-БРИФ.md`** — читать первым. ВСЁ: продукт, эксперт, бренд, аудитория,
  темы, каналы, форматы, структура плана, ассеты, инструменты, хештеги, CTA, KPI, правила.
- **`01-СТАРТ-ПЕРВЫЕ-7-ДНЕЙ.md`** — 7 готовых роликов, чтобы начать постинг сразу.

## Где ещё вся информация
- **`../METANOYA_CONTEXT.txt`** (корень репо) — исчерпывающий контекст всего проекта
  (портрет эксперта, бренд, ТЗ, все 9 этапов, журнал работ). Абсолютный источник правды.
- **`../СТАТУС-ПО-ТЗ.md`** — что в приложении готово.
- **Ассеты для роликов:** `../metanoia-app/public_html/assets/img/lessons/` (36
  иллюстраций уроков), `assets/img/book-cover.jpg` (маяк), `assets/img/verse-day.jpg`,
  промо-видео в `../dev-assets/brand/` и `assets/video/`.

## Инструменты (бесплатно)
Озвучка edge-tts · картинки Pollinations/Flux · стоки Pexels · монтаж ffmpeg ·
сборка роликов локально (reels-machine). Подробности — в мастер-брифе, раздел 10.

## Правила
Голос от школы/команды (OKO TEAM), тон тёплый и спокойный, бренд-палитра и метафора
маяка, вера — бережно и точно. Полные правила — мастер-бриф, раздел 14.
