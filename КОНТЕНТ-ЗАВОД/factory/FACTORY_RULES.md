## 0-БИС. ГЛАВНЫЙ ПРИНЦИП — ВСЁ С НУЛЯ ИЗ АНАЛИЗА, НИКАКИХ ШАБЛОНОВ
Каждый элемент КАЖДОГО ролика ВЫВОДИТСЯ из анализа (бриф конкурентов + бренд + тема + сценарий) — НЕ из фиксированного списка/пресета/шаблона. И дедупится (не повторяется с прошлыми). Это касается ВСЕГО, ВСЕГДА:
- тема, хук, структура сценария — из брифа 1M+ роликов, под нашу нишу;
- кадры — свежие под тему (дедуп USED_FOOTAGE);
- механики/инфографика/наложения — придуманы под ЭТУ тему, новые (дедуп USED_ANIM);
- интро, аутро, стиль/позиция субтитров, палитра-акцент, переходы монтажа — свои под ролик (дедуп по DIVERSITY_LEDGER);
- **МУЗЫКА** — настроение ВЫВОДИТСЯ из темы/сценария/эмоции ролика (грусть→мягкое пиано; сила→струнные/перкуссия; надежда→свет; спор→напряжение), конкретный трек через music_free.py, НИКОГДА не переиспользуется (дедуп used_music.txt);
- голос-подача (темп/паузы) — под эмоцию сценария.
НЕТ ни одного «набора по умолчанию». Каждый раз ДУМАЙ заново под этот ролик. Если что-то похоже на прошлое — переделай. Цель — вирал/миллионы.

## 1. ОБЪЁМ ПУБЛИКАЦИЙ (адаптивный, файл состояния cfg/posts_per_day на VPS)
- Старт: **2 ролика/день** на каждую площадку.
- Через 3 дня стабильной работы — **+1/день** постепенно, до **5/день**.
- Если просмотры проседают хоть на одной площадке ИЛИ 0 — **откат к 2/день**, потом снова постепенно вверх.
- Управляет контроллер cfg-контроллером (posts_controller.py) по данным аналитики.

## 2. КОНТЕНТ-МИКС (ротация по интенту, писать в леджер)
- **50% — виральные** (сильный хук, эмоция, спор+разворот, сохраняемость).
- **30% — реально полезные** (конкретная польза/инструкция/чек-лист по воспитанию в вере).
- **20% — продажи** (мягкий оффер школы, запись, лид-магнит).
- Каждый ролик помечать интентом в DIVERSITY_LEDGER; держать пропорцию по скользящему окну.

## 3. ВОРОНКА ПРОДАЖ / КОДОВЫЕ СЛОВА (строить самой в описаниях)
- В каждом описании: польза → мягкий мостик к школе → CTA. Кодовое слово в комментах (напр. «ВЕРА» / «СТАРТ» в ЛС → лид-магнит/запись).
- Вести всех на сайт okoteam.top (или профильный лендинг школы) и Telegram-канал. Ссылка в профиле/описании/закрепе.
- 20%-ролики — прямой оффер; 50/30% — прогрев + мягкий CTA «подробнее в профиле».

## 4. ОБЩЕНИЕ (сама, ежедневно)

## 5. ПОЛНЫЙ ЦИКЛ СБОРКИ (см. pipeline/PIPELINE.md — следовать дословно)
Анализ 10 конкурентов + по 5 миллионников (YT+IG) с цифрами → красивый документ в бота (competitor_analysis.py) →
сценарий (маркетинг/виральность/хук/воронка/кодовые слова/Humanizer) → кадры 4K каждые 3с (свежие) →
инфографика/наложения каждые 3–5с (НОВЫЕ механики) → проверка разнообразия по всем осям →
обложка FLUX (бесплатно) → проверка озвучки (полнота/ударения) → финальный QA на повторы/динамику/потенциал →
публикация в 3 сети из очереди → отчёт в бота.

## 6. НАДЁЖНОСТЬ / МОСТ
- Часовой мост (monitor_all.py, cron): проверяет очередь, краны, последние публикации, свежесть аналитики, доставку бота, глубину буфера; чинит и рапортует в бота при проблеме.
- Буфер очереди ≥ (posts_per_day × 1.5). Если меньше — досборка.
- Постинг/аналитика/вовлечение — на VPS (не зависает). Тяжёлая сборка — в облаке (routine 09:00), самолечение.
