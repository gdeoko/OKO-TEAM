Правило Даниэля (жёстко): **каждый ролик — как с нуля. НИКАКИХ повторов ни по одной оси,
даже образно/по смыслу.** Если механика/приём/структура/палитра/тип интро уже были —
НЕЛЬЗЯ повторять, придумывай принципиально другое. Читать ПЕРЕД сборкой, дописывать ПОСЛЕ.

## Оси разнообразия (все должны отличаться от 100% прошлых роликов)
1. **Формат** — reel / карусель / сторис-серия / talking-инфографика / клип-цитата. Чередовать.
2. **Тема + рубрика** — не повторять (см. SCENARIOS.md).
3. **Структура сценария** — список-N / один-тезис-разворот / вопрос-ответ / миф-правда /
   история-кейс / письмо-ребёнку / диалог / «до-после» / чек-лист. Каждый раз ДРУГАЯ.
4. **Интро** — не всегда зум по обложке! Варианты: kinetic-типографика, чёрный-разлёт-слов,
   быстрый монтаж-тизер, рукопись, засвет-в-кадр, split-screen, обратный отсчёт. МЕНЯТЬ.
5. **Аутро** — не всегда «маяк/лучи+лого». Варианты: чип-CTA на кадре, рукописный P.S.,
   вопрос-в-камеру, карточка-цитата, лого-морф. МЕНЯТЬ.
6. **Палитра-акцент** — базовый бренд (чёрный+лайм) остаётся, но акцент ролика меняется:
   золото/терракота / глубокий синий / зелень-олива / тёплый персик / холодная сталь и т.д.
7. **Стиль субтитров** — позиция (низ/центр/верх), 1-2-3 слова, караоке-цвет, box/без-box,
   капс/строчные. МЕНЯТЬ раскладку от прошлого.
8. **Механики инфографики** — 8-10 штук, ВСЕ новые и по СМЫСЛУ не повторяющие прошлые
   (см. USED_ANIM.md — там полный список занятых механик).
9. **Кадры** — свежие Pexels, дедуп по USED_FOOTAGE.md. Разные локации/герои/свет.
10. **Переходы монтажа** — другой набор xfade, другой ритм (длина кадра), другой грейд.
11. **Голос-подача** — можно менять темп/паузы через текст, музыку по настроению.

## Занятые «крупные приёмы» (НЕ повторять как ведущий приём)
- Штамп/печать, термометр, весы, дверь, счётчик-одометр, ростки/растение (ролик 04)
- Бумеранг-отскок, кирпичная стена, замок-цепь, переворот-карточки, манометр,
  зеркало-фигуры, A/B-реплики, календарь-стрик, линия-жизни, очаг-свет (ролик 05)
- Жест-отмахнуться, лента-закладка, знак-тупик, волны-сигнал, god-rays, иконки-дел,
  тег-подсветка, орбита-чипы, тумблер (ролик 06)
