# Контент-завод · DUCK'S GAME SPACE (клиент Ducks.Games)

Изолированный воркспейс контент-завода под клиента. Не смешивать с общими артефактами
OKO — только материалы Ducks.Games.

## Структура

- `reference/BRAND_PROFILE.md` — тон, палитра, стоп-слова, продукты, каналы, KPI.
- `reference/logo/` — фирменные логотипы Ducks (положить после получения от клиента).
- `cover/` — обложки Reels и карусельные обложки. Именование `YYYY-MM-DD__slug__version.png`.
- `reels/` — готовые ролики (mp4 1080×1920) и промежуточные шоты по подпапкам ролика.
- `carousel/` — карусели IG/VK (4:5), 5–8 карточек в подпапке ролика.
- `tg-posts/` — тексты TG-постов (md) + карточки/gif.
- `USED_FOOTAGE.md` / `USED_ANIM.md` / `USED_EFFECTS.md` — реестры разнообразия (v6).
- `PLAN_MONTH_01.md` — контент-план на первый месяц (генерируется после анкеты).

## Правила

1. Стоп-слова Ducks (см. `reference/BRAND_PROFILE.md` §3) — жёстко, везде.
2. Кредиты Higgsfield — только по явному разрешению Даниэля.
3. Каждый ролик записывается в реестры до сборки, чтобы не повторять приёмы.
4. Финальные файлы (mp4/png) в git не коммитим — только исходники + метаданные.
   Сборки уходят клиенту через ссылку на S3 / Google Drive.
5. Отчёт по неделе — в TG-чате проекта, шаблон в `PLAN_MONTH_01.md` (генерируется).
