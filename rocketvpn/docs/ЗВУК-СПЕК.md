# Звук Rocket VPN: спецификация синтеза на WebAudio

Здесь лежат числа, по которым те же семь звуков собираются прямо в браузере,
без единого файла. Нужно это в двух случаях: файлы не доехали до клиента, и
второй, когда звук должен ехать за долей прокрутки, а не проигрываться куском.
Синтез умеет тянуть параметр за скроллом, готовая дорожка не умеет.

Рядом с этим файлом лежит снятый банк: `assets/snd/*.mp3`, семь штук,
128 кбит/с, 44 100 Гц. Спецификация повторяет их тембр, а не заменяет их.

Все частоты в герцах, все времена в секундах от начала звука, все громкости
в линейном `gain` от 0 до 1, панорама в `StereoPannerNode.pan` от -1 до 1.

---

## 0. Общая обвязка

### Шина

    источник -> свой фильтр -> свой gain -> panner ─┬─> dry -> master
                                                    └─> send -> convolver -> wet -> master
    master -> DynamicsCompressor -> destination

Мастер-компрессор держит удары, чтобы они не рвали подложку:
`threshold -14 dB`, `knee 8`, `ratio 3.5`, `attack 0.004`, `release 0.18`.
Мастер `gain` при старте 0.0, за 1.2 с поднимается до рабочего значения. Резкий
старт контекста слышно как щелчок.

Контекст поднимать только по первому касанию или клику, иначе браузер его
глушит. `sampleRate` не задавать, брать системный.

### Шумовой буфер

Один буфер белого шума на 4 секунды, монофонический, генерируется один раз:

    const N = ctx.sampleRate * 4;
    const buf = ctx.createBuffer(2, N, ctx.sampleRate);
    for (let c = 0; c < 2; c++) {
      const d = buf.getChannelData(c);
      for (let i = 0; i < N; i++) d[i] = Math.random() * 2 - 1;
    }

Два канала заполняются независимо, отсюда сразу берётся ширина. Розовый шум
получается из белого через `lowpass 1000 Гц Q 0.4`, отдельный буфер не нужен.

### Реверб

Импульс синтетический, затухающий шум:

    длина L секунд, спад exp(-k * t / L), k = 4.5
    ранние отражения: одиночные всплески на 0.011 / 0.019 / 0.031 / 0.047 с

Три пресета, все три собираются на старте:

| пресет | L, с | k | верх среза | где применяется |
|---|---|---|---|---|
| СУХО | 0.35 | 7.0 | 6 кГц | интерфейс, акт 1 |
| БЕТОН | 0.90 | 5.0 | 4.5 кГц | стена, акт 2 |
| АНГАР | 3.40 | 3.2 | 3.0 кГц | тоннель и штаб, акты 3-4 |

Перед свёрткой всегда `lowpass` по колонке «верх среза», Q 0.5. Реверб без
среза верха звучит жестянкой.

### Петли

Три звука зациклены: `gul`, `tonnel`, `shtab`. Стыка не слышно при двух
условиях. Первое: все LFO кратны 1 / длина петли, тогда модуляция приходит
в конец петли в той же фазе, что была в начале. Второе: два экземпляра узла
играют со сдвигом на половину петли и перекрещиваются `linearRamp` за 0.35 с.
Второй способ обязателен для `shtab`, у которого края расходятся почти на 5 дБ.

### Прокрутка

Каждая подложка получает `gain`, который ведёт доля хода акта `д` от 0 до 1:
на входе в акт 0 -> рабочее значение за 0.8 с, на выходе обратно за 0.6 с.
Соседние акты перекрываются на 15 процентов хода, поэтому подложки перетекают
одна в другую, а не сменяются встык. Удары зовутся по пересечению порога `д`
и снимаются с повторного вызова на 1.5 с.

### Рабочие громкости

Мастер-множители, с которыми звуки живут вместе. Те же числа годятся и для
готовых mp3, часть из них снята горячо.

| звук | gain | место |
|---|---|---|
| gul | 0.60 | акт 1, петля |
| stena | 0.70 | акт 2, событие |
| prokol | 0.80 | акт 3, событие, главный |
| tonnel | 0.45 | акт 3, петля |
| shtab | 0.50 | акт 4, петля |
| pusk | 0.55 | акт 5, событие |
| klik | 0.50 | интерфейс |

## 1. gul: подложка станции. Петля 8.0 с

Очень тихий низ и дальний ветер вакуума. Ровно, без мелодии, без событий.
Целевой RMS около -49 dBFS, пик не выше -35 dBFS. Этот звук должен читаться
как давление в ушах, а не как нота.

**Источники**

| узел | тип | частота | gain |
|---|---|---|---|
| НИЗ-A | sine | 46.0 | 0.055 |
| НИЗ-B | sine | 47.3 | 0.040 |
| ОБЕРТОН | sine | 92.0 | 0.012 |
| ВЕТЕР | шумовой буфер, loop | - | 0.030 |
| ШИПЕНИЕ | шумовой буфер, loop, второй экземпляр | - | 0.008 |

НИЗ-A и НИЗ-B расстроены на 1.3 Гц. Биение с периодом 0.77 с не даёт уху
зацепиться за тон. Аккорда здесь быть не должно, третий осциллятор не
добавлять.

**Фильтры**

- ВЕТЕР: `lowpass 380 Гц Q 0.70`, следом `highpass 60 Гц Q 0.50`.
- ШИПЕНИЕ: `bandpass 1800 Гц Q 0.60`, следом `lowpass 6000 Гц Q 0.50`.
- Общий выход: `highpass 25 Гц Q 0.70`, срезает сабсоник, который динамики
  телефона всё равно не отдадут, а запас по громкости съедят.

**Модуляция**, все частоты кратны 0.125 = 1 / 8:

- LFO-1 `sine 0.125 Гц` -> gain ВЕТРА, глубина ±35 процентов.
- LFO-2 `sine 0.250 Гц` -> gain НИЗА-A и НИЗА-B, глубина ±18 процентов.
- LFO-3 `sine 0.125 Гц`, фаза сдвинута на четверть -> частота среза ВЕТРА,
  380 Гц ±60 Гц.

**Огибающая** ровная. Вход 0 -> 1 за 1.4 с при входе в акт, выход 1 -> 0 за
1.0 с. Внутри петли уровень не двигается.

**Панорама.** НИЗ и ОБЕРТОН по центру, `pan 0`. ВЕТЕР и ШИПЕНИЕ разложены
двумя независимыми экземплярами буфера на `pan -0.55` и `pan +0.55`. Низ в
стерео разводить нельзя, он развалится на телефонном динамике.

**Реверб** СУХО, `wet 0.08`. Станция это замкнутый объём, а зал ей не нужен.

## 2. stena: сборка стены. Событие 3.0 с

Тяжёлые каменные блоки складываются в стену, глухие стыки, пыль следом.
Три посадки блока, четвёртая доля времени уходит на осыпь.

**Тайминг посадок:** 0.00, 0.85, 1.75. Пыль 1.90 - 3.00.

**Один блок** (три раза, числа для первого, дальше по таблице сдвигов)

*ТЕРКА*, скольжение перед посадкой, стартует за 0.25 с до удара:

- шум -> `bandpass 900 Гц Q 0.80` -> gain
- gain: 0 -> 0.12 за 0.18 с (linear), 0.12 -> 0 за 0.07 с
- частота среза едет 1300 -> 620 Гц за 0.25 с (exponential)

*ТЕЛО*, вес камня:

- `sine`, частота 78 -> 52 Гц за 0.12 с (`exponentialRampToValueAtTime`)
- gain: 0 -> 0.90 за 0.004 с, дальше `exponentialRamp` до 0.001 за 0.45 с

*СТЫК*, глухой стук камня о камень:

- шум -> `bandpass 220 Гц Q 1.40` -> gain
- gain: 0 -> 0.55 за 0.002 с, спад до 0.001 за 0.09 с

*ЩЕЛЧОК ЗЕРНА*, крошка под гранью:

- шум -> `bandpass 3200 Гц Q 5.0` -> gain 0.10, спад за 0.03 с

| посадка | время | ТЕЛО от/до | gain ТЕЛА | pan |
|---|---|---|---|---|
| 1 | 0.00 | 78 -> 52 | 0.90 | -0.25 |
| 2 | 0.85 | 88 -> 58 | 0.80 | +0.20 |
| 3 | 1.75 | 68 -> 46 | 1.00 | 0.00 |

Третья посадка ниже и громче остальных, стена на ней закрывается.

**ПЫЛЬ**, 1.90 - 3.00:

- шум -> `highpass 2600 Гц Q 0.70` -> `lowpass 9000 Гц Q 0.50` -> gain
- общий gain: 0.05 на входе, спад до 0.004 к 3.00 с
- поверх зерно: каждые 0.03-0.08 с случайный всплеск длиной 0.010 с,
  gain 0.02-0.06, `pan` случайно от -0.7 до 0.7
- ровной струи быть не должно, только рваная сыпь

**Реверб** БЕТОН, `wet 0.18`. Хвост короткий и сухой, звенеть нечему.

## 3. prokol: пробой и вход в трубу. Событие 4.0 с. Главный

Три фазы наложены друг на друга, склейки между ними нет. Это один жест:
удар, осыпь, разгон.

### Фаза 1. Пробой, 0.00 - 0.40

*КРЯК*, разлом породы:

- шум -> `bandpass 1600 Гц Q 0.90` -> gain
- gain: 0 -> 1.00 за 0.003 с, спад до 0.01 за 0.25 с
- частота среза едет 2600 -> 700 Гц за 0.20 с

*УДАР*, вес пробоя:

- `sine`, частота 120 -> 38 Гц за 0.30 с (exponential)
- gain: 0 -> 1.00 за 0.004 с, спад до 0.001 за 0.70 с

*САБ*, продавливание:

- `sine 32 Гц`, gain 0 -> 0.60 за 0.02 с, спад до 0.001 за 1.10 с

### Фаза 2. Осколки, 0.05 - 0.90

Восемнадцать зёрен, время каждого случайно в окне 0.05 - 0.85:

- шум длиной 0.012 с -> `bandpass` -> gain -> `panner`
- частота полосы случайно 3000 - 7000 Гц, `Q 6.0`
- gain случайно 0.15 - 0.40, атака 0.001 с, спад 0.011 с
- `pan` случайно от -0.9 до +0.9, распределение по краям плотнее центра
- три самых поздних зерна ниже по частоте, 1200 - 2000 Гц: крупные куски
  падают последними

### Фаза 3. Проход сквозь трубу, 0.50 - 4.00

*ВОЗДУХ*:

- шум -> `bandpass` -> gain
- частота полосы: 300 Гц (0.50 с) -> 1800 Гц (2.60 с) -> 900 Гц (4.00 с),
  `exponentialRamp`, `Q 1.20`
- gain: 0.02 (0.50) -> 0.55 (2.80) -> 0.25 (4.00)

*ТРУБА*, три резонанса параллельно от того же шума:

    bandpass 180 Гц Q 12   gain 0.15
    bandpass 260 Гц Q 10   gain 0.11
    bandpass 390 Гц Q  7   gain 0.08

Все три едут вверх на 40 процентов от своей частоты за окно 1.0 - 3.2 с,
это и даёт ощущение, что труба сужается по ходу.

*ДОПЛЕР*:

- `DelayNode` в разрыве ВОЗДУХА, базовая задержка 0.006 с
- модулируется `sine 0.40 Гц`, глубина 0.004 с
- к 3.2 с глубина падает до 0.001 с, движение выравнивается

**Панорама.** Удар и саб по центру. Осколки по краям. Воздух развален двумя
экземплярами на ±0.4, причём правый идёт с задержкой 0.008 с, отсюда объём.

**Реверб** АНГАР, `wet` едет 0.10 (0.00) -> 0.28 (2.5) -> 0.20 (4.0).

## 4. tonnel: полёт внутри трубы. Петля 8.0 с

Скорость постоянная, приезда нет. Всё, что дышит, кратно 0.125 Гц.

**Источники**

| узел | тип | параметры | gain |
|---|---|---|---|
| ТЕЛО | шум, loop | `bandpass 420 Гц Q 0.80` | 0.30 |
| СВИСТ | шум, loop, 2-й экземпляр | `highpass 2200 Гц Q 0.70` + `lowpass 9000 Гц Q 0.50` | 0.06 |
| НИЗ-A | sine 96.0 Гц | - | 0.060 |
| НИЗ-B | sine 98.5 Гц | - | 0.040 |
| РЕЗОНАНС-1 | шум -> `bandpass 230 Гц Q 9` | - | 0.120 |
| РЕЗОНАНС-2 | шум -> `bandpass 340 Гц Q 7` | - | 0.080 |

Расстройка низа 2.5 Гц, биение с периодом 0.4 с. Оно держит ощущение
работающей скорости.

**Рёбра трубы.** LFO `sine 0.50 Гц`, четыре прохода за петлю:

- -> gain ТЕЛА, глубина ±30 процентов
- -> частота ТЕЛА, 420 Гц ±120 Гц
- -> частота РЕЗОНАНСА-1, 230 Гц ±35 Гц, фаза сдвинута на 0.25 периода

**Второй слой дыхания.** LFO `sine 0.125 Гц` -> gain СВИСТА, ±40 процентов.
Медленное движение поверх быстрого, ухо перестаёт считать рёбра.

**Огибающая.** Вход 0 -> 1 за 0.6 с, звук должен подхватить сразу за проколом.
Выход 1 -> 0 за 1.2 с.

**Панорама.** ТЕЛО и НИЗ по центру. СВИСТ двумя экземплярами на ±0.60.
РЕЗОНАНСЫ на -0.30 и +0.30.

**Реверб** АНГАР, `wet 0.16`. Больше нельзя, труба узкая.

## 5. shtab: подземный ангар. Петля 9.0 с

Большой холодный объём, дальнее эхо, редкая капля. Ничего не нарастает.

**Постоянная часть**

| узел | тип | параметры | gain |
|---|---|---|---|
| НИЗ-A | sine 50.0 Гц | - | 0.070 |
| НИЗ-B | sine 50.6 Гц | - | 0.050 |
| ТЕХНИКА | sawtooth 100 Гц | `lowpass 180 Гц Q 1.0` | 0.020 |
| ВОЗДУХ | шум, loop | `lowpass 700 Гц Q 0.50` | 0.020 |

Расстройка 0.6 Гц, биение с периодом 1.67 с. Медленное, тяжёлое, ровно то
дыхание, которое положено большому помещению под землёй.

LFO `sine 0.111 Гц` (один период на петлю) -> gain ВОЗДУХА, ±25 процентов.

**КАПЛЯ.** Интервал случайный, 2.5 - 4.0 с:

- `sine`, частота 1400 -> 700 Гц за 0.05 с (exponential)
- gain: 0 -> 0.25 за 0.002 с, спад до 0.001 за 0.08 с
- `pan` случайно от -0.7 до +0.7
- в реверб уходит `wet 0.75`, сухого сигнала почти нет: капля должна быть
  далеко в темноте, а не рядом с ухом

**ТИК МЕТАЛЛА.** Интервал случайный, 5.0 - 8.0 с:

- шум длиной 0.006 с -> `bandpass 4200 Гц Q 8.0`
- gain 0.08, спад 0.02 с
- `pan` случайно ±0.5, `wet 0.55`

**Реверб** АНГАР, общий `wet 0.35`. Ранние отражения 0.09 / 0.13 / 0.21 с
громче обычного, на них и читается размер зала.

**Панорама.** НИЗ и ТЕХНИКА по центру, ВОЗДУХ развален на ±0.45.

**Петля.** Собирать в два экземпляра со сдвигом 4.5 с и перекрестием 0.35 с.
Края у этого звука тихие и разной плотности, встык их сводить нельзя.

## 6. pusk: зажигание и старт. Событие 5.0 с

Четыре фазы подряд, каждая переходит в следующую без паузы.

### Запал, 0.00 - 0.10

- шум -> `highpass 3000 Гц Q 0.70`, gain 0 -> 0.50 за 0.002 с,
  спад до 0.01 за 0.06 с
- `sine 900 Гц`, длина 0.010 с, gain 0.20: сухой щелчок пиропатрона

### Подхват, 0.08 - 1.60

*РЁВ*:

- шум -> `lowpass` -> gain
- частота среза 120 -> 260 Гц за окно (exponential), `Q 0.90`
- gain: 0.02 -> 0.85

*САБ*:

- `sine 42 Гц`, gain 0 -> 0.70 к 1.40 с

*ТУРБУЛЕНТНОСТЬ*:

- шум -> `bandpass 700 Гц Q 0.60`, gain 0.15
- модуляция `sine 7 Гц`, глубина 40 процентов, плюс вторая `sine 3.4 Гц`,
  глубина 25 процентов. Две несоразмерные частоты дают неровное горение,
  одна даст ровный тремор и выдаст синтез с головой

### Пик, 1.60 - 3.20

- gain РЁВА держится 0.85 - 1.00 с медленным дрейфом
- срез открывается 260 -> 420 Гц
- САБ стоит на 0.70

### Уход, 3.20 - 5.00

- срез 420 -> 150 Гц (exponential)
- gain 1.00 -> 0.12
- САБ 42 -> 34 Гц: доплер уходящей массы
- `wet` едет 0.15 -> 0.40, звук отдаляется и остаётся один зал

**Панорама.** САБ по центру. Шумовые слои двумя экземплярами на ±0.35, правый
с задержкой 0.006 с.

**Реверб** АНГАР, длина 2.6 с.

## 7. klik: интерфейсный щелчок. Событие 0.06 с

Сухой приборный контакт. Ни зала, ни резонанса, ни хвоста.

- *ТРАНЗИЕНТ*: шум 0.004 с -> `bandpass 3800 Гц Q 3.0`,
  gain 0 -> 0.80 за 0.0005 с, спад до 0.001 за 0.012 с
- *ТЕЛО*: `sine` 1800 -> 1200 Гц за 0.020 с,
  gain 0.35, спад до 0.001 за 0.035 с
- *КОНТАКТ*: `sine 620 Гц`, gain 0.12, спад до 0.001 за 0.050 с
- общий `highpass 400 Гц Q 0.70`

**Реверб** нет, `wet 0`. Панорама `pan 0`.

Щелчок звучит 0.06 с, файл в банке длиннее из-за минимальной длины у
генератора. При синтезе тишину в конец не дописывать.

Разброс, чтобы двадцать нажатий подряд не звучали одним семплом: частота
ТЕЛА ±8 процентов и общий gain ±12 процентов случайно на каждый вызов.

## 8. Проверка

Сведённый звук считается готовым по четырём числам. Замеры снимаются с
`AnalyserNode` или офлайн через `OfflineAudioContext`.

| звук | пик, dBFS | RMS, dBFS |
|---|---|---|
| gul | -38 | -49 |
| stena | -5 | -30 |
| prokol | -1 | -22 |
| tonnel | -5 | -17 |
| shtab | -1 | -21 |
| pusk | -1 | -6 |
| klik | -10 | -38 |

Это замеры снятого банка, синтез сводится к ним же. Разбег в 3 дБ допустим,
разбег в 10 дБ означает ошибку в громкости слоя.

Отдельно проверяется петля: восемь минут `gul` подряд не должны дать ни
одного слышимого стыка и ни одной различимой ноты. Если через минуту ухо
начинает напевать вместе с подложкой, расстройку низа надо менять.
