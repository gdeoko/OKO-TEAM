# Долги — живая страница okoteam.top/dolg

Не файл в чате, а страница на сервере, которая сама обновляется.

## Что где лежит
Рабочая папка на VPS: `/opt/oko-agents/data_runtime/dolgi/`

| файл | что делает |
|---|---|
| `dolgi.json` | данные: кредиторы, суммы, реквизиты, статусы, история. Единственный источник правды |
| `pochta.py` | опрашивает ящики по IMAP, находит письма кредиторов, кладёт их в `dolgi.json`. Ничего не отправляет |
| `sobrat.py` | собирает `index.php` из `dolgi.json` и кладёт в `/var/www/okoteam/dolg/` |
| `obnovit.sh` | опрос + пересборка, стоит в кроне okoposter каждые 30 минут |
| `.kluch` | ключ доступа к странице, права 600 |
| `chitat_chat.py` | разовое чтение чата по долгам аккаунтом владельца. Запускать ТОЛЬКО при погашенной службе (правило 6j) |

## Доступ
Страница закрыта ключом: первый заход по `okoteam.top/dolg/?k=КЛЮЧ` ставит куку на год,
дальше просто `okoteam.top/dolg`. Без ключа отдаётся 404. Данные личные, в поиск не индексируются
(`X-Robots-Tag: noindex`).

## Что нужно сделать руками один раз (нужен root)
Служба `okoposter` не имеет прав на `/var/www/okoteam`, поэтому папку под страницу
создаёт владелец сервера:

```bash
install -d -o okoposter -g okoposter -m 755 /var/www/okoteam/dolg
```

После этого всё встаёт само: ближайший запуск крона положит туда `index.php` и `.kluch`.
Проверить сразу, не дожидаясь крона:

```bash
sudo -u okoposter /opt/oko-agents/data_runtime/dolgi/obnovit.sh
```

## Пароли ящиков
`pochta.py` берёт доступы из конфига агентов и из мастер-хранилища на сервере, в коде
паролей нет. Сейчас читаются `okoteam.top@gmail.com` и `daniel.okoteam@gmail.com`.
Для `daniel.piano.2002@gmail.com` в хранилище лежит обычный пароль аккаунта, а Gmail по IMAP
пускает только по паролю приложения — нужно выпустить его на id.google.com и дописать в
хранилище рядом с адресом. Скрипт подхватит сам, править код не надо.

## Правило по каждому долгу
Оплата — половина дела. По каждому закрытому договору требуем официальную справку об
отсутствии задолженности: печать, подпись, номер договора, дата закрытия, формулировка
«обязательства исполнены в полном объёме, претензий нет». Скан на почту, оригинал по адресу.
Пока справки нет, карточка висит в статусе «оплачен, ждём справку» и не считается закрытой.
