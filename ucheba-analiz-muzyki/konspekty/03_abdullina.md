# Абдуллина Г.В. Конспекты по анализу музыкальных форм

Санкт-Петербург, «Композитор», 116 страниц, ISBN 978-5-7379-0744-0. Полное
название: «Конспекты по анализу музыкальных форм. Методическое пособие для
средних и высших учебных заведений». Рекомендовано УМО по направлениям
педагогического образования как пособие для студентов направления
«Художественное образование».

Свободной копии нет, цена у издательства около 620 руб, ссылка в
`../biblioteka/КНИГИ.md`.

## Что это за книга

Не учебник, а именно конспекты: сжатый свод сведений для подготовки к экзамену
по музыковедческим дисциплинам. В книге собраны основные жанры и формы вокальной
и инструментальной музыки, специфические приёмы музыкального письма и
терминология от эпохи Возрождения до наших дней.

Формат один блок на одну форму: определение, схема, признаки, применение,
типовые примеры. Читается за вечер, работает как повторение перед зачётом.

## Чем заменить

Тот же формат дают две доступные книги:

- Коленько Р.Г. «Анализ музыкальных форм» (БГУКИ, 2013, 149 стр.), файл в
  `../biblioteka/КНИГИ.md`. Пособие для вузов культуры, сжатое изложение всех
  форм курса.
- Шпаргалка `../shpargalki/КАРТА_ФОРМ.md` в этой папке: собрана по той же логике,
  одна форма - один блок с определением, схемой, признаками и примерами из
  фортепианного репертуара.

## Термины, которые в таких конспектах спрашивают чаще всего

Период, предложение, фраза, мотив, каденция, цезура, квадратность, масштабно
тематическая структура, экспозиционный и развивающий тип изложения, функции
частей, тональный план, реприза точная и изменённая, кода, ход, связка, эпизод,
рефрен, ритурнель, basso ostinato, тема и контртема, стретта, интермедия,
имитация, канон, фактура, склад (гомофонно-гармонический, полифонический,
монодический).
