# Анализ музыкальных произведений (МГИК, 3 курс, фортепиано)

Рабочая папка по предмету. Здесь лежит всё, что нужно к семинарам, контрольным
и экзамену: где взять учебники, что в них искать, как разбирать форму и что
говорить на защите анализа.

## Что где

| Папка | Что внутри |
|---|---|
| `biblioteka/` | Пять книг из списка преподавателя: выходные данные, ссылки, где скачать или купить, чем каждая полезна |
| `konspekty/` | Разбор каждой книги: структура, ключевые понятия, что читать к какой теме |
| `shpargalki/` | Карта всех форм со схемами, алгоритм разбора, словарь терминов |
| `repertuar/` | Фортепианные примеры на каждую форму: что взять для анализа и на что смотреть |

## Статус по книгам из списка

| Книга | Файл | Где взять |
|---|---|---|
| 1. Кюрегян Т.С. Форма в музыке XVII-XX веков | **есть, 345 стр., скан PDF** | прямая ссылка в `biblioteka/КНИГИ.md` |
| 2. Ручьевская Е.А. Классическая музыкальная форма | нет свободной копии | Rucont, 160 руб (легально), либо библиотека МГИК |
| 3. Абдуллина Г.В. Конспекты по анализу музыкальных форм | нет свободной копии | издательство «Композитор» (СПб), библиотека МГИК |
| 4. Ройтерштейн М.И. Основы музыкального анализа | нет свободной копии | НЭБ (читальный зал), либо 4-е изд. «Планета музыки» |

Вместо трёх недостающих книг в папке есть свободно доступные учебники того же
курса (Заднепровская, Коленько, Холопов, сборник booksite), они закрывают те же
темы. Список и ссылки в `biblioteka/КНИГИ.md`.

## Как этим пользоваться

1. Перед семинаром открыть `shpargalki/КАРТА_ФОРМ.md` и найти нужную форму.
2. Взять пример из `repertuar/ФОРТЕПИАНО.md`, разобрать по `shpargalki/АЛГОРИТМ_АНАЛИЗА.md`.
3. Спорное место проверить по Кюрегяну (номера параграфов есть в `konspekty/01_kyuregyan.md`).
