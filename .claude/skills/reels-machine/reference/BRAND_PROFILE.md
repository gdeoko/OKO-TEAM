Скилл универсальный. Этот файл заполняется ОДИН РАЗ на клиента (Шаг 0 онбординга в
SKILL.md). Всё остальное в скилле — общая механика. Ниже: сначала ШАБЛОН (заполнить под
своего клиента), затем ПРИМЕР (V.CODE) — как ориентир.

## ШАБЛОН — ЗАПОЛНИТЬ ПОД КЛИЕНТА (замени <…>)

- **Бренд/бейдж:** <название>
- **Ниша:** <сфера бизнеса, город, соцсеть>
- **CTA:** <«напишите … в директ» / оффер>
- **Бренд-строка финалки:** <например «услуга · город»>

### Палитра (бренд-константа) — по логотипу клиента
- Фон/тёмный: `#0d0d0d` (или фирменный тёмный)
- **Акцент №1 (главный):** `<#HEX из лого>` — идёт в оверлеи/штампы/счётчики/субтитры.
- Акцент №2: `<#HEX или белый>`
- Запрещённые цвета: всё, чего нет в бренде (НЕ ставить «дефолтный» цвет по привычке).

### Типографика
- Субтитры-караоке: `<шрифт, по умолч. Союз Гротеск Bold>`, 76, строчные. Активное слово —
  **акцент №1** (ASS-код `<&HBBGGRR&>`), прошлые белые. НЕ менять между роликами.
- Цифры/заголовки в графике: Montserrat Black / Golos 900 / Manrope 800.

### Голос (бренд-константа)
- **ОСНОВНОЙ (выбран клиентом V.CODE):** `edge-tts` **ru-RU-DmitryNeural**, rate `+6%`,
  boundary `WordBoundary` (нужен для тайминга караоке-субтитров). Чистый мужской, правильные
  ударения, работает везде мгновенно (в т.ч. в триггерных автосессиях). НЕ менять между роликами.
- Опции (по желанию, НЕ по умолчанию): XTTS-v2 (клон тембра по образцу, `pipeline/motion/xtts_voice.py`,
  отдельный venv — см. INTEGRATIONS) и Silero v4_ru (male `eugene`/`aidar`, встроенный словарь
  ударений). XTTS в русских ударениях иногда ошибается — при выборе XTTS ставить ударения вручную (U+0301).
- Для клона реального голоса (напр. Владимира) — прислать 10-30с чистой записи → XTTS по этому референсу.

### Лого и обложка
- `logo_hd.png` — даёт КЛИЕНТ (PNG с прозрачностью). В скилл не входит.
- Обложка = ИИ-генерация (Nano Banana Pro) в бренд-цветах + **композит реального лого**.
- **Связной путь БЕЗ Higgsfield** (автосессии по триггеру — коннекторов нет):
  `pipeline/motion/cover_flux.py` — БЕСПЛАТНЫЙ FLUX (HF ZeroGPU FLUX.1-schnell)
  генерит фон, дальше грейд+виньетка+затемняющий скрим+бренд-заголовок+реальный лого.
  Внутри фолбэк: FLUX → Pexels-стилл (через curl) → сплошной фон.
  Запуск: `python3 cover_flux.py "<visual prompt>" "<ЗАГОЛОВОК>" out.jpg logo_hd.png`
  (нужен `HF_TOKEN`; gradio_client через прокси — `ssl_verify=<CA-бандл>`, НЕ `httpx_kwargs verify`).
  Правило: обложку добавлять ВСЕГДА (даже без платных коннекторов).

### Бренд-кадры (вплетать ≥2 в каждый ролик)
- Ключевые слова стока под нишу клиента: `<напр. для кофейни: barista pour, latte art,
  coffee beans roasting, cozy cafe interior>`. Это «сшивает» ролик с брендом.

### ASS-цвет из HEX (шпаргалка)
HEX `#RRGGBB` → ASS `&HBBGGRR&` (порядок байт обратный). Пример: `#EA5920` → `&H2059EA&`.
