- **Бренд-строка финалки:** «МЕТАНОЙА · школа для детей»

### Палитра (бренд-константа) — по логотипу (μ + золотые крылья)
- Фон/тёмный: `#1A3A52` (тёмно-синий) ИЛИ светлый кремовый `#FAF8F5` (для тёплых сцен).
- **Акцент №1 (главный):** золото `#D4A574` — оверлеи/штампы/счётчики/активное слово субтитров.
- Акцент №2: терракота `#C97064` + голубой `#7AAED4`. Кремовый `#FAF8F5` — текст на тёмном.
- Запрещено: неон, кислотные/кричащие цвета, «дефолтный» зелёный/фиолетовый. Тон — тёплый, спокойный.

### Типографика
- Субтитры-караоке: **Montserrat Bold**, 76, строчные. Активное слово — золото
  (ASS-код `&H74A5D4&`), прошлые — кремово-белые. НЕ менять между роликами.
- Заголовки в графике/обложке: **Playfair Display**; цифры/подписи: **Montserrat**.

### Голос (бренд-константа)
- `ru-RU-SvetlanaNeural` (жен, тёплый), rate `+5%` (спокойнее), boundary `WordBoundary`.
  Позже — клон голоса Екатерины (по её согласию). Формат «говорящая голова» — её реальный голос.

### Лого и обложка
- `logo_hd.png` = `brand/metanoia/png/metanoia-logo-1024.png` (ПРОЗРАЧНЫЙ) (μ + золотые крылья, navy/gold).
- Обложка = ИИ-генерация (Nano Banana Pro) в тёплой storybook-гамме + **композит реального
  лого**. Промпт-стиль: «soft warm children storybook watercolor, cream terracotta gold navy,
  gentle light, lighthouse/warm home motif». Фолбэк без Ultra: сток + текст (PIL) + лого.

### Бренд-кадры (вплетать ≥2 в каждый ролик)
- Тёплые семейные/детские сток-запросы: `mother and child reading together, child praying
  hands candlelight, lighthouse beam soft fog, sunrise window warm light, open storybook,
  family cozy home evening, children learning happy`. Метафора бренда — **маяк/свет**.
  Плюс демо-экраны приложения Метанойя. Это «сшивает» ролик с брендом.

### Грейд
- Тёплый мягкий (`warm_cine` / `flower_soft`), не контрастный неон. Свет, уют, надежда.

### ASS-цвет из HEX (шпаргалка)
HEX `#RRGGBB` → ASS `&HBBGGRR&` (обратный порядок байт). Золото `#D4A574` → `&H74A5D4&`.
