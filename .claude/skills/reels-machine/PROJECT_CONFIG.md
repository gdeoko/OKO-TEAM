## Связь с брендом ПО СМЫСЛУ (не словами)
Ролик полезен/виралем для тех, кто снимает видео/подкасты/контент → это и есть аудитория студии.
Тема (монтаж/свет/нейросети/медийность/подкасты) сама ведёт к «снимай профессионально → приходи в V.CODE».
Где-то бренд не упоминается вообще (охват), где-то мягкий CTA «СЪЕМКА в директ».

1. АНАЛИЗ 30 конкурентов ниши (видеопродакшн/подкасты/монтаж/медийность/нейросети-контент): найти 30
   роликов 1M+, скачать/раскадровка/транскрипт, посмотреть/послушать, разобрать хук/структуру/темп/аудио/воронку.
2. ПРОЧИТАТЬ скиллы: humanizer, marketing-psychology, hook-generator, reels-scripting и др. — применить.
3. СБОРКА от анализа + связка с брендом Владимира: сценарий → кадры по смыслу каждые ~3с (бренд-кадры ≥2) →
   инфографика/наложения/переходы/зумы каждые 3–5с (infographics_gen + assemble_reel) → караоке-субтитры → музыка.
4. Голос Владимира 1.2× с пунктуацией-паузами. Длина 20–50с. Обложка — постер при публикации (не интро).
5. QA + проверка каждого шага ×10 (скрины кадров, ASR звука — 0 «мягко», кадры в тему, инфографика по смыслу).
