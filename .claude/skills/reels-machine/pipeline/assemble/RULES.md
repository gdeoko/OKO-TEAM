# ПРАВИЛА СБОРКИ РОЛИКА (обязательны, проверено v3 — QA 93)

- **Шрифт субтитров — Союз Гротекс Bold** (`assets/SoyuzGrotesk-Bold.ttf`), НЕ Montserrat.
- **Субтитры: по 2 слова в строке, КАРАОКЕ с выделением слова** — ASS `\kf`, PrimaryColour=оранж
  (заливка/выделение), SecondaryColour=белый. Текст берётся из СЦЕНАРИЯ (не из ASR — англ. названия
  искажаются), тайминги — из word-timings (равномерно в окне сегмента).
- **Кадры 4К вертикаль меняются каждые 3–5с**, 10–14 уникальных, дедуп USED_FOOTAGE.
- **Инфографика/наложения кодом — рисуются ЗАНОВО под сценарий** (PIL/код), НЕ шаблоны,
  не переиспользуются: бейджи-метрики, карточки кода, счётчики, кольца — каждый раз новые,
  привязаны к смыслу сегмента, появляются со slide/fade каждые 3–5с. + динамичные переходы.
- **Карточки-инфографика с названиями нейросетей/сущностей** (оранж, верх) на своих сегментах.
- **Обложка через нейросеть (Higgsfield nano_banana_pro / FLUX) — ПЕРВЫМ КАДРОМ** (1.3с), 9:16,
  бренд-цвета, крупный русский заголовок. `generate_image` → скачать → prepend.
- **Голос — Владимир OmniVoice 1.8×** (`voice_omnivoice/vcode_voice.py`).
- **В бота — ролик ФАЙЛОМ (sendDocument) + описание, без лишнего.**
- `assemble_reference.py` — рабочий образец сборки (караоке-выделение + код-инфографика + обложка-кадр).
