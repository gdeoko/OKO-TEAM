# ПРАВИЛА СБОРКИ V.CODE (обязательны каждый ролик, без брака, без шаблонов)

## Субтитры — модуль `assemble/captions.py` (СТАНДАРТ, не отклоняться)
- Союз Гротекс 82, **БЕЗ чёрной обводки** (Outline=0, только мягкая тень).
- **Караоке `\k` по словам: активное/спетое слово оранж `#EA5920`, остальные белые.**
- **Фиксированная позиция** `\pos(540,1560)` — одинаковая ВСЕГДА, без плавания.
- **По 2 слова, без переносов.** Текст из СЦЕНАРИЯ (не ASR), тайминги из words.json (финальный 1.8× звук).

## Анимации/инфографика — модуль `motion/overlay_render.py` (CSS/JS → Chromium → прозрачная секвенция)
- **КАЖДЫЙ ролик — СВОИ overlay, нарисованные ЗАНОВО** (свой HTML/CSS под смысл сегмента), мимо `USED_ANIM`.
- **Движущиеся и чёткие** (slide/pulse/count/draw), НЕ статичные PIL, НЕ кривые. По одному каждые 3–5с.
- Композит PNG-секвенции на кадр ffmpeg-ом в окне сегмента + динамичные переходы между клипами.

## Кадры / голос / обложка
- 10–14 УНИКАЛЬНЫХ 4К-стоков, смена 3–5с, мимо `USED_FOOTAGE`.
- Голос Владимира `voice_omnivoice/vcode_voice.py` 1.8×. Проверить паузы/ударения.
- **Обложка — ПЕРВЫМ КАДРОМ ролика (1.3с внутри видео).** Автономно: `motion/cover_flux.py`
  (FLUX через HF + заголовок PIL Союз Гротекс). Higgsfield nano/FLUX — если есть коннектор.

## Публикация — `publish/publish_bot.py`
- Ролик уходит **ФАЙЛОМ (sendDocument)**, НЕ обычным видео. Обложка уже ВНУТРИ (1-й кадр).
- **Описание — ОТДЕЛЬНЫМ сообщением.** Аналитика — отдельным документом (стадия 1/5).

## ФИКСЫ (обязательно, проверено — устраняют брак)
- **НЕТ тишины в начале:** обложку ставить ПЕРВЫМ кадром (1.2с) как часть видео, звук с t=0 (без adelay). Хук играет под обложкой.
- **Синхрон субтитров:** `captions.align_to_audio(script_words, whisper_words)` — текст из сценария, время из реального 1.8× аудио. НЕ равномерно.
- **Без наложений субтитров:** build_ass сам обрезает конец пары по началу следующей.
- **Инфографика — ВВЕРХУ (y≈360), по ОДНОЙ, не поверх субтитров (низ y≈1560), не внахлёст.** Анимированная (счётчик/бар/пульс), под метрику сегмента.
- Образец рабочей сборки: `assemble/assemble_reference.py`.
