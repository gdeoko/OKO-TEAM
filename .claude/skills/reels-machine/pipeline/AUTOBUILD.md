# AUTOBUILD — ЗАКОН СБОРКИ V.CODE (единственный источник правды)

Цель: РОЛИК-ХИТ на миллионы, а НЕ реклама. Каждый ролик строится ОТ анализа реальных
миллионников, а НЕ из головы и НЕ по шаблону. Читать ПОЛНОСТЬЮ перед каждым роликом.

## ПОСТОЯННО ТОЛЬКО ДВА (бренд-константы):
1. **Формат субтитров** — Союз Гротекс, 2 слова, караоке-выделение оранж, без обводки, фикс-позиция (`captions.py`).
2. **Голос озвучки** — клон Владимира (`vcode_voice.py`), когда VO вообще нужен.

## ВСЁ ОСТАЛЬНОЕ — РАЗНОЕ, НИ ОДНОГО ПОВТОРА (даже косвенно) среди всех роликов:
ниша, тема, формат, длина, хук, СТРУКТУРА, кадры, нарезка/темп, инфографика, наложения,
переходы, музыка, звук/SFX, тип озвучки (музыка-без-VO / VO / текст+музыка), обложка, CTA.
Дедуп через реестры USED_* + плюс здравый смысл (не похоже даже приблизительно).

## ⛔ ЗАПРЕЩЁН ШАБЛОН
НЕТ фиксированного скелета «обложка-наезд → 12 стоков каждые 3с → амбер-плашки → 2-словное
караоке → тот же CTA → тот же эндкард». Это делает ролик рекламой (200 просмотров). Структура
КАЖДОГО ролика берётся из конкретного разобранного вираль-рефа.

## ЭТАП 0 — АНАЛИЗ (ОБЯЗАТЕЛЬНО, перед КАЖДЫМ роликом, всегда новые)
1. Ниша дня (ротация, всегда разная). 10 конкурентов + по 5 роликов 1M+ из YouTube и Instagram
   (`research/discover.py` + IG). ВСЕГДА новые (дедуп USED_COMPETITORS).
2. **СКАЧАТЬ ролики, раскадровка (storyboard-спрайты/кадры), транскрипт, посмотреть целиком.**
3. Метрики: просмотры, лайки, комменты, репосты, сохранения.
4. Разобрать: ХУК (первые 0.5с), структура, темп, ТИП СЪЁМКИ (экшн/лицо/скрин/мем-чат),
   аудио (тренд-музыка/VO/тишина), воронка, описание, продукт, механика, тренды.
5. Красивый документ-аналитика со всеми цифрами и ССЫЛКАМИ → в бота (`report_full.py`).

## СЦЕНАРИЙ/СТРУКТУРА — ОТ РЕФОВ
- Взять 1–2 сильнейших рефа как БЛЮПРИНТ структуры (не копия — механика: хук-первым, их темп,
  их логика кадров, их аудио-подход). Связать со смыслом/брендом.
- **Хук-первым:** сначала спроектировать стоп-скролл первый кадр (экшн/шок/лицо/движение/интрига),
  ПОТОМ остальное. Плашка поверх стока — НЕ хук.
- Прогон через маркетинг/виральность/Humanizer (`scenario_check.py`).

## КАДРЫ / ЗВУК / ИНФОГРАФИКА (единое целое, ведёт к 1M)
- **Кадры строго под смысл слов** (или реальные кадры продукта / один сильный кадр под бит).
  НЕ 12 случайных Pexels-слайдов. Меньше-но-точнее допустимо.
- **Звук:** чаще тренд-музыка с минимумом/без VO; если VO — человечный, короткий, не «диктор».
  Музыка КАЖДЫЙ раз своя под настроение (`music.py`, дедуп).
- **Инфографика — по смыслу и чаще, но НЕ мешает и НЕ декор-штамп.** Только когда добавляет
  (панч-слово, важная цифра), рисуется заново (`overlay_render.py`), разная каждый ролик.
- **CTA** — разный/мягкий, не дословный повтор.
- Обложка — нейросеть (nano_banana при кредитах, иначе FLUX) + реальный логотип, первым кадром.

## ПУБЛИКАЦИЯ / QA / ОТЧЁТ
- QA: хук/динамика/кадры-под-смысл/0 повторов/оценка залёта (Higgsfield virality_predictor если есть).
  В бота ТОЛЬКО прошедшее. Брак — не публиковать.
- Ролик ФАЙЛОМ + описание отдельным сообщением.
- Объём РАСТЁТ (не уменьшать). Метрика — просмотры/удержание, НЕ счётчик реестра.
- Утро 10:00 — аналитика опубликованного (просмотры/лайки/комменты/репосты/подписчики) → петля:
  что стрельнуло — размножаю механику; что сдохло — убиваю формат.
