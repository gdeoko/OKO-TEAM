# oko-content-factory

**Единый Claude Code skill контент-завода OKO TEAM.** Один файл — весь цикл.

Не разовая нарезка видео. Живой SMM-специалист + продюсер + монтажёр + аналитик
в одном скилле. Работает по одному клиенту, масштабируется на много.

## Что делает

Каждый день, без участия человека:

1. **Анализирует конкурентов** — минимум 5 роликов от 1M просмотров в нише
   клиента. Скачивает, транскрибирует, разбирает раскадровку, читает комментарии.
2. **Пишет сценарий** на основе анализа + трендов + аналитики предыдущих
   публикаций клиента. Прогоняет через `humanizer`, `marketing-psychology`,
   `hook-generator`, `reels-scripting`.
3. **Собирает ролик** 15–45 сек, 4K стоки (Pexels/Pixabay), 10–14 уникальных
   клипов, наложения каждые 3 сек, всё под сценарий, никаких повторов.
4. **Публикует** через Hooppy или прямые API (YT/IG/TT).
5. **Собирает аналитику** утром в 10:00 МСК → отчёт клиенту в бота.
6. **Обучается** на данных, находит залетевшие форматы, планирует продолжения.
7. **Не повторяется** никогда — реестры `USED_FOOTAGE.md` / `USED_ANIM.md`.

## Установка как Claude Code skill

```bash
# Клонировать в папку скиллов Claude Code
cd ~/.claude/skills
git clone https://github.com/<your-org>/oko-content-factory.git
```

Skill появится доступным в любом чате Claude Code.

## Запуск для нового клиента

1. Создай `clients/<slug>/BRAND_PROFILE.md` из `templates/BRAND_PROFILE.template.md`.
2. Положи `logo_hd.png` клиента.
3. Заполни доступы в `OKO_MASTER_VAULT.md` (не в этом репо — там только пример).
4. Скопируй `config/secrets.env.example` → `secrets.env`, заполни ключи.
5. Настрой `config/schedule.example.yaml` под клиента.
6. Скажи Claude Code: `запусти контент-завод для <slug>`.

Остальное — в `SKILL.md`.

## Философия

- **Ничего статичного никогда.** Всё двигается всегда.
- **Каждый ролик — с нуля под сценарий.** Никакой шаблонности.
- **Кадр меняется каждые 3 сек**, наложение — каждый кадр или через кадр.
- **10–14 уникальных стоков 4K** на ролик, не повторяются внутри и между.
- **Анализ конкурентов перед каждым роликом.** Минимум 5 от 1M просмотров.
- **Утренний отчёт в бота каждый день в 10:00 МСК.**
- **Залетело — усиливаем.** 3–5 продолжений в том же формате.
- **Higgsfield только на обложки/карусели.** Всё остальное локально, бесплатно.

Полная спецификация — в `SKILL.md`.
