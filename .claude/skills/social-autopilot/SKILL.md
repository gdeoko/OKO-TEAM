# SOCIAL AUTOPILOT — автономный оператор соцсетей

Один скилл на любой проект. Ниже — универсальный движок. Проектные значения (аккаунты, бренд,
цели, токены, page_id) держатся в `PROJECT CONFIG` (заполняется на проект; хранить в
`brain/Claude/Projects/<Project>.md` + секреты).

Ассемблер роликов = **reels-machine** (Законы разнообразия v6). Этот скилл — оркестратор ОПЕРАЦИИ
вокруг него: цикл дня, аналитика, разведка, обучение, отчёты, уведомления, рост.

> ## ⚠️ ОБЯЗАТЕЛЬНО ПЕРЕД ЛЮБОЙ РАБОТОЙ: `PRODUCTION_BIBLE.md`
> Полный свод правил (универсальный, для любого проекта) — в файле
> **[`PRODUCTION_BIBLE.md`](PRODUCTION_BIBLE.md)** рядом с этим скиллом. Это закон.
> На КАЖДЫЙ ролik выполнять на 100%, с нуля, без шаблонов: 5 этапов (анализ 10 конкурентов
> с раскадровкой+транскриптом → сценарий от анализа → сборка с разнообразием → публикация с
> QA/virality-фильтром → отчёт 10:00), матрица разнообразия (0 повторов на 500), анти-дубль,
> хук-первым, кадры под смысл слов, наложения по смыслу, звук не-TTS, честность отчётов,
> объём только растёт. Ключевой инструмент разбора: `recon_deep.py` (раскадровка через
> storyboard-обход 403 + транскрипт + метрики 10 миллионников). Читать библию целиком.

## 1. ЕЖЕДНЕВНЫЙ ЦИКЛ (сердце скилла) — выполнять КАЖДЫЙ день

### Шаг A. Аналитика своих публикаций (ВСЕ ролики, даже старые)
- По каждому аккаунту (IG/YT/TikTok) собрать метрики ВСЕХ прошлых роликов: просмотры, лайки,
  сохранения, репосты, комментарии (и их содержание), удержание, подписки-приросты.
- IG/YT — через студию: **зайти в аккаунт агентом (браузер-сессия)** → Instagram Insights /
  YouTube Studio → снять цифры по каждому ролику. TikTok — Hooppy/веб.
- Выделить: что растёт, что проседает, какие хуки/форматы/темы/CTA заходят. Обновить `WINNERS.md`.

### Шаг B. Разведка конкурентов (перед КАЖДОЙ сборкой)
- Найти **5–10 РАЗНЫХ роликов конкурентов в нише за сегодня, только от 1 000 000 просмотров** (меньше — не берём).
- Полный доступ к IG и YouTube есть → **искать в поиске** похожие ниши, смотреть конкурентов агентом.
- По каждому реф-ролику: посмотреть просмотры (>1М), лайки, сохранения, репосты; **прочитать несколько
  комментариев**; **скачать ролик** (агентом); **сделать транскрипт**; прочитать сценарий; **разобрать
  раскадровку — каждый кадр**. Только после этого — приступать к сборке.
- Логировать в `COMPETITORS.md` (ссылка, метрики, хук, структура, что заимствуем — приём, НЕ копию).

### Шаг C. Тренды + бренд
- Найти актуальные тренды ниши (web/поиск платформ). Свести: тренд + приём конкурента-1М + боль
  бренда + что продвигаем → угол ролика.

### Шаг D. Сценарии (всегда РАЗНЫЕ, обучаются на аналитике)
- Писать сценарии с нуля под угол. Микс категорий проекта (напр. viral/value/sell 50/30/20),
  форматы чередовать (absurd/challenge/checklist/demo/fail/meta/test/before-after/POV/myth/satisfying…).
- Банк идей: `SCENARIOS.md`. Каждый сценарий уникален; повторять формат только если он «выстрелил» (см. §4).
- **Прогнать сценарий через все релевантные скиллы**: медийность/виральность, соцсети, маркетинг,
  копирайтинг, brand — и через **humanizer**: тексты живые, прогревающие, продающие, человечные, динамичные.

### Шаг E. Сборка роликов (reels-machine v6)
Жёсткие правила (нарушение = переделка):
- Длительность **15–45 сек** (не длиннее — иначе просмотров мало).
- **Стоковый кадр меняется каждые 3–5 сек.** Стоки НИКОГДА не повторяются внутри ролика и
  желательно между роликами (реестр `USED_FOOTAGE.md`, дедуп по video id).
- **Наложение через кадр (иногда каждый кадр).** «Наложение» = анимация/инфографика/вставка/3D/эффект:
  3D GLB · WebGL · Spine · Lottie · WebP · GIF · CSS-анимации · кинетик-типографика · партиклы ·
  беспоук-инфографика · картинки (бесплатно через FLUX/HF Z-Image). Внутри ролика наложения НЕ
  повторяются; между роликами — тоже стараемся не повторять (реестр `USED_ANIM.md`).
- **Ничего статичного — всё всегда движется/анимируется** (зум/пан/параллакс минимум).
- ≥2 бренд-кадра (реальный UI приложения: App Store скрины/превью, мои демки — разные каждый раз).
- Обложка первым кадром 0.3с (бесплатная генерация фона + брендовый текст).
- QC-чеклист reels-machine §9: ≥8 уник. клипов, ≥2 бренд-кадра, кодовое слово, обложка, субтитры-караоке.

### Шаг F. Кросс-постинг (одна сборка → 3 площадки)
- **TikTok:** Hooppy API — `tappio-app/factory/vps/hooppy_post_api.py <page_id> <video.mp4> "<caption>"`.
- **Instagram Reels:** прямая стелс-сессия на VPS (desktop create flow, ig_post_desktop.mjs — расширить на Reels/видео).
- **YouTube Shorts:** Data API resumable upload (refresh-токен канала).
- Описания/хэштеги/кодовое слово — под площадку. Публиковать по рамп-графику (§3).

### Шаг G. Сторис / посты / карусели
- Помимо роликов — сторис, посты, карусели: частота и форматы **на своё усмотрение на основе
  аналитики самого аккаунта** (что вовлекает, время активности аудитории). Прогревать, вести на профиль/сайт.

## 2. АНАЛИТИКА И ЕЖЕДНЕВНЫЙ ОТЧЁТ (10:00 МСК в Telegram-бота)
Каждый день в **10:00 по Москве (07:00 UTC)** отправлять в бота отчёт за прошлый день:
- **По каждой соцсети** (через студии, заходя в аккаунт агентом): сколько роликов опубликовано,
  просмотры, лайки, комментарии (сколько + суть), сохранения/репосты, удержание, прирост подписчиков.
- **Сводка по всем роликам** (в т.ч. ранее опубликованным) — динамика, кто разгоняется.
- **Аналитика сайта** (тот же отчёт): визиты, переходы из bio/посылок, клики, что кликали/заполняли, заявки.
- Прогресс к цели: суммарные просмотры / 100М, подписчики / 20 000, роликов выпущено / 500.
- Что сработало вчера и план на сегодня (какие форматы усиливаем).
Отправка: `curl -s "https://api.telegram.org/bot$TAPPIO_ANALYTICS_BOT_TOKEN/sendMessage" -d chat_id=$TAPPIO_ANALYTICS_CHAT_ID -d parse_mode=HTML --data-urlencode text=@report.txt`
(chat_id получить из `getUpdates` после того как владелец напишет боту `/start`; сохранить в секрет).
Расписание — Routine/cron `0 7 * * *` (UTC) на этот скилл.

## 3. ГРАФИК РОСТА (рамп)
- Старт **1 ролик/день**, постепенно **+1 каждые несколько дней** (2→3→4→5…) чтобы к концу периода
  выйти на объём и суммарно дать целевое число (напр. 500 за 45 дней). Рамп защищает свежие аккаунты
  от спам-флага.
- Пример-таблица под 500/45дн держать в `SCENARIOS.md`.

## 4. ОБУЧЕНИЕ НА ПОБЕДИТЕЛЯХ
- Если ролик **выстрелил** (просмотров заметно больше обычного) → взять этот формат, разобрать почему
  зашло (хук/тема/приём/CTA), доработать и **повторять многократно, пока не перестанет залетать**.
- Проседающие форматы/хуки — резать. Всё фиксировать в `WINNERS.md`, обновлять микс форматов день ко дню.

## 5. УВЕДОМЛЕНИЯ ОБ ОГРАНИЧЕНИЯХ
- Если на IG/YouTube/TikTok возникает ограничение/бан/лимит:
  - **Сам можешь исправить** → исправляешь, уведомление НЕ шлёшь.
  - **Сам не можешь** → сразу шлёшь уведомление в бота (что за ограничение, что нужно от владельца).

## 6. РЕЕСТРЫ И ПАМЯТЬ (в репозитории проекта, factory/)
- `USED_FOOTAGE.md` — использованные стоки (video id) — антиповтор.
- `USED_ANIM.md` — использованные приёмы/анимации/3D — антиповтор.
- `COMPETITORS.md` — реф-ролики 1М+ (ссылка, метрики, хук, структура, транскрипт, вывод).
- `WINNERS.md` — что выстрелило, что режем, текущий микс форматов.
- `SCENARIOS.md` — банк сценариев + рамп-график + разбор ниш.
- Итоги дня — в `brain/Claude/Projects/<Project>.md`.

## 7. ИНФРАСТРУКТУРА (см. INTEGRATIONS.md)
- Браузер-агент на VPS (patchright, стелс) — вход в соцсети/студии, скачивание роликов конкурентов,
  транскрипт, аналитика через студии, IG-постинг.
- Бесплатная генерация: HF Z-Image/FLUX (обложки/картинки), Pexels/Pixabay (стоки), Freesound (звук),
  Sketchfab/HF (3D GLB). Higgsfield — только где реально нужно (кредиты).
- TikTok — Hooppy API (рецепт в INTEGRATIONS.md §1d). IG — сессии. YouTube — Data API токены.
- Отчёты — Telegram-бот проекта.
