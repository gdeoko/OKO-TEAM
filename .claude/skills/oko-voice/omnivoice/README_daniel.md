# 🎙️ OKO — Клон голоса Даниэля (набор для любого чата)

Этот набор позволяет озвучивать **любой текст твоим голосом** — бесплатно и безлимитно.
Прикрепи эту папку/архив в любом чате с ИИ-агентом (или используй сам) — и голос доступен.

---

## 📦 Что внутри

| Файл | Что это |
|---|---|
| `reference/daniel_ref_15s.wav` | **Главный референс** — 15 сек твоего чистого голоса. Это «сид» клонирования. |

| `requirements.txt` | Зависимость (`gradio_client`). |
| `README.md` | Эта инструкция. |

## 🚀 Способ 1 — просто прикрепить референс (работает где угодно)

Прикрепи **`reference/daniel_ref_15s.wav`** к любому голосовому ИИ-инструменту, который
умеет клонировать голос (zero-shot voice cloning), и попроси озвучить текст этим голосом.
Референс — универсальный: подходит для OmniVoice, VoxCPM, XTTS, F5-TTS, ElevenLabs и др.

Фраза для агента:
> «Вот референс моего голоса (`daniel_ref_15s.wav`). Озвучь этим голосом текст: …»

## 🖥️ Способ 2 — запустить скрипт (бесплатно, через HF Space)

```bash
pip install -r requirements.txt
python clone_voice_omnivoice.py "Привет! Это команда ОКО." out.wav
```

Длинный текст / другой референс / точная длительность:
```bash
python clone_voice_omnivoice.py "твой длинный текст" out.wav --ref reference/daniel_ref_30s.wav --du 20
```

- `--du` — длительность в секундах (по умолчанию считается автоматически по длине текста,
  чтобы фраза не обрезалась).
- `--lang` — язык: `Russian` (по умолчанию), `English` и др. (600+ языков).
- `--ns` — качество (больше = чище, но дольше рендер). По умолчанию 48.

### HF-токен (необязательно)
Скрипт работает и без токена. Если упираешься в лимит ZeroGPU — получи бесплатный токен
на https://huggingface.co/settings/tokens и задай:
```bash
export HF_TOKEN=hf_xxxxxxxx
```

## 💡 Советы для лучшего качества
- Для коротких фраз хватает `daniel_ref_15s.wav`; для длинных — `daniel_ref_30s.wav`.
- Пиши текст с пунктуацией (точки/запятые) — интонации будут естественнее.
- Если голос звучит «спешно» — увеличь `--du`.
- Референс уже почищен и нормализован — заново обрабатывать не нужно.
