# 🎙️ OKO — Клон голоса Даниэля (PRO-набор для любого чата)

Полный набор, чтобы озвучивать **любой текст голосом Даниэля на студийном уровне** —
с правильными русскими ударениями, чистым звуком и нормальным темпом речи.
Прикрепи этот архив в **любом чате с ИИ-агентом** — и голос доступен где угодно.

> Что на выходе: голос Даниэля • студийная чистота (resemble-enhance) •
> правильные ударения (словарь) • темп 1.7× • 44.1 кГц hi-fi.

## 🚀 Способ 1 — прикрепить в любом чате (проще всего)

1. Прикрепи **весь этот архив** (или папку) в чат с ИИ-агентом (Claude, ChatGPT и т.п.).
2. Напиши:
   > «Распакуй архив и озвучь этот текст моим голосом через `oko_voice_pro.py`:
   > <твой текст>. Нужен HF PRO токен из переменной HF_TOKEN.»
3. Агент запустит конвейер и вернёт готовый mp3.

Если у агента **нет** возможности запускать код — прикрепи только
`reference/daniel_ref_28s.wav` и попроси: «озвучь этим голосом текст …» (референс
универсален: подходит для OmniVoice, VoxCPM, XTTS, F5-TTS, ElevenLabs и др.).

## ⭐ Способ 2 — запуск скрипта (максимальное качество)

```bash
pip install -r requirements.txt
export HF_TOKEN=hf_xxxxxxxx           # аккаунт с HF PRO = безлимит движка A
python oko_voice_pro.py "Любой сценарий..." out.mp3
```

Опции:
| Флаг | Смысл | По умолчанию |
|---|---|---|
| `--ref reference/daniel_ref_28s.wav` | референс голоса | 28 сек |
| `--speed 1.7` | темп речи (1.0 = обычный) | 1.7 |
| `--no-enhance` | без resemble-enhance (быстрее, звук чуть проще) | вкл. |
| `--engine omnivoice` | форс одного движка (omnivoice/voxcpm/qwen3/megatts3) | авто |

Текст любой длины — режется на фрагменты и склеивается автоматически.

## 🎯 Ударения — «русский на высшем уровне»

Мы НЕ размечаем весь текст автоматически (это портит естественность). Вместо этого
правим ударение **точечно** — только для слов из `stress_dict.txt`.

Формат словаря (ударение = гласная + знак `́`, юникод U+0301):
```
ОКО=О́КО
око=о́ко
```
Заметил слово, где движок ошибся в ударении? Добавь строку `слово=сло́во` — и всё.
Проверенный формат для движка A — **юникод-ударение** (не «+»).

## ♾️ Безлимит и качество

- Движок «A» = **OmniVoice** (лучший по тембру Даниэля). Чтобы он был **безлимитным
  и быстрым** — нужен **HF PRO** ($9/мес) на аккаунте, чей `HF_TOKEN` используешь:
  оформить → **https://huggingface.co/subscribe/pro** (40 мин GPU/день = сотни клипов).
- Без PRO скрипт всё равно работает: при исчерпании дневной квоты OmniVoice ротатор
  сам переключается на VoxCPM / Qwen3 / MegaTTS3 (тоже бесплатные).
- Студийный энхансер: **resemble-enhance** (тоже HF, входит в квоту).

Проверить PRO: https://huggingface.co/settings/billing

## 🧩 Как это работает (конвейер PRO)
1. **Ударения** — подстановка из `stress_dict.txt` (точечно).
2. **Клон** — OmniVoice (A) по чистому референсу, `ns=64` (макс. качество синтеза);
   длинный текст → фрагменты → склейка; авто-фолбэк на другие движки по квоте.
3. **resemble-enhance** — студийная чистота + живость (solver RK4, nfe 128).
4. **Мастеринг** — темп ×1.7, презенс-подъём, громкость вещателя, 44.1 кГц hi-fi.

## 🛠️ Если что-то не так
- `quota exceeded` у OmniVoice → оформи HF PRO, либо ротатор сам возьмёт другой движок.
- Нет `ffmpeg` → он ставится вместе с `imageio-ffmpeg` (в requirements), скрипт находит его сам.
- Голос «спешит»/«медленный» → поменяй `--speed` (например 1.5 или 1.8).
- Ошибка ударения в слове → добавь его в `stress_dict.txt`.
