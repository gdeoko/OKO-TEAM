# OKO Voice — канонический голос бренда (бесплатно, локально)

**Решение Даниэля (закреплено навсегда, для всех чатов и агента):**
озвучка OKO делается **бесплатными локальными нейро-TTS**, НЕ платными кредитами.

**Почему именно эти движки — БЕЗЛИМИТ.** Silero и XTTS работают локально (ни API, ни ключей,
ни квот, ни оплаты за символ) → можно гнать **любой объём** (у Даниэля поток огромный).
Ставим ТОЛЬКО безлимитные локальные движки; платные кредитные (ElevenLabs/Higgsfield) — нельзя.

**Голос — ПОД ПРОЕКТ, не всегда один.** Движок фиксирован (Silero/XTTS), а конкретный голос
подбирается под проект: муж/жен/характер/клон. `eugene` — дефолт бренд-озвучки OKO, не единственный.

| Движок | Когда | Голос | Цена |
|---|---|---|---|
| **Silero v4_ru** | по умолчанию: уроки, ролики, агент, бот, VPS | **eugene** (муж, БРЕНД) | **$0** |
| **XTTS-v2 (Coqui)** | когда нужно «ещё живее» или клон голоса по образцу | клон из ref-wav / студийный | **$0** |
| ~~edge-tts~~ | НЕ использовать — звучит как робот, ошибки ударений | — | $0 |
| ~~ElevenLabs / Higgsfield-голос~~ | НЕ использовать для рядовой озвучки — платно (кредит ≈ $0.066, ~$1/урок) | — | $$ |

Silero держит ударения (`put_accent`), быстрый на CPU, модель ~40МБ.
XTTS-v2 ближе к ElevenLabs по «живости», умеет клонировать голос по 6–20с образца.

## Быстрый старт
```bash
# один раз за сессию (torch уже может стоять):
pip3 install -q torch torchaudio --index-url https://download.pytorch.org/whl/cpu
# для XTTS дополнительно:  pip3 install -q coqui-tts "transformers<4.50"

# бренд-голос OKO (Silero eugene):
python3 .claude/skills/oko-voice/scripts/oko_tts.py --textfile script.txt --out vo.wav --mp3
# явно:
python3 .claude/skills/oko-voice/scripts/oko_tts.py --engine silero --voice eugene --text "Привет, это ОКО." --out vo.wav
# премиум/клон (XTTS-v2):
python3 .claude/skills/oko-voice/scripts/oko_tts.py --engine xtts --ref ref_voice.wav --text "..." --out vo.wav
```
Env-переключатели: `OKO_TTS_ENGINE=silero|xtts`, `OKO_TTS_VOICE=eugene`, `OKO_XTTS_SPEAKER`.

**Для уроков Академии и голосового ИИ-агента — только этот пайплайн.** Решает ВСЕ жалобы
владельца: «хвостики/мамблы», «звучит не студийно», «как под водой / по телефону», + скорость 1.5×.

```bash
python3 .claude/skills/oko-voice/scripts/oko_voice_pro.py --textfile s.txt --speed 1.0 --out vo.wav  # натуральный темп
```
### ЧТО ИМЕННО ДАВАЛО «под водой / по телефону» (диагноз v1) и как починено (v2)
- **Причина №1 — afftdn (FFT-шумодав) на чистом TTS** → «musical noise» = подводность.
  Fix: денойз убран ПОЛНОСТЬЮ. XTTS-выход уже чистый (шум-фон ~−48дБ). arnndn/RNNoise
  тоже НЕ ставим — на TTS он ЛОМАЕТ речь (whisper: «чистый звук»→«чтодамок»; .rnnn-модели
  скачаны, протестированы, отвергнуты).
- **Причина №2 — референс 22050 + нет «воздуха»** → энергия обрывалась на ~8кГц = «телефон».
  Замер: v1 `band_edge=7910Гц, E>8к=0.01%`. Fix: реф на НАТИВНЫХ **24000Гц**
  (`oko_ref_pro_24k.wav`) + presence +1.5дБ@4.5к + high-shelf +2дБ@8к.
  Замер v2: `band_edge=10348Гц, E>8к=0.19%` — в ~19× больше «воздуха». Телефонность ушла.
- **Референс:** `oko-app/brand/voice/oko_ref_pro_24k.wav` (по умолчанию) — 24000 моно,
  собран из самого чистого голосового владельца МИНИМАЛЬНО: `highpass=60 + loudnorm`,
  БЕЗ лоупасса/шумодава, полная полоса до ~10.8кГц. Потолок ~9-11кГц задаёт сам opus-исходник
  Telegram — выше «взять» неоткуда, поэтому «воздух» добираем high-shelf'ом в мастеринге.
  Старый `oko_ref_pro.wav` (22050) оставлен, но НЕ дефолт.
- **Победивший конфиг XTTS (A/B, интеллигибельность 0.93+):**
  `temperature=0.3, repetition_penalty=10.0, top_k=30, top_p=0.75, length_penalty=1.0,
  split_sentences=False`. Генерация на НАТИВНЫХ 24000Гц (НЕ ронять до 22050).
- **Против «хвостиков»: tail-trim по whisper word-timestamps** (как в v1) — посегментно, режем
  по концу последнего реального слова + 0.18с + fade; хвост-галлюцинация отрезается.
- **СКОРОСТЬ `--speed` (дефолт 1.5, требование владельца):** `atempo` в самом конце цепочки
  (сохраняет высоту → без «чипмунка»). Разборчивость 1.5× проверена whisper — текст полный.
- **Мастеринг v2 (БЕЗ подводности):** `highpass=60 → лёгкий deesser(~6кГц) → presence
  +1.5дБ@4.5к → high-shelf +2дБ@8к → loudnorm I=-16:TP=-1.5 → atempo=speed`.
  НИКАКОГО afftdn/arnndn/реверба/эксайтера/лоупасса.
- **Тон `--tone`:** `clean` (дефолт) | `warm` (+тело low-mid) | `bright` (ещё воздушнее) |
  `low` (−1 полутон, rubberband). `--retries N` — лучший из N по интеллигибельности.
- **Ограничение:** если «ОКО» стоит ПОСЛЕДНИМ словом фразы — XTTS его комкает; строить фразу так,
  чтобы «ОКО» не было в самом конце. На 1.5× изредка проскакивает лишнее короткое слово-призвук
  (напр. «то») — при важных дублях гнать `--retries 3`.

### Премиум-путь Higgsfield (клон голоса) — для РУССКОГО НЕ рекомендован
Владелец разрешил кредиты ради качества, поэтому путь протестирован и задокументирован:
- Zero-shot клон через `generate_audio` model=`seed_audio` (ByteDance), `medias=[{role:audio_references,...}]`,
  `format=wav, sample_rate=24000`. Стоимость ~2.4 кред/абзац. Персистентный клон-голос
  (`create_voice`) НЕ нужен и упирается в лимит голосов аккаунта (заняты чужими проектами).
- **Итог сравнения:** Higgsfield звучит тонально ЯРЧЕ/воздушнее (E>8к=0.80% против 0.19% у local),
  НО коверкает русское произношение (whisper: «объяснения без воды»→«чести в пании с безвакой»,
  «телефонного»→«дельфонный»). Для РУССКИХ уроков — непригодно. Держать как опцию для англо-контента
  или если ByteDance подтянет RU. **Дефолт и лучший для RU — локальный XTTS v2.**
- Сэмплы сравнения лежат рядом: `oko-app/brand/voice/oko_v2_local.mp3` (XTTS v2, ставить это) и
  `oko_v2_higgsfield.mp3` (Higgsfield, для сравнения).
- **Про RVC/so-vits (проверено, НЕ взлетело на CPU):** обучение RVC требует 10-30 мин датасета
  (у нас ~1 мин) и GPU; на CPU с 1 мин выйдет металлический артефакт — это УХУДШИТ чистоту,
  а не улучшит. XTTS уже решает обе жалобы (чистота + отсутствие хвостов), поэтому RVC не нужен.
  Голый TTS→RVC не ставим: fairseq/faiss на Python 3.11/CPU хрупок и даёт регресс качества.

## XTTS-v2 (премиум/клон) — базовый рецепт (низкоуровнево, для oko_tts.py)
- Модель `tts_models/multilingual/multi-dataset/xtts_v2` (~1.8ГБ, качается coqui-tts).
- **Клон голоса по образцу** (лучший «живой» результат): `speaker_wav="ref.wav"` (15–30с
  чистой речи одного человека, 22050 моно PCM), `language="ru"`. Это буквально голос
  человека → звучит живо. Пример — клон голоса Даниэля по его двум ~55с записям.
- **ГРАБЛЯ torchcodec (обязательно!):** torch≥2.9/torchaudio требует torchcodec для
  `torchaudio.load`, а он тянет CUDA-либы (`libnvrtc`) → падает на CPU. Обход: torchcodec
  должен быть УСТАНОВЛЕН (иначе `import TTS` падает), НО подменить загрузчик на soundfile:
  ```python
  import torch, torchaudio, soundfile as sf
  def _sf_load(p,*a,**k):
      d,sr=sf.read(p,dtype='float32',always_2d=True); return torch.from_numpy(d.T.copy()),sr
  torchaudio.load=_sf_load          # ДО import TTS
  from TTS.api import TTS
  ```
- Ставить: `pip install coqui-tts "transformers==4.57" torchcodec soundfile`.
- **Ускорение/темп:** генерить в натуральном темпе → `ffmpeg atempo=1.5` (сохраняет питч).
  XTTS-клон часто читает медленно — 1.3–1.5× выводит в нормальный дикторский темп.
- **Ударения:** XTTS свой g2p (RUAccent-метки `+` НЕ передавать — читает как артефакт).
  Стресс-ошибки править точечно фонетикой по слуху владельца (я аудио не слышу).

## Пайплайн озвучки урока/ролика (как делать правильно)
1. Текст сценария → числа прописью, сложные ударения через `+` перед гласной (`догово+р`).
2. `oko_tts.py` (Silero eugene) → `vo.wav` (48кГц). Длинный текст скрипт сам бьёт по предложениям.
3. Тайм-коды слов для караоке — faster-whisper (`small`, `word_timestamps`) по готовому wav.
4. Мастеринг: `loudnorm I=-14:TP=-1.5` (видео) / `-16` (голос-ассистент).

## Грабли
- Silero лимит ~1000 симв/вызов — скрипт бьёт автоматически.
- Сеть только `curl --cacert /root/.ccr/ca-bundle.crt` (urllib мимо прокси; модель качается curl'ом).
- XTTS + transformers 5.x = `isin_mps_friendly` ImportError → ставить `transformers<4.50`.
- torch — CPU-колесо (`--index-url .../whl/cpu`), иначе тянет CUDA.
