# Маркетинговые скиллы — источники

Установлены 2026-07-05. Все под лицензией MIT (файл LICENSE лежит в каждой папке скилла).

## coreyhaines31/marketingskills
https://github.com/coreyhaines31/marketingskills

- `copywriting` — продающие тексты для страниц (лендинги, офферы, хедлайны, CTA)
- `copy-editing` — редактура готового текста, усиление слабых мест
- `social` — посты для соцсетей под каждую платформу
- `emails` — письма и email-цепочки
- `launch` — стратегия запусков продуктов
- `marketing-psychology` — психология продаж и триггеры принятия решений
- `content-strategy` — контент-стратегия и планирование
- `lead-magnets` — лид-магниты
- `offers` — упаковка оффера: бонусы, гарантии, ценностное фреймирование
- `marketing-plan` — маркетинговый план / основа бизнес-плана

## charlie947/social-media-skills
https://github.com/charlie947/social-media-skills

- `voice-builder` — профиль голоса бренда (создаёт about-me.md и voice.md — запусти первым!)
- `post-writer` — посты в твоём голосе (требует файлы от voice-builder)
- `post-scorer` — оценка черновика поста до публикации
- `hook-generator` — хуки / первые строки
- `content-matrix` — контент-план на неделю/месяц
- `reels-scripting` — сценарии Reels / вертикальных видео / сторис
- `gemini-carousel` — карусели: бриф по слайдам + промпты для генерации картинок

## blader/humanizer
https://github.com/blader/humanizer

- `humanizer` — убирает следы ИИ из текста (прогонять финальные тексты перед отдачей клиенту)

## Рабочий порядок

1. Один раз: `voice-builder` — собрать голос.
2. Черновик: `copywriting` / `post-writer` / `social` / `emails` и т.д.
3. Проверка: `post-scorer` (для постов), `copy-editing` (для длинных текстов).
4. Финал: `humanizer` — снять ИИ-паттерны перед отправкой клиенту.
