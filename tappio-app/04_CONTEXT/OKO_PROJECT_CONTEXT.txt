СЕКЦИЯ 8 · ОКО БЭКЕНД (архитектура — api.php / cron.php / polling.php)
================================================================================

ЭТО ЭТАЛОН — на нём строим бэкенд smart-apps-site. Тот же подход:
PHP-скрипты на хостинге, JSON-файлы как БД, Gmail SMTP, Telegram Bot API.

8.1. ФАЙЛОВАЯ СТРУКТУРА (на хостинге okoteam.top):
  /api.php             — главный роутер (saveLead, confirmPayment, drip,
                          saveAnketa, downloadAnketa, sendNewsletter,
                          checkPaid, getStats, getSubscribers, manualConfirm)
  /cron.php            — крон дожимов (запуск каждые 30 мин)
  /polling.php         — Telegram-бот для админа (long-polling)
                         запуск каждую минуту, 6 итераций × 10 сек
  /data.json           — БД: subscribers, payments, settings, newsletter_log
  /bot_state.json      — состояния TG-бота (мультишаговые диалоги)
  /polling_offset.txt  — оффсет Telegram getUpdates
  /anketas.json        — заполненные анкеты
  /partials/           — partial-заявки (для дожимов)
  /.htaccess           — конфиг Apache
  /thanks              — страница "Оплата прошла" (без расширения, ForceType)

8.2. .HTACCESS — ключевые правила:
  · Options -Indexes
  · ServerSignature Off
  · AddDefaultCharset UTF-8
  · ForceType text/html для sistema|zavod|web (без расширения)
  · Кэш статики (картинки, css, js)
  · Deny для data.json / .env / cron.php / polling_offset.txt / bot_state.json
  · CORS для api.php: Access-Control-Allow-Origin: *

8.6. РОУТЕР api.php — actions:
  · saveLead         — клиент заполнил форму:
                       ── для custom продуктов (web/voronka/bot) → клиенту
                          одно письмо "Заявка принята", Даниэлю — с анкетой
                       ── для обычных (sistema/zavod/consult) → клиенту с
                          кнопкой "Перейти к оплате" (Lava), Даниэлю — лид
                       Везде дублируется в TG: tgWithButtons() с inline-кнопками
                       partial для дожимов: PARTIALS_DIR/md5(email+product).json
  · confirmPayment   — Lava webhook ИЛИ manualConfirm
                       Помечает paid=true, удаляет partial, шлёт письмо
                       "Оплата получена" + Telegram админу
  · drip             — крон-эндпоинт (защищён ADMIN_KEY)
                       Дожим 1: через 3600 сек (1 час), drip1=true
                       Дожим 2: через 86400 сек (24 часа), drip2=true
                       Удаление partial: через 172800 сек (48 часов)
  · saveAnketa       — клиент заполнил анкету (по q1..q64 IDs)
                       Сохранение в anketas.json
                       Уведомление Даниэлю на email + TG
                       Кнопки: "Скачать анкету", "Написать клиенту"
  · downloadAnketa   — скачивание анкеты в виде HTML-файла
                       Готовый красивый шаблон, тёмная тема ОКО
  · sendNewsletter   — рассылка по сегментам (all/paid/unpaid/product)
                       Замена {{name}} и {{email}} в шаблоне
                       Лог в newsletter_log
  · checkPaid        — браузер проверяет paid=true (для thanks страницы)
  · getStats         — статистика для админа
  · getSubscribers   — список лидов
  · manualConfirm    — ручное подтверждение оплаты (по ADMIN_KEY)

8.7. cron.php — упрощённая версия drip:
  · Запуск: */30 * * * * php /path/cron.php
  · То же что api.php?action=drip, но без HTTP

8.8. polling.php — TG-бот админа Даниэля:
  · Запуск: */1 * * * * php /path/polling.php
  · 6 итераций × 10 сек = ~1 минута на каждый крон
  · getUpdates с offset из polling_offset.txt
  · Главное меню (persistent keyboard): Лиды, Оплаты, Продукты, Дожимы,
    Рассылка, Команды
