## РАЗНООБРАЗИЕ (НОЛЬ ПОВТОРОВ — главное требование)
Каждый ролик КАК С НУЛЯ. Не повторяются между роликами: тема/угол, кадры (4К стоки),
музыка, SFX, грейд, темп, СТРУКТУРА и состав/порядок наложений, механики. Дедуп: билдер
(кэш+USED_FOOTAGE/USED_ANIM), gen_scripts (rng на id, ротация app spy/brain/tape),
QC-гейт (qc.py — флаг overlay-set-repeat). Два аккаунта — не постить одно и то же.

## КОНВЕЙЕР НА КАЖДЫЙ РОЛИК (cron_once.sh → auto_run.sh → make_reel4.sh)
1. **Анализ конкурентов перед роликом**: recon.py <app> quiet — топ YouTube ниши (живые
   метрики, 1M+), хуки; на основе свежего РАЗНОГО угла конкурента строится тема ролика
   (script_polish пишет comp_angle + yt_title из реального заголовка конкурента).
   Полный красивый документ-аналитика в бота — ежедневно (recon.py all, триггер 08:30).
2. **Сценарий**: тренд-ключи + humanizer + усиление хука + virality-скор (script_polish.py).
   Воронка/кодовое слово/CTA в caption; для sales-типа — усиленный CTA.
3. **Сборка**: 4К-кадры (дедуп), код-инфографика (разный состав), AI-обложка FLUX
   (gen_cover_ai.py, Pollinations, connector-free) + бренд-текст; озвучка с эмфазой хука.
4. **QC-гейт** (qc.py): длина/кадры/наложения/разнообразие + скор «на залёт» → в отчёт.
5. **Публикация** 3 соцсети (TikTok/YouTube/IG) + отчёт в бота; дедуп по posted_reels.json.
