## ПРАВИЛА FLIKI ПРОМПТОВ

### Длительность: 15-50 секунд (СТРОГО!)
- 5-6 сцен по 3-5 секунд каждая
- 1500-3000 символов текста промпта

### Структура каждого промпта:
```
# Title in English

Background music: dark cinematic ambient with [вариация]. Volume: 7%

Subtitles: OFF. Captions: OFF. Text overlays: OFF. Do not add any text layers...

[SCENE 1 - HOOK - 3 sec]
Visual: [описание стокового кадра]
Voiceover: "Текст озвучки на русском"

[SCENE 2 - 5 sec]
Visual: [описание]
Voiceover: "..."
```

### Музыка ВСЕГДА:
`dark cinematic ambient with [вариация]`. Допустимые вариации:
- deep analog synth bass, sparse piano, sub-bass drone
- muted percussion, cello drones, fingerpicked guitar with dark pad
- evolving pad textures, metallic textures, filtered pulse
- crystalline synth tones, warm Rhodes piano, buzzing textured synth

**ЗАПРЕЩЕНО:** upbeat corporate, bright cheerful, acoustic pop, epic orchestral с хором, motivational

### B-roll кадры (Visual:) — ТОЛЬКО реальные стоковые видео:
Fliki подбирает стоковые видео из библиотек Pexels/Shutterstock. Описывать ТОЛЬКО то, что реально существует в стоковых библиотеках.

**ОБЯЗАТЕЛЬНО привязывать к нише** видеопродакшн/контент/камеры/студии:
- Камеры, объективы, штативы, softbox, LED панели
- Видеографы за работой, монтаж на ноутбуке
- Телефоны с Instagram/аналитикой
- Рабочие процессы бизнесов (руки мастера за работой)

**ЗАПРЕЩЕНО:**
- Дата-центры, серверные, голограммы
- Летающие объекты в пустоте, каскады экранов
- Модели мозга, абстрактные визуализации
- Корпоративные офисы с митингами
- Аэросъемка городов (если ролик не про город)
- Любые кадры которые НЕ найдутся в стоковой библиотеке

### Озвучка (Voiceover:):
- Русский язык
- Числа ПРОПИСЬЮ (не цифрами): "тридцать тысяч" а не "30 000"
- Без длинных тире (—)
- Без "не X а Y" противопоставлений
- Без ИИ-штампов: является, вот почему, именно поэтому, высокий уровень
- Без дробления: "Вот. Так. Работает." — запрещено
- Без нанизывания "и и и" (3+ союзов "и" в одном предложении)
- Без нумерованных списков в озвучке
- Обращение на "вы"
