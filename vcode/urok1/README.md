# Урок 16:9: как собирается

Конвейер одного урока академии V.LIONOFF. Из текста урока получается ролик
1920x1080 с голосом автора, живыми кадрами, анимацией по смыслу речи,
субтитрами, музыкой и обложкой. Всё, кроме кадров, бесплатно.

## Порядок

1. **Сценарий.** `scenario.json`: сцены по 20-30 секунд, у каждой свой вид
   (определение, сравнение, цифра, арифметика, шаги, миф, карта курса, итог,
   практика, финал), текст озвучки и данные для графики. Текст пишется из
   конспекта урока, своими словами.
2. **Озвучка.** `python3 ozvuchka_scen.py --env <файл окружения>`.
   Голос Владимира (клон OmniVoice по 30-секундному образцу), по кускам не
   длиннее 220 знаков: на длинном тексте модель вставляет лишнее слово на
   своих стыках. Каждый кусок чистится по словам whisper. На выходе
   `golos/<сцена>.wav` и `golos/golos.json` с длительностью и таймкодом
   каждого слова.
3. **Кадры.** Промпты в `scratchpad/bin/urok1_prompts.py`, генерация на сервере
   `gen2.py` (APIMODELS, gpt-image-2.5-flare, ячейка 2K high, $0.04 за кадр).
   Четыре-шесть кадров дополнительно оживляются видео (minimax-h3-lite, 3 с,
   $0.06): в сцене первые три секунды идёт движение, дальше мягкий переход на
   фотографию с наездом.
4. **Монтажный лист.** `python3 sborka.py` складывает сценарий, длительности и
   ассеты в `remotion/public/montazh.json`. Длина сцены равна длине её озвучки
   плюс полсекунды, поэтому кадр никогда не обрывается на слове.
   Подписи на экране берутся из текста сценария, а время, из расшифровки:
   whisper слышит «два заведения-наведения», и такой мусор в кадр не пускаем.
5. **Рендер.** `cd remotion && npx remotion render src/index.ts Urok out/urok.mp4
   --concurrency=4`. Одиннадцать минут собираются примерно за двадцать.
6. **Отдача.** `python3 zalit.py remotion/out/urok.mp4 b1-l1 обложка.jpg`:
   ролик уезжает кусками по 12 МБ (в один запрос он не проходит) и сам
   привязывается к уроку вместе с обложкой.

## Почему анимация попадает в речь

У каждой сцены есть список слов с таймкодами. Строка списка, шаг или пилюля
появляются не по ровной раскладке, а в тот кадр, где произносится их первое
слово (`кадрПоСлову` в `remotion/src/ui.tsx`). Если слово в речи не нашлось,
работает запасная ровная раскладка, поэтому сцена не ломается никогда.

## Что держать в голове

- Длинных тире в тексте нет нигде: ни в сценарии, ни в субтитрах.
- Кадры генерим без единой буквы: весь текст рисует код, иначе кириллица в
  генерации ломается.
- Обложка, наоборот, делается генерацией с текстом внутри промпта и логотипом
  первым референсом, как физическим предметом сцены.
- Музыка лежит тише речи на 16 дБ и идёт петлёй.
