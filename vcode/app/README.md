# V.LIONOFF, приложение

Телеграм-мини-приложение, сайт, бот и админ-панель в одной папке. Школа
контент-креаторов (академия с курсами, тестами и сертификатами), биржа заказов
между бизнесом и исполнителями и партнёрская программа.

Живой адрес: **https://okoteam.top/vlionoff/**
Бот: **@vcodemedia_bot** (кнопка «Открыть» ведёт в приложение)

## Из чего собрано

PHP 8 и SQLite, фронтенд, один файл ванильного JS без сборки. Выбор нарочный:
папку целиком можно перенести на любой обычный хостинг клиента, ничего
собирать и устанавливать не нужно.

```
app/
  public_html/          ← то, что видно наружу
    index.html          мини-приложение и сайт одним файлом
    assets/app.css      оформление: тёмная и светлая темы, неон, анимации
    assets/app.js       все экраны, маршруты, инфографика
    assets/img/         лого, ключ-арты, обложки блоков
    api/index.php       API приложения (один вход)
    api/admin.php       API админки
    api/bot.php         вебхук бота
    admin/index.html    админ-панель
  core/                 конфигурация, база, вход, Telegram
  db/schema.sql         схема (18 таблиц)
  content/*.json        курсы: блоки, уроки, слайды, тесты
  bot/funnel.php        воронка бота по расписанию
  tools/                деплой, импорт контента, вебхук, обложки
```

## Экраны

| нижнее меню | что внутри |
|---|---|
| Главная | приветствие, кольцо уровня, серия дней, «продолжить урок», свежие заявки, лента |
| Обучение | курсы, блоки с обложками, уроки: слайды, конспект, тест, практика, сертификат |
| Заявки | биржа: лента заявок, фильтры, отклик, каталог исполнителей, размещение заявки |
| Тариф | Старт, PRO, Наставник, оплата, партнёрская ссылка, история платежей |
| Профиль | витрина для заказчика, услуги, цена, портфолио, сертификаты, настройки, вход в админку |

Вне Телеграма тот же адрес открывается как сайт: лендинг с программой, ценами и
кнопкой «Открыть в Telegram».

## Запуск у себя

```bash
php -S 127.0.0.1:8099 -t public_html tools/dev_router.php   # локально
php tools/import_content.php                                # загрузить курсы
php tools/dev_token.php                                     # тестовый вход без Телеграма
```

База создаётся сама при первом запросе (`data/vcode.db`).

## Боевой сервер

```bash
bash tools/deploy.sh            # разложить код и накатить контент
bash tools/deploy.sh --nginx    # то же плюс конфиг nginx
php tools/set_webhook.php       # подключить бота
```

Настройки с токенами живут в `core/config.local.php` (в git его нет, пример,
`tools/config.local.example.php`).

## Что нужно от клиента

1. **lava.top**: регистрация, ключ API и id офферов, после этого оплата внутри
   приложения включается сама (`lava` в настройках).
2. **ЮKassa** на самозанятого, если нужны чеки.
3. Свой домен, когда захочет: приложение умеет жить и в подпапке, и на своём
   домене (`tools/nginx-vcode.conf` готов).
4. Аватар бота ставится в @BotFather, API такого не умеет: файл
   `public_html/assets/img/icon.png`.
