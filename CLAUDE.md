## 🔴 РЕГЛАМЕНТ КОНТЕНТ-ЗАВОДА DIESEL CARGO (один заход в день, потом тишина)
**ОДИН большой заход в 07:00 МСК (04:00 UTC). Делаем ВСЁ за раз, дальше молчим весь день.**
Никаких почасовых пробуждений и проверок — они жгут токены впустую. Будят только ОШИБКИ
(через мост/подписку). В конце дня — одна короткая проверка «всё ок».

Порядок захода в 07:00 МСК:
1. **Активности** (обе пачки A/B): лайки/комменты/репосты/подписки по согласованной квоте.
2. **Анализ 10 свежих роликов 1М+**: досмотреть до конца, скачать транскрибацию,
   разобрать по 15 пунктам каждый (хук, сценарий, формат, воронка, механики, виральность,
   медийность, маркетинг, сильные стороны). Собрать ФАЙЛ со ссылками и анализом каждого.
3. **Сборка дневной партии роликов НА ОСНОВЕ этого файла.** Разнообразие ВО ВСЁМ между
   всеми 500 роликами: хуки, темы, сценарии, форматы, музыка, SFX, кадры/стоки, наложения,
   монтаж, переходы, стили CSS-анимаций, механики инфографики. **Ничего статичного:** смена
   анимации/инфографики/стокового кадра/динамики каждые ~3 сек, красивые профессиональные
   переходы, кодированная инфографика по СМЫСЛУ сценария (build_accents: speedo/donut/vs/
   route/odometer/iconrow/linechart/sidebars/…). Сценарий — из роликов, собравших миллионы.
4. **QA каждого ролика** через `qa_score.py` — в очередь только при ≥85/100.
5. **Программирование публикаций по графику через 2 часа**, первый в 10:00 МСК (07:00 UTC):
   5 роликов → 10·12·14·16·18 МСК; 10 роликов → +20·22·00·02·04 МСК. Готовые: обложка+описание.
6. Всё уходит в планировщик VPS ЗА ОДИН заход. Дальше — тишина.

МСК = UTC+3. 07:00 МСК = 04:00 UTC (анализ+сборка). 10:00 МСК = 07:00 UTC (первая публикация).

## Жёсткие правила от Даниэля
1. **Никаких окон подтверждения. НИКОГДА.** Разрешения выданы на всё
   (`.claude/settings.json` + `settings.local.json`: `bypassPermissions` +
   wildcard-allow `mcp__<server>__*` на все MCP + **PreToolUse-хук авто-одобрения**
   `permissionDecision:allow` на matcher `*`). Не спрашивать подтверждений на
   инструменты, деплой и правки. При разрыве MCP («stream closed» / «Tool permission
   stream closed») — **молча переподключаться и повторять вызов самому**, пока не
   пройдёт; окон не выводить, Allow не просить. NB: хук применяется со СЛЕДУЮЩЕЙ
   сессии — в текущей окна ещё могут мигать, всё равно добивать ретраями.
2. **НЕ публиковать Claude-артефакты.** Даниэль смотрит прогресс только по публичной
   ссылке. Артефакт-зеркало отключено навсегда.
3. Правки применяются как постоянные правила, не разово.
4. В интерфейсе OKO — никаких эмодзи, только SVG-иконки в стиле бренда.
   Бренд: чёрный + лайм #9AFF00, Bebas Neue + Montserrat, тёмная и светлая темы.
5. Работать автономно: делать, деплоить, отчитываться результатом.
