## Жёсткие правила от Даниэля
1. **Никаких окон подтверждения.** Разрешения выданы на всё (`.claude/settings.json`).
   Не спрашивать подтверждений на инструменты, деплой и правки.
2. **НЕ публиковать Claude-артефакты.** Даниэль смотрит прогресс только по публичной
   ссылке. Артефакт-зеркало отключено навсегда.
3. Правки применяются как постоянные правила, не разово.
4. В интерфейсе OKO — никаких эмодзи, только SVG-иконки в стиле бренда.
   Бренд: чёрный + лайм #9AFF00, Bebas Neue + Montserrat, тёмная и светлая темы.
5. Работать автономно: делать, деплоить, отчитываться результатом.
6. **ЛОГО — ТОЛЬКО НАСТОЯЩЕЕ, ВЕЗДЕ И ВСЕГДА, в base64, не искажая пропорции.**
   Файлы: `brand/oko-logo.png` (оригинал 1000×1000), `brand/oko-logo-256.png`,
   `brand/oko-logo-b64.txt` (готовый data-URI для вставки в `<img src=...>`).
   В агентах — `oko-agents/core/brand.py` (`LOGO_DATA_URI`). НЕ рисовать SVG-заглушки,
   НЕ растягивать, НЕ менять цвета лого. Обновлять эти файлы при новой версии лого.
7. **ПЛАТНЫЕ КРЕДИТЫ/ГЕНЕРАЦИИ — ТОЛЬКО С ЯВНОГО РАЗРЕШЕНИЯ ДАНИЭЛЯ.** Правило №1
   (никаких подтверждений) НЕ распространяется на трату денег. СПРАШИВАТЬ перед:
   генерациями Higgsfield (`generate_image/video/audio/3d`, upscale, Marketing Studio —
   жгут кредиты), рендерами Shotstack **prod** (`SHOTSTACK_PROD_KEY` платный — для тестов
   ТОЛЬКО sandbox), fal.ai, платными API. Бесплатное можно без спроса: Shotstack sandbox
   (вотермарк), стоки Pexels/Pixabay/Shutterstock-preview, edge-tts, HF ZeroGPU,
   локальный ffmpeg/Playwright. Для черновиков/тестов — всегда бесплатный путь.

## Публичная ссылка (единственная витрина прогресса)

Как обновлять (после каждого значимого изменения прототипа):
1. Источник правды — `oko-app/prototype/index.html` (самодостаточный файл).
2. Higgsfield website_id: `5426760c-49ec-46c4-b3ff-b22a6dd598a5`.
   `mcp__Higgsfield__website_repo_access` → клонировать репо сайта →
   скопировать прототип в `app/src/oko-prototype.html` → commit+push →
   `mcp__Higgsfield__deploy_website` env=production. Таймаут 60с не ошибка —
   деплой доходит, проверять curl'ом по маркеру версии.
3. Версия — чип «сборка vX.Y» в шапке прототипа, поднимать при каждом деплое.
4. В прототипе есть экран «Прогресс сборки» (PROGRESS в JS) — обновлять статусы этапов.

## Интеграции и API-ключи (для ЛЮБОГО чата)
**Паспорт: `INTEGRATIONS.md` — ЕДИНЫЙ файл всех интеграций.** Читать в начале
каждой сессии и АКТИВНО ИСПОЛЬЗОВАТЬ перечисленное по необходимости — не изобретать
обходные пути, если инструмент уже подключён. Ключи в `secrets.env.b64` (base64)
автозагружаются SessionStart-хуком в каждый shell. Вручную:
`source <(base64 -d secrets.env.b64)`.
Главный производственный скилл: `/oko-magic` (.claude/skills/oko-magic/SKILL.md).
Видеоролики: скилл `/reels-machine` + раздел 1а паспорта.
Ключи не вписывать в код сайтов и не отдавать в браузер.

**Правило пополнения (обязательное, для всех чатов):** подключил новую
интеграцию/сервис/ключ — СРАЗУ допиши её в `INTEGRATIONS.md` (что даёт, как
проверить, грабли); новый ключ → в `secrets.env` +
`base64 -w0 secrets.env > secrets.env.b64` (коммитить ТОЛЬКО b64); запушь оба
файла в текущую ветку И в дефолтную `claude/adoring-tesla-fFKEd`, чтобы паспорт
попадал во все новые чаты.

## Правило ГЕНЕРАЦИИ КАРТИНОК (для ЛЮБОГО чата Claude — обязательно)
1. **Дизайн/фото/карточки/обложки — генерировать через Higgsfield** (Ultra-подписка,
   безлимит): модель `nano_banana_pro` (текст+диаграммы, 4K) или `marketing_studio_image`
   (коммерция/товар/реклама) — ~2 кредита, ШИКАРНОЕ качество. Лучше офигительная генерация,
   чем «хрень» из блайнд-FLUX. Вызов: `mcp__Higgsfield__generate_image` model=nano_banana_pro.
2. **Промпт картинки — ВСЕГДА детально, от 2000 символов, на АНГЛИЙСКОМ языке.** Описывать:
   сцену, объект, материалы/фактуру, свет (источник/направление/мягкость), объектив/глубину,
   композицию/ракурс, цвета в HEX (бренд), настроение, стиль/референс, negative space под
   текст, точный текст на картинке (если нужен) с правильным написанием, качество (8K, ultra
   sharp, commercial product photography). Чем детальнее — тем лучше результат.
3. Тестовые дизайн-задачи клиентов — ТОЛЬКО шикарно (Higgsfield + детальный промпт), не блайнд.
   Флакон/товар генерим фотореалистично, текст/вёрстку при нужде — HTML-оверлеем поверх.
