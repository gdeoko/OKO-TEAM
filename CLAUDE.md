# Память ветки: МЕТАНОЙА ПРИЛОЖЕНИЕ

Эта ветка (`claude/metanoya-github-setup-15oovz`) целиком про приложение школы Метанойя.
Клиент Екатерина Павленко, исполнитель OKO TEAM, владелец Даниэль (@ktodaniel).

## Читать в начале сессии, по порядку

1. `МЕТАНОЙА-ПАМЯТЬ.md` (корень) — договорённости с клиентом, новый формат урока,
   список правок, ответы на её вопросы, порядок работ. Главный файл.
2. `METANOYA_CONTEXT.txt` (корень) — исходное ТЗ и структура.
3. `СТАТУС-ПО-ТЗ.md`, `ОТВЕТЫ-ЕКАТЕРИНЕ.md`, `metanoia-app/GO-LIVE-ЧЕКЛИСТ.md`.
4. Общая память OKO лежит в ветке `main`: `CLAUDE.md`, `OKO_BOOTSTRAP.md`,
   `OKO_AGENT_CONTROL.md`, `ВОССТАНОВЛЕНИЕ.md`. Читать так:
   `git fetch origin main && git show origin/main:CLAUDE.md`.

Корневые `README.md`, `index.html`, `src/`, `public/` в этой ветке остались от сайта
DUCK'S GAME SPACE. К Метанойе они отношения не имеют, не трогать.
Приложение лежит в `metanoia-app/public_html/`.

## Доступы

```bash
. ~/.oko/secrets.env          # ключи в окружение
cat ~/OKO_MASTER_VAULT.md     # все пароли и доступы, раздел 8 «EKAT / МЕТАНОЙА»
```

Если файлов нет, их приносит SessionStart-хук. Вручную с боевого сервера:
`vexec 'cat /opt/oko-poster/cfg/OKO_MASTER_VAULT.md'`, обёртка `vexec` в `OKO_BOOTSTRAP.md`
на ветке `main`. Хранилище качать кусками по 40 КБ, ручка режет вывод на 90 КБ.

## Правила Даниэля

1. Никаких окон подтверждения, разрешения выданы на всё.
2. `AskUserQuestion` не вызывать никогда. Нужен выбор — обычным текстом в конце ответа.
3. Артефакты Claude не публиковать.
4. Правки применять как постоянные правила, а не разово.
5. Работать автономно: сделать, выложить, отчитаться результатом.
6. Отвечать по-русски, кратко, mobile-first. **Длинное тире не ставить**, иишных
   оборотов не употреблять.
7. Платные генерации и кредиты — только с явного слова Даниэля. Картинки генерировать
   браузером сервера (`gemini_web.mjs`), это бесплатно.
