## Жёсткие правила от Даниэля
1. **Никаких окон подтверждения.** Разрешения выданы на всё (`.claude/settings.json`).
   Не спрашивать подтверждений на инструменты, деплой и правки.
1а. **НИКОГДА не вызывать AskUserQuestion (всплывающая форма с вариантами).**
   В веб-интерфейсе она виснет и повторяется каждую секунду — Даниэль читает с телефона.
   Нужен выбор — задать вопрос ОБЫЧНЫМ ТЕКСТОМ в конце ответа, пронумерованными
   вариантами, и продолжать работу по своему лучшему варианту, не блокируясь.
   Правило постоянное, для всех сессий и всех репозиториев.
2. **НЕ публиковать Claude-артефакты.** Даниэль смотрит прогресс только по публичной
   ссылке. Артефакт-зеркало отключено навсегда.
3. Правки применяются как постоянные правила, не разово.
4. В интерфейсе OKO — никаких эмодзи, только SVG-иконки в стиле бренда.
   Бренд: чёрный + лайм #9AFF00, Bebas Neue + Montserrat, тёмная и светлая темы.
5. Работать автономно: делать, деплоить, отчитываться результатом.
6. **ЛОГО — ТОЛЬКО НАСТОЯЩЕЕ, ВЕЗДЕ И ВСЕГДА, в base64, не искажая пропорции.**
   Файлы: `brand/oko-logo.png` (оригинал 1000×1000), `brand/oko-logo-256.png`,
   `brand/oko-logo-b64.txt` (готовый data-URI для вставки в `<img src=...>`).
   В агентах — `oko-agents/core/brand.py` (`LOGO_DATA_URI`). НЕ рисовать SVG-заглушки,
   НЕ растягивать, НЕ менять цвета лого. Обновлять эти файлы при новой версии лого.

7. **ПЛАТНЫЕ КРЕДИТЫ/ГЕНЕРАЦИИ — ТОЛЬКО С ЯВНОГО РАЗРЕШЕНИЯ ДАНИЭЛЯ.** Правило №1
   (никаких подтверждений) НЕ распространяется на трату денег. СПРАШИВАТЬ перед:
   генерациями Higgsfield (`generate_image/video/audio/3d`, upscale, Marketing Studio —
   жгут кредиты), рендерами Shotstack **prod** (`SHOTSTACK_PROD_KEY` платный — для тестов
   ТОЛЬКО sandbox), fal.ai, платными API. Бесплатное можно без спроса: Shotstack sandbox
   (вотермарк), стоки Pexels/Pixabay/Shutterstock-preview, edge-tts, HF ZeroGPU,
   локальный ffmpeg/Playwright. Для черновиков/тестов — всегда бесплатный путь.

8. **ССЫЛКА НА ОПЛАТУ — ТОЛЬКО НАШ ДОМЕН, И СРАЗУ ДВА ВАРИАНТА.** Клиенту уходит
   страница `okoteam.top/p/<код>`, собранная `core.shortlink.pay_page` (репо
   `gdeoko/oko-agents`), и на ней всегда обе кассы: карта через Lava и счёт на
   юрлицо через ЮKassa. Эталон, с которого списываем:
   https://okoteam.top/p/klubnyy-dom-noty-mesyac-2/
   Прямые `app.lava.top/...` и `yoomoney.ru/checkout/...` не отправлять НИКОГДА:
   чужой домен и строка параметров на пол-экрана читаются как скам, человек не
   платит. Это касается переписки, КП, договоров и писем. На сервере проверка
   `core.outbound_guard.check` не пропустит сообщение с сырой ссылкой кассы
   (причина `raw_payment_link`). Собрать страницу:
   `vexec 'cd /opt/oko-agents && .venv/bin/python -c "from core import lava, yookassa, shortlink; ..."'`
   (пример целиком — `ETALONS.md`, раздел 3, в репо `gdeoko/oko-agents`).

   `tools/runway_web/runway_web.mjs` (видео). На сервере они лежат в
   `/opt/oko-poster/`. Gemini-драйвер для визуала не используем.

   Руками с сервера:

       node /opt/oko-poster/chatgpt_web.mjs "<английский промпт>" /файл.png
       RW_METKA=кадр node /opt/oko-poster/runway_web.mjs minimax "<промпт>" /ролик.mp4 5 9:16

2. **Платные API с поштучной оплатой не трогаем.** Ни `GEMINI_KEY_PAID`, ни ключи
   OpenAI, ни Higgsfield: там каждая картинка и каждая секунда ролика стоят денег,
   а через браузер то же самое уже оплачено. Higgsfield отключён совсем, двести
   долларов в месяц без безлимита. Ключ Gemini остаётся мозгу агента для текста,
   к визуалу отношения не имеет. Ключ Runway API годится под точечные задачи, но
   у него отдельный кошелёк, безлимит живёт только в веб-кабинете.

3. **Картинки ТОЛЬКО ChatGPT. Gemini для визуала не используем совсем** (слово
   владельца 25.08.2026). Ключ Gemini остаётся мозгу агента для ТЕКСТА (API), к
   картинкам и роликам отношения не имеет. Запасного пути через Gemini-браузер нет:
   если ChatGPT не открылся - чиним выход/вход браузера, а не переключаемся на Gemini.

4. **Выход в сеть решает.** Отказ «не поддерживается в вашей стране» лечится сменой
   выхода, а не выводами. Главный выход Pantera ОБХОД № 16, Нидерланды, socks5 на
   `127.0.0.1:10840`, через него открывается всё. Дубай `10809`, Франкфурт `10808`,
   США `10811` держим запасными. Поднять заново:
   `python3 /opt/oko-poster/pantera_up.py "ОБХОД № 16"`. Перебирать надо ВСЕ
   шестнадцать обходов, а не три поднятых.

5. **Промпт картинки - ВСЕГДА по-английски и от 2000 знаков.** Сцена, объект,
   материалы и фактура, свет с направлением и мягкостью, объектив и глубина,
   композиция и ракурс, цвета в HEX по бренду, настроение, стиль, свободное место
   под текст, качество (8K, ultra sharp, commercial product photography). Русский
   текст, который должен появиться НА картинке, пишем в кавычках внутри английского
   промпта. Драйвер сам не пропустит промпт короче двух тысяч знаков.
   К промпту можно приложить до десяти файлов: настоящий логотип, товар, лицо
   человека в нескольких ракурсах.

6. **Объём упрётся в лимиты аккаунта** - поднимаем второй и третий профиль браузера
   со своими аккаунтами и своими выходами. Для контент-завода так масштабируется
   хоть до сотни аккаунтов.

## КАРТА GPU: ЗАМКИ ПО ДЕНЬГАМ (правило написано деньгами 04.09.2026)

```bash
python3 /opt/oko-poster/gpu/gpu.py prices    # цены, потолок, что проходит
python3 /opt/oko-poster/gpu/gpu.py balance   # деньги на счету
```

Наша карта - RTX PRO 6000 Blackwell 96 ГБ. **Цену спрашиваем в СВОЁМ датацентре и

смену карты, есть кроме RunPod у Nebius, Hyperstack и Verda; у packet.ai его нет. **Фиксированный месячный тариф провайдера сам
по себе ничего не гарантирует:** карту не заберут только там, где dedicated / bare-metal /
single-tenant или reserved-договор на срок. Данные лежат на сетевом диске `oko-stack`

## КАРТА ПОД ВИДЕО: СЧИТАЕМ $ ЗА КЛИП, А НЕ $ ЗА ЧАС (04.09.2026)

Видео основной продукт, поэтому карту выбираем по цене готового клипа и по времени

## КАРТУ БЕРЁМ ON-DEMAND, SPOT НЕ БЕРЁМ НИКОГДА (слово владельца 04.09.2026)

Слёт карты посреди пачки роликов не вариант. Под словом «заберут» лежат два разных
риска, и стоят они разного.

**Посреди работы карту снимают ТОЛЬКО на spot.** On-demand инстанс наш, пока сами не
удалим: у Verda это прямо в условиях, у RunPod то же значит SECURE против Community.
Лечится бесплатно - spot в работе не берём, хотя он вдвое дешевле.

**На СТАРТЕ после стопа карты может не найтись** - вот это и случилось 01.09. От этого
on-demand не спасает, гарантию на старт продаёт только резерв.

| путь | карта | $/час | снимут посреди задачи | месяц | что гарантирует |
|---|---|---|---|---|---|
| spot Verda | RTX PRO 6000 96 | 0.945 | **ДА, в любой момент** | - | ничего |
| **on-demand Verda** | **RTX PRO 6000 96** | **1.890** | **нет** | 1380 | инстанс наш до удаления |
| on-demand Hyperstack | RTX Pro 6000 SE 96 | 1.850 | нет | 1350 | то же |
| on-demand RunPod Secure | RTX PRO 6000 96 | 2.090 | нет | 1526 | то же + наш том рядом |
| on-demand Verda | H200 141 | 4.000 | нет | 2920 | вдвое быстрее |
| **резерв Hyperstack** | RTX Pro 6000 SE 96 | **1.26-1.30** | нет | **920-950** | и старт тоже |

Рабочий выбор: **on-demand Verda $1.890** (дешевле нашего RunPod, карта та же). Резерв
за $920/мес это 440 часов on-demand, берём его по слову Даниэля при 400+ часах в месяц.

Порядок под пачку: стартуем ОДИН раз на всю пачку, не старт-стоп на каждый ролик.

```bash
python3 /opt/oko-poster/gpu/gpu.py пачка 180   # держать карту 3 часа, не гасить по простою
python3 /opt/oko-poster/gpu/gpu.py пачка-стоп  # снять режим
```

Режим пачки чинит нашу же грабку: сторож гасил карту по десяти минутам простоя, а пауза
между клипами бывает длиннее. Потолок цены и бюджет сессии пачка НЕ отменяет.
Разбор целиком - библия, раздел 18.3.0ж.


## ПРИЁМКА И КАЧЕСТВО (правило владельца, действует ВЕЗДЕ). Паспорт - `oko-agents/docs/QA_И_ПРИЁМКА.md`
