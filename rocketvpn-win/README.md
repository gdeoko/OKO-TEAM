# Rocket VPN для Windows 7 и 8

Клиент Xray под те системы, которые выбросили все остальные. Ссылки
принимает только с `rocketconfig.top`, тема и знак от Rocket VPN,
обновляется сам с гитхаба.

    src/RocketVPN/        исходники клиента (.NET Framework 4.8, WinForms)
    .github/workflows/    сборка ядра и клиента, релиз по тегу

---

## Почему всё устроено именно так

**Почему .NET Framework 4.8.** Windows 7 и 8 выброшены из всех живых
стеков: .NET 5 и новее требуют десятку, Electron снял их поддержку в
2023 году. Framework 4.8 идёт от Windows 7 SP1 до Windows 11 одной
сборкой и уже стоит почти на каждой живой семёрке. Другого способа
сделать родной клиент под эту пару систем сегодня нет.

**Почему ядро собирается у нас, а не качается готовым.** Готовые сборки
Xray с гитхаба собраны свежим Go, а Go с версии 1.21 требует Windows 10:
на семёрке такой файл не запускается вовсе, молча. Поэтому ядро
собирается в том же прогоне компилятором Go 1.20, последним с поддержкой
семёрки, из тега Xray, который этим компилятором собирается
(`XRAY_ТЕГ` в сборке).

**Почему системный прокси, а не туннель на весь компьютер.** Туннель
требует драйвера сетевого адаптера. Нынешний Wintun подписан по правилам
Windows 10, и семёрка такую подпись не принимает: драйвер не встанет, а
человек увидит «не работает» без объяснений. Системный прокси понимают
браузеры, Телеграм, почта и всё, что уважает настройки Windows; драйвера
нет, прав администратора не нужно. Туннель остаётся отдельной задачей со
своим риском.

**Почему TLS включается руками.** Семёрка по умолчанию здоровается по
TLS 1.0, а сервера его уже не слушают. Без одной строки в `Сеть.cs` не
грузится ни подписка, ни проверка обновлений, и это первая причина, по
которой старый клиент «не видит сеть».

## Ограничение по домену

Правило сетевого администратора: клиент работает только со ссылками
`rocketconfig.top`. Держит его код, а не памятка. Проверка стоит в самой
двери `Подписка.Загрузить`, мимо неё в программе нет ни одного пути к
сети. Домен задан константой `Подписка.Домен`; меняется правкой строки и
пересборкой, из настроек его не поменять.

Разрешены сам домен и его поддомены, только по `https`. Чужая ссылка
отбивается словами, а не молчанием: человек должен видеть, почему она не
подошла.

## Что читает клиент

Подписку в виде списка ссылок, открытым текстом или в base64. Понимает
`vless://`, `trojan://`, `vmess://`, `ss://`, с `tcp`, `ws` и `grpc`, с
`tls`, `reality` и без защиты.

Clash yaml и sing-box json пока не читаются. Это сделано нарочно: без
живого примера подписки угадывать их раскладку нельзя, а выдуманный
разбор хуже честного отказа, потому что молча отдаст не тот сервер. На
таком ответе клиент прямо пишет, что прислать. Появится пример от
`rocketconfig.top` - добавим за час.

## Сборка

Собирает GitHub Actions, руками ничего ставить не нужно.

    пуш тега v1.0.0     собирает и выкладывает релиз
    кнопка Run workflow  собирает архивы без релиза

Локально на Windows со студией или .NET SDK:

    dotnet build src/RocketVPN/RocketVPN.csproj -c Release

Рядом с готовым `RocketVPN.exe` обязаны лежать `xray.exe`, `geoip.dat` и
`geosite.dat`: без них клиент скажет, что ядра нет, и не подключится.

## Обновления

Клиент спрашивает у гитхаба последний релиз, сравнивает с собой, качает
архив своей разрядности, **сверяет SHA-256** и раскладывает поверх себя
через маленький cmd (заменить свой же exe работающая программа не
может - файл занят).

Нет файла сумм в релизе - установка отменяется. Подменённый по дороге
архив это чужая программа с нашим значком, и проверять её нечем, кроме
суммы.

Репозиторий релизов задан в `Обновление.Владелец` и
`Обновление.Репозиторий`. Пока папка лежит внутри OKO-TEAM, обновления
работать не будут: нужен свой репозиторий, в нём и релизы.

## Чего ещё нет

- Туннель на весь компьютер (см. выше про драйвер).
- Разбор Clash yaml и sing-box json (ждём пример подписки).
- Подпись исполняемого файла сертификатом. Без неё SmartScreen на
  десятке ругается на первую сотню запусков. На семёрке это мягче, но
  сертификат всё равно нужен, и это покупка, а не код.
- Проверка на живой семёрке. Из облака её не сделать: нужна машина с
  Windows 7 у администратора.
