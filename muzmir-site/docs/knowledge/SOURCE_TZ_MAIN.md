## 1. О ЗАКАЗЧИКЕ И ПРОЕКТЕ

**КЦ «Музыкальный Мир»** — Московская арт-организация, проводит международные и всероссийские многожанровые онлайн-конкурсы и фестивали культуры и искусства при поддержке Министерств культуры и образования субъектов РФ, портала PROКультура.РФ, Национальных проектов «Культура», Союза композиторов России.

**Действующие конкурсы:**
Симфония Звёзд, Вершина Мастерства, Мировая Сцена, Слава России, Профи, Эврика, Будущее России, Атланты Искусства, День Победы, Грани Таланта, Творчество без Границ.

**Задача проекта:**
Заменить текущий сайт на конструкторе Nethouse (55+ ручных страниц, приём заявок только через email) на полноценную автоматизированную платформу с:
- собственным бэкендом и базой данных,
- личным кабинетом участника,
- админ-панелью для команды КЦ,
- автоматизацией всех процессов (публикации, рассылки, оценка, дипломы, оплаты),
- интеграцией с VK/Telegram/YouTube/TikTok/Instagram через агента,
- премиум-дизайном (светлый, тёплый, золотисто-бежевый).

## 2. АРХИТЕКТУРА (WHAT WE BUILD)

### 2.1. Технологический стек

**Бэкенд:**
- PHP 8.2+ (проверено на проектах-примерах Duck's/Зановости)
- SQLite (PDO) — база данных
- Cron для отложенных задач
- CURL для внешних API (SMTP, ЮKassa, Telegram, VK)

**Фронтенд:**
- HTML5 + CSS3 (кастомные анимации, gradient, backdrop-filter)
- Vanilla JS (без тяжелых фреймворков)
- SVG + CSS-анимации для 3D-эффектов и инфографики
- PWA (Progressive Web App) — иконка на рабочем столе, push, офлайн

**Telegram Mini App:**
- Тот же сайт, но с адаптацией под WebApp SDK Telegram
- Автологин через initData из Telegram

**Хостинг:**
- VPS Linux (Ubuntu 22.04 LTS)
- Nginx + PHP-FPM
- Let's Encrypt (HTTPS)
- Cloudflare (защита + CDN + бесплатно)

**Внешние сервисы:**
- Gmail SMTP (через CURL) — рассылки
- ЮKassa REST API — платежи
- Telegram Bot API — уведомления и Mini App
- VK API — публикации, чат
- YouTube Data API v3 — видео
- Dadata API — валидация адресов и организаций
- Яндекс.Спеллер — орфография
- Higgsfield API (500 кредитов) — базовые шаблоны дизайна
- HeyGen API — озвучка и видео

**У заказчика есть агент** с базой знаний КЦ и доступами ко всем соцсетям (VK, TG, YouTube, TikTok, Instagram).

**Взаимодействие:**

1. **Сайт → Агент** (webhook)
   - Событие: открыт конкурс → агент публикует пост во всех соцсетях
   - Событие: закрыт приём → агент публикует
   - Событие: результаты опубликованы → агент публикует с ссылкой на протокол

2. **Агент → Сайт** (REST API)
   - Модерация комментариев → эскалация в админку
   - Ответы участникам → доступ к статусу заявок из БД

   - Знает про авторизованного пользователя (его заявки, оплаты)

**API-эндпоинты для агента:**
```
POST /api/v1/agent/webhook       # события сайта → агенту
GET  /api/v1/agent/user/{id}      # данные пользователя
GET  /api/v1/agent/application/{id}  # данные заявки
POST /api/v1/agent/chat           # чат-сообщения
```

Заказчик даст URL и токен своего агента.
