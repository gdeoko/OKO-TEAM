# Конспект: «Рабочий документ 2026» — КЦ «Музыкальный Мир»

Источник: `working_document.html` (~1.45 МБ, отрендеренный интерактивный SPA-документ).
Файл — не статья, а **рабочая панель-приложение** (single-file HTML+CSS+JS) для управления
культурным центром на период **18 мая — 18 августа 2026** (93 дня). Тёмно-синий #0d1b5e +
золото #c9a84c, шрифты Playfair Display + Raleway, тёмная тема. Летающие ноты, звёзды,
сетка, glow-orbs на фоне.

---

## 1. ЧТО ЭТО ЗА ДОКУМЕНТ И ЕГО РАЗДЕЛЫ

Приложение-дашборд с сайдбаром и 6 страницами (SPA, `showPage()`):

1. **Главная (Панель управления)** — блок «Сегодня» (авто-дата, тема дня, задачи дня,
   «День N из 93»), быстрые кнопки, 4 карточки-метрики (ВК-подписчики, YouTube-просмотры,
   выручка ₽, заявки/мес — редактируемые кликом, хранятся в localStorage), **Трекер роста**
   (ввод раз в неделю: ВК/YouTube/заявки/доход с показом дельты), навигационные блоки.
2. **Контент-план** — календарь по месяцам (табы Май 18-31 / Июнь / Июль / Август 1-18).
   Клик по дате → модалка с контентом дня. Легенда: контентный пост / видео / технический /
   праздничный. Данные в JS-объектах `CP_MAY_NEW_DAYS`, `CP_JUNE_DAYS`, `CP_JULY_DAYS`
   (август пуст).
3. **Бизнес-план** — 18 карточек-разделов (см. ниже), KPI-строка сверху.
4. **Чек-лист** — календарь задач по дням с прогресс-барами по месяцам, чекбоксы
   (localStorage). Данные `CL_MAY_DAYS`/`CL_JUNE_DAYS`/`CL_JULY_DAYS` (август пуст).
5. **Материалы** — 12 карточек: скрипты продаж, промпты картинок/дипломов, гала-концерт,
   спонсорство, мастер-класс, аллея славы, клуб, КП для ДШИ, шаблоны постов, письма
   реактивации, чек-лист-PDF (лид-магнит). Всё с кнопками «Копировать».
6. **Перспективы** — прогресс-бары к целям, таймлайн-дорожная карта Май→Декабрь,
   таблица структуры выручки к 1 млн ₽/мес.

Разделы бизнес-плана (18): Точка А, Финансовый план, Воронка продаж, Реклама, Монетизация,
Рассылки, Расходы, Рост ВК (до 100К), Рост Telegram (до 20К), Закрытый клуб, KPI,
Конкуренты, Email-стратегия, Корпоративные конкурсы ДШИ/ДМШ, Реестр талантов, Партнёрство
с гостиницами, Найм команды, Риски, Дорожная карта.

## 3. ДИЗАЙН / ВИЗУАЛЬНЫЕ ИДЕИ ДЛЯ ПЕРЕНОСА НА САЙТ

Палитра-токены (готовы к копированию):
`--db:#0d1b5e --db2:#0a1445 --db3:#061030 --g:#c9a84c --gl:#e0c060 --gd:#9a7030
--b:#4a9fd4 --bl:#6ab8f0`. Шрифты Playfair Display (заголовки) + Raleway (текст).

Фоновые приёмы (анимированные, CSS-only, легко переносятся):
- **Летающие музыкальные ноты** (♩♪♫𝄞𝄢) — `@keyframes floatNote`, всплывают снизу вверх с
  вращением и свечением (text-shadow золотой glow), разные размеры/задержки.
- **Звёздное поле** (`.stars`) — многослойный radial-gradient точками.
- **Сетка** (`.bg-grid`) с radial-mask (затухание к краям).
- **Glow-orbs** — размытые круги (blur 80px) с `@keyframes pulse` (масштаб+прозрачность).

Компоненты-паттерны (стоит применить):
- Sticky-хедер с blur-backdrop, круглый логотип в золотой рамке; мобильный гамбургер + сайдбар-оверлей.
- **Прогресс-бар периода** в сайдбаре («18 мая ——— 18 авг», % пройдено).
- **Блок «Сегодня»** — авто-дата, тема дня, задачи, счётчик «День N из 93».
- **Карточки-метрики** и **трекер роста** с дельтой (↑ +N за неделю), редактирование inline,
  сохранение в localStorage.
- **KPI-строка** (крупная цифра + подпись + цель-дельта золотом).
- **Календарь-heatmap**: клетки дней с цветными точками-индикаторами типа контента
  (легенда: пост/видео/технич./праздник), состояния `is-today/is-past/is-sunday`, клик→модалка.
- **Модалки** контента дня / чек-листа / промптов (overlay + slide-in, аккордеон-топики).
- **Таймлайн дорожной карты** (`.timeline-wrap`/`.tl-item`) — вертикальная линия, точки-вехи
  (`.tl-dot.next` подсвечена), дата+заголовок+описание+теги (зелёные/синие метки сумм).
- **Прогресс-бары к целям** (`.goal-bar`) — «18 300 / 40 000» + заливка %.
- **Таблицы** (`.biz-table`, `.fin-table`) с золотыми `highlight`/`good`/`total-row`.
- **Кнопки «Копировать»** у каждого текстового блока (скрипты/промпты/письма).
- Меню-карточки с SVG-иконками в фирменном стиле (в интерфейсе только SVG, эмодзи — лишь в
  заголовках блоков документа как декор; для OKO-стиля их надо заменить на SVG).
- Анимация появления страниц `@keyframes fadeIn`; `scroll-behavior:smooth`.

## 4. ЧТО ДОПОЛНЯЕТ / ПРОТИВОРЕЧИТ (наблюдения из файла)

Это **отдельный клиентский проект** (КЦ «Музыкальный Мир»), не связан с брендом OKO —
палитра сине-золотая, свой домен и соцсети. При переносе на сайт учесть внутренние
нестыковки самого документа (нужно свести к одному значению перед публикацией):
- ВК-подписчики: **20 000** (Точка А, KPI) vs **18 300** (главная, Перспективы).
- Цель ВК к августу: **100 000** (раздел KPI/рост ВК) vs **40 000** (Перспективы). Цель 1 млн:
  **август** (финплан/дорожная карта бизнес-плана) vs **декабрь** (Перспективы).
- Телефон: **+7 (950) 945-99-00** (письма/спонсорство) vs **+7 (999) 504-88-99**
  (шаблоны/КП ДШИ/мастер-класс).
- Клуб: заявлено «11 привилегий», в карточке «Материалы» подпись «10 привилегий»; текст листа
  привилегий — 11 пунктов.
- Стоимость абонемента: 990 ₽/мес (везде), но привилегии в двух местах со скидкой 20% и 25%.
- Email в письмах закодирован Cloudflare-защитой (`__cf_email__`) — реальные адреса скрыты;
  на сайте указан `info@xn----7sbugdeiegh1b0a9hen.xn--p1ai`.
- Контент-план и чек-лист заполнены только по **22 июля**; август (1–18) — пустые заготовки
  (`CP_AUGUST_DAYS={}`, `CL_AUGUST_DAYS={}`), хотя период документа до 18 августа.
- Данные метрик/трекера/чекбоксов персистятся в **localStorage** (не в БД) — при переносе на
  реальный сайт нужен бэкенд.
