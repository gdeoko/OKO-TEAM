## 1. ТЕХНОЛОГИЧЕСКИЙ СТЕК (важно — совпадает с уже реализованным)

**Бэкенд:** PHP 8.2+ + SQLite (PDO). Cron. cURL для внешних API.

## 5. УМНАЯ ФОРМА ЗАЯВКИ (8 шагов + все проверки)

Шаги: 1) Выбор конкурса; 2) Данные участника; 3) Данные педагога/учреждения; 4) Конкурсный номер (номинация, название, ссылка); 5) Контакты и адрес доставки (если платно); 6) Согласие с положением и ПД; 7) Оплата ЮKassa (если платно); 8) Подтверждение + номер заявки.

**Проверки:**
- ФИО: автокоррекция регистра (иванов иван → Иванов Иван), только кириллица + дефис, минимум 2 слова. Для коллектива — отдельное поле «Название коллектива» с автокавычками «...». Валидация педагога (не «Иванов Иванов Иванов»).
- Дата рождения ↔ сверка с возрастной категорией.
- Возрастная категория — выпадающий список.
- Номинация — выпадающий список с подразделами + соло/дуэт/ансамбль/хор.
- Название номера — автокавычки «...», проверка орфографии (Яндекс.Спеллер / LanguageTool).
- Ссылка — HEAD-запрос (живая ли, публичный доступ), определение платформы. РАЗРЕШЕНО: RuTube, Google Диск, Яндекс Диск, ОК видео, ВК видео, Дзен видео, Cloud Mail. ЗАПРЕЩЕНО: Instagram, Facebook, TikTok, YouTube, иностранные мессенджеры. Отклонять архивы (.zip/.rar).
- Email — regex + DNS MX-запись + отсев одноразовых (mailinator и т.п.), опц. код подтверждения.
- Телефон — автоформат +7 (___) ___-__-__, определение оператора/региона, опц. SMS-код.
- Адрес — Dadata автоподсказки ФИАС + сверка индекса, поля квартира/подъезд/домофон.
- Учреждение — Dadata автоподсказки.
- Согласие ПД — обязательный чекбокс, кнопка активируется через 15 сек после клика на положение.
- Автосохранение черновика (localStorage + БД), проверка дубликатов, Recaptcha v3 (невидимая).

**Автокоррекция текста:** ВСЕ БОЛЬШИМИ→Первая заглавная; тройные пробелы→одинарные; !!!!→!, ???→?, ...→…; умные кавычки; удаление лишних переносов.

**Система номеров:**
- Номер заявки: `[КОД_КОНКУРСА]-[ГГГГ]-[НОМЕР]` → пример `MC-2026-00347` (Мировая Сцена №347).
- Номер диплома = номер заявки + суффикс типа: `-Д` основной, `-ДД` дополнительный, `-ИД-XX` именной коллектив, `-БЛ` благодарность. Пример `MC-2026-00347-Д`.

**Доп. автоматизации формы:** транслит ФИО для международных дипломов; импорт заявок из Excel; флаг подозрительных заявок модератору; программа лояльности (5+ конкурсов = скидка 10%, 10+ = 15%, 20+ = 20%); реферальная система педагогов; автоответы на статусные события; обратная связь по дипломам через 7 дней.
