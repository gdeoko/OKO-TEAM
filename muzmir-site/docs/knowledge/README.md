# База знаний проекта КЦ «Музыкальный Мир»

Извлечено из полного пакета заказчика (4 ZIP + отдельные файлы, июль 2026). Читать при работе над сайтом.

## Дистилляты (конспекты по группам файлов)
- `01_TZ.md` — техническое задание, дизайн-система, 10 правил контента, обязательный функционал.
- `02_knowledge.md` — база знаний центра (история, 95+ конкурсов, руководство, жюри, статистика).
- `03_context.md` — рабочий контекст SMM (карта сайта, бизнес-процессы, тон, FAQ, шаблоны).
- `04_working_doc.md` — рабочий документ-дашборд (бизнес-план, финплан, продукты, дизайн-идеи).
- `05_content_plan.md` — контент-план (конкурсы с датами, соцсети, автопостинг).
- `06_php_ref.md` — PHP-референс заказчика (паттерны бота/заявок/рассылок).
- `07_html_and_dump.md` — образцы дизайна/UX + дамп сайта (реальный контент).
- `09_screens_site.md` — разбор 14 скриншотов старого сайта (меню, контент, стиль).
- `10_screens_admin.md` — разбор 13 скринов админки (страницы, формы, ТОЧНЫЕ прайсы).

## Ключевое
- `GROUND_TRUTH.md` — эталон данных (контакты, конкурсы, номинации, шкала).
- `CORRECTIONS.md` — правки по итогам пакета (что исправлено/на решение Даниэля).

## Источники (полный текст)
- `SOURCE_knowledge_base.txt`, `SOURCE_TZ_MAIN.md`, `SOURCE_content_plan.txt`, `SOURCE_colors.json`, `SOURCE_fonts.md`.

## ВАЖНЫЕ КОНФЛИКТЫ (решение за Даниэлем)
1. **Тема:** ТЗ требует СВЕТЛУЮ кремово-золотую (тёмная «запрещена»). Даниэль после первой (светлой) версии велел сделать ТЁМНУЮ в стиле ОКО АПП. Сейчас — тёмная по умолчанию + светлая по переключателю. Позднее указание Даниэля приоритетнее ТЗ.
2. **Шрифты:** ТЗ — Playfair Display + Manrope + Marck Script; сейчас — Bebas Neue + Cormorant + Manrope.
3. **ФИО директора публично:** ТЗ правило №1 — не называть Ильясова на сайте (только «Оргкомитет»); сейчас на «О нас» он указан. На дипломе подпись директора уместна.

Секреты (ACCESS_KEYS) и почтовые базы (PII, ~11K) в git НЕ хранятся — только в приватной папке на VPS.
