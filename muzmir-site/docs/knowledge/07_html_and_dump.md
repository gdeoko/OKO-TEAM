Два стилевых семейства в примерах:

СЕМЕЙСТВО 1 — «OKO dark/lime» (фирменный стиль OKO TEAM):
Файлы: example_web, example_sistema, example_zavod (+ частично anketa/admin).
Токены (единые во всех трёх):
- Фон `#050505`, акцент лайм `--lime:#9AFF00`, стекло `rgba(255,255,255,.04)`, границы `.08`.
- Шрифты: заголовки `Unbounded` (900), текст `Onest`. (в проде OKO по CLAUDE.md — Bebas+Montserrat;
  в этих примерах — Unbounded+Onest, учесть расхождение.)
- Приёмы: верхний прогресс-бар скролла (`.pb`), reveal-on-scroll `.rv/.vis`, светящиеся
  разделители `.sec-sep` (анимация `sepglow`), пульсация CTA (`pglow`), badge с мигающей точкой
  (`hbdot/blink`), фикс-навбар с blur + класс `.scrolled`, мобильное меню-оверлей `.mob-nav`,
  hover-подъём карточек (`translateY(-2px)` + свечение лайм).
- Структурные компоненты (landing): hero (badge → title с `.lime` акцентом → sub → 4 h-stat →
  2 кнопки `.bl`+`.bg`) → pain-grid (2 колонки карточек-болей с иконкой+CTA) → how-аккордеон
  (нумерованные шаги, раскрытие) → tariffs (раскрывающиеся карточки-тарифы с toggle, `.featured`,
  вложенные пункты) → соцдоказательство/отзывы → «10 дней работы / что за первый месяц» →
  «Без системы vs С системой» сравнение → FAQ-аккордеон → финальный CTA.
- Заголовки секций: пара `.sec-lbl` (мелкий uppercase лайм-лейбл) + `.sec-h` (крупный Unbounded).

- Логотип встроен в base64 (в одном файле), ВЕЗДЕ SVG-иконки, НЕ эмодзи (совпадает с правилом OKO).
- Адаптив mobile-first (проверяет с телефона).

  доверие/статус, интерактив (опросы/викторины/цитаты).
- Вертикальные видео (VK Клипы/Shorts/TikTok/Reels/Rutube): 1/день (март–май) → 2 (июнь–авг) →
  3 (сент+). Формат: ТЕМА / ТЕКСТ ДЛЯ ОЗВУЧКИ / ОПИСАНИЕ / «Для поиска: слова».
- НЕ использовать: упоминание жюри; истории/отзывы прошлых победителей (базы нет); репосты отзывов.

ДОПОЛНЯЕТ (готовые к переиспользованию паттерны/каркасы):
- Движок многошаговой анкеты (sistema_anketa) → форма заявки на конкурс/фестиваль с автосейвом.
- Корзина/чекаут/трекинг заказа (meat_shop) → продажа дипломов и наград, «статус заявки».
- Пароль-админка с CRUD (meat_admin) → панель управления конкурсами/заявками/наградами/промо.
- Multi-page роутер + юр-страницы (zanovosti) → структура сайта КЦ + Политика ПД/Согласие/Оферта.
- OKO-каркас лендинга (web/zavod/sistema) → отдельный лендинг под КАЖДЫЙ платный конкурс
  (ровно то, что нужно для рекламы: один оффер = одна посадочная, а не «общая ссылка»).
- UX-хотелки заказчика (календарь-с-модалками, localStorage-состояния, base64-лого, SVG-иконки,
  копирование текстов) — совпадают с правилами OKO (SVG вместо эмодзи, brand-l3 в base64).

ПРОТИВОРЕЧИТ / ТРЕБУЕТ РАЗВЕДЕНИЯ:
- ПАЛИТРА И ШРИФТЫ. OKO = чёрный+лайм #9AFF00 (Bebas+Montserrat по CLAUDE.md; Unbounded+Onest в
  примерах). КЦ «Музыкальный Мир» = тёмно-синий+золото+голубой, «культурно-статусный» стиль.
  Нельзя переносить лайм OKO на сайт КЦ — это разные бренды. Сверить, какой шрифт-стек OKO
  каноничен (в проде и в примерах он разный).
- ЦИФРЫ. Публичные для контента («300 000+ участников, 1000+ конкурсов») расходятся с
  фактическими (95+ мероприятий, 30 621 заявка, ~20к подписчиков) — на сайте не смешивать
  «маркетинговые» и «реальные» числа.
- Часть монетизации помечена «на будущее/отложено» (VIP, школа педагогов, партнёрка) — на сайте
  сейчас НЕ публиковать.
- Дамп B — это рабочий проект-документ (контент-план/бизнес-план/чек-лист) для внутренней работы,
  а НЕ публичный сайт. Публичный сайт КЦ = подмножество: О нас, Конкурсы/Фестивали/Акции,
  Награды, Формы заявок, Оплата дипломов/наград, Аллея Славы, Абонемент, юр-страницы, контакты.
