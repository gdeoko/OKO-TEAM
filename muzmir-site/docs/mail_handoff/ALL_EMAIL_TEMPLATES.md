# Каталог всех писем муз-мира — тексты и точки отправки

Точные тексты каждого письма (subject + body), как оно собирается в коде, откуда отправляется.

**Источник правды**: точные строки из живых PHP-файлов прода на 15-16 августа 2026.

### 1.1 Приветственное письмо новому партнёру ⚠️ ФУНКЦИИ НЕТ, писать в новой сессии

**Триггер**: `partner_accept($instId)` в `core/partner.php` — ставит статус, генерит slug/promo/пароль, но **письмо не отправляет автоматически**.

**Текущий поток**:
- Админ в `/admin/?p=partners` жмёт «Принять» → вызывается `partner_accept`
- Пароль ложится в `$_SESSION['partner_password_shown'][$id]` (показывается ОДИН РАЗ на след странице)

**Что нужно сделать в новой сессии** (для автопринятия из inbox):

## 3. ПИСЬМА СВОЕЙ БАЗЕ (news@ через unisender)

### 3.1 Волна запуска сезона (combo:YYYY-MM)

**Триггер**: разово через `launch_combo_enqueue()` в `core/launch_combo.php` (запускается вручную через админку или `monthly_launch.php` 1-го числа месяца).
**Функция сборки тела**: `nl_build_body($row)` в `core/newsletter.php` — собирается ПРИ ОТПРАВКЕ на лету (не при постановке в очередь).
**Отправка**: воркер → `unisender` → news@муз-мир.рф.

**Subject** (из `campaign_subject('launch')`):
```
Мы открылись! Конкурсы, награды и дипломы - Культурный центр «Музыкальный Мир»
```

Или для `'3days'`/`'last_day'`:
```
Открыт приём заявок - 4 конкурса с наградами и дипломами
```

**Живой пример**: `07_live_etalons/letter_bodies/live_konkurs_body.html`.

**Компоненты письма** (все из `core/mail_campaigns.php`):
1. **Приветствие**: «Здравствуйте, {$name}!» через `person_greeting_name($email, $rawName)` — распознавание имени из email если не указано
2. **Хедер**: `mmc_h('Открыт приём заявок', 'до 25 августа 2026')` — крупный заголовок с подзаголовком
3. **Карточки конкурсов**: `mmc_competition_card($c)` — по одной на каждый открытый конкурс:
   - Логотип конкурса
   - Название («Величие России»)
   - Тип (Всероссийский/Международный)
   - «Приём заявок до {дата}»
   - Кнопки «Подать заявку» + «Положение»
4. **Блок «Личный кабинет»** (`mmc_kabinet_block()`) — показывается ТОЛЬКО если у пользователя ещё не было входов:
   - Логин (email)
   - Пароль (временный, 9 символов)
   - Кнопка «Войти в кабинет»
5. **Блок «VIP-клуб»** (`mmc_vip_perks_grid()`) — показывается если не член клуба:
   - Таблица привилегий
   - Кнопка «Вступить в клуб»
6. **Футер** (`mm_email_footer()`):
   - Контакты центра
   - Ссылка отписки (`/api/v1/unsubscribe.php?token=...`)
