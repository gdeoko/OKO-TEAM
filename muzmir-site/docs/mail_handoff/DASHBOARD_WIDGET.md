# Виджет «Массовая рассылка» в дашборде админки

Файл: `03_prod_files/admin/dashboard.php` (39 КБ, весь дашборд).
Виджет сделан в этом чате, вставлен в самое начало страницы (перед основной сеткой KPI).

## Что показывает

### Заголовок
- **Индикатор ВКЛ/ВЫКЛ**: круглая точка (зелёная/красная) + крупный текст
- **Цветная левая рамка**: зелёная когда ВКЛ, красная когда ВЫКЛ
- **Причина остановки** (когда ВЫКЛ): текст из `mass_sending_off_reason` + время `mass_sending_changed_at`
- **День прогрева** (когда ВКЛ): «День N кампании» от `nl_warmup_started`
- **Последнее письмо**: время последнего успешного `sent_at` из `mail_queue WHERE priority>0`

### Метрики (сетка карточек)
- **Ушло сегодня / План дня**: прогресс-бар (например «1250 / 4000»)
  - «Ушло сегодня» = `nl_bulk_sent_today()`
  - «План дня» = `nl_daily_cap()`
- **В очереди (массовых)**: `COUNT WHERE priority>0 AND status='queued'`
- **На паузе**: если есть `status='paused'`
- **Не доставлено**: `status='failed'`

### Лесенка прогрева
Просто отрисовка `nl_warmup_ladder` строкой (пример: «4000, 6000, 8000, 10000, 12000»).

## Кнопки быстрого управления

**Когда ВЫКЛ:**
- `▶ Возобновить` — если есть массовые на паузе:
  - `UPDATE mail_queue SET status='queued' WHERE status='paused' AND priority>0`
  - `mass_sending_set(true)`
  - Если `nl_warmup_started` пусто — ставит сегодня
- `Открыть «Рассылки» → Запустить` — если очереди нет: ссылка на `/admin/?p=newsletter`

**Когда ВКЛ:**
- `⏸ Пауза` — заморозить массовые:
  - `UPDATE mail_queue SET status='paused' WHERE status='queued' AND priority>0`
  - `mass_sending_set(false, 'paused_by_owner_dashboard')`

**Всегда:**
- `Очередь отправок` → `/admin/?p=dispatch`
- `Настройки темпа` → `/admin/?p=settings` (nl_warmup, nl_warmup_max, split, окно)

## Техническая реализация

### POST-хендлер на `/admin/?p=dashboard`
- `do=mass_toggle&act=pause|resume`
- CSRF защищён (стандартный `csrf_check()` из admin/_boot.php)
- После действия — редирект обратно на дашборд с флэш-сообщением

### Используемые функции (все существующие)
- `mass_sending_enabled()` — читает `settings.mass_sending`
- `mass_sending_set(bool $on, string $reason='')` — переключает + пишет reason
- `nl_daily_cap()` — суточный потолок для сегодняшнего дня
- `nl_campaign_start()`, `nl_campaign_day()` — день кампании
- `nl_bulk_sent_today()` — счётчик отправленных сегодня

### Идемпотентность
Патч сделан с проверкой `if ('mass_sending_widget' in s)` — можно перезапускать деплой без дублирования.

### Бэкап оригинала
На проде: `admin/dashboard.php.bak-20260813-230255-widget`.
