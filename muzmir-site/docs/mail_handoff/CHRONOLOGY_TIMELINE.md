### ~08:20-09:33 МСК — первый час рассылки, ловим баги

**Баг 1**: Маршрутизация пулов. Институции идут через `unisender` (news@) вместо `unisender-cold` (novosti@) — репутация news@ загрязняется холодными контактами.
- Причина: `newsletter_process_queue()` загружал только `bulk`-пул.
- Патч 1: загрузка обоих пулов + `poolByBox` маппинг.
- Патч 2: раздельные SQL-выборки на bulk и cold (иначе `ORDER BY id ASC LIMIT 40` брал только старые inst-строки, konkurs вообще не шёл).
- **Осадок**: 80 писем institutions ушли с news@ до фикса. Не смертельно (~0.2% базы), но не лечится.

**Баг 2**: У писем учреждениям было только 1 вложение (обращение PDF), а должно быть 9 (обращение + 4 афиши + 4 положения).
- Причина 1: `invite_official_letter()` собирала `$mail['attach']` массив, но возвращала только `pdf`.
- Причина 2: `invite_open_comps()` не возвращала `id` в SELECT — путь к афише всегда `/comp/0/afisha.jpg`.
- Причина 3: копирование в `/tmp/inv_<hex>/` — системная чистка сносит.
- Патчи: return + INSERT id + перенос в `data/attach_cache/inv_`.
