# Индекс всех шаблонов (письма, PDF, HTML)

Полный список того что где рендерится, с точными путями.

## Шаблоны PDF (Playwright bastion)

Все PDF рендерятся через bastion `104.171.132.45` — там крутится headless Chromium через Playwright. Функция `partner_render_pdf($url, $outPath)` в `core/partner_docs.php` (общая), плюс `pdf_letter.php` для обращений и `diploma_render.php` для дипломов.

| Документ | HTML-шаблон | Рендерер (PHP) | Куда сохраняется |
|---|---|---|---|
| Партнёрский сертификат | `03_prod_files/templates/partner-cert.php` | `partner_cert_pdf()` в `core/partner_docs.php` | `data/partners/cert/ИП-2026-XXXXX.pdf` |
| Партнёрская благодарность | `03_prod_files/templates/partner-thanks.php` | `partner_thanks_pdf()` в `core/partner_docs.php` | `data/partners/thanks/БЛГ-ИП-2026-XXXXX-РX.pdf` |
| Обращение к учреждению | генерится программно в `core/pdf_letter.php` | `pdf_letter_generate()` | `data/letters/obrashchenie-DDMMYYYY-NNN.pdf` |
| Обращение к ведомству | тот же `pdf_letter.php` (kind='ministry') | тот же | `data/letters/obrashchenie-DDMMYYYY-NNN.pdf` |
| Диплом | `core/diploma_html.php` (программно) | `diploma_render.php` | `public/uploads/diplomas/...` |
| VIP-сертификат | `core/club_cert.php` (программно) | внутри club_cert | `public/uploads/club_cert/...` |

## Шаблоны писем (HTML в теле email)

### 1. Массовая рассылка своей базе (combo:2026-MM)

**Сборщик**: `core/launch_combo.php` → функция `launch_combo_enqueue()` + `core/newsletter.php::nl_build_body()`.

Тело собирается ПРИ ОТПРАВКЕ (в момент когда воркер шлёт письмо), а не при постановке. Это позволяет:
- Актуальный пароль (может измениться)
- Актуальный список открытых конкурсов
- Актуальные блоки (кабинет / VIP-клуб)

Компоненты:
- **Хедер** — `mm_email_layout()` в `core/mailer.php` (бренд, лого)
- **Приветствие** — «Здравствуйте, [Имя]!» через `person_greeting_name($email, $rawName)`
- **Карточки конкурсов** — `mmc_competition_card()` из `core/mail_campaigns.php`
- **Блок «Ваш личный кабинет»** — `kabinet_onboarding_html($email, $name, $pass)` из `core/kabinet_onboarding.php` (если у юзера ещё не было входов)
- **Блок «VIP-клуб»** — `mmc_vip_perks_grid()` (если не член клуба)
- **Футер** — `mm_email_footer()` (отписка + контакты)

Тема: `campaign_subject('launch')` — «Мы открылись! Конкурсы, награды и дипломы — Культурный центр «Музыкальный Мир»»

### 2. Приглашение учреждению (обращение о партнёрстве)

**Сборщик**: `core/letter_mail.php` → функция `lm_mail_institution($inst, $number, $comps, $unsubUrl)`.

Тема (после нашего патча — БЕЗ ФИО):
```
Приглашаем к участию в конкурсах — [Название учреждения] (исх. №14082026/641)
```

Тело (плоский текст → в HTML):

### 3. Приглашение к министерству

Функция: `lm_mail_ministry()` в `core/letter_mail.php`.

Отличия от учреждения:
- Тема: «Обращение об информационной поддержке всероссийского конкурса (исх. №...)»
- Обращение к «Уважаемый [ФИО министра]!» (в реестре Минкультуры ФИО актуальные, в отличие от 40к учреждений)
- Формулировки более официальные
- Просьба: поддержать информационно (разослать по подведомственным учреждениям)
- Вложения: только PDF обращения (без положений/афиш)
- Отправка: pool='official' (kc@ прямой SMTP)

## Функции сборки писем (глобальный layout)

Файл: `core/mailer.php`:
- `mm_email_layout($inner, $opts=[])` — общий контейнер (бренд, footer, лого)
- `mm_email_footer($opts=[])` — футер с отпиской
- `mm_email_head()` — head с CSS
- `h($s)` — escape для HTML

Файл: `core/mail_campaigns.php`:
- `mmc_h($text, $sub='')` — заголовок с подзаголовком
- `mmc_competition_card($comp)` — карточка конкурса (лого, название, дедлайн, кнопка «Подать заявку»)
- `mmc_awards_strip($cid=0)` — полоска примеров наград
- `mmc_vip_perks_grid()` — таблица VIP-привилегий
- `mmc_kabinet_block()` — блок «Ваш личный кабинет»
- `mmc_cta($label, $href, $variant='navy')` — кнопка призыва к действию

Файл: `core/letter_mail.php`:
- `lm_render($number, $data)` — универсальный рендер PDF-обращения
- `lm_docline($number, $addressee)` — строка с номером и адресатом
- `lm_p($html, $style='')` — параграф с стилем
- `lm_salut($fio)` — приветствие («Уважаемая Мария Петровна!» или «Уважаемые коллеги!»)
- `lm_addressee($role, $org, $fio)` — блок адресата
- `lm_head($title, $subtitle)` — заголовок обращения

## Что важно (правило Даниэля по текстам)

Из корневого CLAUDE.md — правило «живой текст»:
1. **Длинное тире не ставить НИКОГДА.** Только дефис.
2. **Никаких противопоставлений** «не X, а Y».
3. **Никаких иишных структур** («важно отметить», «таким образом», «комплексный подход»).
4. **Обращение по имени** («Здравствуйте, Мария»), НЕ третьим лицом.
5. Прочитать вслух — не должно звучать как реклама.

Проверка автоматом: `core/humanize.check()` (был на проде — если попадётся, применяй ко всем новым письмам).
