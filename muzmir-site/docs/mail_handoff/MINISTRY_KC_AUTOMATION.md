## Как сейчас работает (готово, не ломать)

### Крон `cron/ministry_replies.php` (`5 * * * *`, раз в час)

Читает `kc@` через IMAP (`imap.yandex.ru:993`, пароль `umycdzpnplwlbriz`).

Логика (краткая):
1. `im_search UNSEEN` в INBOX.
2. Для каждого письма — парсит, оставляет только те где `From` совпадает с адресом из базы ведомств (`institutions WHERE kind='ministry'`).

4. PDF → JPG первой страницы (для галереи /support).
5. Публикует в раздел «Поддержка» на сайте.
6. Помечает ведомство ответившим (`replied_at` в `official_letters`).
7. Шлёт уведомление владельцу в Telegram + готовит пост в ВК.

**Результат**: свежий скан от Минкультуры автоматически появляется в галерее /support сверху.

Файл на проде: `cron/ministry_replies.php` (23 КБ). Копия в `03_prod_files/cron/`.

    id INTEGER PRIMARY KEY AUTOINCREMENT,
    institution_id INTEGER,
    email TEXT,
    kind TEXT NOT NULL,   -- approved|declined|question|thanks_sent
    payload TEXT DEFAULT '',
    fired_at TEXT DEFAULT (datetime('now'))
