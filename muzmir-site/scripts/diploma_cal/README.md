# Бланк диплома: калибровка и проверка ритма

Инструменты, которыми в октябре 2026 подгонялись бланки «Мирового акцента»,
«Гордости поколения», «Территории таланта» и «Вершины творчества».
Запускаются на мосту (Playwright там стоит), HTML листов собирает прод.

- `ink_cal.cjs` + `ink_cal.py` — снимает поправку границ букв (`ink_cal`,
  `ink_cal_extra`, `ink_cal_named`, `ink_cal_thanks` в `diploma_template`):
  что сборщик считает по canvas против того, что реально печатается.
  `node ink_cal.cjs <лист.html> <префикс>` → `python3 ink_cal.py <префикс>`.
- `gaps.cjs` — печатает положение каждой строки листа и запас до подписей.
  Запас у предела (около 6 мм) значит, что ровный шаг сжат: поднять
  `pad_top`/опустить `pad_bottom` или ограничить `dtype_max`/`degree_k`.
- `apimodels_gen.py` — генерация картинок через APIMODELS
  (`gpt-image-2.5-flare`, 2K, high, $0.04), лого конкурса уходит референсом.

Настройки бланка конкурса (`competitions.diploma_template`):
`theme`, `pad_top`, `pad_bottom`, `dtype_max` (потолок слова ДИПЛОМ, pt),
`degree_k` (множитель звания), `thanks` (переопределения для благодарности),
`thanks_bg` (свой фон благодарности; владелец решил: один фон на конкурс,
поэтому не используется).
