# Машина с видеокартой: как поднять, чем гонять, как погасить

Проверено 1 сентября 2026. Всё, что ниже, делалось руками в этот день и
работает. Числа настоящие.

---

## 1. Что это

Аренда RunPod на аккаунте OKO. Модели лежат на **сетевом томе
`oko-stack`** (250 ГБ, зона EU-RO-1, id `gilfw5k8tb`) и переживают
любой под: поднимаешь машину, подключаешь том, всё уже на месте.

Ключи в `secrets.env` на сервере агентов: `RUNPOD_API_KEY`,
`RUNPOD_USER_ID`, `RUNPOD_S3_KEY`.

**Vast.ai это другая машина**, там свой под и он обычно занят. Путать их
не надо: у RunPod том с моделями, у Vast его нет.

## 2. Что стоит на томе

| Что | Модель | Файл |
|---|---|---|
| Видео | MiniMax H3 (Hailuo 3) | `diffusion_models/minimax_h3_*` |
| Фото | Krea-2 Raw | `diffusion_models/krea2_raw_fp8_scaled` |
| **3D из картинки** | **Hunyuan3D 2.1** | `checkpoints/hunyuan_3d_v2.1.safetensors` |

| Музыка, эффекты | ACE-Step, Stable Audio Open | `checkpoints/` |
| Код | Qwen3-Coder 30B через Ollama | `/workspace/ollama` |

Плюс ComfyUI в `/workspace/ComfyUI` и сборщик `/workspace/oko-stack.sh`.

## 3. Как поднять

```bash
# на сервере агентов, ключи уже в окружении
curl -s -X POST https://rest.runpod.io/v1/pods \
  -H "Authorization: Bearer $RUNPOD_API_KEY" -H "Content-Type: application/json" \
  -d '{"name":"oko-3d",
       "imageName":"pytorch/pytorch:2.8.0-cuda12.8-cudnn9-devel",
       "gpuTypeIds":["NVIDIA GeForce RTX 4090"],
       "gpuCount":1,
       "networkVolumeId":"gilfw5k8tb",
       "containerDiskInGb":30,
       "ports":["22/tcp","8888/http"],
       "env":{"PUBLIC_KEY":"<содержимое ~/.runpod/ssh/runpodctl-ssh-key.pub>"},
       "dockerStartCmd":["bash","-lc","mkdir -p ~/.ssh && echo \"$PUBLIC_KEY\" >> ~/.ssh/authorized_keys && chmod 700 ~/.ssh && chmod 600 ~/.ssh/authorized_keys && (apt-get update -qq && apt-get install -y -qq openssh-server >/dev/null 2>&1); mkdir -p /run/sshd && /usr/sbin/sshd -D -p 22"]}'
```

Грабли, все пойманы на живом запуске:

- **Том живёт в EU-RO-1, и не всякая карта там есть.** A40, L40S и
  RTX 6000 Ada отвечают «could not find any pods with required
  specifications». RTX 4090 и RTX PRO 4500 есть. Цена в этой зоне 0,74
  доллара в час, а не 0,34 из общего прайса.
- **Имя образа проверяется до наличия карты.** Ошибка про образ значит,
  что карта-то нашлась.
- **Один запрос это один под.** Перебор из трёх образов в цикле поднял
  ТРИ машины разом. Снимать лишние немедленно, деньги идут за каждую.
- **SSH.** `runpodctl ssh add-key` заводит ключ на аккаунте, но под
  читает `PUBLIC_KEY` из окружения при старте, поэтому ключ надо
  передать в `env` при создании. Ключ лежит в
  `~/.runpod/ssh/runpodctl-ssh-key`.
- **Порт 22 появляется не сразу**: `runpodctl ssh info <id>` пару минут
  отвечает «port 22 is declared but the host has not published a
  mapping».

## 4. Как запустить ComfyUI

Питон с торчем в этом образе **`/opt/conda/bin/python`**, а не
`python3`: системный питон торча не видит вовсе, и `oko-stack.sh` на нём
падает с `ModuleNotFoundError: torch`.

```bash
cd /workspace/ComfyUI
/opt/conda/bin/pip install -q -r requirements.txt huggingface_hub   # 10 минут
/opt/conda/bin/python main.py --listen 127.0.0.1 --port 8188 --disable-auto-launch
```

Чтобы не ставить пакеты каждый раз, на томе собран
**`/workspace/venv311`** (venv поверх conda с `--system-site-packages`).
Следующий подъём: `/workspace/venv311/bin/python main.py …` и никакого
ожидания.

ComfyUI слушает ТОЛЬКО localhost. Наружу его не открываем: публичный
адрес такого сервиса это открытая дверь. Задания кладём изнутри пода.

## 5. Как гнать 3D из фотографии

`/workspace/гнать.py задание.json` кладёт задание и ждёт результат.
Задание для Hunyuan3D 2.1 (проверено, 58 секунд на модель):

```
ImageOnlyCheckpointLoader (hunyuan_3d_v2.1.safetensors)
  → CLIPVisionEncode (картинка)
  → Hunyuan3Dv2Conditioning
  → EmptyLatentHunyuan3Dv2 (3072)
  → KSampler (40 шагов, cfg 5.5, euler)
  → VAEDecodeHunyuan3D (num_chunks 8000, octree 384-512)
  → VoxelToMeshBasic (порог 0.6)
  → SaveGLB
```

Что получается: честная сетка на 280-620 тысяч треугольников без
текстуры, с воксельной лесенкой по поверхности.

**Текстуры этим путём НЕ выйдет.** `BakeTextureFromVoxel` просит
`voxel_colors`, а модель формы их не даёт: нужна отдельная модель
покраски (hunyuan3d-paint), её на томе нет. Пока меш кладём на сайт со
СВОИМ материалом.

## 6. Как довести меш до сайта

`blender -b -noaudio -P чистка.py -- вход.glb выход.glb 45000` на
сервере агентов:

1. сглаживание по объёму (фактор 0,32 в два прохода) снимает воксельную
   лесенку, не съедая силуэт. Сильнее нельзя: при 0,6 в четыре прохода
   боковые модули корабля слились с корпусом;
2. срез до бюджета треугольников;
3. нормали наружу: у меша из вокселей часть граней вывернута, и на
   сайте это чёрные пятна;
4. начало координат в середину, габарит в единицу.

Замер: корабль 286 892 → 45 000 треугольников, 3,6 МБ. Станция
621 128 → 45 000, 3,8 МБ.

## 7. Как погасить

```bash
curl -s -X DELETE -H "Authorization: Bearer $RUNPOD_API_KEY" \
  https://rest.runpod.io/v1/pods/<id>
```

Гасить **обязательно**: под тикает 0,74 доллара в час независимо от
того, считает он что-нибудь или стоит. Том остаётся и стоит копейки
(0,024 доллара в час на весь аккаунт).

Счёт за этот заход: с 16,45 до 13,81 доллара, то есть 2,64 за час
работы вместе с тремя лишними подами, поднятыми по ошибке.

## 8. Что делать дальше

- MiniMax H3 для оживления: из готового кадра делает ролик со звуком.
- Krea-2 как запасной путь для фото, когда GPT занят.
