## 0. СТЕК

| Слой | Технология |
|---|---|
| Ядро клиента | React Native + Expo (iOS / Android / Web из одного кода) |
| TG Mini App | Веб-сборка того же ядра + @telegram-apps/sdk, платформенный адаптер |
| Backend API | Node.js (NestJS или Fastify) на VPS Timeweb Cloud |
| БД + Realtime | Supabase (Postgres, Realtime channels, Auth) |
| Медиа | S3 (Timeweb S3 / R2) + CDN, presigned upload, multipart |
| Звонки | LiveKit Cloud SDK |
| Автоматизации | n8n (self-hosted на том же VPS) |
| ИИ | Claude API (системы, тексты, агенты), Gemini API (анализ видео, обложки), Fliki API (рендер роликов), Whisper + ffmpeg (субтитры, сборка видео) |
| Платежи | Lava.top + крипта + рублёвый эквайринг (вебхуки -> активация подписки) |
| Уведомления | Telegram-бот (для Mini App) + push (Expo Notifications) для нативных |

Монорепо: `/apps/mobile` (Expo), `/apps/web` (та же кодовая база, web-таргет), `/apps/tg-adapter`, `/server`, `/agents` (промпты + конфиги), `/infra` (docker-compose, деплой).

## 1. МОДУЛИ И ЭКРАНЫ

### 1.1 Авторизация
- Вход: Telegram (в Mini App — автоматом из initData), телефон/e-mail для остальных витрин.
- Один аккаунт на всех устройствах, всё состояние на сервере.
- Реф-код в ссылке регистрации -> привязка к партнёру (2 уровня).

### 1.2 Мессенджер (ядро)
- Личные чаты, группы, каналы. Supabase Realtime.
- Сообщения: текст, фото, видео, голосовые, кружочки, файлы, реакции, ответы, пересылка.
- Медиа через presigned URL напрямую в S3; лимиты размера по тарифу (Free 100 МБ, Start/Pro 2 ГБ, Business/Scale без лимита).
- Голосовые/кружочки: запись на клиенте, сжатие перед загрузкой.
- Статусы: доставлено/прочитано, онлайн, печатает.
- Поиск по чатам и сообщениям.

### 1.3 Звонки
- LiveKit: 1-на-1 и групповые созвоны (до 50 участников на старте).
- В TG Mini App кнопка звонка открывает внешний браузер/приложение.
- Запись созвона (платные тарифы) -> S3.

### 1.4 Лента
- Посты каналов и сообществ: текст, медиа, карусели.
- Старт: хронологическая лента подписок + вкладка «Рекомендации» (простой скоринг: свежесть + вовлечённость). Алгоритмы-ML — после запуска, по данным.
- Лайки, комментарии, репост в чат, сохранённое.

### 1.5 Каркас мини-аппов
- Реестр мини-аппов, каждый = экран (iframe/нативный модуль) + мост к API (`window.OKO.call(...)`).
- Доступность по тарифам, счётчики лимитов (проверок видео и т.д.).

### 1.6 Мини-аппы запуска
**A. Система роста по анкете**
- Анкета (структура из ANKETA, 8 секций) -> очередь -> Claude API с мастер-промптом (MASTER-TZ) -> HTML-система в стиле OKO -> в S3 -> в личный кабинет клиента.
- Превью в командный чат Даниэля -> [ОК / Правка] -> выдача клиенту.

**B. Видео-премодератор**
- Загрузка ролика (multipart, до 10 ГБ) -> Gemini-анализ: оценка готовности %, вероятность рекомендаций, сила хука, риски (политика/коммерция/авторские), технические параметры, рекомендации.
- Кнопка «Исправить одним кликом»: перегенерация обложки, правка описания/субтитров -> ffmpeg-пересборка.
- Кнопка «Опубликовать»: постинг во все подключённые сети.
- Исходники: lifecycle 24 часа, автоудаление.
- Лимиты по тарифам: Free 1/мес, Start 10, Pro 30, Business+ без лимита.

**C. Партнёрский кабинет**
- Реф-ссылка (приложение + сайт), QR.
- Статистика в реальном времени: клики -> регистрации -> оплаты -> начисления (15% L1 / 5% L2, ступень 15%->5% после 6 мес подписки клиента).
- История выплат, заявка на выплату, реквизиты.
- Материалы для продвижения (креативы, тексты, обучение).

### 1.7 Подписки и оплата
- Витрина тарифов: крупно цена «/мес при оплате за год», плашки скидок (3м −10%, 6м −15%, год −20%), рублёвое зеркало.
- Оплата: Lava.top / крипта / эквайринг -> вебхук -> активация. В TG Mini App дополнительно Stars.
- Тарифные флаги во всех модулях (лимиты, доступы) — единый middleware.

### 1.8 ИИ-штат
- Агент «Поддержка»: подключён к чатам, RAG по базе знаний (тарифы, инструкции, FAQ), кнопка «позвать человека», эскалации в @okohelp.
- Агент «Ассистент»: командный чат Даниэля — утренний отчёт (регистрации, оплаты, MRR, проблемные диалоги), команды натуральным языком -> задачи через n8n.
- Правила: деньги/возвраты/обещания только эскалация; логи всех диалогов.

### 1.9 Конвейер контент-завода (Business/Scale)
- n8n-пайплайн: контент-план -> сценарии (Claude) -> Fliki (рендер) -> Whisper (субтитры) + ffmpeg (прожиг + обложка Gemini) -> очередь постинга -> публикация по расписанию (IG/YT/TT/VK/TG API) -> сбор метрик -> отчёт + корректировка контент-плана.
- Панель клиента: календарь публикаций, статусы, метрики.
- Кнопка подтверждения Даниэля перед выдачей (отключаемая поклиентно).

### 1.10 Админка
- Пользователи, подписки, платежи, партнёрские начисления и выплаты, лимиты, фича-флаги, логи агентов, метрики (DAU, MRR, конверсии, отвал).

## 3. БЕЗОПАСНОСТЬ И ЛИМИТЫ
- Все медиа — presigned, никаких файлов через API-сервер.
- Rate limiting на API и на нейро-эндпоинты (защита от выжигания токенов).
- Токены соцсетей клиентов — шифрование в БД.
- Роли: user / partner / staff / admin.
- Антиспам в чатах: лимиты сообщений для Free, репорты, мут/бан.
